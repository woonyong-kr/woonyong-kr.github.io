# Data
{: .no_toc }

서비스에 들어온 데이터는 저장한 뒤 다시 조회하거나, 여러 단계를 거쳐 분석과 모델 추론에 사용한다. 이 과정에서 값의 의미와 형식이 달라지거나 일부가 누락되면 결과를 믿기 어려워진다.

데이터베이스에서는 저장과 조회의 원리를, 데이터 엔지니어링에서는 수집부터 제공까지의 흐름을 다룬다. 데이터 분석은 이렇게 준비한 자료에서 질문에 답을 찾는 과정으로 이어진다. MiniDB는 데이터베이스 구현을 익히는 학습 주제다.
