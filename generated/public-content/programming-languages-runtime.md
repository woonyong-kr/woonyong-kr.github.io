# 프로그래밍
{: .no_toc }

처음에는 작은 프로그램을 직접 실행하며 값이 어디에 저장되고 어떤 순서로 바뀌는지 따라간다. 함수와 타입, 객체를 익힌 뒤에는 언어마다 같은 문제를 어떻게 표현하는지 비교할 수 있다.

Kotlin과 Java를 중심으로 여러 언어의 문법과 특징을 정리한다. 작성한 코드가 실행되기까지의 과정은 언어 구현, 런타임, 빌드와 의존성 관리로 이어진다.
