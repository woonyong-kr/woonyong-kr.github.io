# AI
{: .no_toc }

모델이 답을 생성하는 것과 사용자가 믿고 사용할 수 있는 서비스를 만드는 것은 서로 다른 문제를 포함한다. 어떤 데이터를 전달할지, 외부 도구를 언제 호출할지, 답변의 근거와 품질을 어떻게 확인할지 결정해야 한다.

머신러닝과 LLM의 원리를 바탕으로 AI 애플리케이션, 도구 호출, 에이전트와 RAG를 다룬다. 평가와 안전성, 추론과 운영을 연결해 모델을 서비스에 적용하는 과정을 정리한다.
