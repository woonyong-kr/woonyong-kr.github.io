# 알고리즘·수학
{: .no_toc }

프로그램을 작성하다 보면 같은 결과를 내는 코드라도 데이터가 많아질수록 실행 시간이 크게 달라진다. 자료를 어떻게 저장하고 처리하는지 살펴보면 이런 차이를 설명할 수 있다.

자료구조와 알고리즘에서 출발해 복잡도로 비용을 비교하고, 수학을 통해 논리와 계산의 근거를 다룬다.
