# 플랫폼
{: .no_toc }

로컬에서 실행한 프로그램을 서비스로 운영하려면 빌드와 배포, 실행 환경, 상태 확인이 이어져야 한다. 이 과정이 사람의 기억에만 의존하면 환경이 바뀔 때 같은 결과를 재현하기 어렵다.

개발 환경과 Git에서 시작해 CI/CD, 컨테이너와 클라우드로 범위를 넓힌다. 모니터링과 장애 대응은 실제 동작을 확인하는 방법으로, 개발 도구는 반복되는 작업을 줄이는 방법으로 다룬다.
