# DevOps
{: .no_toc }

로컬에서 실행한 프로그램을 서비스로 운영하려면 빌드와 배포, 실행 환경, 상태 확인이 이어져야 한다. 이 과정이 사람의 기억에만 의존하면 환경이 바뀔 때 같은 결과를 재현하기 어렵다.

개발 환경과 Git에서 시작해 CI/CD, 컨테이너와 클라우드로 범위를 넓힌다. [Observability](/wiki/observability/)에서는 로그·지표·추적을 연결해 상태와 원인을 살펴보고, 모니터링과 알림은 정해 둔 상태를 확인하는 활동으로 다룬다. 장애 대응과 개발 도구는 이 관찰을 복구와 반복 작업의 개선으로 연결한다.

[시크릿 관리](/wiki/secrets-management/), [공급망 보안](/wiki/supply-chain-security/), [클라우드 보안](/wiki/cloud-security/)은 코드가 실행 환경에 도달하고 운영되는 과정의 보호 기준으로 연결한다.
