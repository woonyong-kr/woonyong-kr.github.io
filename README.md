# woonyong-kr.github.io

최우녕의 기술 블로그와 공개 지식 지도 배포 저장소입니다.

**사이트: <https://woonyong-kr.github.io>**

여기 있는 파일은 전부 빌드 산출물입니다. 원본(콘텐츠 Markdown · React 소스)은
비공개 저장소 `woonyong-kr/woon-site`에 있고, 그쪽에서 `npm run build && npm run deploy`
로 이 저장소가 갱신됩니다. **이 저장소의 파일을 직접 수정하지 않습니다** — 다음
배포에서 덮어써집니다.
