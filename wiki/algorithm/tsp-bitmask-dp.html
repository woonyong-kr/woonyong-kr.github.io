외판원 순회와 비트마스크 DP — 현재 도시와 방문 집합만 남기는 법

외판원 순회와 비트마스크 DP — 현재 도시와 방문 집합만 남기는 법

한 줄 요약: 외판원 순회에서는 지금까지의 방문 순서 전체를 기억할 필요가 없다. 현재 도시와 방문 집합만 남기면 같은 하위 문제를 하나의 DP 상태로 묶을 수 있다.

외판원 순회와 비트마스크 DP가 비용을 줄이는 자리

외판원 순회 문제에서는 모든 도시를 한 번씩 방문한 뒤 시작점으로 돌아오는 경로 가운데 비용이 가장 작은 경로를 찾아야 한다. 먼저 각 방문 순서를 모두 시도하는 순열 완전탐색을 떠올릴 수 있지만, 도시 수가 조금만 늘어도 경우의 수가 빠르게 증가한다.

이를 DP로 바꾸려면 서로 다른 탐색 경로가 언제부터 같은 하위 문제로 합쳐지는지 찾아야 한다. 이 문서에서는 다음 세 가지를 판단 기준으로 삼는다.

  • 외판원 순회를 순열 탐색 대신 상태 압축 DP로 바꾸는 이유
  • 현재 도시 + 방문 집합이 앞으로의 최소 비용을 구하기에 충분한 상태인 이유
  • 비트마스크가 방문한 도시의 집합을 표현하는 데 적합한 이유

외판원 순회와 비트마스크 DP 차이

외판원 순회(TSP)는 모든 도시를 정확히 한 번씩 방문하고 출발점으로 돌아오는 최소 비용 경로를 찾는 문제다. 비트마스크 DP는 이 문제 자체가 아니라, 반복되는 하위 문제를 묶어 계산량을 줄이는 풀이 방법이다.

남은 최소 비용을 결정하려면 다음 두 정보만 알면 된다.

  • 현재 도시 cur
  • 이미 방문한 도시 집합 visited

두 정보가 같다면 앞으로 방문할 수 있는 도시와 시작점으로 돌아가는 조건도 같다. 따라서 여기까지 어떤 순서로 왔는지는 미래의 최소 비용을 계산할 때 필요하지 않다. 서로 다른 방문 순서로 같은 현재 도시와 방문 집합에 도달했더라도, 이후의 계산은 하나의 DP 상태로 공유할 수 있다.

비트마스크는 이때 방문 집합을 정수 하나로 압축하는 표현 방식이다. 각 비트가 도시 하나의 방문 여부를 나타내므로, 특정 도시의 방문 여부를 검사하거나 새 도시를 집합에 추가하는 연산을 간결하게 처리할 수 있다.

다만 상태를 압축해도 일반적인 TSP가 쉬운 문제로 바뀌는 것은 아니다. 이 예시는 N <= 16 같은 제한이 있기 때문에 O(N^2 * 2^N) DP를 적용할 수 있는 교육용 대표 사례다.

실제 흐름

풀이 흐름은 상태를 정의한 뒤, 방문하지 않은 다음 도시로 이동하며 상태를 확장하고, 모든 도시를 방문했을 때 시작점으로 돌아가는 비용을 더하는 순서로 이해하면 된다.

외판원 순회와 비트마스크 DP 코드와 값

다음 자료에서는 앞서 정의한 상태가 실제 구현과 값의 변화로 어떻게 이어지는지 확인한다.

이 예시의 비트 연산은 다음 역할을 한다.

  • visited & (1 << nxt)는 nxt 도시를 이미 방문했는지 검사한다.
  • visited | (1 << nxt)는 nxt 도시를 방문 집합에 추가한다.
  • cost[cur][nxt] == 0은 이동할 길이 없다는 뜻으로 해석해 후보에서 제외한다.

이 예시가 보여 주는 상태 설계의 핵심은 과거의 세부적인 방문 순서를 버리고, 미래의 선택과 비용을 결정하는 최소 정보만 남기는 것이다. 이 문제에서 그 정보는 현재 도시와 방문 집합이다.

상태를 공유하면 순열 완전탐색 O(N!)보다 계산량을 크게 줄일 수 있다. 그러나 도시 수에 따라 상태 수가 빠르게 늘어나는 점은 그대로이므로 큰 N에는 여전히 부담스럽다. 이 때문에 이 방식은 N <= 16 정도의 제한에서 특히 자주 사용된다.
