File Page Offset, Read, Zero

File Page Offset, Read, Zero

확인 범위: 이 문서는 ELF 세그먼트에서 파일로 읽을 영역과 0으로 채울 영역을 나누는 일반 원리와 페이지별 계산 기준을 설명하고, Linux 및 PintOS 코드는 그 원리가 구현되는 방식을 보여주는 예시로 다룬다. 제시된 코드 좌표·상수·실행 흐름의 특정 버전 일치 여부와 실제 동작·성능은 별도의 소스 대조, 빌드 및 실행 기록이나 측정 없이 검증된 결과로 간주하지 않는다.

한 줄 요약: ELF 세그먼트를 적재할 때 한 페이지 안에서 파일에서 읽을 read_bytes와 0으로 채울 zero_bytes가 갈리며, 이 경계는 세그먼트의 p_filesz(디스크 기록량)와 p_memsz(확보할 메모리)의 차이에서 나온다.

File Page Offset, Read 상태

ELF 세그먼트를 메모리에 적재할 때, 한 페이지(4KB) 안에서 **파일에서 읽어야 할 부분(read_bytes)과 0으로 채워야 할 부분(zero_bytes)**이 공존한다. 이 분할은 ELF 세그먼트의 파일 크기(p_filesz)와 메모리 크기(p_memsz)의 차이에서 발생하며, BSS(.bss) 영역의 초기화되지 않은 전역 변수를 0으로 보장하는 핵심 메커니즘이다.

상세 설명

추상 개념 (ELF의 file vs memory 크기 차이)

ELF 프로그램 헤더의 PT_LOAD 세그먼트에는 두 크기가 있다:

필드의미예시
p_filesz디스크 파일에 실제로 기록된 바이트 수0x1A30
p_memsz메모리에 확보해야 할 바이트 수0x2000

p_memsz > p_filesz인 경우, 차이만큼의 바이트는 0으로 채운다. 이것이 BSS 세그먼트다.

실제 OS (Linux)

Linux의 load_elf_binary() → elf_map() + padzero()가 같은 일을 한다:

  • 파일 매핑: mmap()으로 ELF 파일을 직접 매핑
  • BSS 경계 페이지: padzero(elf_bss)로 마지막 파일 페이지의 나머지를 0으로 채움
  • 순수 BSS 페이지: MAP_ANONYMOUS로 할당 (커널이 자동으로 0 초기화)

File Page Offset, Read 값 추적

예시: .data + .bss 세그먼트

페이지 분할:

페이지 VApage_read_bytespage_zero_bytes파일 오프셋성격
0x004040002608 (0x0A30)14880x3000파일/BSS 경계 페이지
0x0040500004096-전체 BSS

정밀 계산:

  • page_offset = 0x00404000 & 0xFFF = 0 (정렬됨)
  • read_bytes = 0 + 0x0A30 = 2608
  • total_pages = ROUND_UP(0 + 0x1800, 4096) / 4096 = 2
  • zero_bytes = 8192 - 2608 = 5584

페이지 0: page_read = min(2608, 4096) = 2608, page_zero = 4096 - 2608 = 1488 → 경계 페이지! 2608B 읽고 1488B 0으로

페이지 1: read_bytes 남음 = 0, zero_bytes 남음 = 4096 → 전체 제로 페이지

왜 0으로 채우는가?

C 언어 표준은 초기화되지 않은 전역/정적 변수가 0임을 보장한다:

0으로 채우지 않으면 이전 프로세스의 메모리 내용이 보일 수 있어 보안 취약점이 된다.

순서도

flowchart TD
    A["ELF PT_LOAD 세그먼트"] --> B{"p_filesz > 0?"}
    B -->|Yes| C["read_bytes = offset + p_filesz"]
    B -->|No| D["read_bytes = 0"]
    C --> E["zero_bytes = ROUND_UP(memsz) - read_bytes"]
    D --> F["zero_bytes = ROUND_UP(memsz)"]
    E --> G["load_segment loop"]
    F --> G

    G --> H{"read_bytes > 0?"}
    H -->|Yes| I["page_read = min(read_bytes, 4096)"]
    H -->|No| J["page_read = 0, page_zero = 4096"]
    I --> K["page_zero = 4096 - page_read"]
    K --> L["file_read_at + memset(0)"]
    J --> L
    L --> M["install_page"]
    M --> N{"more pages?"}
    N -->|Yes| H
    N -->|No| O["완료"]
