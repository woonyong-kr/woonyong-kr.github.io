RoBERTa 개선점

RoBERTa 개선점

한 줄 요약: RoBERTa는 BERT의 encoder-only 구조와 Masked LM을 거의 그대로 두고 NSP 제거·더 큰 데이터와 batch·동적 마스킹으로 학습 레시피를 강화한 모델이며, 성능이 구조가 아니라 학습 방식에서 크게 온다는 것을 보여준다.

RoBERTa는 BERT 구조를 거의 그대로 두고, 사전학습 방법을 더 강하게 만든 BERT 계열 모델이다.

RoBERTa 개선점 문제

BERT는 양방향 문맥을 읽는 encoder-only Transformer가 문장 이해 과업에 강하다는 것을 보여줬다. 그런데 BERT의 성능이 구조 때문인지, 학습 설정 때문인지는 따로 확인할 필요가 있었다.

RoBERTa의 질문은 단순하다.

BERT 구조를 유지한 채 데이터와 학습 방식을 더 잘 고치면 성능이 얼마나 올라가는가?

이 질문 덕분에 “새 구조를 만들기 전에 학습 레시피를 충분히 밀어붙였는가”라는 판단 기준이 생긴다.

BERT와 RoBERTa의 최소 비교

차이를 학습 목표, 데이터, 마스킹 방식으로 나누면 다음과 같다.

동적 마스킹은 같은 문장을 여러 번 볼 때 매번 다른 위치를 가리는 방식이다.

같은 문장이라도 매번 다른 복원 문제를 풀게 되므로, 모델이 특정 마스크 위치만 외우는 쪽으로 덜 기운다.

RoBERTa 개선점 선택 기준

  • RoBERTa가 바꾼 것
    • NSP 제거
    • 더 큰 batch와 더 긴 학습
    • 더 많은 데이터
    • 동적 마스킹
  • RoBERTa가 크게 바꾸지 않은 것
    • encoder-only Transformer 구조
    • Masked LM 중심 학습
    • 문장 이해 과업에 강한 활용 방향
  • 이 문서를 볼 때의 핵심
    • 모델 성능은 구조만으로 결정되지 않는다.
    • 데이터, batch, 학습 시간, 목적함수 구성도 같은 크기로 중요하다.
    • BERT 계열 개선은 “아키텍처 혁신”보다 “학습 레시피 최적화”에서 나온 부분이 크다.

정리

  1. RoBERTa는 BERT의 encoder-only 구조와 Masked LM을 거의 그대로 두고 학습 레시피를 강화한 모델이다.
  2. NSP 제거, 더 큰 데이터·batch·긴 학습, 동적 마스킹으로 성능을 끌어올렸다.
  3. 그래서 BERT 계열 개선의 핵심 교훈은 “새 아키텍처”보다 “학습 레시피 최적화”에 있다.

직접 확인하려면: 같은 문장을 여러 epoch 학습할 때 마스크 위치가 매번 달라지는지(동적 마스킹) 확인하고, NSP 유무로 문장 쌍 과업 성능을 비교한다.

RoBERTa 개선점 관련 문서

  • RoBERTa가 출발한 기본 구조
  • RoBERTa가 제거한 보조 목적함수
  • Masked LM이 모델 성격을 나누는 기준
