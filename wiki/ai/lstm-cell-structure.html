LSTM 셀 구조

LSTM 셀 구조

한 줄 요약: LSTM cell은 forget gate, input gate, output gate 세 개와 별도의 cell state c_t를 두어, 정보를 선택적으로 버리고·쓰고·읽는 구조다.

LSTM 셀 구조 필요성

GRU 게이팅에서 gate의 역할을 개념으로 봤다. 이 문서는 LSTM cell 내부의 수식과 shape를 하나씩 펼친다.

Vanilla RNN의 은닉 상태 h_t는 매 시점 tanh로 완전히 다시 계산된다. 오래전 정보가 곱셈 체인을 거치며 희석되고, 역전파에서 기울기 소실이 발생한다.

LSTM은 이 문제를 덧셈 경로로 해결한다. cell state c_t가 시점 사이를 곱셈이 아니라 forget + add 형태로 흐르기 때문에, gradient가 먼 과거까지 비교적 안정적으로 전달된다.

LSTM 셀 구조 흐름

전체 구조 한눈에 보기

LSTM cell 하나의 입력과 출력은 다음과 같다.

Vanilla RNN은 (x_t, h_{t-1}) → h_t만 전달한다. LSTM은 여기에 c_t(cell state)를 추가해 장기 기억 전용 통로를 만든다.

%% LSTM cell에서 gate가 c_t와 h_t를 만드는 흐름
flowchart TD
  x_t["x_t<br/>현재 입력"]
  h_prev["h_{t-1}<br/>이전 은닉 상태"]
  c_prev["c_{t-1}<br/>이전 셀 상태"]
  concat["[x_t, h_{t-1}]<br/>gate 공통 입력"]
  forget["forget gate<br/>f_t = sigmoid(W_f · [x_t, h_{t-1}] + b_f)"]
  input["input gate<br/>i_t = sigmoid(W_i · [x_t, h_{t-1}] + b_i)"]
  candidate["candidate<br/>g_t = tanh(W_g · [x_t, h_{t-1}] + b_g)"]
  output["output gate<br/>o_t = sigmoid(W_o · [x_t, h_{t-1}] + b_o)"]
  keep["이전 기억 유지/삭제<br/>f_t * c_{t-1}"]
  write["새 기억 쓰기<br/>i_t * g_t"]
  cell_update["cell state 갱신<br/>c_t = f_t * c_{t-1} + i_t * g_t"]
  cell_out["c_t<br/>새 셀 상태"]
  hidden_filter["밖으로 읽기<br/>o_t * tanh(c_t)"]
  hidden_out["h_t<br/>새 은닉 상태"]
  forget --> input
  input --> candidate
  candidate --> output
  x_t --> concat
  h_prev --> concat
  concat --> forget
  concat --> input
  concat --> candidate
  concat --> output
  c_prev --> keep
  forget --> keep
  input --> write
  candidate --> write
  keep --> cell_update
  write --> cell_update
  cell_update --> cell_out
  cell_out --> hidden_filter
  output --> hidden_filter
  hidden_filter --> hidden_out

네 가지 계산: gate 수식

모든 gate는 같은 입력 [x_t, h_{t-1}]을 받는다. 다른 점은 가중치와 활성화 함수뿐이다.

1. Forget gate — 이전 기억을 얼마나 버릴지

f_t의 각 원소가 0에 가까우면 해당 위치의 이전 기억 c_{t-1}을 지운다. 1에 가까우면 그대로 유지한다.

2. Input gate — 새 정보를 얼마나 쓸지

3. Candidate — 새로 쓸 기억 후보

g_t는 -1에서 1 사이의 값이다. 실제로 cell state에 더해질 양은 i_t * g_t로 결정된다. input gate가 0이면 아무리 좋은 후보라도 쓰이지 않는다.

4. Output gate — cell state 중 무엇을 밖으로 내보낼지

Cell state 갱신과 은닉 상태 계산

cell state 갱신은 LSTM의 핵심이다.

이 식이 덧셈 경로다. Vanilla RNN은 h_t = tanh(W · ...)로 전체를 다시 계산하지만, LSTM은 이전 c_{t-1}에서 일부를 지우고(f_t *) 새 값을 더한다(+ i_t * g_t). gradient가 c_{t-1}에서 c_t로 갈 때 f_t만 곱해지므로, f_t가 1에 가까우면 gradient가 거의 그대로 흐른다.

은닉 상태 h_t는 cell state의 필터링된 버전이다.

c_t를 tanh로 정규화한 뒤, output gate로 필요한 부분만 내보낸다. h_t가 다음 시점의 입력이 되고, 필요하면 예측에도 쓰인다.

왜 gate마다 별도의 가중치인가?

네 계산 f_t, i_t, g_t, o_t는 모두 같은 [x_t, h_{t-1}]를 입력으로 받지만, 각각 W_f, W_i, W_g, W_o라는 서로 다른 가중치를 쓴다. 같은 입력을 보고도 “버릴 것”, “쓸 것”, “후보”, “내보낼 것”이라는 네 가지 판단을 독립적으로 내리기 위해서다.

아래 코드는 LSTM cell 한 step을 numpy로 직접 구현한 것이다. 밑바닥 딥러닝1(numpy)·밑바닥 LLM(PyTorch) 어느 책도 LSTM cell을 직접 구현하지 않으므로, 게이트 수식을 numpy 계층 스타일로 옮겼다.

이 코드가 하는 일은 딱 하나다. 이전 기억 (h_prev, c_prev)과 현재 입력 x_t를 받아 새 기억 (h_t, c_t)를 만든다.

PyTorch — 같은 cell을 nn.LSTM으로

실전 PyTorch는 위 네 게이트 계산을 nn.LSTM이 내부에서 한다. 직접 구현 대신 모듈 하나로 끝난다.

nn.LSTM의 학습 가능한 가중치는 weight_ih(입력→게이트)와 weight_hh(은닉→게이트)로, 네 게이트의 W를 한 행렬에 쌓아 둔다. c0/h0를 생략하면 0으로 자동 초기화된다. numpy 구현의 W_f, W_i, W_g, W_o가 PyTorch에서는 weight_ih/weight_hh 안에 합쳐져 있는 것뿐, 계산 내용은 같다.

shape 변환 예시

구체적인 숫자로 shape를 따라간다. input_dim = 4, hidden_dim = 3이라 하자.

가중치 행렬 4개가 모두 (hidden_dim, input_dim + hidden_dim) shape다. LSTM의 파라미터 수는 Vanilla RNN의 약 4배가 된다. 이것이 LSTM이 더 무거운 대신 더 잘 기억하는 이유다.

구체적 대입 예시

첫 번째 차원은 forget gate가 0.9이므로 이전 값 1.0이 거의 그대로 살아남는다. 두 번째 차원은 forget gate가 0.1이므로 이전 값이 사실상 지워지고 input gate가 0.8으로 새 값을 강하게 밀어넣는다.

정리

LSTM cell은 네 가지 계산(forget, input, candidate, output)을 통해 cell state c_t를 선택적으로 갱신한다. 핵심은 c_t = f_t * c_{t-1} + i_t * g_t라는 덧셈 경로다. 이 경로가 gradient를 먼 과거까지 비교적 안정적으로 전달한다.

파라미터는 Vanilla RNN의 4배지만, 그만큼 “무엇을 버리고 무엇을 쓸지”를 학습할 수 있다. 더 단순한 대안이 필요하면 gate를 2개로 줄인 GRU 셀 구조를 본다.
