트랜스포머 블록

트랜스포머 블록

범위: 이 문서는 트랜스포머 블록의 구성과 흐름, Pre-Norm·Post-Norm 및 잔차 연결의 일반 원리와 선택 기준을 교육용 numpy·PyTorch 예시로 설명한다. 제시된 코드는 특정 라이브러리 버전, 전체 의존 코드, 실행 기록이나 성능 측정으로 검증된 구현이 아니므로 실제 동작과 학습 안정성은 해당 환경에서 별도로 검증해야 한다.

한 줄 요약: 트랜스포머 블록은 Multi-Head Attention + Feed-Forward Network를 LayerNorm과 잔차 연결로 감싼 구조이며, 이 블록을 N번 반복 적층해 GPT 같은 깊은 모델을 구성한다.

트랜스포머 블록 문제

신경망을 깊게 쌓으면 더 복잡한 패턴을 학습할 수 있다. 그러나 단순히 레이어를 쌓으면 기울기 소멸/폭발 문제로 학습이 불가능해진다. 트랜스포머 블록은 이 문제를 잔차 연결(Residual Connection)과 LayerNorm으로 해결한다.

하나의 블록 안에서 두 가지 역할이 분리된다. MHA(Multi-Head Attention)는 토큰 간 정보를 섞고, FFN(Feed-Forward Network)은 각 토큰의 표현을 독립적으로 변환한다. 이 두 서브레이어를 잔차 연결로 감싸면, 96개 블록을 쌓아도(GPT-3) 기울기가 전달된다.

트랜스포머 블록 흐름

Transformer block은 Multi-Head Attention + Feed-Forward Network + Layer Norm + Residual Connection의 조합이다. GPT-2 small은 이 블록을 12번 쌓고, GPT-3은 96번 쌓는다. 하나의 블록이 하나의 “사고 단계”에 해당하며, 깊어질수록 더 추상적인 패턴을 포착한다.

블록 구조

%% Pre-Norm Transformer block의 residual 흐름
flowchart TD
  input["Input x"]
  ln1["LayerNorm"]
  mha["MHA"]
  add1["+"]
  ln2["LayerNorm"]
  ffn["FFN"]
  add2["+"]
  output["Output"]
  input --> ln1
  ln1 --> mha
  mha --> add1
  input --> add1
  add1 --> ln2
  ln2 --> ffn
  ffn --> add2
  add1 --> add2
  add2 --> output

트랜스포머 블록 코드

numpy 구현 — LayerNorm

LayerNorm은 BatchNorm과 달리 배치 차원이 아니라 feature 차원(d_model)에서 정규화한다. 시퀀스 길이가 달라도 정상 작동하고, 추론 시 별도의 running mean/var가 필요 없다.

numpy 구현 — Feed-Forward Network

GELU를 사용하는 이유: ReLU는 음수 입력에서 기울기가 완전히 0이 된다(dead neuron). GELU는 음수 입력도 확률적으로 통과시켜 정보 흐름이 끊기지 않는다.

numpy 구현 — 전체 Transformer Block

Residual Connection이 학습을 가능하게 하는 이유

residual이 없으면 깊은 레이어의 Jacobian 곱에서 기울기가 소멸(vanishing)하거나 폭발(exploding)하기 쉽다. y = x + f(x)의 Jacobian에는 항등 경로 I가 추가되어 gradient가 변환 경로만 통과하도록 강제되지 않는다. 다만 두 경로가 상쇄될 수 있으므로 gradient 크기가 항상 1 이상이라는 보장은 아니다.

PyTorch 구현 — 밑바닥 LLM

norm_first=True이면 Pre-Norm, False이면 Post-Norm이다. Pre-Norm은 정규화를 서브레이어 앞에 두어 깊은 모델에서 학습 안정성이 높다.

첫 번째 구현은 norm_first=True일 때 Pre-Norm, False일 때 Post-Norm이다. 두 번째 구현은 Pre-Norm이다. 두 구현 모두 shortcut = x로 입력을 저장한 뒤 서브레이어 출력에 더하며, nn.Dropout은 잔차 합산 직전에 적용한다.

%% GPT-2 small 기준 TransformerBlock의 tensor shape 흐름
flowchart TD
  input["입력 x<br/>(B, T, 768)"]
  ln1["LayerNorm<br/>(B, T, 768)"]
  mha["MHA<br/>(B, T, 768)"]
  drop1["Dropout<br/>(B, T, 768)"]
  add1["+"]
  ln2["LayerNorm<br/>(B, T, 768)"]
  ffn["FFN<br/>(B, T, 768)"]
  drop2["Dropout<br/>(B, T, 768)"]
  add2["+"]
  output["출력<br/>(B, T, 768)"]
  input --> ln1
  ln1 --> mha
  mha --> drop1
  drop1 --> add1
  input --> add1
  add1 --> ln2
  ln2 --> ffn
  ffn --> drop2
  drop2 --> add2
  add1 --> add2
  add2 --> output

정리

트랜스포머 블록은 MHA + FFN + LayerNorm + 잔차 연결의 조합이다. MHA가 토큰 사이 정보를 섞고, FFN이 각 토큰을 독립적으로 변환한다. Pre-Norm 구조는 정규화를 서브레이어 앞에 두어 깊은 모델의 학습 안정성을 높인다. 잔차 연결은 y = x + f(x)로 기울기가 항등 경로를 통해 전달되게 한다. GPT-2는 이 블록을 12개, GPT-3는 96개 쌓는다.

연결 문서: Multi Head Attention · LayerNorm · Feed Forward Network · 잔차 연결
