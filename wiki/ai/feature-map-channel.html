특성 맵·채널 — 다채널 합성곱과 필터 개수가 결정하는 것

특성 맵·채널 — 다채널 합성곱과 필터 개수가 결정하는 것

확인 범위: 이 문서는 다채널 합성곱에서 채널·특성 맵·필터 수와 출력 shape·파라미터 수의 관계를 설명하는 개념 및 계산 예시이며, 제시된 numpy 코드는 연산 흐름을 보여 주기 위한 구현 예시다. 특정 라이브러리·버전에서의 동작 검증이나 실행 기록·성능 측정 결과를 제시하지 않으므로, 실제 구현의 정확성·호환성·성능 판단에는 별도 검증이 필요하다.

한 줄 요약: 필터 하나는 입력의 모든 채널을 동시에 보고 특성 맵 한 장을 만들며, 필터 개수가 출력 채널 수를 결정한다.

특성 맵·채널 구분

커널·필터·스트라이드·패딩 문서에서 1채널 입력에 커널 하나를 적용하는 과정을 봤다. 하지만 실제 이미지는 RGB 3채널이고, CNN 층을 쌓으면 채널이 32, 64, 128로 늘어난다.

“채널이 늘어난다”는 말이 정확히 무엇을 뜻하는지, 필터 하나가 다채널 입력을 어떻게 처리하는지, 필터 개수가 왜 출력 채널 수를 결정하는지를 이 문서에서 다룬다.

특성 맵·채널 흐름

채널이란

채널(Channel)은 입력 텐서의 깊이 차원이다. 흑백 이미지는 1채널, RGB 이미지는 3채널이다. CNN의 중간 층에서는 각 채널이 하나의 특성 맵(feature map)을 나타낸다.

%% 채널 shape 예시
flowchart LR
  mnist["흑백 MNIST<br/>(1, 28, 28)"]
  rgb["RGB 이미지<br/>(3, 28, 28)"]
  conv["Conv 출력<br/>(32, 26, 26)"]

텐서 표기는 (C, H, W) 순서다. 배치까지 포함하면 (N, C, H, W)이다.

특성 맵이란

특성 맵(Feature Map)은 하나의 필터가 입력 전체를 순회한 결과다. 세로선 감지 필터를 적용하면 “세로선 특성 맵”이 나오고, 가로선 감지 필터를 적용하면 “가로선 특성 맵”이 나온다.

특성 맵의 각 칸은 “이 위치에서 해당 패턴이 얼마나 강하게 나타나는가”를 나타내는 숫자다. 값이 클수록 패턴이 강하다.

다채널 합성곱의 동작

입력이 C_in 채널이면 필터 하나도 C_in 채널을 가진다. 채널마다 2D 합성곱을 수행한 뒤, 결과를 모두 더해 하나의 2D 출력을 만든다. 여기에 편향(bias) 하나를 더하면 특성 맵 한 장이 완성된다.

%% 다채널 합성곱 구조
flowchart LR
  input["입력<br/>(C_in, H, W)"]
  filter["필터 1개<br/>(C_in, FH, FW)"]
  channel_results["채널별 2D 결과<br/>2D 결과 0<br/>2D 결과 1<br/>2D 결과 2"]
  sum_bias["모두 합산 + bias"]
  output["출력 1장<br/>(OH, OW)"]
  input --> filter
  filter --> channel_results
  channel_results --> sum_bias
  sum_bias --> output

핵심: 필터 하나는 입력의 모든 채널을 동시에 본다. 채널별 패턴을 조합해 하나의 특징을 추출한다.

필터 개수 = 출력 채널 수

필터를 여러 개 사용하면 각 필터가 서로 다른 특성 맵을 만든다. 필터 C_out개를 사용하면 출력은 C_out 채널이 된다.

입력 shape:   (C_in, H, W)
필터 shape:   (C_out, C_in, FH, FW)   ← C_out개 필터, 각각 C_in 채널
편향 shape:   (C_out,)                 ← 필터마다 bias 하나
출력 shape:   (C_out, OH, OW)          ← 특성 맵 C_out장

예시: RGB 이미지 (3, 28, 28)에 필터 32개 (32, 3, 3, 3)를 적용하면, 출력은 (32, 26, 26)이다 (pad=0, stride=1). 필터 하나당 가중치 수는 3×3×3 = 27, 전체 가중치 수는 32×27 + 32(bias) = 896이다. 같은 크기의 완전연결층이라면 3×28×28 × 32×26×26 = 수백만 개 가중치가 필요하다.

파라미터 수 계산

Conv 층의 파라미터 수:

파라미터 수 = C_out × (C_in × FH × FW) + C_out
           = C_out × C_in × FH × FW + C_out (bias)

MNIST CNN 예시에서 파라미터를 세보면:

Conv1: (32, 1, 3, 3) + bias 32  →  32 × 1 × 9 + 32 = 320
Conv2: (64, 32, 3, 3) + bias 64 →  64 × 32 × 9 + 64 = 18,496

Conv2의 파라미터가 Conv1보다 훨씬 많다. 입력 채널(C_in)이 32로 늘어났기 때문이다.

특성 맵·채널 텐서 코드

다채널 합성곱 (numpy 구현)

이 코드가 하는 일: 필터 하나가 입력의 모든 채널을 동시에 보고 원소별 곱의 합으로 특성 맵 한 장을 만든다. 이 과정을 C_out번 반복하면 출력 텐서가 완성된다.

구체적 연산 예시

이 코드가 하는 일: 2채널 입력에서 각 채널의 같은 위치 영역을 각각의 커널로 합성곱한 뒤, 채널별 결과를 더해 출력 한 칸을 만드는 과정을 단계별로 분해한다.

텐서 shape 변환 흐름

%% 텐서 shape 변환 흐름
flowchart TD
  input["RGB 입력<br/>(1, 3, 28, 28)"]
  conv1["Conv1<br/>필터 (32, 3, 3, 3)"]
  conv2["Conv2<br/>필터 (64, 32, 3, 3)"]
  conv3["Conv3<br/>필터 (128, 64, 3, 3)"]
  input --> conv1
  conv1 --> conv2
  conv2 --> conv3

채널 수가 늘어날수록 파라미터가 급증한다. 이것이 깊은 CNN에서 채널 설계가 중요한 이유다.

정리

채널은 텐서의 깊이 차원이며, 입력에서는 색상(RGB), 중간 층에서는 특성 맵을 나타낸다. 필터 하나는 입력의 모든 채널을 동시에 보고, 채널별 합성곱 결과를 합산해 특성 맵 한 장을 만든다. 필터 개수가 출력 채널 수를 결정한다. 층을 쌓으면서 채널을 늘리면 더 복잡한 패턴을 표현할 수 있지만 파라미터가 급증한다. Conv 층의 파라미터 수는 C_out × C_in × FH × FW + C_out이다.
