연쇄법칙

연쇄법칙

범위: 이 문서는 연쇄법칙과 신경망 역전파에 적용되는 일반 원리, 계산 예시 및 코드상 적용 형태를 설명한다. 제시된 코드의 실제 동작 여부와 버전별 차이, 실행 결과 및 성능에 관한 판단은 별도의 코드·환경·실행 기록과 측정을 통해 검증해야 한다.

한 줄 요약: 연쇄법칙(Chain Rule)은 합성 함수의 미분을 각 함수의 미분의 곱으로 분해하는 규칙이다. 역전파의 수학적 토대다.

연쇄법칙 필요성

신경망은 층이 겹겹이 쌓인 합성 함수다. 손실 L을 입력 쪽 파라미터 W1으로 미분하려면, 중간에 거치는 모든 함수를 한꺼번에 미분해야 한다. 합성 함수 전체를 한 번에 미분하는 것은 복잡하고 오류가 나기 쉽다.

연쇄법칙은 이 문제를 “각 층의 미분을 따로 구한 뒤 곱한다”로 바꾼다. 각 층은 자기 입출력 관계의 미분(국소 미분)만 알면 되고, 그것을 체인처럼 연결하면 전체 미분이 나온다. 이것이 역전파가 동작하는 원리다.

연쇄법칙 흐름

비유: 환율 변환 체인

달러를 유로로 바꾸고, 유로를 원화로 바꾼다고 하자.

  • 1달러 = 0.85유로 (dEUR/dUSD = 0.85)
  • 1유로 = 1,400원 (dKRW/dEUR = 1,400)

달러 1달러가 변하면 원화는 얼마나 변하는가?

dKRW/dUSD = dKRW/dEUR × dEUR/dUSD = 1,400 × 0.85 = 1,190

각 환전소의 환율(국소 미분)을 곱하면 전체 환율(전체 미분)이 나온다. 이것이 연쇄법칙이다.

정의

함수 y = f(x), z = g(y)가 합성되어 z = g(f(x))일 때:

dz/dx = dz/dy × dy/dx

세 함수가 합성되면:

z = h(g(f(x)))일 때:

dz/dx = dz/dg × dg/df × df/dx

함수가 아무리 많이 합성되어도 각 함수의 미분을 순서대로 곱하면 된다.

구체적 숫자로 확인

z = (2x + 3)²에서 x = 1일 때 dz/dx를 구한다.

단계 1: 합성 함수를 분해한다.

  • u = 2x + 3 (안쪽 함수)
  • z = u² (바깥 함수)

단계 2: 각 함수의 미분(국소 미분)을 구한다.

  • du/dx = 2
  • dz/du = 2u

단계 3: 연쇄법칙으로 곱한다.

  • dz/dx = dz/du × du/dx = 2u × 2

단계 4: x = 1을 대입한다.

  • u = 2(1) + 3 = 5
  • dz/dx = 2(5) × 2 = 20

검증: z = (2x+3)²을 전개하면 z = 4x² + 12x + 9이므로 dz/dx = 8x + 12. x = 1이면 dz/dx = 20. 일치한다.

신경망에서의 연쇄법칙

2층 신경망의 손실 함수를 합성 함수로 표현한다.

L = CrossEntropy(Softmax(W2 × ReLU(W1 × x + b1) + b2), t)

이것을 층 단위로 분해하면:

  • z1 = W1 × x + b1 (Affine1)
  • a1 = ReLU(z1) (ReLU)
  • z2 = W2 × a1 + b2 (Affine2)
  • L = CE(Softmax(z2), t) (Softmax + CE)

W1에 대한 기울기를 구하려면:

dL/dW1 = dL/dz2 × dz2/da1 × da1/dz1 × dz1/dW1

각 항은 각 층의 국소 미분이다. 역전파는 이 곱셈을 출력에서 입력 방향으로 수행한다.

%% 신경망 층별 역전파 흐름
flowchart TD
  loss["Softmax + CE Loss<br/>L = CE(Softmax(z2), t)"]
  affine2["Affine2<br/>z2 = W2a1 + b2<br/>local: dz2/da1"]
  relu["ReLU<br/>a1 = max(0, z1)"]
  affine1["Affine1<br/>z1 = W1x + b1<br/>local: dz1/dW1"]
  loss --> affine2
  affine2 --> relu
  relu --> affine1

역전파는 오른쪽(출력)에서 왼쪽(입력)으로 진행한다. 각 층은 상류에서 흘러온 기울기에 자신의 국소 미분을 곱해 하류로 넘긴다.

덧셈과 곱셈의 연쇄법칙

덧셈: z = x + y이면 dz/dx = 1, dz/dy = 1이다. 상류 기울기 dL/dz가 흘러오면:

  • dL/dx = dL/dz × 1 = dL/dz
  • dL/dy = dL/dz × 1 = dL/dz

상류 기울기를 그대로 양쪽에 복사한다.

곱셈: z = x × y이면 dz/dx = y, dz/dy = x이다. 상류 기울기 dL/dz가 흘러오면:

  • dL/dx = dL/dz × y
  • dL/dy = dL/dz × x

상류 기울기에 상대방 값을 곱한다. 이것이 Affine 층의 역전파에서 W.T를 곱하고 X.T를 곱하는 이유다.

연쇄법칙 코드

연쇄법칙이 코드에서 나타나는 곳

밑바닥 딥러닝1의 신경망은 각 층의 backward() 메서드가 연쇄법칙의 한 단계를 수행한다.

dout이 상류에서 흘러온 기울기다. 각 층의 backward(dout)는 연쇄법칙에 따라 dout × (국소 미분)을 계산하고, 결과를 다음 층(하류)으로 넘긴다.

Affine 층에서 연쇄법칙 적용

dout @ self.W.T에서 dout이 상류 기울기이고, self.W.T가 국소 미분이다. 행렬 곱셈의 연쇄법칙은 스칼라 곱셈의 연쇄법칙이 행렬로 확장된 것이다.

연쇄법칙을 숫자로 추적

x = 2.0, W = 3.0, b = 1.0인 1뉴런 1층 네트워크에서 L = (Wx + b - t)²/2, t = 10.0이라 하자.

dL/dW = -6이 의미하는 것: W를 1 늘리면 손실이 6 줄어든다. 경사 하강법은 이 방향으로 W를 이동시킨다.

연쇄법칙의 흐름을 다이어그램으로

%% 스칼라 예제의 순전파와 역전파
flowchart LR
  x["x<br/>x = 2<br/>dx = -9"]
  w["W<br/>W = 3<br/>dW = -6"]
  b["b<br/>b = 1<br/>db = -3"]
  mul["곱셈<br/>z1 = W x<br/>z1 = 6"]
  add["덧셈<br/>z = z1 + b<br/>z = 7<br/>dz = -3"]
  loss["Loss<br/>L = (z - t)^2 / 2<br/>L = 4.5<br/>dL = 1"]
  x --> mul
  w --> mul
  mul --> add
  b --> add
  add --> loss
  loss -.-> add
  add -.-> b
  add -.-> mul
  mul -.-> w
  mul -.-> x

각 노드에서 상류 기울기(dz = -3)에 국소 미분을 곱한다. 곱셈 노드에서 W의 기울기를 구할 때 상대방 값 x = 2를 곱하고, x의 기울기를 구할 때 상대방 값 W = 3을 곱한다.

정리

연쇄법칙은 합성 함수의 미분을 각 함수의 국소 미분의 곱으로 분해한다. 신경망의 각 층은 국소 미분만 계산하면 되고, 역전파가 이를 체인처럼 연결하여 전체 기울기를 구한다. 덧셈 노드는 기울기를 복사하고, 곱셈 노드는 상대방 값을 곱한다. 이 두 규칙이 계산 그래프와 역전파의 수학적 기초다.
