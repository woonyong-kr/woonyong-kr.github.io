활성화 함수

활성화 함수

한 줄 요약: 활성화 함수는 뉴런의 가중합에 적용하는 비선형 함수이며, 이것이 없으면 아무리 층을 쌓아도 전체 네트워크가 하나의 선형 변환과 같아진다.

가중합을 그대로 출력하면 생기는 문제

퍼셉트론에서는 계단 함수가 가중합을 0 또는 1로 바꾼다. 이때 계단 함수 같은 변환 없이 가중합을 그대로 다음 층으로 넘기면, 여러 층을 쌓아도 선형 함수의 합성을 벗어나지 못한다.

선형 함수 f(x) = ax + b를 두 번 합성하면 g(f(x)) = c(ax+b)+d = acx + (cb+d)이다. 두 함수의 합성도 여전히 1차식이다. 같은 방식으로 100층을 쌓더라도 전체 계산은 y = w’x + b’ 형태의 선형 변환으로 표현된다.

각 층의 선형 계산 뒤에 활성화 함수를 두면 층 사이에 비선형 변환이 들어간다. 문서에서 다루는 신경망에서는 이 비선형성이 곡선 결정 경계나 XOR 같은 비선형 문제를 표현하기 위해 필요하다.

계단 함수에서 ReLU와 GELU까지

계단 함수

퍼셉트론에서 쓰는 계단 함수는 입력이 0보다 크면 1, 그렇지 않으면 0을 출력한다.

step(x) = 1 (x > 0)
           0 (x <= 0)

계단 함수는 0에서 불연속이고, 나머지 구간에서는 미분값이 0이다. 따라서 이 미분값으로 gradient를 전달하는 학습 방식에서는 가중치를 어느 방향으로 바꿔야 하는지에 관한 신호가 전달되지 않는다. 이 성질 때문에 계단 함수는 여기서 설명하는 gradient 기반 학습의 활성화 함수로 사용하기 어렵다.

Sigmoid

Sigmoid는 계단 함수와 달리 출력이 매끄럽게 변한다.

sigmoid(x) = 1 / (1 + exp(-x))

출력 범위는 (0, 1)이며 모든 점에서 미분할 수 있다. 미분은 다음과 같다.

sigmoid'(x) = sigmoid(x) * (1 - sigmoid(x))

Sigmoid의 최대 기울기가 0.25인 이유

sigmoid(x) * (1 - sigmoid(x))는 sigmoid(x) = 0.5일 때 최대가 된다. 이때 값은 0.5 * 0.5 = 0.25이며, x = 0에서 나온다.

따라서 Sigmoid 자체의 국소 미분값은 최대 0.25다. 아래 계산은 여러 층에서 이 미분값만 연속해서 곱한다고 단순화했을 때 gradient가 얼마나 작아질 수 있는지를 보여준다.

1층 통과: 0.25
3층 통과: 0.25^3 = 0.0156
5층 통과: 0.25^5 = 0.00098

이 단순 계산에서는 5층을 지난 값이 원래의 약 0.1% 수준이 된다. 실제 신경망의 gradient에는 가중치와 다른 연산의 미분도 함께 작용하지만, Sigmoid의 작은 미분값이 층마다 반복해서 곱해지면 기울기 소실(vanishing gradient problem)에 영향을 줄 수 있다. 이 문서에서는 이를 Sigmoid를 은닉층에 사용하지 않는 이유로 설명한다.

ReLU

ReLU(Rectified Linear Unit)는 양수는 그대로 통과시키고 음수는 0으로 만든다.

ReLU(x) = max(0, x)

양수 구간의 기울기는 1이므로, 이 구간에서는 ReLU 자체의 미분 때문에 gradient가 줄어들지 않는다. 계산도 max(0, x) 한 번으로 표현된다. 반면 음수 구간의 기울기는 0이므로, 입력이 계속 음수 구간에 머무는 뉴런에는 gradient가 전달되지 않는 dead neuron 문제가 생길 수 있다.

Tanh, Leaky ReLU, GELU

출력의 중심과 음수 구간을 처리하는 방식에 따라 다른 활성화 함수를 선택할 수 있다.

tanh(x)=ex+e−xex−e−x​=2σ(2x)−1

Tanh의 출력 범위는 (−1,1)이고 0을 중심으로 한다. 다만 입력의 절댓값이 커지면 Sigmoid처럼 기울기가 작아진다.

LeakyReLU(x)={xαx​(x>0)(x≤0)​(α는 보통 0.01)

Leaky ReLU는 음수 구간에도 작은 기울기를 남겨 dead neuron 문제를 줄인다. GELU는 xΦ(x)로 정의하며, Φ는 표준 정규분포의 누적분포함수다. 음수를 즉시 0으로 자르지 않고 부드럽게 감쇠하며, 이 문서에서는 Transformer 계열에서 널리 사용하는 함수로 다룬다.

활성화 함수가 놓이는 위치

활성화 함수는 가중합(Affine) 뒤이자 다음 층 앞에 놓인다.

%% 활성화 함수가 Affine 뒤에 놓이는 흐름
flowchart LR
  input["입력 x"]
  affine["Affine<br/>z = xW + b"]
  relu["ReLU<br/>a = f(z)"]
  next_layer["다음 층"]
  input --> affine
  affine --> relu
  relu --> next_layer

은닉층에서는 ReLU 또는 GELU를 사용할 수 있고, 출력층에서는 과업에 맞는 함수를 선택한다.

  • 은닉층: ReLU (기본), GELU (Transformer)
  • 출력층 이진 분류: Sigmoid → 0~1 확률
  • 출력층 다중 분류: Softmax → 확률 분포 (합=1)
  • 출력층 회귀: 항등 함수 (활성화 없음)

같은 입력에 대한 출력 비교

입력 x = [-2.0, -1.0, 0.0, 1.0, 2.0]에 대한 각 함수의 출력은 다음과 같다.

 x     | step | sigmoid | tanh   | ReLU | GELU
-------|------|---------|--------|------|------
-2.0   |  0   | 0.119   | -0.964 | 0.0  | -0.045
-1.0   |  0   | 0.269   | -0.762 | 0.0  | -0.159
 0.0   |  0   | 0.500   |  0.000 | 0.0  |  0.000
 1.0   |  1   | 0.731   |  0.762 | 1.0  |  0.841
 2.0   |  1   | 0.881   |  0.964 | 2.0  |  1.955

계단 함수는 0과 1만 출력한다. Sigmoid는 0과 1 사이에서 부드럽게 변하고, ReLU는 양수를 그대로 통과시키므로 입력이 커지면 출력도 함께 커진다.

Sigmoid의 출력은 0 중심이 아니다. 이 성질은 은닉층에서 사용할 때 학습을 비효율적으로 만들 수 있다. GELU는 다음과 같이 근사할 수도 있다.

GELU(x)≈xσ(1.702x)

코드로 확인하는 활성화 함수

계단 함수와 Sigmoid (밑시딥1 Ch3)

sigmoid에서 np.exp(-x)는 배열의 원소별로 동작한다. 따라서 벡터를 입력하면 각 원소에 대응하는 sigmoid 값이 나온다.

ReLU 클래스의 forward와 backward

forward는 self.mask에 0 이하인 입력의 위치를 저장한다. backward는 같은 위치의 gradient를 0으로 만든다. 이 구현에서는 forward에서 출력에 반영되지 않은 위치로 gradient를 전달하지 않는다.

Softmax와 overflow 방지

exp(1000)처럼 큰 값을 직접 계산하면 overflow가 날 수 있다. 이 코드는 입력에서 np.max(x)를 빼고 지수 함수를 계산한다. 최댓값을 빼도 분자와 분모에 같은 상수 exp(-c)가 곱해져 약분되므로 Softmax 결과는 달라지지 않는다.

softmax(a) = exp(a) / sum(exp(a))
           = exp(a-c) / sum(exp(a-c))   (c = max(a))

신경망에서 쓰이는 위치

이 코드에서는 은닉층마다 Affine → BatchNorm → ReLU → Dropout 순서로 층을 쌓고, 마지막 출력층에만 Softmax를 붙인다. 문서에 제시된 밑바닥 딥러닝1 프로젝트의 MNIST 분류 신경망 구조다.

PyTorch의 모듈형과 함수형 API

nn.Sequential처럼 계층을 조립할 때는 nn.Module 구현을 사용하고, forward() 안에서 직접 계산할 때는 함수형 API를 사용할 수 있다.

F.softmax(x, dim=-1)처럼 정규화할 차원을 명시한다. 학습 시 nn.CrossEntropyLoss는 logits에 필요한 연산을 내부에서 처리하므로 모델 출력에 Softmax를 먼저 적용하지 않는다.

활성화 함수와 텐서 shape

%% 활성화 함수와 Affine 층의 텐서 shape 흐름
flowchart TD
  input["입력<br/>(batch, input_dim)"]
  affine1["Affine1<br/>x @ W + b<br/>(batch, hidden_dim)"]
  relu["ReLU<br/>max(0, x)<br/>(batch, hidden_dim)"]
  affine2["Affine2<br/>x @ W + b<br/>(batch, class_count)"]
  softmax["Softmax<br/>exp(z) / sum(exp(z))<br/>(batch, class_count)"]
  input --> affine1
  affine1 --> relu
  relu --> affine2
  affine2 --> softmax

이 흐름에서 활성화 함수는 shape을 바꾸지 않고 값만 변환한다. Affine 층은 가중치 행렬을 통해 shape을 바꾼다.

NumPy ReLU 함수

np.maximum은 배열의 각 원소에 max(0, x)를 적용한다.

PyTorch 함수형 ReLU

forward() 안에서 활성화 함수를 직접 호출할 때는 함수형 API를 쓸 수 있다.

함수 선택을 설명하는 기준

활성화 함수는 선형 계산(Affine) 사이에 비선형 변환을 넣는다. 계단 함수는 대부분의 구간에서 미분값이 0이므로 gradient 기반 학습에 필요한 신호를 전달하기 어렵다. Sigmoid는 미분할 수 있지만 미분값이 최대 0.25라, 여러 층에서 반복되면 기울기 소실에 영향을 줄 수 있다. ReLU는 양수 구간의 기울기가 1인 대신 음수 구간에서 dead neuron 문제가 생길 수 있으며, Leaky ReLU는 음수 구간에 작은 기울기를 남긴다. GELU는 음수 입력을 부드럽게 감쇠한다.

은닉층과 출력층은 역할이 다르므로 같은 함수를 일괄적으로 쓰지 않는다. 이 문서에서 은닉층의 선택지는 ReLU와 GELU이며, 출력층에서는 이진 분류에 Sigmoid, 다중 분류에 Softmax, 회귀에 항등 함수를 사용한다.
