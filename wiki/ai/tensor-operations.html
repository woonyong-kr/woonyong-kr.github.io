텐서 연산과 브로드캐스팅 — 다차원 배열을 자유자재로 다루는 규칙

텐서 연산과 브로드캐스팅 — 다차원 배열을 자유자재로 다루는 규칙

한 줄 요약: 신경망 코드는 행렬 곱 외에도 reshape, axis 연산, 브로드캐스팅, 불리언 마스킹이 반복된다. 이 네 가지 shape 조작 규칙을 알면 어떤 층의 코드든 읽을 수 있다.

텐서 연산과 브로드캐스팅 구분

벡터·행렬 연산에서 y = xW + b라는 행렬 곱을 다뤘다. 그러나 신경망 코드를 실제로 읽으면 행렬 곱만으로는 설명이 안 되는 연산이 곳곳에 나온다.

  • Softmax에서 np.max(x, axis=1, keepdims=True) — axis와 keepdims가 뭔가?
  • BatchNorm에서 np.mean(x, axis=0) — 왜 axis=0인가?
  • ReLU에서 self.mask = (x <= 0) — 불리언 배열로 뭘 하는가?
  • Affine에서 x.reshape(x.shape[0], -1) — 왜 reshape하고, -1은 뭔가?

이 연산들은 전부 텐서(다차원 배열)의 shape을 이해하고 조작하는 규칙이다. 행렬 곱이 “층의 선형 변환”이라면, 여기서 다루는 연산은 “층이 돌아가기 위한 배관 작업”이다.

텐서 연산과 브로드캐스팅 차이

ndarray의 차원과 shape

numpy의 ndarray는 같은 타입 숫자를 n차원 격자에 담는 자료구조다. 차원 수(ndim)에 따라 이름이 달라진다.

  • 0차원 (스칼라): 숫자 하나. np.float64(3.14). shape = ()
  • 1차원 (벡터): 숫자를 한 줄로 나열. shape = (n,). 편향 b가 이 모양이다.
  • 2차원 (행렬): 행과 열. shape = (m, n). 배치 입력 X, 가중치 W가 이 모양이다.
  • 3차원 이상 (텐서): shape = (batch, height, width) 등. CNN 입력 이미지가 (N, C, H, W)이다.

shape의 각 숫자는 그 축(axis)에 원소가 몇 개인지 나타낸다. shape (2, 3)은 “0번 축에 2개, 1번 축에 3개”라는 뜻이다.

reshape — shape을 바꾸되 데이터는 그대로

reshape는 배열의 원소 순서를 유지한 채 shape만 바꾼다. 원소 총 개수가 같아야 한다.

-1의 의미: shape에 -1을 넣으면 “나머지를 자동 계산하라”는 뜻이다. Affine 층에서 이것이 핵심적으로 사용된다.

CNN의 출력은 (N, C, H, W) 같은 4차원이다. 이것을 Affine 층(행렬 곱)에 넣으려면 (N, C*H*W)로 펼쳐야 한다. reshape(x.shape[0], -1)이 이 변환을 한다.

역전파에서는 원래 shape으로 되돌린다.

axis — 어떤 축을 따라 연산할지

np.sum, np.mean, np.max 같은 집계 함수는 axis 인자로 “어느 방향으로 줄일지”를 정한다.

%% axis 방향에 따른 집계 결과
flowchart LR
  input["x<br/>shape: (N, D)"]
  axis0["axis=0<br/>행(배치) 방향으로 줄인다<br/>각 특징별 N개 샘플을 합산/평균<br/>결과 shape: (D,)"]
  axis1["axis=1<br/>열(특징) 방향으로 줄인다<br/>각 샘플별 D개 특징을 합산/평균<br/>결과 shape: (N,)"]
  input --> axis0
  input --> axis1

비유로 생각하면 이렇다. 교실에 학생 N명이 있고, 각 학생의 시험 과목이 D개다. axis=0은 “과목별 평균 점수” (학생 방향 합산), axis=1은 “학생별 총점” (과목 방향 합산)이다.

keepdims: keepdims=True로 하면 줄인 축이 크기 1로 남는다. 브로드캐스팅에서 이것이 중요하다.

브로드캐스팅 — shape이 다른 배열끼리 연산하는 규칙

numpy에서 shape이 다른 두 배열을 +, -, *, /로 연산하면, 작은 쪽이 자동으로 확장된다. 이것이 브로드캐스팅(broadcasting)이다.

규칙 (오른쪽 축부터 비교한다):

  • 두 축의 크기가 같으면 → 그대로 연산
  • 한쪽이 1이면 → 1인 쪽을 다른 쪽 크기로 복사 (메모리 복사 없이)
  • 둘 다 1이 아니고 다르면 → 에러
작동하는 경우:
(N, 256) + (256,)     → (N, 256)    # 편향 덧셈. (256,)을 (1, 256)으로 맞추고, 1→N 확장
(N, 10)  - (N, 1)     → (N, 10)     # Softmax의 max 빼기. 1→10 확장
(N, D)   / (N, 1)     → (N, D)      # Softmax의 합 나누기

실패하는 경우:
(N, 256) + (N,)       → 에러!       # 오른쪽 축: 256 vs N. 둘 다 1이 아니고 다름

Softmax에서 keepdims=True가 필수인 이유가 여기에 있다.

불리언 인덱싱 — 조건으로 원소를 선택하거나 바꾸기

비교 연산(<=, >, == 등)을 배열에 적용하면 같은 shape의 불리언 배열이 나온다. 이것을 인덱스로 쓰면 조건에 맞는 원소만 접근할 수 있다.

ReLU가 정확히 이 방식으로 동작한다. “0 이하인 위치를 0으로 바꾸는 것”이 ReLU의 전부다.

텐서 연산과 브로드캐스팅 코드

ReLU — 불리언 마스킹의 대표 사례

forward에서 만든 self.mask를 backward에서 재사용한다. 순전파에서 “어떤 뉴런이 꺼졌는가”를 기록해 두고, 역전파에서 꺼진 뉴런으로는 기울기를 흘리지 않는다.

Softmax — axis, keepdims, 브로드캐스팅의 조합

이 코드에 세 가지 핵심 연산이 모두 들어 있다.

shape 변환을 단계별로 따라가면 이렇다.

%% Softmax shape 변환 흐름
flowchart LR
  x["x<br/>shape: (N, D)"]
  max_val["1단계: 행별 최댓값<br/>np.max(x, axis=1, keepdims=True)<br/>(N, 1)"]
  shifted["2단계: 최댓값 빼기<br/>x - max_val<br/>(N, D)"]
  exp_x["3단계: 원소별 지수<br/>np.exp(shifted)<br/>shape: (N, D)"]
  sum_val["4단계: 행별 합<br/>np.sum(exp_x, axis=1, keepdims=True)<br/>(N, 1)"]
  out["5단계: 정규화<br/>exp_x / sum_val<br/>(N, D)"]
  x --> max_val
  max_val --> shifted
  shifted --> exp_x
  exp_x --> sum_val
  sum_val --> out

숫자로 확인한다.

BatchNorm — axis=0 통계와 브로드캐스팅

BatchNorm에서 axis=0인 이유: 같은 특징(feature)에 대해 배치 전체의 평균과 분산을 구해야 하기 때문이다. “학생별 총점”이 아니라 “과목별 평균”을 구하는 것이다.

Softmax의 axis=1과 비교하면 방향이 정반대다.

%% BatchNorm axis=0과 Softmax axis=1 비교
flowchart LR
  batchnorm["BatchNorm: axis=0 (배치 방향)"]
  softmax["Softmax: axis=1 (특징 방향)"]
  batchnorm --> softmax

Affine backward — axis 합산으로 편향 기울기

순전파에서 (N, 256) + (256,) 브로드캐스팅으로 b가 N번 “복사”되었으니, 역전파에서는 그 역연산인 np.sum(dout, axis=0)으로 N개를 합산하는 것이다. 브로드캐스팅의 역전파는 합산이다.

연산별 shape 변환 요약

%% 텐서 연산별 shape 변환 요약
flowchart TD
  summary["연산 &#124; 입력 shape &#124; 인자 &#124; 출력 shape<br/>reshape &#124; (N, D) &#124; (N, H, W) &#124; (N, H, W)"]

정리

  • reshape는 원소를 유지한 채 shape만 바꾼다. -1은 나머지 차원을 자동 계산한다. CNN 출력을 Affine 입력으로 펼칠 때 필수다.
  • axis는 집계 방향을 정한다. axis=0은 배치 방향(BatchNorm), axis=1은 특징 방향(Softmax)이다.
  • 브로드캐스팅은 shape이 다른 배열을 자동 확장한다. keepdims=True가 없으면 브로드캐스팅이 깨진다. 브로드캐스팅의 역전파는 np.sum이다.
  • 불리언 마스킹은 조건에 맞는 위치만 선택하거나 바꾼다. ReLU의 forward/backward가 대표적이다.
  • 연결 문서: MLP 순전파
