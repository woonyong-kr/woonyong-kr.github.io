최대사후확률

최대사후확률

확인 범위: 이 문서는 MAP와 MLE의 차이, 사전분포에 따른 정규화 효과와 선택 기준을 설명하는 개념 자료이며, 포함된 코드는 원리를 보여 주는 예시다. 특정 코드베이스나 라이브러리 버전에서의 동작, 실행 결과, 성능은 실제 구현과 실행 기록·측정을 별도로 확인해야 한다.

한 줄 요약: MAP는 MLE에 “파라미터가 어떤 분포를 따를 것 같다”는 사전 지식(prior)을 더한 추정 방법이며, 가우시안 사전분포를 쓰면 L2 정규화(weight decay)가 된다.

최대사후확률 구분

최대우도추정(MLE)은 데이터만 보고 파라미터를 정한다. 데이터가 충분하면 잘 동작하지만, 데이터가 적으면 극단적인 파라미터를 허용한다. 동전 3번 던져 3번 다 앞이 나왔을 때, MLE는 p = 1.0(앞면 확률 100%)이라고 추정한다. 상식적으로 p = 1.0은 이상하다.

MAP(Maximum A Posteriori, 최대사후확률)은 “관측 데이터 + 사전 믿음”을 함께 사용한다. “동전은 보통 공정하다”라는 사전 지식(Beta(2,2))을 넣으면 p = 0.8 정도로 완화된 추정을 얻는다.

신경망에서 MAP를 알아야 하는 이유는 세 가지다.

  • weight decay(L2 정규화)가 MAP의 특수 경우임을 이해한다. weight decay 계수 λ는 사전분포의 분산 역수다.
  • 오버피팅 방지의 수학적 근거를 이해한다. 사전분포가 큰 가중치에 벌점을 부과한다.
  • 베이지안 학습의 출발점이다. MAP는 사후분포의 점추정이고, 완전 베이지안은 사후분포 전체를 사용한다.

최대사후확률 흐름

베이즈 정리에서 MAP까지

베이즈 정리:

P(θ|D) = P(D|θ) × P(θ) / P(D)

  • P(θ|D): 사후확률(posterior). 데이터 D를 본 뒤 파라미터 θ에 대한 믿음.
  • P(D|θ): 우도(likelihood). 파라미터 θ일 때 데이터 D가 나올 확률.
  • P(θ): 사전확률(prior). 데이터를 보기 전 파라미터에 대한 믿음.
  • P(D): 증거(evidence). 모든 θ에 대해 우도를 적분한 값. θ와 무관한 상수.

MAP는 사후확률을 최대화하는 θ를 찾는다.

θ_MAP = argmax_θ P(θ|D) = argmax_θ P(D|θ) × P(θ)

P(D)는 θ와 무관하므로 무시한다. 로그를 취하면:

θ_MAP = argmax_θ [ log P(D|θ) + log P(θ) ]

이를 최소화 문제로 바꾸면:

θ_MAP = argmin_θ [ −log P(D|θ) − log P(θ) ] = argmin_θ [ Loss(θ) + 정규화 항 ]

MLE와의 차이: MLE = argmax_θ log P(D|θ). MAP에는 log P(θ) 항이 추가된다. MLE는 P(θ)가 균일분포인 MAP의 특수 경우다.

왜 가우시안 사전분포가 L2 정규화인가?

사전분포를 가우시안으로 놓는다. P(θᵢ) = N(0, σ²).

각 파라미터 θᵢ에 대해:

log P(θᵢ) = −θᵢ² / (2σ²) + 상수

모든 파라미터에 대해 합하면:

log P(θ) = −1/(2σ²) × Σ θᵢ² + 상수

MAP 목적함수에 대입하면:

θ_MAP = argmin_θ [ −log P(D|θ) + 1/(2σ²) × Σ θᵢ² ] = argmin_θ [ Loss(θ) + λ × Σ θᵢ² ]

여기서 λ = 1/(2σ²)이다. 이것이 L2 정규화(weight decay)다.

  • σ가 크면 (사전 지식이 약하면) → λ가 작다 → 정규화 효과 약함 → MLE에 가까움.
  • σ가 작으면 (파라미터가 0 근처여야 한다는 강한 믿음) → λ가 크다 → 정규화 효과 강함.

다른 사전분포의 효과

  • 가우시안 P(θ) = N(0, σ²) → L2 정규화 (ridge). 큰 가중치를 부드럽게 줄인다.
  • 라플라스 P(θ) ∝ exp(−|θ|/b) → L1 정규화 (lasso). 일부 가중치를 정확히 0으로 만든다. 희소성을 유도한다.
  • 균일분포 P(θ) = 상수 → 정규화 없음. MAP = MLE.

MLE vs MAP 비교: 동전 던지기

MLE는 관측 데이터만 반영해 p = 1.0이라는 극단적 추정을 내놓는다. MAP는 사전 지식이 극단을 억제한다.

신경망에서 L2 정규화 = MAP

L2 정규화를 쓴다는 것은 “가중치가 0 근처의 가우시안 분포를 따를 것이다”라는 사전 지식을 넣는 것이다. λ가 크면 사전 지식이 강해져 가중치가 작아지고, λ가 작으면 데이터에 더 의존한다.

λ 값에 따른 추정 변화

λ가 커질수록 MAP 추정값은 0(사전분포의 평균)에 가까워진다.

정리

MAP는 MLE에 사전분포를 더한 추정 방법이다. argmin [Loss + λ × ‖θ‖²] 형태의 정규화 학습은 가우시안 사전분포의 MAP와 수학적으로 동치다. λ = 1/(2σ²)이므로 weight decay 계수를 조절하는 것은 사전 지식의 강도를 조절하는 것이다.
