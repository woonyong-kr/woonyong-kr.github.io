그래디언트 클리핑 — 기울기 폭주를 막는 안전장치

그래디언트 클리핑은 역전파에서 기울기가 지나치게 커졌을 때, gradient의 방향은 유지하면서 크기만 제한하는 안전장치다.

기울기가 커지면 생기는 문제

LLM 학습에서는 긴 sequence와 큰 embedding 차원을 처리하고, 여러 Transformer block을 거쳐 손실을 역전파한다. 이런 학습 과정에서 일부 batch의 loss가 크게 튀는 상황이 나타나면 gradient norm도 함께 커질 수 있다.

optimizer는 계산된 gradient를 바탕으로 파라미터를 업데이트한다. gradient가 적당하면 파라미터가 조금씩 움직이고 loss도 서서히 줄어든다. 반대로 gradient norm이 매우 커지면 파라미터가 한 번에 크게 움직인다. 이후 step에서 loss가 nan이 되거나 학습이 불안정해질 수 있다.

기울기 소실·폭발에서 다루는 것처럼, 깊은 신경망에서는 gradient가 layer를 거듭하며 커지는 구조적 문제가 생길 수 있다. learning rate를 줄이면 모든 step의 보폭은 작아지지만, 특정 batch에서 gradient가 갑자기 커지는 상황을 별도로 제한하지는 않는다. gradient clipping은 이런 순간에 gradient 크기가 정해진 한도를 넘지 않도록 막는다.

Max Norm Gradient Clipping의 계산

gradient clipping은 속도 제한 장치에 비유할 수 있다. 차에 해당하는 optimizer는 내비에 해당하는 gradient가 가리키는 방향으로 움직인다. 평소에는 그대로 이동하지만, 내비가 “200km/h로 가라”고 지시하면 속도 제한기가 80km/h로 낮춘다. 이동 방향은 유지하고 속도만 제한하는 셈이다.

가장 흔한 방식은 전체 gradient의 L2 norm을 기준으로 크기를 제한하는 Max Norm Clipping이다.

모든 파라미터의 gradient를 하나로 모아 norm을 잰다.

total_norm = sqrt(sum(g_i^2))

total_norm <= max_norm 이면:
  그대로 둔다.

total_norm > max_norm 이면:
  모든 gradient에 (max_norm / total_norm) 비율을 곱한다.

total_norm이 max_norm 이하라면 gradient를 바꾸지 않는다. 한도를 넘으면 모든 gradient에 같은 비율을 곱한다. 예를 들어 max_norm = 1.0이고 현재 gradient norm이 5.0이면 모든 gradient에 1/5을 곱한다.

원래 gradient: g = [3, 4]   → norm = 5
clip 후:       g' = [0.6, 0.8] → norm = 1

[3, 4]와 [0.6, 0.8]은 같은 방향을 가리킨다. 모든 성분에 같은 양의 비율을 곱했기 때문이다. 따라서 학습 방향 자체를 바꾸기보다 한 번에 이동하는 거리를 줄인다.

학습 루프에서 적용하는 위치

input token batch
  → model forward
  → cross entropy loss
  → loss.backward()        ← gradient 계산
  → gradient clipping       ← 여기
  → optimizer.step()        ← 파라미터 업데이트
  → optimizer.zero_grad()

클리핑은 backward() 뒤, optimizer.step() 전에 적용한다. backward() 전에는 아직 자를 gradient가 계산되지 않았다. step() 후에는 gradient를 사용한 파라미터 업데이트가 이미 끝났으므로 클리핑하기에 늦다.

learning rate와 weight decay는 역할이 다르다. learning rate는 모든 step에 적용되는 기본 보폭을 정한다. gradient clipping은 특정 step의 gradient가 한도를 넘을 때만 크기를 제한한다. weight decay는 파라미터 크기를 꾸준히 억제하지만, clipping은 순간적으로 커진 gradient를 대상으로 한다.

클리핑을 너무 강하게 적용하면 모델이 필요한 만큼 움직이지 못해 학습이 느려질 수 있다. 이 문서에서는 max_norm = 1.0에서 시작해 loss curve를 보며 조정하는 방식을 제시한다.

PyTorch에서 Gradient Clipping 적용

clip_grad_norm_은 모든 파라미터의 gradient를 모아 L2 norm을 계산한다. 그 norm이 max_norm보다 크면 모든 gradient에 max_norm / total_norm 비율을 곱한다. 따라서 이 호출은 loss.backward()로 gradient를 계산한 뒤, optimizer.step()으로 파라미터를 업데이트하기 전에 놓인다.

그래디언트 누적과 함께 쓸 때

gradient accumulation을 사용하면 여러 번 계산한 gradient를 모은 뒤 파라미터를 업데이트한다. 이때는 누적이 끝나고 optimizer.step()을 호출하기 직전에 한 번만 clip한다. 누적 중간마다 clip하면 각 단계의 gradient에 서로 다른 제한이 적용되어, 최종적으로 누적되는 gradient의 방향이 달라질 수 있다.

코드에 적힌 계산에서는 두 gradient를 합친 전체 norm이 약 11.18이다. 모든 성분에 같은 clip_coef를 곱하면 전체 norm은 1.0이 된다. g1과 g1_clipped의 코사인 유사도는 1.0으로 계산되므로 두 벡터의 방향은 같다. 이 설명은 코드와 수식에 따른 결과이며, 여기서는 코드의 실제 실행 여부를 별도로 확인하지 않았다.

적용할 때 기억할 점

gradient clipping은 전체 gradient의 L2 norm이 max_norm을 넘을 때 모든 gradient에 같은 비율을 곱한다. 적용 위치는 backward() 뒤이자 optimizer.step() 전이다. 그래디언트 누적과 함께 사용한다면 누적이 끝난 시점에 한 번 적용한다. learning rate가 매 step의 기본 보폭을 정한다면, clipping은 순간적으로 지나치게 커진 보폭을 제한한다.
