Attention은 부드러운 사전 조회다

한 줄 요약: Attention은 Python 딕셔너리처럼 key로 value를 찾는 구조로 비유할 수 있다. 다만 정확히 일치하는 key 하나를 고르는 대신, 모든 key와의 유사도를 계산해 value들을 비율에 따라 섞는다.

고정 벡터의 병목에서 다시 참조하기까지

RNN 기반 Seq2Seq 모델은 입력 시퀀스를 하나의 고정 벡터로 압축한다. 문장이 길어지면 앞쪽 정보가 사라질 수 있다. Bahdanau Attention은 이 병목을 다루기 위해 디코더가 매 시점마다 인코더의 모든 시점을 다시 참조하게 한다.

이 동작은 사전(dictionary) 조회에 빗대어 이해할 수 있다. 디코더의 현재 상태를 질문(query)으로 보고, 인코더의 각 시점 출력을 색인(key)이자 내용(value)으로 본다. 모델은 질문과 각 색인의 유사도를 계산한 뒤, 더 잘 맞는 시점의 정보가 더 많이 반영되도록 내용을 섞는다. 여기서 사전 조회는 Attention의 계산을 설명하기 위한 비유이며, Python 딕셔너리와 완전히 같은 연산이라는 뜻은 아니다.

Transformer의 Self-Attention도 query, key, value를 이용한다. Bahdanau Attention이 디코더에서 인코더의 시점들을 참조한다면, Self-Attention에서는 한 시퀀스 안의 토큰들이 서로를 조회한다. 따라서 “Attention = Soft Dictionary Lookup”이라는 관점은 두 구조의 공통된 계산 흐름을 비교하는 데 사용할 수 있다.

하드 룩업과 소프트 룩업

Python 딕셔너리는 하드 룩업(hard lookup)의 예다.

이 예에서는 key가 정확히 일치해야 한다. 일치하면 value 하나를 반환하고, 아니면 KeyError가 난다. 선택된 항목과 선택되지 않은 항목의 관계는 1과 0으로 구분된다.

Attention을 소프트 룩업(soft lookup)으로 설명할 때는 모든 key와의 유사도를 계산하고, 그 유사도에 따라 value를 섞는다는 점에 주목한다.

score(“cat”) = 0.7, score(“sat”) = 0.2, score(“mat”) = 0.1 result = 0.7 × value(“cat”) + 0.2 × value(“sat”) + 0.1 × value(“mat”)

이 예에서는 어떤 key도 선택 단계에서 완전히 버리지 않는다. 유사도가 높은 key의 value가 결과에 더 많이 반영된다. 유사도 점수를 softmax로 정규화하면 가중치의 합은 1이 된다.

왜 “부드러운” 조회인가

하드 룩업을 one-hot 선택으로 나타내면 하나만 1이고 나머지는 0이다. 이런 불연속적인 선택을 그대로 사용하면 선택 기준을 그래디언트로 학습하기 어렵다.

소프트 룩업은 softmax를 사용해 각 key에 0과 1 사이의 연속적인 가중치를 부여한다. softmax를 포함한 계산은 미분할 수 있으므로, 모델은 “어떤 key를 더 많이 볼지”에 영향을 주는 값을 역전파로 학습할 수 있다.

조회를 이루는 세 단계

여기서 다루는 Attention 계산은 유사도 계산, 정규화, 가중합의 세 단계로 읽을 수 있다.

%% Attention 소프트 룩업 단계
flowchart TD
  score["1. 유사도 계산<br/>Score<br/>query와 모든 key 비교<br/>결과: raw score"]
  normalize["2. 정규화<br/>Normalize<br/>softmax 적용<br/>결과: 합이 1인 attention weight"]
  weighted_sum["3. 가중합<br/>Weighted Sum<br/>weight × value를 모두 더함<br/>결과: context vector"]
  score --> normalize
  normalize --> weighted_sum

Bahdanau Attention은 유사도를 작은 신경망(additive)으로 계산하고, Transformer는 dot product를 사용한다. 유사도 계산법은 다르지만, 이 문서에서 설명하는 범위에서는 query로 key를 비교하고 그 결과에 따라 value를 읽는다는 공통 구조로 볼 수 있다.

수식으로 보기

score_i = dot(query, key_i)

weight_i = exp(score_i) / sum_j(exp(score_j))

context = sum_i(weight_i × value_i)

  • score_i: query와 i번째 key의 유사도다. 이 식에서 dot product가 크면 두 벡터가 비슷한 방향이다.
  • weight_i: softmax를 거친 정규화된 가중치다. 모든 weight의 합은 1이다.
  • context: 모든 value의 가중합이다. weight가 큰 value가 결과에 더 많이 반영된다.

Transformer에서는 score를 sqrt(d_k)로 나눈다(scaled dot-product). key 차원이 커질수록 dot product의 절대값도 커져 softmax가 한 토큰에 과하게 몰릴 수 있기 때문이다.

코드로 계산 흐름 따라가기

가장 단순한 소프트 룩업: projection 없이

아래 코드는 Q/K/V projection 없이 입력 벡터 자체로 attention을 계산한다. 유사도 계산, 정규화, 가중합이라는 소프트 룩업의 골격을 보여준다.

이 코드를 사전 비유에 대응시키면 다음과 같이 읽을 수 있다.

  • inputs @ inputs.T: 각 토큰(query)과 모든 토큰(key)의 유사도를 계산한다.
  • softmax: 유사도 점수를 합이 1인 비율로 바꾼다. 더 비슷한 key가 더 높은 가중치를 받는다.
  • attn_weights @ inputs: 그 비율에 따라 모든 value를 섞는다. 높은 가중치를 받은 토큰의 정보가 결과에 더 많이 반영된다.

이 예에서는 query와 key로 같은 입력 벡터를 사용한다. 따라서 각 벡터를 자기 자신과 곱한 점수가 크게 나타나 자기 자신에게 attention이 몰릴 수 있다는 한계가 있다.

W_Q, W_K, W_V를 추가한 소프트 룩업

projection을 추가하면 같은 입력을 서로 다른 역할의 표현으로 바꿀 수 있다.

  • W_Q는 “이 토큰이 어떤 정보를 찾는가”에 해당하는 변환을 학습한다.
  • W_K는 “이 토큰이 어떤 질문과 잘 매칭되는가”에 해당하는 변환을 학습한다.
  • W_V는 “매칭되었을 때 넘길 정보”에 해당하는 변환을 학습한다.

세 표현은 같은 입력 벡터에서 출발하지만 서로 다른 가중치를 거친다. 그 결과 “찾는 것”, “찾아지는 것”, “전달하는 것”을 분리해 학습할 수 있다. 이 분리는 자기 자신이 언제나 가장 높은 가중치를 받아야 한다는 제약을 없애지만, 특정 실행에서 실제 가중치가 어떻게 분포하는지는 계산 결과를 확인해야 한다.

텐서 흐름

%% Attention 텐서 흐름
flowchart TD
  input["입력 X<br/>(T, d_in)"]
  q["Q<br/>@ W_Q → (T, d_out)"]
  k["K<br/>@ W_K → (T, d_out)"]
  v["V<br/>@ W_V → (T, d_out)"]
  score["Score = Q @ K^T<br/>(T, T)"]
  weight["Weight<br/>row별 softmax → (T, T)"]
  output["Output = Weight @ V<br/>(T, d_out)"]
  input --> q
  input --> k
  input --> v
  q --> score
  k --> score
  score --> weight
  weight --> output
  v --> output

이 계산은 행렬 곱과 softmax로 모든 토큰의 조회를 함께 표현한다. 앞의 코드에서는 유사도 계산, 정규화, value의 가중합이 차례로 이어진다. 이처럼 토큰별 조회를 행렬 연산으로 구성하면 for문으로 각 조회를 하나씩 처리하지 않고 병렬로 계산할 수 있다.

이해를 연결하는 관점

Attention을 소프트 사전으로 보는 비유는 query로 key를 비교하고, 그 유사도에 따른 가중치로 value를 섞는 계산을 설명한다. 하드 룩업처럼 하나만 선택하지 않고 연속적인 가중치를 사용하므로, 어떤 key를 더 반영할지에 영향을 주는 값을 역전파로 학습할 수 있다. 이 문서에서 다룬 공통 구조는 Bahdanau Attention, Transformer Self-Attention, Cross-Attention을 비교하는 출발점으로 사용할 수 있다.
