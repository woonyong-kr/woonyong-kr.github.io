GPT 자기회귀 모델 계열 — GPT-1에서 GPT-4까지, 같은 구조가 스케일로 바꾼 것들

GPT 자기회귀 모델 계열 — GPT-1에서 GPT-4까지, 같은 구조가 스케일로 바꾼 것들

GPT 계열은 Transformer 디코더와 다음 토큰 예측이라는 공통 기반 위에서 모델 크기, 학습 데이터, 컨텍스트 길이, 정렬 방식을 확장해 왔다. 세대별 결과는 미세조정, 제로샷 전이, 인컨텍스트 학습, 멀티모달 입력처럼 서로 다른 활용 방식으로 나타났다.

같은 구조를 키우면 무엇이 달라지는가

GPT 구조 문서는 “Transformer 디코더 블록을 어떻게 조립하면 다음 토큰 예측 모델이 되는가”를 다뤘다. 구조를 이해한 뒤에는 같은 구조의 크기와 학습 데이터를 늘렸을 때 활용 방식이 어떻게 달라지는지를 살펴볼 수 있다.

GPT-1(117M)에서 GPT-3(175B)까지 공통 기반은 Transformer 디코더다. 그러나 세대가 바뀌면서 블록 수, 임베딩 차원, 데이터 규모, 컨텍스트 길이가 커졌고, 일부 세부 구조도 달라졌다. GPT-2는 Pre-Norm을 사용하고 컨텍스트 길이를 늘렸으며, GPT-3는 Sparse Attention을 부분적으로 적용했다. 따라서 이 계보를 구조가 전혀 바뀌지 않은 단순한 확대라고만 보기는 어렵다.

활용 방식의 변화도 세대별로 구분해서 봐야 한다. GPT-1은 사전학습 뒤 과업별 미세조정을 사용했다. GPT-2는 별도 미세조정 없이 여러 과업에서 의미 있는 결과를 보였다. GPT-3는 가중치를 바꾸지 않고 프롬프트에 설명이나 예시를 넣는 zero-shot, one-shot, few-shot 방식을 비교했다. 이 결과들은 규모 확대와 함께 나타났지만, 규모만이 각 변화의 유일한 원인이라고 단정할 근거는 이 문서에 제시되어 있지 않다.

각 세대의 모델 크기와 데이터, 구조 변경, 평가된 활용 방식을 차례로 보면 공통 기반과 세대별 차이를 함께 이해할 수 있다. 이어지는 구현 코드는 이 계보 가운데 GPT-2 구조를 설정값으로 재현하는 방법을 보여준다.

세대별 변화

GPT 계열 진화 한눈에 보기

  • GPT-1 (2018) GPT-2 (2019) GPT-3 (2020) GPT-4 (2023)
  • 117M 파라미터 1.5B 파라미터 175B 파라미터 추정 1.8T (MoE)
  • BooksCorpus WebText 40GB Common Crawl 570GB 비공개
  • ctx 512 ctx 1,024 ctx 2,048 ctx 8K~128K
  • “사전학습 + 미세조정” “제로샷 전이” “인컨텍스트 학습” “멀티모달 + 정렬”

이 비교에서 GPT-1부터 GPT-3까지의 수치는 공개된 모델 규모와 학습 설정을 설명한다. GPT-4의 파라미터 수와 MoE 여부는 공개된 아키텍처 정보가 아니라 추정치이므로, 확인된 사양과 구분해서 읽어야 한다.

GPT-1 — 사전학습 뒤 과업별로 미세조정한다 (2018)

GPT-1은 대규모 텍스트로 다음 토큰 예측을 사전학습한 뒤, 개별 과업에 맞게 미세조정하는 방식을 사용했다. 과업별 모델을 처음부터 학습하는 방식과 달리, 하나의 사전학습 모델에서 얻은 언어 표현을 여러 과업에 활용한다.

구조는 Transformer 디코더 12층이다. BooksCorpus(약 7,000권의 책)로 사전학습한 뒤 분류·함의·유사도·다지선다 과업마다 출력층을 바꿔 끼우고 미세조정했다. 문서에 제시된 평가 결과로는 12개 과업 중 9개에서 당시 최고 성능을 넘었다.

  • 파라미터: 117M
  • 구조: 12 layers, 768 dim, 12 heads
  • 컨텍스트 길이: 512
  • 데이터: BooksCorpus (~5GB)
  • 핵심 기여: “unsupervised pretraining → supervised fine-tuning” 2단계 패러다임 확립

이 결과는 다음 토큰 예측으로 학습한 표현을 여러 언어 과업의 출발점으로 사용할 수 있음을 보여준다. 다만 여기서 확인되는 범위는 GPT-1이 평가한 과업과 설정에 한정된다.

GPT-2 — 미세조정하지 않은 언어 모델의 과업 수행을 평가한다 (2019)

GPT-2는 모델과 데이터를 키웠을 때 별도 미세조정 없이도 여러 과업을 수행할 수 있는지를 살폈다.

공통 기반은 GPT-1과 같은 Transformer 디코더지만 세부 설정에는 변화가 있다. Layer Normalization을 각 sub-layer 앞으로 옮기는 Pre-Norm을 사용했고, 컨텍스트 길이를 512에서 1,024로 늘렸다.

학습 데이터와 모델 크기도 확대했다. Reddit에서 3점 이상 karma를 받은 링크의 텍스트를 모아 WebText(40GB)를 만들었고, 다음 네 가지 크기의 모델을 학습했다.

  • GPT-2 small: 12 layers, 768 dim, 117M → GPT-1과 같은 크기
  • GPT-2 medium: 24 layers, 1024 dim, 345M
  • GPT-2 large: 36 layers, 1280 dim, 774M
  • GPT-2 XL: 48 layers, 1600 dim, 1.5B

GPT-2 XL은 별도 미세조정 없이 텍스트 생성, 요약, 번역, 독해에서 의미 있는 결과를 보였다. GPT-2가 제시한 “언어 모델링이 곧 unsupervised multitask 학습이다”라는 관점은 하나의 언어 모델이 학습 데이터에 포함된 여러 과업의 패턴을 활용할 수 있다는 설명이다. 이 결과가 모든 과업에서 미세조정이 불필요하다는 뜻은 아니다.

GPT-3 — 프롬프트의 설명과 예시로 과업을 지정한다 (2020)

GPT-3는 가중치를 바꾸지 않고 프롬프트에 과업 설명이나 예시를 제공하는 방식으로 새 과업에 적응하는지를 평가했다.

구조는 GPT-2의 Transformer 디코더를 이어받았다. 다만 alternating dense and locally banded sparse attention 방식으로 Sparse Attention을 부분적으로 적용했다.

모델과 학습 데이터의 규모는 다음과 같다.

  • 96 layers, 12288 dim, 96 heads, 175B 파라미터
  • 컨텍스트 길이: 2,048
  • 데이터: Common Crawl 필터링 + WebText + Books + Wikipedia (약 570GB, 300B 토큰)

GPT-3는 프롬프트에 포함하는 정보에 따라 세 가지 활용 모드를 구분했다.

  • Zero-shot: 과업 설명만 제공. “Translate English to French:”
  • One-shot: 예시 1개 포함. “sea otter → loutre de mer, peppermint →”
  • Few-shot: 예시 여러 개 포함.

문서에 제시된 비교에서는 모델이 커질수록 few-shot 성능이 크게 올랐다. 13B 이하에서는 few-shot과 zero-shot의 차이가 작았지만, 175B에서는 few-shot 결과가 미세조정 모델에 근접한 과업이 나타났다. 이는 평가된 일부 과업에서 관찰된 결과이며, 모든 과업이나 모델 규모에 같은 관계가 성립한다고 일반화할 수는 없다.

GPT-4 — 공개된 기능과 공개되지 않은 구조를 구분한다 (2023)

GPT-4는 아키텍처 세부 사항을 공개하지 않았다. 이 문서에서 확인된 기능과 설정은 다음과 같다.

  • 텍스트와 이미지를 모두 입력으로 받는 멀티모달 모델
  • 컨텍스트 길이 8K (이후 32K, 128K로 확장)
  • RLHF로 정렬하여 안전성과 유용성을 높임

MoE(Mixture of Experts) 구조와 1.8T 파라미터라는 설명은 추정이며, 공개된 아키텍처 사양으로 다룰 수 없다. 사전학습 구조가 GPT-3의 연장선이라는 설명이나 RLHF가 실질적 품질 차이를 만들었다는 판단도 세부 구조와 평가 근거가 공개되지 않은 범위에서는 제한적으로 해석해야 한다. 이 문서에서 분명히 비교할 수 있는 변화는 멀티모달 입력과 인간 선호 정렬이 GPT-4의 주요 설명 축으로 등장했다는 점이다.

오픈 소스 계열 — LLaMA, Mistral

GPT-3 이후 OpenAI 모델의 세부 정보가 비공개로 전환된 가운데, LLaMA와 Mistral은 Transformer 디코더와 Causal LM 목적함수를 유지하면서 세부 설계를 바꾼 계열로 볼 수 있다.

  • LLaMA (Meta, 2023): GPT 구조에 RMSNorm, RoPE, SwiGLU, GQA를 적용. 7B65B. 공개 데이터만으로 학습해 GPT-3 175B에 필적하는 성능을 7B13B 크기에서 달성했다.
  • Mistral 7B (Mistral AI, 2023): Sliding Window Attention과 GQA로 추론 효율을 높인 7B 모델. LLaMA 2 13B를 여러 벤치마크에서 넘었다.

여기서 GPT 계열이라는 표현은 Transformer 디코더를 쌓고 Causal LM 목적함수로 다음 토큰을 예측한다는 구조적 공통점을 가리킨다. 정규화 방식(LayerNorm → RMSNorm), 위치 인코딩(학습 가능 → RoPE), 활성화 함수(GELU → SwiGLU), 어텐션 효율화(MHA → GQA)는 서로 다른 세부 설계다. 성능 비교는 해당 모델이 보고한 데이터와 벤치마크 범위에서 읽어야 한다.

세대별 활용 방식 비교

  • GPT-1 (2018)
    • 파라미터: 117M
    • 관찰된 변화: unsupervised pretraining으로 얻은 표현을 여러 과업에 활용
    • 활용: 사전학습 → 과업별 미세조정
  • GPT-2 (2019)
    • 파라미터: 1.5B
    • 관찰된 변화: 별도 미세조정 없이 여러 과업에서 결과를 생성
    • 활용: 제로샷 전이
  • GPT-3 (2020)
    • 파라미터: 175B
    • 관찰된 변화: 프롬프트 예시로 가중치 변경 없이 과업을 지정
    • 활용: 인컨텍스트 학습 (few-shot)
  • GPT-4 (2023)
    • 파라미터: 비공개 (1.8T MoE는 추정)
    • 공개된 변화: 멀티모달 입력 + RLHF 정렬
    • 활용: 범용 AI 어시스턴트

구현 코드에서 GPT-2 계보 확인하기

밑바닥 LLM 구현은 GPT-2 설정을 재현한다

밑바닥 LLM 과제의 GPTConfig는 GPT-2의 Transformer 디코더 설정을 표현한다. n_layers, emb_dim, n_heads 등에 GPT-2의 모델별 값을 넣으면 네 가지 크기를 구성할 수 있다.

이 설정에서 GPT-2의 네 가지 크기를 비교하는 값은 다음과 같다.

이 계산은 emb_dim, n_layers, n_heads에 모델별 설정을 넣고 전체 파라미터 수를 추산한다. 주석에 적힌 결과는 small 124M, medium 355M, large 774M, xl 1558M이다. 코드가 실제로 실행되었다는 기록은 이 문서에 없으므로, 이 값은 실행 검증 결과가 아니라 코드에 기재된 계산 결과로 다뤄야 한다.

GPT-1과 GPT-2의 LayerNorm 위치 비교

GPT-1은 Post-LN(sub-layer 뒤에 LayerNorm), GPT-2는 Pre-LN(sub-layer 앞에 LayerNorm)을 사용한다. 다음 구현은 두 방식에서 LayerNorm과 residual add의 순서가 어떻게 달라지는지 보여준다.

Pre-LN에서는 residual 경로에 LayerNorm이 놓이지 않는다. Post-LN에서는 residual add 뒤의 값이 LayerNorm을 거친다. 이 차이는 깊은 모델에서 gradient 흐름과 학습 안정성에 영향을 줄 수 있으며, GPT-2가 48층 모델에 Pre-LN을 사용했다. 다만 이 변경만으로 48층 학습이 가능해졌다고 단정할 근거는 이 문서에 제시되어 있지 않다.

설정이 모델 규모를 바꾸는 방식

  • config 변경
  • GPT-2 small | → | GPT-2 XL
  • 12L, 768D | n_layers: 48 | 48L, 1600D
  • 124M | emb_dim: 1600 | 1.5B
  • 텍스트 완성 | | 제로샷 QA
  • 수준 | | 수준

GPTModel 클래스의 공통 구조를 유지한 채 config의 모델 크기 관련 값을 바꾸면 GPT-2 small부터 GPT-2 XL까지 서로 다른 규모를 표현할 수 있다. 앞의 설정표에서는 n_layers, emb_dim, n_heads가 함께 달라지므로 두 값만 바뀐다고 설명해서는 안 된다.

모델 규모와 평가된 능력 사이의 관계도 구분해서 읽어야 한다. 같은 계열의 코드를 더 큰 설정으로 구성할 수 있다는 것은 구현상의 사실이다. 더 큰 모델이 제로샷 과업에서 더 나은 결과를 낸다는 주장은 별도의 학습 데이터와 평가 결과를 포함하며, 설정값 변경만으로 능력 변화가 자동으로 보장된다는 뜻은 아니다.

이 계보를 읽는 기준

GPT-1부터 GPT-3까지는 Transformer 디코더와 Causal LM이라는 공통 기반을 유지하면서 모델 크기, 데이터, 컨텍스트 길이와 일부 세부 구조를 확장했다. 그 과정에서 GPT-1의 과업별 미세조정, GPT-2의 제로샷 전이, GPT-3의 인컨텍스트 학습이 각각 주요 활용 방식으로 제시되었다. GPT-4에서는 멀티모달 입력과 RLHF 정렬이 주요 변화로 알려졌지만, 파라미터 수와 MoE 여부 같은 아키텍처 세부 사항은 공개 정보와 추정을 구분해야 한다.

밑바닥 LLM의 GPTConfig는 이 가운데 GPT-2의 모델 크기 차이를 설정값으로 표현한다. 이 구현은 공통 구조와 규모 차이를 이해하는 데 사용할 수 있다. 세대별 능력 차이를 설명할 때는 규모뿐 아니라 학습 데이터, 컨텍스트 길이, 세부 구조, 정렬 방식과 평가 범위도 함께 살펴봐야 한다.
