헤드 분할과 결합 — Multi-Head Attention이 여러 관점을 병렬로 보는 방법

확인 범위: 이 문서는 Multi-Head Attention의 head 분할·결합 구조와 고정된 d_model에서 head 수를 정하는 일반 원리를 설명하고, 제시된 PyTorch 구현을 통해 shape 변환과 파라미터 계산을 해설한다. 실제 코드의 동작, 라이브러리·구현 버전에 따른 차이, 실행 결과와 성능에 관한 판단은 별도의 실행 기록과 측정으로 검증해야 한다.

한 줄 요약: Multi-Head Attention은 Q/K/V를 여러 head로 쪼개 각각 독립 attention을 계산한 뒤, 결과를 이어 붙이고 하나의 출력 projection으로 합친다.

여러 관계를 병렬로 다루는 흐름

Self Attention에서 하나의 Q/K/V로 토큰 관계를 계산하면 하나의 attention 결과가 나온다. “The cat sat on the mat”에서 “sat”은 주어(“cat”), 위치(“on”), 목적어(“mat”)와 관련될 수 있다. Multi-Head Attention은 이런 관계를 여러 head에서 병렬로 다룰 수 있도록 Q/K/V의 d_model 차원을 나눈다. 각 head가 실제로 어떤 관계를 학습하는지는 학습 결과에 달려 있지만, 구조상 서로 다른 관계 패턴을 담을 수 있다.

전체 흐름은 projection, head 분할, head별 attention, concat, output projection 순서다. d_model이 n_heads로 나누어떨어질 때 각 head의 차원은 head_dim = d_model / n_heads가 된다. 분할 자체는 기존 텐서의 shape과 차원 순서를 바꾸는 연산이므로 학습 가능한 파라미터를 추가하지 않는다.

Projection에서 Output Projection까지

%% Multi-Head Attention의 projection, head split, attention, concat 흐름
flowchart TD
  input["입력 x<br/>(B, T, D)"]
  wq["W_Q<br/>Q: (B, H, T, D_h)"]
  wk["W_K<br/>K: (B, H, T, D_h)"]
  wv["W_V<br/>V: (B, H, T, D_h)"]
  attention["각 head별 독립 attention<br/>score = Q @ K^T / sqrt(head_dim)<br/>softmax -&gt; weights @ V<br/>(B, H, T, D_h)"]
  concat["Concat<br/>reshape -&gt; (B, T, D)"]
  output_projection["W_O projection<br/>출력: (B, T, D)"]
  input --> wq
  input --> wk
  input --> wv
  wq --> attention
  wk --> attention
  wv --> attention
  attention --> concat
  concat --> output_projection

1. Projection

입력 x에 가중치 행렬 W_Q, W_K, W_V를 각각 곱해 Q, K, V를 만든다. 각 행렬의 크기가 (d_model, d_model)이므로 Q, K, V의 shape은 모두 (B, T, d_model)이다.

2. Head 분할

각 텐서를 (B, T, d_model)에서 (B, T, n_heads, head_dim)으로 reshape한다. 이어서 차원 순서를 바꿔 (B, n_heads, T, head_dim)으로 만든다. head 차원이 분리되면 모든 head의 attention을 병렬로 계산할 수 있다.

3. Head별 Attention

각 head는 head_dim 차원의 Q, K, V로 스케일드 점곱 어텐션을 수행한다. 계산 순서는 score = Q @ K^T / sqrt(head_dim) → softmax → attention_output = weights @ V이다. 각 head의 출력 shape은 전체를 함께 표시하면 (B, n_heads, T, head_dim)이다.

4. Concat

head별 출력을 (B, n_heads, T, head_dim)에서 (B, T, n_heads, head_dim)으로 다시 옮긴다. 마지막 두 차원을 이어 붙이면 (B, T, n_heads × head_dim)이 되고, n_heads × head_dim = d_model이므로 (B, T, d_model)을 복원한다.

5. Output Projection

결합한 벡터에 W_O: (d_model, d_model)을 곱한다. 이 projection은 서로 다른 head의 출력을 하나의 표현으로 통합한다.

Head 수와 연산량의 관계

attention 행렬을 만드는 연산만 비교하면, head 수가 늘어도 모든 head를 합친 차원은 d_model로 유지된다.

Single-head: d_model = 768, attention 행렬 (T, T)을 만드는 비용은 T × T × 768.

Multi-head (12 heads): 각 head의 head_dim = 64, 비용은 T × T × 64 × 12 = T × T × 768.

따라서 이 예시에서 head별 attention 연산의 합은 single-head와 같다. 이 비교는 attention 행렬 계산을 기준으로 한 것이며, 전체 모듈에는 Q/K/V projection과 output projection W_O도 포함된다.

코드에서 찾는 Split과 Concat

밑바닥 LLM 책의 MultiHeadAttention 구현에서 projection과 head 분할에 필요한 구성은 다음과 같다.

W_q, W_k, W_v는 각각 (d_model, d_model) 행렬이다. out_proj는 concat한 결과를 통합하는 W_O에 해당한다.

Split은 Q.view(B, T, n_heads, head_dim).transpose(1, 2)에서 확인할 수 있다. d_model 차원을 n_heads × head_dim으로 나누고 head 차원을 앞으로 옮긴다. K와 V에도 같은 변환을 적용한다.

Concat은 context.transpose(1, 2).contiguous().view(B, T, C)에 해당한다. head 차원을 토큰 차원 뒤로 옮긴 다음 이어 붙여 d_model 차원을 복원한다. contiguous()는 transpose로 메모리 레이아웃이 불연속이 될 수 있으므로 view 전에 연속된 형태로 만드는 호출이다.

Shape 변환 추적

d_model = 8, n_heads = 2, head_dim = 4, T = 3인 경우의 분할과 결합 흐름은 다음과 같다.

%% Split과 concat의 shape 변환 추적
flowchart TD
  split_start["Split 시작<br/>Q: (1, 4, 8)"]
  split_view["view<br/>(1, 4, 2, 4)"]
  split_transpose["transpose(1, 2)<br/>(1, 2, 4, 4)"]
  scores["Attention per head<br/>scores: (1, 2, 4, 4)"]
  context["context<br/>(1, 2, 4, 4)"]
  concat_transpose["Concat: transpose(1, 2)<br/>(1, 4, 2, 4)"]
  concat_view["view<br/>(1, 4, 8)"]
  split_start --> split_view
  split_view --> split_transpose
  split_transpose --> scores
  scores --> context
  context --> concat_transpose
  concat_transpose --> concat_view

파라미터 수와 Head 분할

이 구현에서 Multi-Head Attention의 학습 가능한 주요 파라미터는 네 개의 행렬이다.

W_Q: d_model × d_model = 768 × 768 = 589,824 W_K: d_model × d_model = 768 × 768 = 589,824 W_V: d_model × d_model = 768 × 768 = 589,824 W_O: d_model × d_model = 768 × 768 = 589,824

총 파라미터 = 4 × d_model^2 = 4 × 768^2 = 2,359,296

이 계산은 bias를 제외한 값이다. d_model을 고정한 채 head 수만 바꾸면 네 행렬의 크기는 변하지 않는다. Head 분할은 이 행렬들의 출력을 재배치하므로 새 학습 파라미터를 만들지 않는다. bias를 사용하면 각 행렬에 d_model개씩 추가된다.

다시 설명할 때의 기준

Multi-Head Attention의 head 분할과 결합은 projection → split → head별 attention → concat → output projection 순서로 따라가면 된다. Split은 view + transpose, concat은 transpose + contiguous + view에 대응한다. Head 수를 늘리는 것은 고정된 d_model을 더 작은 head_dim으로 나누는 일이므로, 분할 자체의 파라미터 수와 모든 head의 attention 차원 합은 달라지지 않는다.
