경사 하강법

경사 하강법

범위: 이 문서는 경사 하강법의 갱신 원리와 학습률 선택 기준을 설명하고, 제시된 numpy 코드를 구현 예로 해설한다. 특정 코드의 동작·수렴·성능을 검증한 결과는 아니며, 이를 판단하려면 실제 코드와 버전, 실행 기록 및 성능 측정이 필요하다.

한 줄 요약: 경사 하강법(Gradient Descent)은 손실 함수의 기울기를 구해 그 반대 방향으로 파라미터를 조금씩 이동시켜 최소점을 찾는 최적화 알고리즘이다.

경사 하강법 문제

신경망 학습은 손실 함수 값을 가장 작게 만드는 가중치를 찾는 문제다. 가중치가 수백만 개이면 모든 조합을 시험하는 방법은 불가능하다. 손실 함수의 해를 한 번에 구하는 닫힌 식도 대부분 존재하지 않는다.

남은 방법은 현재 위치에서 손실이 줄어드는 방향을 알아내 그쪽으로 한 걸음 옮기는 것이다. 그 방향을 알려 주는 것이 기울기(gradient)다. 기울기는 손실이 가장 가파르게 증가하는 방향을 가리킨다. 따라서 기울기의 반대 방향으로 움직이면 손실이 줄어든다. 이 반복이 경사 하강법이다.

기울기를 구하는 방법은 수치 미분과 해석적 미분에서 다룬다. 경사 하강법은 그렇게 구한 기울기를 “어떻게 파라미터에 반영하는가”를 정의한다.

경사 하강법 구조

안갯속 산에서 가장 낮은 골짜기로 내려가는 상황에 비유할 수 있다. 발밑의 경사를 손으로 더듬어 가장 가파르게 내려가는 방향을 찾고, 그쪽으로 한 걸음 옮긴다. 이를 반복하면 골짜기에 도달한다. 한 걸음의 크기가 학습률(learning rate)이다.

갱신 규칙

파라미터를 x, 손실 함수를 f, 학습률을 lr이라 하면 갱신 규칙은 다음과 같다.

x_new = x_old - lr * (df/dx)
  • df/dx: x에 대한 손실의 기울기. 손실이 증가하는 방향.
  • -: 그 반대 방향으로 가야 손실이 줄어든다.
  • lr: 한 걸음의 크기. 기울기에 곱해 이동량을 정한다.

왜 학습률이 중요한가?

학습률이 너무 크면 → 최소점을 건너뛰어 발산한다. 학습률이 너무 작으면 → 수렴이 너무 느리고 지역 최소점에 갇힌다.

같은 함수 f(x) = x^2 + x 에서 x를 갱신해 본다. 최소점은 df/dx = 2x + 1 = 0, 즉 x = -0.5다.

lr = 0.1, x = 1.0 에서 시작:
  df/dx = 2(1.0) + 1 = 3.0
  x = 1.0 - 0.1 * 3.0 = 0.7      → 최소점(-0.5)에 가까워짐
lr = 1.5, x = 1.0 에서 시작:
  x = 1.0 - 1.5 * 3.0 = -3.5     → 최소점을 지나쳐 더 멀어짐 (발산)

학습률은 손실 곡면의 모양과 함께 수렴 여부를 좌우한다. 손실 곡면 자체의 성질은 볼록·비볼록 손실 곡면에서 다룬다.

경사 하강법 코드

numpy 구현 — 수치 미분 기반 경사 하강

numeric_gradient로 현재 위치의 기울기를 구하고, x -= lr * grad로 갱신한다. 이 한 줄이 경사 하강법의 전부다. step_num만큼 반복하며 손실이 낮은 쪽으로 이동한다.

numpy 구현 — 수치 미분으로 기울기 구하기

각 성분을 한 번에 하나씩 미세하게 흔들어 손실 변화량을 측정한다. 중앙 차분 (fx1 - fx2) / 2h은 한쪽 차분보다 오차가 작다. 파라미터가 많으면 느리므로 실제 학습에서는 오차역전파법으로 기울기를 구한다.

numpy 구현 — SGD로 일반화하기

스칼라 x 대신 여러 레이어의 가중치 dict 전체에 같은 규칙을 적용한 것이 SGD(확률적 경사 하강법)다. 미니배치 단위로 기울기를 구해 갱신하는 점만 다르다. Momentum, Adam 등 더 발전한 옵티마이저는 SGD 변형에서 다룬다.

갱신 흐름

%% 경사 하강법 갱신 흐름
flowchart TD
  current["현재 파라미터<br/>x (shape D)"]
  gradient["기울기 계산<br/>grad = df/dx (shape D)<br/>numeric / 역전파"]
  updated["갱신된 파라미터<br/>x_new"]
  repeat["다시 기울기 계산<br/>손실이 충분히 줄 때까지 반복"]
  minimum["최소점 도달<br/>수렴"]
  current -->|"f(x) 평가"| gradient
  gradient -->|"x -= lr * grad"| updated
  updated -->|"수렴 안 됨"| repeat
  repeat -->|"반복"| gradient
  updated -->|"수렴"| minimum

정리

경사 하강법은 손실의 기울기 반대 방향으로 파라미터를 조금씩 옮겨 최소점을 찾는다. 갱신 규칙은 x = x - lr * df/dx 한 줄이다. 학습률이 너무 크면 발산하고 너무 작으면 느리다. 기울기는 수치 미분으로 근사할 수 있지만, 실제 신경망은 오차역전파법으로 빠르게 구한다. SGD는 이 규칙을 미니배치와 다수 파라미터로 확장한 것이다.
