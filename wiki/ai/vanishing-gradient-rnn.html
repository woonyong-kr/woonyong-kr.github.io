RNN의 기울기 소실 — 시간축 반복 곱이 gradient를 지우는 현상

RNN의 기울기 소실 — 시간축 반복 곱이 gradient를 지우는 현상

확인 범위: RNN의 시간축 기울기 소실 원리와 구조적 대응을 설명한다. 예제 수치와 실제 학습 가능 거리는 코드·버전·측정 결과로 검증해야 한다.

한 줄 요약: RNN에서 기울기 소실은 BPTT로 시간축을 거슬러 역전파할 때, tanh 미분과 W_hh의 반복 곱으로 gradient가 0에 수렴하는 현상이다.

RNN의 기울기 소실 혼동

기울기 소실·폭발은 깊은 MLP에서 층 방향으로 발생한다. RNN에서는 같은 현상이 시간 방향으로 일어나며, 같은 가중치 W_hh를 반복 곱하기 때문에 더 심각하다.

이 문서는 RNN 시간축의 기울기 소실을 다룬다. 전체 BPTT 알고리즘과 수식 유도는 BPTT와 Truncated BPTT에서 상세히 설명한다.

RNN의 기울기 소실 계산

MLP vs RNN의 기울기 소실

MLP에서는 각 층이 다른 가중치를 가진다. 층마다 활성화 함수의 미분이 곱해지지만, 가중치 행렬이 서로 다르므로 소실 속도가 일정하지 않다.

RNN에서는 모든 시점에서 같은 W_hh를 곱한다. gradient가 [diag(1 - h_t²) · W_hh]를 T번 반복 곱한 것이므로, W_hh의 최대 특잇값이 1보다 작으면 기하급수적으로 0에 수렴한다.

dh_t/dh_k = Π_{i=k+1}^{t} [diag(1 - h_i²) · W_hh]

||W_hh|| < 1이면: ||dh_t/dh_k|| ≈ ||W_hh||^(t-k) → 0
||W_hh|| > 1이면: ||dh_t/dh_k|| ≈ ||W_hh||^(t-k) → ∞

왜 tanh가 소실을 일으키는가?

tanh의 미분은 1 - tanh(x)²다. 출력 범위가 (-1, 1)이므로 미분의 최댓값은 1(x=0일 때)이고, x가 0에서 멀어질수록 0에 가까워진다.

tanh(x)의 미분 = 1 - tanh(x)²

x = 0   → tanh(0) = 0     → 미분 = 1 - 0   = 1.0   (최대)
x = 1   → tanh(1) = 0.76  → 미분 = 1 - 0.58 = 0.42
x = 2   → tanh(2) = 0.96  → 미분 = 1 - 0.93 = 0.07
x = 3   → tanh(3) = 0.995 → 미분 = 1 - 0.99 = 0.01  (거의 0)

한 시점을 거슬러 올라갈 때 diag(1 - h_i²) · W_hh를 곱한다. tanh 미분이 0.4이고 W_hh의 특잇값이 0.9이면, 한 step당 약 0.36배로 줄어든다. 20 step이면 0.36²⁰ ≈ 4.7 × 10⁻⁹. gradient가 사실상 사라진다.

gradient 흐름 다이어그램

순전파(→)와 역전파(←)의 gradient 흐름을 비교한다.

  • 순전파:
  • x_1 x_2 x_3 x_4 x_T
  • h_0 → [W_hh] → h_1 → [W_hh] → h_2 → [W_hh] → h_3 → … → h_T
  • tanh tanh tanh
  • loss
  • 역전파 (dL/dh_1을 구하려면):
  • dL/dh_T ← × tanh’·W_hh ← × tanh’·W_hh ← … ← × tanh’·W_hh
  • 1.0 ~0.36 ~0.13 ~4.7e-9
  • (1 step) (2 steps) (20 steps)

같은 tanh'·W_hh를 반복 곱하므로, 먼 과거의 gradient는 지수적으로 감소한다. 이것이 RNN이 장기 의존성을 학습하지 못하는 근본 원인이다.

실전에서의 영향

  • sequence에서 20~30 step 이상 떨어진 token 사이의 관계는 학습이 거의 불가능하다.
  • 문장의 주어가 30 단어 뒤의 동사와 수일치해야 하는 경우, Vanilla RNN은 이 관계를 잡지 못한다.
  • LSTM은 cell state에 덧셈 경로를 만들어 gradient가 곱셈 없이 흐를 수 있게 했다. 이것이 장기 의존성 문제의 첫 번째 해법이다.
  • Transformer의 숏컷 연결은 같은 원리를 층 방향에 적용한 것이다. 덧셈 경로가 gradient를 보존한다.

RNN vs LSTM의 gradient 경로 비교

Vanilla RNN (곱셈 경로):
c 없음. h만 전달.

dL/dh_1 = dL/dh_T × Π [tanh'(h_i) · W_hh]    ← 곱셈 T-1번 → 소실

LSTM (덧셈 경로):
c_t = f_t * c_{t-1} + i_t * g_t

dL/dc_1 = dL/dc_T × Π [f_i]                   ← forget gate만 곱함
                                                  f_i ≈ 1이면 gradient 보존

LSTM의 cell state 경로에서 gradient는 forget gate f_t만 곱해진다. f_t가 1에 가까우면 gradient가 거의 손실 없이 먼 과거까지 전달된다. 이것이 LSTM이 장기 의존성을 학습할 수 있는 이유다.

MLP 역전파와의 비교

MLP의 역전파에서도 곱셈 누적이 일어나지만, 각 층의 가중치가 다르다.

특잇값과 소실/폭발의 관계

최대 특잇값이 1보다 작으면 소실, 1보다 크면 폭발한다. 정확히 1인 경우가 이상적이지만, 학습 중에 유지하기 어렵다. 실전에서는 gradient clipping(폭발 방지)과 LSTM/GRU(소실 방지)를 함께 쓴다.

정리

RNN의 기울기 소실은 BPTT에서 같은 W_hh와 tanh 미분을 시간축으로 반복 곱하기 때문에 발생한다. W_hh의 최대 특잇값이 1보다 작으면 gradient가 지수적으로 0에 수렴하여, 20 step 이상 떨어진 의존성은 학습이 불가능하다. 해법은 크게 세 가지다: Truncated BPTT로 역전파 범위를 제한하거나, LSTM/GRU처럼 덧셈 경로로 기억 구조를 바꾸거나, gradient clipping으로 폭발을 방지한다.
