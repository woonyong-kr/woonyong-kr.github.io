퍼셉트론과 다층 신경망

퍼셉트론과 다층 신경망

한 줄 요약: 단일 퍼셉트론은 직선 하나로만 분류할 수 있지만, 층을 쌓고 비선형 활성화 함수를 넣으면 XOR 같은 비선형 문제도 풀 수 있다.

퍼셉트론과 다층 신경망 구분

단일 퍼셉트론은 입력의 가중합에 계단 함수를 적용하는 선형 분류기다. AND, OR, NAND 같은 문제는 직선 하나로 분리할 수 있어서 퍼셉트론 하나로 충분하다.

하지만 XOR은 다르다. (0,0)과 (1,1)은 출력 0, (0,1)과 (1,0)은 출력 1인데, 이 네 점을 직선 하나로 분리할 수 없다. 이것이 퍼셉트론의 근본적 한계다.

해법은 퍼셉트론을 여러 층으로 쌓는 것이다. 다층 퍼셉트론(Multi-Layer Perceptron, MLP)은 각 층에서 비선형 활성화 함수를 적용하여 복잡한 결정 경계를 만든다. 밑바닥 딥러닝1 Ch2에서는 기존 게이트(AND, OR, NAND)를 조합하여 XOR을 구현하면서 이 원리를 보여준다.

퍼셉트론과 다층 신경망 차이

공간 변환으로 이해하기

단일 퍼셉트론은 2차원 공간에 직선 하나를 긋는 것과 같다. XOR 문제에서 (0,0)과 (1,1)은 출력 0, (0,1)과 (1,0)은 출력 1인데, 이 네 점을 직선 하나로 분리할 수 없다.

다층 퍼셉트론의 해법: 공간을 변환한다.

1층(은닉층)에서 입력 공간을 비틀어서 새로운 좌표계를 만든다. 이 새로운 공간에서는 XOR의 네 점이 직선 하나로 분리 가능한 배치가 된다. 2층(출력층)은 이 변환된 공간에서 직선을 긋는다.

밑바닥 딥러닝1에서는 이를 기존 게이트 조합으로 설명한다:

XOR(x1, x2) = AND(NAND(x1, x2), OR(x1, x2))

NAND와 OR이 각각 1층, AND가 2층 역할이다.

수학적 정의

단일 퍼셉트론의 출력:

y = step(w1 * x1 + w2 * x2 + b)

다층 퍼셉트론(2층)의 은닉층 출력 h와 최종 출력 y:

h = f(W1 @ x + b1)    -- 1층: 선형 변환 + 비선형 활성화
y = g(W2 @ h + b2)    -- 2층: 선형 변환 + 출력 활성화

행렬 표기로 쓰면:

h = f(W(1) * x + b(1))
y = g(W(2) * h + b(2))

여기서 f, g는 활성화 함수다. 만약 f와 g가 모두 선형이면 합성해도 여전히 선형(y = W’ * x + b’)이므로, 비선형 활성화 함수가 반드시 필요하다.

XOR 진리표 추적

입력 (1, 0) — 기대 출력: 1

  • NAND(1,0): -0.5 * 1 + (-0.5) * 0 + 0.7 = 0.2 > 0 → s1 = 1
  • OR(1,0): 0.5 * 1 + 0.5 * 0 - 0.2 = 0.3 > 0 → s2 = 1
  • AND(1,1): 0.5 * 1 + 0.5 * 1 - 0.7 = 0.3 > 0 → y = 1 (정답)

입력 (1, 1) — 기대 출력: 0

  • NAND(1,1): -0.5 * 1 + (-0.5) * 1 + 0.7 = -0.3 ≤ 0 → s1 = 0
  • OR(1,1): 0.5 * 1 + 0.5 * 1 - 0.2 = 0.8 > 0 → s2 = 1
  • AND(0,1): 0.5 * 0 + 0.5 * 1 - 0.7 = -0.2 ≤ 0 → y = 0 (정답)

전체 진리표:

x1x2s1(NAND)s2(OR)y(AND)기대값
001000
101111
011111
110100

단일 vs 다층 퍼셉트론 비교

특성단일 퍼셉트론다층 퍼셉트론
결정 경계직선(초평면) 1개곡선, 영역 조합
XOR 해결불가가능
표현력선형 함수만비선형 함수 가능
파라미터 수적음층/뉴런에 비례
범용 근사불가가능 (UAT)

범용 근사 정리(Universal Approximation Theorem): 은닉층이 1개 이상이고 충분한 뉴런을 가진 MLP는 임의의 연속 함수를 원하는 정밀도로 근사할 수 있다.

퍼셉트론과 다층 신경망 코드

numpy: 게이트 조합으로 XOR 구현

XOR은 단일 함수로 구현할 수 없다. NAND와 OR의 출력(s1, s2)이 은닉층 뉴런의 역할을 하고, 이 출력을 AND에 넣는 것이 2층 구조다.

numpy: 행렬 형태로 일반화

개별 게이트를 조합하는 방식이 행렬곱 한 번으로 압축된다. 이것이 MLP 순전파의 핵심 패턴이다.

numpy: 실제 MNIST 네트워크의 다층 구조

밑바닥 딥러닝1의 MNIST 네트워크는 XOR의 원리를 784차원 입력으로 확장한다.

XOR 예제에서 수동으로 설정했던 가중치가, 실제 네트워크에서는 He 초기화 후 학습으로 찾아가는 것이다.

PyTorch: 학습으로 XOR 해결

출력이 Y와 같은지는 실행해서 확인한다. 고정 seed를 사용해 초기화는 재현되지만, library와 실행 환경이 다르면 수렴 시점이 달라질 수 있다.

밑바닥 딥러닝1에서 수동으로 설정했던 가중치를, PyTorch에서는 loss.backward()와 optimizer.step()으로 자동 학습한다. 계단 함수 대신 sigmoid를 쓰는 이유는 미분 가능성 때문이다. 계단 함수는 미분값이 0이어서 gradient가 흐르지 않는다.

정리

단일 퍼셉트론은 선형 분류만 가능하다. XOR처럼 직선 하나로 분리할 수 없는 문제는 풀 수 없다. 다층 퍼셉트론은 층을 쌓고 비선형 활성화 함수를 적용하여 이 한계를 극복한다. NAND + OR → AND 조합이 2층 MLP의 가장 작은 예시이고, 범용 근사 정리에 따르면 은닉층이 충분한 MLP는 임의의 연속 함수를 근사할 수 있다.
