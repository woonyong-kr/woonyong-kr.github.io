전이 학습 — 고정 기준선에서 부분 미세조정까지

전이 학습은 큰 데이터셋에서 배운 표현을 새 문제의 출발점으로 재사용하는 방법이다. 핵심은 pretrained 모델을 가져오는 행위가 아니라, 무작위 초기화보다 나은지 같은 데이터 분할과 지표로 검증하는 데 있다.

1. 비교 가능한 기준선을 만든다

먼저 무작위 초기화 모델 또는 작은 직접 학습 모델의 validation 성능과 학습 시간을 기록한다. pretrained backbone을 쓰는 실험도 같은 train·validation split, 입력 크기, 증강과 지표를 사용해야 한다.

2. 특징 추출기로 고정한다

backbone의 가중치를 고정하고 새 task의 classifier head만 학습한다. 데이터가 적거나 원본 task와 비슷할수록 빠르고 안정적인 기준선이 된다. 이 단계에서 train 성능만 오르고 validation이 멈추면 head의 과적합을 먼저 의심한다.

3. 상위 층부터 부분 미세조정한다

고정 기준선이 부족하면 출력에 가까운 상위 block부터 푼다. pretrained 가중치를 훼손하지 않도록 head보다 낮은 learning rate를 쓰고, 한 번에 너무 많은 층을 풀지 않는다. 새 데이터가 원본 데이터와 멀수록 더 많은 층을 조정할 수 있지만 과적합과 catastrophic forgetting 위험도 커진다.

4. 효과를 판정한다

무작위 초기화, 고정 backbone, 부분 fine-tuning을 같은 조건으로 비교한다. 정확도뿐 아니라 class별 오류, 추론 비용, 학습 시간과 재현성을 함께 본다. pretrained 모델의 학습 데이터와 라이선스도 배포 판단에 포함한다.

예를 들어 고양이·개 분류 데이터 600장이라면 먼저 고정 backbone으로 head만 학습하고, 그다음 마지막 block 하나만 풀어 validation 성능이 실제로 오르는지 비교한다.

확인 문제

  • 현재 실험에서 변하지 않아야 할 비교 조건은 무엇인가?
  • 어떤 신호가 나타날 때 backbone의 일부를 풀 것인가?
  • 성능 향상이 pretrained 데이터의 누출이나 편향 때문은 아닌가?

컴퓨터 비전 학습 경로에서 이미지 표현과 CNN을 먼저 보고, 생성·복원 문제라면 생성 모델 학습 경로로 이어 간다.
