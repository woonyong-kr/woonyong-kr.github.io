소프트맥스

소프트맥스

범위: 이 문서는 소프트맥스의 수학적 성질, 수치 안정화, temperature와 cross-entropy 결합 원리 및 일반적인 선택 기준을 설명하며, 제시된 NumPy·PyTorch 코드는 적용 예시다. 특정 코드와 라이브러리 버전에서의 동작, 실행 결과, 수치 일치 여부 및 성능에 관한 판단은 실제 코드 확인과 별도의 실행·측정이 필요하다.

한 줄 요약: Softmax는 임의의 실수 벡터를 합이 1인 확률 분포로 변환한다. 분류 신경망의 출력층과 Attention score 정규화에 핵심적으로 쓰인다.

소프트맥스 필요성

신경망의 출력층은 각 클래스에 대한 점수(로짓, logit)를 내놓는다. 예를 들어 MNIST 10자리 분류에서 [2.0, 1.0, 0.1] 같은 raw score가 나온다. 이 점수만으로는 “클래스 0일 확률이 몇 %인지” 알 수 없다.

Softmax가 해결하는 문제:

  • 로짓은 음수도, 매우 큰 양수도 될 수 있다. 확률로 해석하려면 0~1 범위에 합이 1인 분포가 필요하다.
  • 단순히 max를 취하면 “가장 높은 점수” 하나만 남고 나머지 정보가 사라진다. Softmax는 순서를 보존하면서 모든 클래스에 확률을 배분한다.
  • Cross-entropy loss와 결합하면 역전파 기울기가 y - t(예측 - 정답)로 극히 간결해진다. 이 수학적 장점 때문에 softmax + cross-entropy를 항상 함께 쓴다.

소프트맥스 계산

수학적 정의

입력 벡터 a = (a1, a2, …, an)에 대해 softmax의 k번째 출력:

softmax(ak) = exp(ak) / (exp(a1) + exp(a2) + ... + exp(an))

핵심 성질:

  • 출력 범위: 0 < softmax(ak) < 1 — 항상 양수, 1 미만
  • 합 = 1: 모든 출력의 합이 정확히 1 — 확률 분포
  • 순서 보존: ai > aj이면 softmax(ai) > softmax(aj)
  • 지수적 강조: 큰 값은 더 크게, 작은 값은 더 작게 만든다

“경쟁적 정규화”로 이해하면 쉽다. 여러 후보가 각자 점수를 가지고 있을 때, softmax는 이 점수를 “파이의 비율”로 변환한다. 점수가 높을수록 큰 조각을 차지하고, 지수 함수 덕분에 점수 차이가 클수록 비율 차이가 극단적으로 벌어진다.

왜 overflow가 발생하는가?

exp(ak)는 ak가 크면 매우 큰 수가 된다. 예를 들어 exp(1000) = inf (float overflow).

해결: 최댓값 c = max(a)를 빼준다.

softmax(ak) = exp(ak - c) / sum_i(exp(ai - c))

분자와 분모에 동일한 exp(-c)가 곱해지므로 결과가 변하지 않는다.

exp(ak) * exp(-c) / (sum_i(exp(ai)) * exp(-c)) = exp(ak) / sum_i(exp(ai))

빼기 후 지수의 최댓값이 exp(0) = 1이 되므로 overflow가 발생하지 않는다.

왜 Temperature 스케일링을 쓰는가?

softmax(ak; T) = exp(ak / T) / sum_i(exp(ai / T))
  • T → 0: softmax가 argmax에 수렴한다. 가장 큰 값만 1, 나머지 0. “확신적” 분포.
  • T = 1: 기본 softmax.
  • T → ∞: 균등 분포에 수렴한다. 모든 클래스가 1/n. “불확실한” 분포.

LLM 텍스트 생성에서 temperature를 조절하여 창의성(높은 T)과 일관성(낮은 T)의 균형을 맞춘다.

Softmax + Cross-Entropy의 기울기

Cross-entropy loss: L = -sum_k(tk * log(yk))

여기서 tk는 원-핫 레이블, yk = softmax(ak).

Softmax 입력 ak에 대한 기울기:

dL/dak = yk - tk

이 결과가 놀라울 정도로 간결하다. 정답 클래스가 k=2이고 y2 = 0.7이면, 기울기는 0.7 - 1 = -0.3이다. “현재 출력과 정답의 차이”가 곧 기울기가 된다. 이 성질 덕분에 softmax와 cross-entropy를 항상 함께 사용한다.

숫자로 확인

기본 softmax:

입력: a = [2.0, 1.0, 0.1]

exp(2.0) = 7.389,  exp(1.0) = 2.718,  exp(0.1) = 1.105
합 = 11.212
softmax = [7.389/11.212, 2.718/11.212, 1.105/11.212] = [0.659, 0.242, 0.099]
합 검증: 0.659 + 0.242 + 0.099 = 1.000

overflow 방지 트릭:

입력: a = [1000, 1001, 999]

트릭 없이: exp(1000) = inf (overflow)

트릭 적용 (c = 1001):

  • a - c = [-1, 0, -2]
  • exp(-1) = 0.368, exp(0) = 1.000, exp(-2) = 0.135
  • 합 = 1.503
  • softmax = [0.245, 0.665, 0.090]

Temperature 효과 (a = [3.0, 1.0, 0.5]):

  • T=0.1 → [1.000, 0.000, 0.000] — 거의 argmax
  • T=0.5 → [0.953, 0.035, 0.012] — 매우 확신적
  • T=1.0 → [0.836, 0.113, 0.069] — 기본
  • T=2.0 → [0.583, 0.214, 0.167] — 부드러움
  • T=10.0 → [0.378, 0.321, 0.310] — 거의 균등

Softmax + Cross-Entropy 기울기:

정답: 클래스 0 (원-핫: [1, 0, 0]), 출력: y = [0.659, 0.242, 0.099]

dL/da = y - t
dL/da1 = 0.659 - 1 = -0.341  (정답 클래스: 확률을 높여야 한다)
dL/da2 = 0.242 - 0 =  0.242  (오답 클래스: 확률을 낮춰야 한다)
dL/da3 = 0.099 - 0 =  0.099  (오답 클래스: 확률을 낮춰야 한다)
기울기의 합: -0.341 + 0.242 + 0.099 = 0.000 (항상 0)

keepdims=True가 중요하다. (N,1) shape을 유지해야 (N, C) 행렬과 브로드캐스팅으로 빼기/나누기가 가능하다.

입력과 출력 shape은 모두 (batch_size, num_classes)이며, 출력의 각 행 합이 1인지 확인한다.

  sum["row sum<br/>shape = (N, 1)"]
  out["exp / sum<br/>shape = (N, C)"]
  x --> max
  max --> shifted
  shifted --> exp
  exp --> sum
  sum --> out

Softmax + Cross-Entropy 역전파:

%% Softmax와 Cross-Entropy 역전파 흐름
flowchart LR
  logits["Logits z<br/>raw score"]
  softmax["Softmax<br/>y = softmax(z)"]
  y["확률 y<br/>예측 분포"]
  loss["Cross-Entropy<br/>L = -sum(t log y)"]
  target["정답 t<br/>one-hot label"]
  gradient["역전파 결과<br/>dL/dz = y - t<br/>softmax + cross-entropy 결합"]
  logits --> softmax
  softmax --> y
  y --> loss
  target --> loss
  loss --> gradient
  gradient --> logits

핵심: softmax와 cross-entropy를 따로 미분하면 복잡하지만, 합쳐서 미분하면 y - t 로 극히 간단해진다.

정리

Softmax는 로짓을 확률 분포로 바꾸는 정규화 함수다. exp(a - max(a)) 트릭으로 overflow를 방지하고, cross-entropy loss와 결합하면 역전파 기울기가 y - t로 간결해진다. Temperature 파라미터로 분포의 날카로움을 조절할 수 있으며, LLM 텍스트 생성에서 창의성과 일관성의 균형을 맞추는 데 쓰인다. 학습 코드에서 CrossEntropyLoss를 쓸 때는 softmax를 중복 적용하지 않도록 주의한다.
