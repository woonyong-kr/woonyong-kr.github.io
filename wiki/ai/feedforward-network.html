Feedforward 네트워크

Feedforward 네트워크

범위: 이 문서는 Feedforward 네트워크의 일반적인 개념과 구조, 다른 신경망과의 구분 기준을 설명하고, 제시된 NeuralNetwork 코드와 MNIST 예시로 순방향 계산 흐름을 해설한다. 다만 특정 구현의 실제 동작, 라이브러리·버전별 세부 사항, 실행 결과와 성능은 검증하거나 측정한 결과로 다루지 않는다.

한 줄 요약: Feedforward 네트워크는 데이터가 입력층에서 출력층까지 한 방향으로만 흐르고, 출력이 다시 입력으로 되돌아가지 않는 신경망 구조다.

Feedforward 네트워크 문제

퍼셉트론을 여러 층 쌓으면 다층 퍼셉트론(MLP)이 된다. MLP는 XOR 같은 비선형 문제를 풀 수 있다. 그런데 이 “층을 쌓는다”는 것이 정확히 어떤 구조인가?

핵심은 데이터 흐름의 방향이다. 입력이 들어오면 첫 번째 층을 통과하고, 그 결과가 두 번째 층에 들어가고, 마지막 층에서 출력이 나온다. 출력이 다시 앞쪽 층으로 돌아가는 경로는 없다. 이 “앞으로만 가는(feed-forward)” 구조가 가장 기본적인 신경망 아키텍처다.

이 구조를 명확히 이해해야 나중에 출력이 다시 입력으로 돌아가는 순환 신경망(RNN)과 구분할 수 있다. Feedforward 네트워크는 고정된 크기의 입력을 받아 고정된 크기의 출력을 내는 함수다. 시간 개념이 없고, 기억이 없다.

Feedforward 네트워크 흐름

Feedforward의 정의

Feedforward 네트워크(순방향 신경망)는 계산 그래프에 순환(cycle)이 없는 신경망이다. 데이터는 입력층 → 은닉층(들) → 출력층으로만 흐른다. 어떤 층의 출력도 자기 자신이나 이전 층의 입력으로 되돌아가지 않는다.

“Feedforward”라는 이름은 정보가 앞으로만 먹여진다(fed forward)는 뜻이다. 반대 개념은 feedback(되먹임)이다. RNN은 이전 시점의 출력을 현재 시점의 입력으로 되먹이므로 feedforward가 아니다.

3가지 구성 요소

Feedforward 네트워크는 세 종류의 층으로 구성된다.

  • 입력층 (Input Layer): 외부 데이터를 받는다. MNIST에서는 28×28 = 784개 픽셀 값이 입력이다. 계산은 하지 않는다.
  • 은닉층 (Hidden Layer): 입력을 변환한다. 각 은닉층은 선형 변환(y = xW + b)과 비선형 활성화 함수의 조합이다. 층이 깊어질수록 더 복잡한 패턴을 표현할 수 있다.
  • 출력층 (Output Layer): 최종 결과를 내보낸다. 분류 문제에서는 Softmax로 확률을 출력하고, 회귀 문제에서는 선형 출력을 그대로 쓴다.
%% Feedforward 네트워크의 층 흐름
flowchart LR
  input["입력층<br/>Input<br/>(784,)"]
  hidden1["은닉층 1<br/>Affine<br/>+ ReLU<br/>변환 + 활성화"]
  hidden2["은닉층 2<br/>Affine<br/>+ ReLU<br/>변환 + 활성화"]
  output["출력층<br/>Affine<br/>+ Softmax<br/>확률로 변환"]
  input --> hidden1
  hidden1 --> hidden2
  hidden2 --> output

한 층의 패턴: 선형 변환 + 비선형 활성화

Feedforward 네트워크의 모든 은닉층은 같은 패턴을 반복한다.

z = x @ W + b          ← 선형 변환 (Affine)
a = activation(z)       ← 비선형 활성화 (ReLU, Sigmoid 등)

선형 변환만 반복하면 아무리 층을 쌓아도 하나의 선형 함수와 같다 (W2 @ W1 @ x = W' @ x). 층 사이에 비선형 활성화 함수를 넣어야 각 층이 의미를 가진다. 이것이 활성화 함수가 필수인 이유다.

Feedforward vs Recurrent

Feedforward 네트워크와 순환 신경망(RNN)의 차이는 데이터 흐름에 순환이 있느냐 없느냐다.

  • Feedforward: 입력 하나를 받아 출력 하나를 낸다. 이전 입력의 기억이 없다. 같은 입력에 항상 같은 출력이 나온다.
  • Recurrent: 이전 시점의 은닉 상태(hidden state)가 현재 시점의 입력으로 들어온다. 순서가 있는 데이터(텍스트, 시계열)를 다룰 수 있지만, 구조가 더 복잡하다.

CNN(합성곱 신경망)도 feedforward 구조다. 합성곱 연산이 선형 변환의 일종이고, 데이터가 앞으로만 흐른다. Transformer 블록도 기본적으로 feedforward 방향이지만, Self-Attention이라는 다른 종류의 연산을 포함한다.

Feedforward 네트워크 코드

OrderedDict로 층을 쌓는 구조

밑바닥부터 시작하는 딥러닝1의 NeuralNetwork 클래스는 OrderedDict에 층을 순서대로 넣어 feedforward 구조를 만든다.

OrderedDict는 삽입 순서를 보장한다. Affine1 → BatchNorm1 → ReLU1 → Dropout1 → Affine2 → ... → Softmax 순서가 곧 feedforward 경로다. 이 순서가 뒤바뀌거나 순환하면 feedforward가 아니게 된다.

forward() — 앞으로만 흐르는 계산

이 코드가 feedforward의 본질이다. for layer in self.layers.values()로 각 층을 순서대로 통과시키고, 이전 층의 출력 out이 다음 층의 입력이 된다. 되돌아가는 경로가 없다.

텐서 shape 변환 — MNIST 분류기의 feedforward

기본 설정 [512, 256] 은닉층의 shape 변환을 따라간다.

%% MNIST 분류기의 feedforward shape 흐름
flowchart LR
  input["입력<br/>(N, 784)"]
  affine1["Affine1<br/>(N, 512)"]
  relu1["ReLU1<br/>(N, 512)"]
  affine2["Affine2<br/>(N, 256)"]
  relu2["ReLU2<br/>(N, 256)"]
  affine3["Affine3<br/>(N, 10)"]
  softmax["Softmax<br/>(N, 10)"]
  input --> affine1
  affine1 --> relu1
  relu1 --> affine2
  affine2 --> relu2
  relu2 --> affine3
  affine3 --> softmax

각 화살표가 하나의 층이다. 왼쪽에서 오른쪽으로만 진행한다. 역방향(backward)은 학습(가중치 갱신)을 위한 것이지, 데이터 흐름이 되돌아가는 것이 아니다.

구체적 계산 — 입력 하나의 feedforward

MNIST 이미지 한 장(784 픽셀)이 네트워크를 통과하는 과정을 수치로 본다.

6번의 연산이 순서대로 실행된다. 각 단계의 출력이 다음 단계의 입력이 되고, 되돌아가는 연산은 없다. 이것이 feedforward 네트워크의 전부다.

정리

Feedforward 네트워크는 데이터가 입력층에서 출력층까지 한 방향으로만 흐르는 신경망이다. 각 은닉층은 선형 변환(Affine)과 비선형 활성화 함수(ReLU 등)를 반복한다. 출력이 이전 층으로 되돌아가는 경로가 없으므로, 같은 입력에 항상 같은 출력이 나오고, 이전 입력의 기억이 없다. MLP, CNN은 모두 feedforward 구조다. 시간 순서가 있는 데이터를 다루려면 은닉 상태를 되먹이는 RNN 구조가 필요하다.
