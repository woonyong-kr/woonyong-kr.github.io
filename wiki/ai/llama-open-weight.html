Llama 오픈 가중치

Llama 오픈 가중치

한 줄 요약: Llama는 Meta가 모델 가중치를 받을 수 있게 공개한 LLM 계열로, 로컬 실행·파인튜닝·파생 모델 생태계의 중요한 기반이지만 사용 전 라이선스와 허용 사용 정책을 확인해야 한다.

Llama를 볼 때는 “오픈소스인가?”보다 가중치를 내려받아 실행·수정·파인튜닝할 수 있는가, 그리고 어떤 라이선스 조건이 붙는가를 먼저 봐야 한다. Meta는 Llama 모델 가중치를 제공하지만, 모델별 license와 acceptable use policy를 함께 둔다.

Llama 오픈 가중치 필요성

닫힌 API 모델은 편하다. 하지만 모델 내부를 바꾸거나, 로컬에서 돌리거나, 데이터 보안을 위해 외부 API를 피해야 하는 상황에서는 가중치가 필요하다.

Llama 계열은 이 지점에서 자주 등장한다.

  • 연구자가 모델 구조와 tokenizer를 직접 확인한다.
  • 개발자가 LoRA/QLoRA 같은 방식으로 작은 도메인 모델을 만든다.
  • 로컬 PC나 사내 서버에서 llama.cpp 로컬 추론으로 실험한다.
  • 다른 팀이 Llama 기반 instruct 모델이나 domain model을 배포한다.

이 말은 즉, Llama는 “API로 호출하는 모델”이라기보다 내가 weight 파일을 받아 실행 환경과 튜닝 방식을 직접 선택할 수 있는 모델 계열로 이해하면 좋다.

로컬 실험 흐름은 보통 이렇게 나뉜다

로컬 실험 흐름은 보통 이렇게 나뉜다.

여기서 “오픈 가중치”라는 말은 소스 코드가 모두 공개되었다는 뜻이 아니다. 적어도 모델 weight를 받아서 실행할 수 있다는 뜻에 가깝다. 학습 데이터 전체, 학습 파이프라인, 모든 내부 결정이 공개되었다는 뜻으로 확대하면 안 된다.

Llama 오픈 가중치 적용 기준

Llama 계열을 선택할 때는 다음을 분리해서 본다.

  • 접근성
    • weight를 실제로 받을 수 있는가?
    • 어떤 배포 채널에서 license를 수락해야 하는가?
  • 사용 조건
    • 상업적 사용, 파생 모델, 출력물 사용, 금지 용도 조건이 있는가?
    • 회사나 프로젝트 정책상 acceptable use policy를 받아들일 수 있는가?
  • 실행 환경
    • GPU 서버에서 돌릴 것인가, 로컬 장비에서 돌릴 것인가?
    • llama.cpp처럼 GGUF 기반 런타임이 필요한가?
  • 학습/튜닝 목적
    • full fine-tuning이 필요한가, LoRA/QLoRA처럼 일부 파라미터만 조정해도 되는가?
    • 채팅 포맷 템플릿과 tokenizer가 데이터 형식에 맞는가?

정리

  1. Llama는 가중치를 받아 로컬 실행·파인튜닝·파생 모델을 만들 수 있는 오픈 가중치 LLM 계열이다.
  2. “오픈 가중치”는 weight를 받아 실행할 수 있다는 뜻이지, 학습 데이터·파이프라인까지 모두 공개된 오픈소스라는 뜻이 아니다.
  3. 그래서 사용 전 해당 버전의 license와 acceptable use policy를 확인하는 것이 첫 단계다.

직접 확인하려면: 쓰려는 Llama 버전의 license 문서에서 상업적 사용·파생 모델·금지 용도 조항을 직접 읽고, 프로젝트 정책과 맞는지 본다.
