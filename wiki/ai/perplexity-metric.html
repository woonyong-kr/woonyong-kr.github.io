퍼플렉서티

퍼플렉서티

확인 범위: 이 문서는 퍼플렉서티의 정의, 계산 원리, 해석과 비교 기준을 설명하고 입력에 포함된 코드를 계산 패턴의 예시로 제시한다. 특정 구현·버전에서의 동작이나 제시된 성능 수치는 실제 코드, 실행 기록, 측정 조건을 대조해 검증한 결과로 보지 않는다.

한 줄 요약: 퍼플렉서티(Perplexity, PPL)는 cross-entropy loss의 지수 변환이다. 모델이 다음 토큰을 예측할 때 “평균적으로 몇 개의 후보 중에서 고르는 것과 같은 수준인지”를 숫자 하나로 나타낸다.

퍼플렉서티 문제

언어 모델을 학습하면 loss가 내려간다. 하지만 “loss가 2.3이다”라는 숫자만으로는 모델이 얼마나 잘하는지 직관적으로 판단하기 어렵다. cross-entropy loss는 정보 이론의 단위(nat 또는 bit)이기 때문이다.

퍼플렉서티는 이 loss를 “모델이 매 토큰마다 균등하게 고르는 후보 수”로 바꿔준다. PPL = 50이면, 모델이 매 토큰을 예측할 때 50개 후보 중 하나를 고르는 수준이라는 뜻이다. 어휘 크기가 50,257인 GPT-2에서 PPL이 50이면 전체 어휘의 0.1%로 범위를 좁힌 것이므로 꽤 잘하는 편이다.

사전학습 중 train loss와 validation loss를 비교할 때, PPL로 변환하면 “지금 모델이 토큰당 몇 개 후보 수준인가”로 읽을 수 있어 해석이 쉬워진다.

퍼플렉서티 계산

비유

시험 문제를 푸는 학생을 생각하자. 4지선다 문제에서 찍기만 하면 PPL = 4이다. 공부를 해서 2개로 좁힐 수 있으면 PPL = 2이다. 답을 확신하면 PPL ≈ 1이다. PPL이 낮을수록 모델이 “덜 헷갈려한다.”

정의

cross-entropy loss L이 주어졌을 때:

PPL = exp(L)

여기서 L은 토큰당 평균 cross-entropy loss이다.

왜 exp인가?

cross-entropy loss는 정답 토큰의 확률에 음의 로그를 씌운 것이다.

L = -(1/N) * sum(log P(t_i | t_1, …, t_{i-1}))

N은 토큰 수, P(t_i | …)는 모델이 i번째 위치에서 정답 토큰에 부여한 확률이다.

만약 모델이 매 위치에서 K개의 토큰에 균등한 확률 1/K를 부여한다면:

L = -(1/N) * N * log(1/K) = log(K)

따라서:

PPL = exp(L) = exp(log(K)) = K

즉, PPL은 “균등 분포에서의 후보 수”와 같은 단위로 loss를 변환한 것이다.

수치 예시

모델의 평균 cross-entropy loss가 3.5일 때:

PPL = exp(3.5) ≈ 33.1

모델이 매 토큰마다 약 33개 후보 중에서 고르는 수준이다.

학습이 진행되어 loss가 2.0으로 내려가면:

PPL = exp(2.0) ≈ 7.4

후보가 7개 수준으로 줄었다. loss가 1.5 줄었을 뿐인데 PPL은 33에서 7로 크게 떨어졌다. exp 변환이기 때문에 loss의 작은 차이가 PPL에서는 큰 차이로 나타난다.

범위와 해석 기준

  • PPL = 1: 모델이 다음 토큰을 완벽하게 예측한다 (이론적 하한).
  • PPL = vocab_size: 모든 토큰에 균등한 확률을 부여한다 (학습하지 않은 모델).
  • GPT-2 (small, WebText): PPL ≈ 35 (원 논문 기준)
  • GPT-3 (175B, LAMBADA): PPL ≈ 3.0

PPL은 같은 데이터셋에서 측정해야 비교 가능하다. 데이터셋이 다르면 어휘 분포가 달라서 PPL 값이 직접 비교되지 않는다.

퍼플렉서티 코드

GPT 학습에서 PPL 계산 (밑바닥 LLM)

F.cross_entropy는 내부에서 softmax + 음의 로그를 합쳐서 계산한다. 반환값은 모든 위치의 평균 loss이다. 이 값에 exp를 씌우면 PPL이 된다.

핵심은 두 줄이다. 평균 loss를 구하고, math.exp로 변환한다. 이것이 PPL 계산의 전부다.

numpy로 직접 계산

PPL은 정답 토큰 확률의 기하평균의 역수이기도 하다. 확률이 높을수록 기하평균이 올라가고, 역수인 PPL은 내려간다.

shape 변환 추적

%% PPL 계산에서 텐서 shape가 loss와 perplexity로 변환되는 흐름
flowchart TD
  input["input_batch<br/>shape: (B, T)"]
  logits["logits<br/>shape: (B, T, V)"]
  flat["flatten<br/>logits_flat: (B*T, V)"]
  loss["cross_entropy<br/>입력: logits_flat"]

  input --> logits
  logits --> flat
  flat --> loss
  loss --> ppl

정리

퍼플렉서티는 cross-entropy loss에 exp를 씌운 것이다. “모델이 매 토큰마다 균등하게 K개 후보 중 하나를 고르는 수준”으로 해석한다. PPL이 낮을수록 모델이 다음 토큰을 잘 예측한다. 같은 데이터셋 기준으로 비교해야 의미가 있다. 학습 중 validation loss를 PPL로 변환하면 모델의 진전 상황을 직관적으로 파악할 수 있다.
