대조 손실

대조 손실

한 줄 요약: 대조 손실은 정답 레이블 대신 “두 샘플이 같은가 다른가”만 보고, 같은 쌍의 임베딩 거리는 줄이고 다른 쌍의 거리는 margin까지 벌리는 손실이다.

대조 손실 필요성

Cross Entropy Loss는 입력마다 정답 클래스가 정해져 있어야 한다. 개 사진에는 “개”라는 레이블이 붙어 있어야 학습한다. 그런데 정답 클래스를 매기기 어려운 문제가 있다.

  • 얼굴 인식: 세상의 모든 사람을 클래스로 둘 수 없다. 새 사람이 계속 등장한다.
  • 임베딩 학습: 문장이나 이미지를 벡터로 바꿀 때, “이 문장의 정답 벡터”는 존재하지 않는다.

이런 문제에서 필요한 정보는 절대적 클래스가 아니라 상대적 관계다. “이 두 얼굴은 같은 사람”, “이 두 문장은 같은 뜻” 같은 쌍(pair) 정보만 있으면 된다.

대조 손실은 이 쌍 정보만으로 학습한다. 같은 쌍은 임베딩 공간에서 가깝게, 다른 쌍은 멀게 만든다. 정답 벡터를 지정하지 않고도 “비슷함의 구조”를 학습하는 손실이다.

대조 손실 흐름

비유

자석을 떠올린다. 같은 쌍의 두 점은 끌어당기는 자석으로 붙인다. 다른 쌍의 두 점은 밀어내는 자석으로 떼어 놓는다. 단, 무한히 밀어내면 발산하므로 일정 거리(margin)까지만 민다. 그만큼 떨어지면 더 이상 힘을 주지 않는다.

정의 (margin 기반 contrastive loss)

두 임베딩 z1, z2와 쌍 레이블 y가 있다. y=1이면 같은 쌍(positive), y=0이면 다른 쌍(negative)이다.

먼저 두 임베딩 사이의 유클리드 거리를 구한다.

d = sqrt( sum_i (z1_i - z2_i)^2 )

손실은 다음과 같다.

L = 0.5 * [ y * d^2 + (1 - y) * max(margin - d, 0)^2 ]

각 항의 의미:

  • y * d^2
    • 같은 쌍일 때만 켜진다.
    • 거리 d가 클수록 손실이 커진다 → d를 줄이는 방향으로 학습한다.
  • (1 - y) * max(margin - d, 0)^2
    • 다른 쌍일 때만 켜진다.
    • d가 margin보다 작으면 손실 발생 → d를 키우는 방향으로 학습한다.
    • d가 margin 이상이면 max(margin - d, 0) = 0 → 손실 0. 더 밀지 않는다.

왜 margin이 필요한가?

margin이 없으면 다른 쌍을 무한히 멀리 밀어낸다. 거리가 커질수록 손실이 계속 줄어드니, 모델은 임베딩을 한없이 발산시킨다. 학습이 불안정해진다.

margin은 “이 정도 떨어졌으면 충분하다”는 경계다. margin=1.0이면 다른 쌍의 거리가 1.0에 도달하는 순간 그 쌍은 더 이상 손실에 기여하지 않는다. 모델은 아직 덜 떨어진 쌍에만 집중한다.

끌어당김과 밀어냄

%% 대조 손실의 끌어당김과 밀어냄
flowchart LR
  pos_z1["z1"]
  pos_loss["d를 0으로<br/>당김"]
  pos_z2["z2"]
  neg_z1["z1"]
  neg_loss["d를 margin까지<br/>밀어냄"]
  margin["margin<br/>이상은 손실 0"]
  neg_z2["z2"]
  pos_z1 --> pos_loss
  pos_loss --> pos_z2
  neg_z1 --> neg_loss
  neg_loss --> margin
  neg_z2 --> margin

현대적 변형: InfoNCE

쌍 하나만 보는 대신, 한 개의 positive와 여러 개의 negative를 한꺼번에 대조하면 학습이 더 빠르다. 이때 거리 대신 코사인 유사도를 쓰고, 분류처럼 softmax를 적용한 것이 InfoNCE다.

logits = (정규화된 q) · (정규화된 k)^T / tau      # (N, N) 유사도 행렬
L = CrossEntropy(logits, 대각선 인덱스)
  • tau(temperature): 유사도 분포의 날카로움을 조절한다. 작을수록 가장 비슷한 쌍에 집중한다.
  • 대각선이 positive(자기 짝), 나머지 열이 negative다.
  • 즉 InfoNCE는 softmax + cross entropy를 N개 후보 중 정답 짝 고르기로 재해석한 대조 손실이다. SimCLR, CLIP 같은 표현 학습이 이 형태를 쓴다.

대조 손실 코드

밑바닥 딥러닝1(numpy)과 밑바닥 LLM(PyTorch) 책 모두 대조 손실을 직접 구현하지 않는다. 아래는 표준 수식을 그대로 옮긴 교육용 구현이며, sandbox 실행으로 값을 검증했다.

numpy 구현 (margin 기반)

d는 쌍마다의 거리, pos는 같은 쌍에서만, neg는 다른 쌍에서만 켜진다. np.maximum(margin - d, 0)이 margin 너머의 밀어냄을 0으로 끊는다.

구체적 숫자로 추적하기

거리를 따라가면 동작이 보인다.

  • 쌍0 (y=1): d=0.1414 → 이미 가깝다. 손실 0.5*0.1414^2 ≈ 0.010. 더 당기라는 약한 신호.
  • 쌍1 (y=0): d=1.4142 ≥ margin=1.0 → 힌지가 0. 손실 0. 충분히 멀어 무시.
  • 쌍2 (y=1): d=0.2236 → 약하게 당김.

다른 쌍(쌍1)이 이미 margin을 넘었으므로 손실에 기여하지 않는다. 손실은 거의 같은 쌍의 잔여 거리에서만 나온다.

PyTorch 구현 (nn.Module + autograd)

F.pairwise_distance가 numpy의 거리 계산을, torch.clamp(..., min=0)이 np.maximum(..., 0)을 대신한다. nn.Module을 상속했으므로 모든 연산이 autograd 그래프에 기록된다.

loss.backward() 한 줄이 모든 임베딩에 대한 gradient를 채운다. numpy 버전은 미분식을 직접 유도해야 하지만, PyTorch는 requires_grad=True로 만든 텐서의 연산을 추적해 자동 미분한다.

텐서 shape 흐름 (InfoNCE)

%% InfoNCE 텐서 shape 흐름
flowchart LR
  q["q<br/>(N, D)"]
  q_norm["normalize(q)<br/>(N, D)"]
  k["k<br/>(N, D)"]
  k_norm["normalize(k)<br/>(N, D)"]
  matmul["q @ k.T<br/>logits (N, N)"]
  ce["CE(대각선)<br/>loss (스칼라)"]
  example["예: N=4, D=8<br/>(4,8) @ (8,4) = (4,4)<br/>행 i, 열 j = q_i와 k_j의 코사인 유사도<br/>정답 = [0, 1, 2, 3]"]
  q --> q_norm
  k --> k_norm
  q_norm --> matmul
  k_norm --> matmul
  matmul --> ce
  matmul -.-> example

행렬곱 한 번으로 모든 q-k 쌍의 유사도를 얻고, 대각선을 정답으로 두는 cross-entropy가 InfoNCE다. positive 1개와 negative N-1개를 동시에 대조한다.

정리

  • 대조 손실은 절대 클래스 대신 쌍 관계(같다/다르다)만으로 임베딩을 학습한다.
  • margin 기반: 같은 쌍은 d^2로 당기고, 다른 쌍은 max(margin-d,0)^2로 margin까지만 밀어낸다. margin이 발산을 막는다.
  • InfoNCE는 거리 대신 코사인 유사도 + softmax + cross-entropy로 N개 후보 중 정답 짝을 고르는 형태다. 표현 학습(SimCLR, CLIP)의 표준이다.
  • numpy 버전은 미분을 직접 유도해야 하지만, PyTorch는 nn.Module + loss.backward()로 autograd가 gradient를 자동 계산한다.
