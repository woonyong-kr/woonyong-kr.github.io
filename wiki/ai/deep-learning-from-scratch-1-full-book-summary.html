밑바닥부터 시작하는 딥러닝 1 — 전체 책 정리

확인 범위: 이 문서는 책의 장별 개념, 학습 흐름, 구현 선택 기준을 정리한 설명이며, 본문에 포함된 코드와 수치는 이해를 돕는 예시다. 특정 코드베이스·버전의 동작이나 실행 결과, 성능과 속도에 관한 판단은 실제 구현과 실행 기록 및 측정으로 별도 검증해야 한다.

한 줄 요약: NumPy만으로 퍼셉트론부터 CNN까지 신경망 부품을 직접 구현하며 원리를 익히는 책 전체를 장별 핵심 질문과 결과물로 압축하고, Ch4 수치 미분에서 Ch5 역전파로 같은 gradient를 빠르게 구하는 전환을 중심축으로 잡는다.

책의 목적

이 책의 목표는 딥러닝 프레임워크를 먼저 쓰는 것이 아니라, NumPy만으로 신경망의 핵심 부품을 직접 구현하면서 원리를 이해하는 것이다.

큰 흐름은 다음과 같다.

flowchart LR
  python["Python/NumPy 기초"] --> perceptron["퍼셉트론"]
  perceptron --> forward["신경망 순전파"]
  forward --> loss["손실 함수와 학습"]
  loss --> backprop["오차역전파법"]
  backprop --> optimization["학습 개선 기법"]
  optimization --> cnn["CNN"]
  cnn --> practice["깊은 네트워크와 실전 기술"]

이 책에서 가장 중요한 전환은 Ch4와 Ch5 사이에 있다.

Ch2 퍼셉트론

핵심

퍼셉트론은 여러 입력에 가중치를 곱하고, 편향을 더한 뒤, 임계값을 넘는지 판단하는 단순한 모델이다.

가중치 w는 각 입력의 중요도이고, 편향 b는 뉴런이 얼마나 쉽게 켜지는지를 조절한다.

단층 퍼셉트론

AND, NAND, OR 같은 선형적으로 나눌 수 있는 문제는 단층 퍼셉트론으로 표현할 수 있다.

이들은 모두 직선 하나로 0과 1 영역을 나눌 수 있다.

XOR의 의미

XOR은 단층 퍼셉트론으로 풀 수 없다. 직선 하나로는 XOR의 0과 1을 분리할 수 없기 때문이다.

하지만 NAND, OR, AND를 조합하면 XOR을 만들 수 있다.

이것이 다층 구조의 필요성을 보여준다.

이 장의 의미

Ch2는 “단순한 뉴런 하나로는 한계가 있지만, 여러 뉴런을 층으로 쌓으면 더 복잡한 함수를 표현할 수 있다”는 사실을 보여준다.

관련 문서:

  • 단일 퍼셉트론 — 입력을 받아 0 또는 1을 출력하는 가장 작은 판별기
  • 퍼셉트론과 다층 신경망

Ch3 신경망

핵심

신경망은 퍼셉트론을 여러 층으로 쌓은 구조다. Ch2의 퍼셉트론은 계단 함수처럼 딱 잘라 판단했지만, Ch3에서는 sigmoid, ReLU 같은 부드러운 활성화 함수를 사용한다.

전체 흐름:

flowchart LR
  input["입력"] --> affine["가중합"]
  affine --> activation["활성화 함수"]
  activation --> next["다음 층"]
  next --> output["출력층"]
  output --> softmax["softmax"]
  softmax --> probability["확률"]

활성화 함수

활성화 함수는 각 층에 비선형성을 넣는다. 비선형성이 없으면 여러 층을 쌓아도 결국 하나의 선형 변환과 같아진다.

주요 함수:

함수역할특징
step퍼셉트론 판단0 또는 1
sigmoid은닉층 활성화0~1, 부드럽지만 기울기 소실 가능
ReLU은닉층 활성화양수는 그대로, 음수는 0
identity회귀 출력층입력을 그대로 출력
softmax분류 출력층점수를 확률 분포로 변환

관련 문서:

  • 활성화 함수
  • 소프트맥스

순전파

순전파는 입력 데이터가 층을 차례로 통과해 출력으로 변환되는 과정이다.

핵심은 개별 뉴런 계산이 아니라 행렬곱으로 한 층 전체를 계산한다는 점이다.

손실 함수

손실 함수는 모델의 나쁨을 숫자로 나타내는 함수다. 학습은 이 손실을 줄이는 방향으로 진행된다.

대표 손실:

손실주 용도의미

Cross entropy분류정답 클래스에 준 확률

MNIST에서는 cross entropy가 자연스럽다.

정답 확률이 높으면 loss는 0에 가까워지고, 정답 확률이 낮으면 loss는 커진다.

미니배치

미니배치 학습은 전체 손실의 근사값을 사용해 빠르게 학습하는 방식이다.

용어:

수치 미분

수치 미분은 가중치를 아주 조금 바꿔보고 손실이 어떻게 변하는지 직접 계산한다.

신경망에서는 모든 파라미터 원소에 대해 이 작업을 반복한다.

이것이 편미분이다. 함수 인자가 배열 하나처럼 보여도, 그 배열 안의 각 원소는 수학적으로 별도의 변수다.

Gradient

gradient는 모든 편미분값을 모은 배열이다.

gradient는 loss가 증가하는 방향을 가리킨다. 따라서 학습에서는 반대 방향으로 움직인다.

연쇄법칙

역전파의 수학적 기반은 연쇄법칙이다.

신경망은 여러 함수가 연결된 큰 합성 함수다. 따라서 마지막 손실에서 시작해 각 층을 거꾸로 지나며 gradient를 계산한다.

flowchart RL
  loss["loss"] --> softmax["SoftmaxWithLoss.backward()"]
  softmax --> affine2["Affine.backward()"]
  affine2 --> relu["ReLU.backward()"]
  relu --> affine1["Affine.backward()"]
  affine1 --> input["입력 gradient"]

계층forwardbackward

Softmax-with-Loss 계층

softmax와 cross entropy를 합쳐 하나의 계층으로 다룬다.

flowchart LR
  logits["logits"] --> softmax["softmax"]
  softmax --> cross_entropy["cross entropy"]
  cross_entropy --> loss["loss"]

backward에서는 dlogits = (y - t) / batch_size를 계산한다.

이 결과가 Ch5 구현에서 매우 중요하다. 출력층에서 복잡한 미분 대신 예측 확률 - 정답 형태로 gradient가 나온다.

Ch7 합성곱 신경망 CNN

핵심

완전연결 신경망은 이미지를 1차원 벡터로 펼친다. 이 과정에서 이미지의 공간 구조가 사라진다.

CNN은 이미지의 높이, 너비, 채널 구조를 유지한 채 학습한다.

방식입력 표현공간 구조
Fully Connected(28, 28)을 (784,)로 펼침사라짐

합성곱

합성곱은 작은 필터를 이미지 위로 이동시키며 지역 패턴을 찾는 연산이다.

flowchart LR
  region["입력 이미지 일부 영역"] --> convolution["필터와 원소별 곱·합"]
  kernel["학습 가능한 필터"] --> convolution
  convolution --> feature["feature map의 한 값"]

필터는 엣지, 방향, 질감 같은 지역적 특징을 감지한다.

핵심 용어:

용어의미

stride필터를 몇 칸씩 이동할지
padding가장자리에 0 등을 채워 출력 크기를 조절
feature map필터 적용 결과
channel색상 또는 특징 차원

출력 크기:

Padding

padding은 이미지 가장자리 정보가 빨리 사라지는 것을 막고, 출력 크기를 조절한다.

Stride

stride가 커지면 필터가 더 크게 이동하므로 출력 크기가 작아진다.

Pooling

Pooling은 공간 크기를 줄이는 연산이다.

대표:

효과:

  • 특징 요약

im2col

합성곱을 그대로 for 루프로 구현하면 느리다. im2col은 입력 이미지를 펼쳐서 합성곱을 큰 행렬곱으로 바꾸는 기법이다.

장점:

  • 구현이 단순해진다.
  • NumPy의 빠른 행렬곱을 활용할 수 있다.

단점:

  • 메모리를 더 많이 사용한다.

  pool2 --> affine1["Affine"] --> relu3["ReLU"] --> affine2["Affine"]

CNN은 이미지 분류에서 강력한 성능을 낸다. MNIST처럼 작은 데이터에서도 완전연결망보다 이미지 구조를 더 잘 활용한다.

특히 헷갈리기 쉬운 오해

1. softmax는 정답을 만드는 함수가 아니다

softmax는 현재 점수를 확률로 바꾸는 함수다. 학습은 그 확률과 정답을 비교해 loss를 만들고, loss의 gradient로 가중치를 수정하면서 일어난다.

2. loss 값이 새 가중치가 되는 것이 아니다

loss는 채점 점수다. 새 가중치는 gradient로 만든다.

3. 좋은 상태는 가중치가 0인 상태가 아니다

좋은 상태는 정답 클래스의 softmax 확률이 1에 가깝고, cross entropy loss가 0에 가까운 상태다.

4. 편미분은 배열 인자 하나의 미분이 아니다

코드에서 x가 하나의 배열로 전달되어도, 수학적으로는 x[0], x[1], … 각각이 별도의 변수다. 각 원소를 하나씩 바꾸고 나머지는 고정하기 때문에 편미분이다.

5. 수치 미분과 역전파는 다른 gradient를 구하는 것이 아니다

둘 다 같은 목적의 gradient를 구한다. 차이는 계산 방법과 속도다.
