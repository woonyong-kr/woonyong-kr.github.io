다층 RNN — 은닉층을 쌓아 표현력을 높이는 순환 신경망

다층 RNN — 은닉층을 쌓아 표현력을 높이는 순환 신경망

범위: 이 문서는 다층 RNN의 구조와 표현력, 층 수 및 Dropout의 일반 원리와 선택 기준을 개념적으로 설명하고, 제시된 NumPy 예제로 계산 흐름·shape·파라미터 수를 보여준다. 특정 라이브러리의 동작이나 모델별 성능, 적정 깊이와 학습 안정성에 관한 판단은 실제 코드·버전·실행 기록 또는 성능 측정으로 검증한 결과가 아니다.

한 줄 요약: 다층 RNN(Stacked RNN)은 RNN 층을 여러 개 쌓아, 아래층이 저수준 패턴을 뽑고 위층이 고수준 패턴을 조합하게 만드는 구조다.

다층 RNN 문제

RNN 은닉 상태에서 Vanilla RNN의 기본 구조를 봤다. 하나의 은닉층이 매 시점마다 h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)를 계산한다.

MLP에서 은닉층을 하나만 쓰면 표현력이 부족해서 여러 층을 쌓는 것과 같은 동기다. RNN도 은닉층이 하나면 시간축 패턴은 잡을 수 있지만, 입력의 추상화 수준은 한 단계뿐이다.

예를 들어 자연어 처리에서 1층 RNN은 단어 수준의 패턴(주어-동사 일치, 인접 단어 관계)을 포착한다. 하지만 문단 수준의 주제 전환이나 감성의 복합적 변화를 잡으려면 더 높은 수준의 표현이 필요하다. 층을 쌓으면 아래층의 출력이 위층의 입력이 되어 점점 추상적인 패턴을 조합할 수 있다.

실제로 기계 번역, 음성 인식 등에서 2~4층 RNN이 1층보다 뚜렷하게 성능이 좋다. Transformer 이전의 Seq2Seq 모델 대부분이 다층 RNN을 사용했다.

다층 RNN 구조

비유: 공장 조립 라인을 생각한다. 1층 작업자가 원자재에서 부품을 깎아내고, 2층 작업자가 부품을 조립하고, 3층 작업자가 완성품을 검사한다. 각 층은 자기 시간표대로 일하면서 아래층이 만든 결과물을 입력으로 받는다.

정의: 다층 RNN은 L개의 RNN 층을 수직으로 쌓은 구조다. l번째 층의 시점 t 계산은 다음과 같다.

h_t^(l) = f(W_xh^(l) · h_t^(l-1) + W_hh^(l) · h_{t-1}^(l) + b^(l))
  • h_t^(l-1): 아래층(l-1)의 시점 t 은닉 상태. 1층이면 입력 x_t가 이 자리에 들어간다.
  • h_{t-1}^(l): 같은 층(l)의 이전 시점 은닉 상태.
  • f: 활성화 함수 (tanh 또는 LSTM/GRU cell).

동작 순서:

  1. 시점 t의 입력 x_t가 1층 RNN에 들어간다.
  2. 1층이 h_t^(1)을 계산한다.
  3. h_t^(1)이 2층의 입력이 된다.
  4. 2층이 h_t^(2)를 계산한다.
  5. L층까지 반복한 후, 최상위층 h_t^(L)이 출력에 사용된다.
  • 시점 t의 데이터 흐름 (3층 Stacked RNN):
  • x_t
  • 1층 RNN | ← h_{t-1}
  • 저수준 패턴
  • h_t
  • 2층 RNN | ← h_{t-1}
  • 중간 수준 패턴
  • h_t
  • 3층 RNN | ← h_{t-1}
  • 고수준 패턴
  • h_t
  • 출력 y_t

시간축으로 펼치면 2차원 격자가 된다. 가로축은 시간(t), 세로축은 층(l)이다. 각 노드는 아래쪽(같은 시점의 아래층)과 왼쪽(같은 층의 이전 시점)에서 입력을 받는다.

  • 시간 → t=1 t=2 t=3
  • x_1 x_2 x_3
  • 1층: h_1^(1) → h_2^(1) → h_3
  • 2층: h_1^(2) → h_2^(2) → h_3
  • 3층: h_1^(3) → h_2^(3) → h_3
  • y_1 y_2 y_3

왜 깊어지면 표현력이 올라가는가?

MLP에서 Feedforward 네트워크를 깊게 쌓으면 앞쪽 층이 저수준 특징(선분, 모서리)을 추출하고 뒤쪽 층이 고수준 특징(숫자 형태)을 조합하는 것과 같다.

다층 RNN에서도 비슷한 현상이 관찰된다.

  • 1층: 단어 수준의 형태소, 품사 패턴
  • 2층: 구(phrase) 수준의 구문 구조
  • 3층: 문장 수준의 의미, 감성

다만 RNN에서 층을 깊게 쌓는 데는 한계가 있다. MLP나 CNN은 수십수백 층을 쌓지만, RNN은 보통 24층이 한계다. 이유는 두 가지다.

  • 시간축과 층축 두 방향으로 gradient가 흘러야 하므로 기울기 소실·폭발이 더 심해진다.
  • 층마다 sequence 전체를 순차 계산해야 하므로 계산 비용이 선형으로 늘어난다.

다층 RNN 코드

다층 RNN numpy 구현

핵심은 안쪽 for문이다. layer_input이 1층에서는 x_t이고, 2층부터는 바로 아래층의 h[l-1]이 된다. 각 층은 자신만의 W_xh, W_hh를 가진다.

shape 변환 추적

입력: x_t (4,)
  1층: W_xh^(1) (3, 4) @ x_t (4,) + W_hh^(1) (3, 3) @ h^(1) (3,) → h^(1) (3,)
  2층: W_xh^(2) (3, 3) @ h^(1) (3,) + W_hh^(2) (3, 3) @ h^(2) (3,) → h^(2) (3,)
  3층: W_xh^(3) (3, 3) @ h^(2) (3,) + W_hh^(3) (3, 3) @ h^(3) (3,) → h^(3) (3,)
출력: h^(3) (3,)

1층의 W_xh만 shape이 (hidden_dim, input_dim)이고, 나머지 층은 모두 (hidden_dim, hidden_dim)이다. 아래층과 위층의 hidden_dim이 같으면 이렇게 깔끔하게 맞아떨어진다.

파라미터 수 비교

1층 RNN:
  W_xh: 3 × 4 = 12
  W_hh: 3 × 3 = 9
  b: 3
  합계: 24

3층 Stacked RNN:
  1층: 3×4 + 3×3 + 3 = 24
  2층: 3×3 + 3×3 + 3 = 21
  3층: 3×3 + 3×3 + 3 = 21
  합계: 66

층을 3배로 늘려도 파라미터 수는 약 3배다. hidden_dim을 3배로 키우면 파라미터가 9배 이상 늘어나는 것과 비교하면, 층을 쌓는 것이 파라미터 효율적으로 표현력을 높이는 방법이다.

Dropout과 다층 RNN

다층 RNN에서는 층 사이에 Dropout을 넣는 것이 일반적이다. 시간축 방향에는 Dropout을 넣지 않는다. 시간축에 넣으면 은닉 상태의 연속성이 깨져서 장기 의존성이 더 나빠진다.

x_t → 1층 RNN → Dropout → 2층 RNN → Dropout → 3층 RNN → y_t
                 ↑                    ↑
            층 사이에만 적용     시간축에는 적용하지 않음

이 규칙은 PyTorch의 nn.RNN(dropout=0.2, num_layers=3) 구현에서도 동일하다. dropout 인자는 마지막 층을 제외한 각 층의 출력에만 적용된다.

실전에서의 층 수

  • 1층: baseline. 간단한 sequence 과제에 충분하다.
  • 2층: 대부분의 과제에서 1층 대비 성능이 올라간다.
  • 3~4층: 기계 번역, 음성 인식 등 복잡한 과제에서 사용한다. Google의 GNMT(2016)는 8층 LSTM을 사용했지만, 이 정도 깊이는 residual connection 없이는 학습이 어렵다.
  • 5층 이상: 기울기 소실이 심해져 숏컷 연결이나 Layer Normalization 없이는 학습이 불안정하다.

Transformer가 12~96층을 쌓을 수 있는 것과 대조적이다. Transformer는 시간축의 순차 의존이 없고, residual connection과 LayerNorm이 기본 구조에 포함되어 있기 때문이다.

정리

다층 RNN은 RNN 층을 수직으로 쌓아 아래층은 저수준 패턴, 위층은 고수준 패턴을 조합하게 만드는 구조다. 각 층은 자기만의 가중치를 가지며, 아래층의 은닉 상태를 입력으로 받는다. 실전에서는 2~4층이 일반적이고, Dropout은 층 사이에만 적용한다. 시간축과 층축 두 방향의 기울기 흐름 때문에 MLP처럼 수십 층을 쌓기는 어렵다.
