인공지능 문제를 구분하는 첫 기준

우리가 해결 절차를 정확히 알고 있다면 일반 프로그램으로 충분하다. 반면 사진에서 나이를 추정하거나 자연어의 의도를 분류하는 일처럼 규칙을 빠짐없이 쓰기 어려운 문제는 데이터에서 패턴을 학습하는 접근이 필요할 수 있다. AI를 공부할 때 첫 질문은 “어떤 모델을 쓸까?”가 아니라 “이 문제에서 사람이 알고 있는 규칙과 관찰 가능한 데이터는 무엇인가?”다.

AI가 필요한 장면을 구분한다

모든 자동화가 AI는 아니다. 정렬, 세금 계산, 정해진 형식 검증처럼 입력과 절차가 명확한 일은 알고리즘으로 직접 구현하는 편이 예측 가능하고 검증하기 쉽다. AI가 주로 필요한 장면은 입력의 변형이 많고, 규칙을 사람이 전부 열거하기 어렵지만, 성공과 실패의 사례나 환경의 반응은 관찰할 수 있을 때다.

예를 들어 메일 주소 형식 검사는 규칙으로 작성할 수 있다. 반면 스팸 메일 판별은 발신자, 문장, 링크와 사용자 행동이 계속 달라지므로 과거 표본에서 패턴을 학습하는 방식이 유리할 수 있다. 이때도 모델은 “스팸의 본질을 이해한 것”이 아니라 주어진 데이터와 목적함수 안에서 구분 경계를 학습한 것이다.

네 가지 접근을 같은 질문으로 비교한다

  • 기호적 추론은 지식과 규칙을 사람이 표현하고 추론 엔진이 결론을 도출한다. 결정 경로를 설명하기 쉽지만 규칙을 추출하고 유지하기 어렵다.
  • 신경망 학습은 입력과 원하는 결과의 사례를 이용해 가중치를 조정한다. 이미지·음성·텍스트처럼 규칙을 직접 쓰기 어려운 문제에 강하지만 데이터와 평가 설계가 결과를 제한한다.
  • 탐색·진화적 최적화는 후보 해를 만들고 평가하며 더 나은 후보를 찾는다. 정답 데이터보다 적합도나 제약을 정의하기 쉬운 문제에 쓸 수 있다.
  • 강화학습·에이전트 접근은 환경에서 행동하고 보상을 관찰하며 정책을 개선한다. 한 번의 정답보다 연속된 선택의 결과가 중요한 문제에 맞는다.

실제 시스템은 한 접근만 사용하지 않는다. 음성을 신경망으로 인식한 뒤 명시적 업무 규칙으로 권한을 확인하고, 검색 알고리즘으로 후보를 고른 다음 사람이 최종 승인할 수 있다. 따라서 “AI인가 아닌가”보다 각 단계의 책임과 검증 방법을 분리하는 편이 중요하다.

약한 AI와 범용 지능을 혼동하지 않는다

현재 사용하는 추천, 분류, 생성 모델은 특정 입력과 목표 안에서 동작하는 약한 AI다. 여러 작업을 수행하는 대규모 언어 모델도 학습 데이터, 문맥, 도구와 평가 범위에 묶여 있다. 자연스러운 대화를 만든다는 사실만으로 인간과 같은 이해·의식·일반적 판단 능력을 증명하지는 않는다. 튜링 테스트 역시 대화에서 사람과 구별하기 어려운지를 보는 행동 기준이지 내부 이해를 측정하는 완전한 정의가 아니다.

작은 예제로 접근을 선택한다

“지원할 개발자 공고를 찾는다”는 목표를 생각해보자.

  1. 지역·경력·고용 형태 같은 필수 조건은 명시적 규칙으로 거른다.
  2. 공고와 프로젝트 경험의 의미 유사성은 텍스트 표현이나 언어 모델로 보조할 수 있다.
  3. 지원 여부는 근거와 부족한 조건을 사람이 확인해 결정한다.
  4. 지원 결과가 쌓이면 추천 기준이 실제 결과와 맞았는지 평가한다.

모든 단계를 하나의 모델에 맡기지 않으면 오류가 난 지점과 수정할 규칙을 다시 찾기 쉽다.

기초에서 응용까지 읽는 순서

문제 유형을 고른 뒤에는 다음 순서로 이동한다.

  1. 기호 AI와 규칙 기반 추론에서 사실·규칙·탐색을 본다.
  2. 신경망과 딥러닝에서 데이터로 표현을 학습하는 원리를 본다.
  3. 컴퓨터 비전 학습 경로와 자연어 처리 학습 경로에서 입력과 출력 구조를 비교한다.
  4. 생성 모델, 강화학습, 멀티모달 학습으로 문제 범위를 확장한다.
  5. 책임 있는 AI에서 실제 사용 조건과 검증 책임을 확인한다.

이 순서는 모델의 최신성 순위가 아니라 선수 개념 순서다. 이미 아는 단계는 건너뛰되, 새 문제에서는 입력·정답·평가 기준부터 다시 고정한다.

스스로 확인할 질문

  • 지금 문제는 절차를 모르는가, 아니면 절차는 알지만 구현 비용이 큰가?
  • 학습 데이터의 정답은 누가 어떤 기준으로 만들었는가?
  • 모델이 틀렸을 때 관찰할 수 있는 실패와 책임자는 누구인가?
  • AI 없이 해결한 기준선과 비교했을 때 실제로 무엇이 좋아졌는가?
