역전파 계층 구현

역전파 계층 구현

한 줄 요약: 신경망의 각 계층(Affine, ReLU, Softmax-with-Loss)을 forward와 backward 메서드를 가진 독립 모듈로 구현하면, 역전파가 계층을 역순으로 호출하는 것만으로 완성된다.

역전파 계층 구현 구분

오차역전파법의 원리를 이해했다고 해서, 실제 신경망에서 gradient가 어떻게 흐르는지 바로 구현할 수 있는 것은 아니다. 전체 네트워크를 하나의 거대한 수식으로 미분하면 코드가 복잡해지고, 층을 추가하거나 바꿀 때마다 미분을 처음부터 다시 해야 한다.

해결책은 계층을 모듈화하는 것이다. 각 계층이 forward()와 backward()를 독립적으로 갖고, forward에서 저장한 중간값을 backward에서 쓴다. 이렇게 하면 새 계층을 끼워 넣어도 나머지 코드를 건드릴 필요가 없다.

역전파 계층 구현 흐름

계층 모듈화의 규칙

모든 계층은 두 가지 계약을 지킨다:

  • forward(x) → 입력 x를 받아 출력을 반환한다. 동시에 backward에서 쓸 중간값을 self에 저장한다.
  • backward(dout) → 출력 쪽에서 흘러온 gradient dout을 받아, 입력 쪽 gradient dx를 반환한다. 가중치가 있으면 self.dW, self.db도 저장한다.

네트워크 전체 역전파는 계층 리스트를 역순으로 돌면서 backward()를 연쇄 호출하면 된다.

%% 계층별 backward 호출 흐름
flowchart TD
  softmax["Softmax + Loss<br/>backward 시작<br/>y_pred - y_true"]
  relu["ReLU<br/>mask 적용<br/>dx 반환"]
  affine["Affine<br/>dx 반환<br/>dW"]
  softmax --> relu
  relu --> affine

역전파 계층 구현 코드

1. Affine 계층 (완전연결층)

수식: y = xW + b

backward의 핵심은 행렬 미분이다:

  • dL/dW = x^T @ dout — 입력의 전치와 상위 gradient의 행렬곱
  • dL/db = sum(dout, axis=0) — 배치 차원을 합산
  • dL/dx = dout @ W^T — 상위 gradient와 가중치 전치의 행렬곱

왜 전치(transpose)를 곱하는가?

forward에서 y = xW이다. 연쇄법칙을 행렬로 적용하면:

dL/dx = dL/dy * dy/dx = dout @ W^T dL/dW = dx/dW^T * dL/dy = x^T @ dout

shape으로 확인한다:

  • x: (batch, 784), W: (784, 256), y: (batch, 256)
  • dout: (batch, 256)
  • dW = x^T @ dout → (784, batch) @ (batch, 256) = (784, 256) ✓
  • dx = dout @ W^T → (batch, 256) @ (256, 784) = (batch, 784) ✓

2. ReLU 계층

수식: y = max(0, x)

ReLU의 미분은 단순하다:

  • x > 0이면 기울기 = 1 → gradient 그대로 통과
  • x <= 0이면 기울기 = 0 → gradient 차단

forward에서 저장한 boolean mask를 backward에서 재사용한다. 가중치 파라미터가 없으므로 dW, db는 없다.

구체적 연산 예시

3. Softmax-with-Loss (출력층)

Softmax와 Cross-Entropy Loss를 합쳐서 미분하면 gradient가 깔끔해진다.

이 코드가 하는 일: Softmax 출력에서 정답 class 위치만 1을 빼고, 배치 크기로 나눈다. 결과는 (y_pred - y_one_hot) / batch_size와 같다.

왜 이렇게 단순한가?

Softmax 출력 y_k에 대해 Cross-Entropy Loss L을 미분하면:

dL/d(logit_k) = y_k - t_k

y_k는 Softmax 확률, t_k는 one-hot 정답이다. 정답 class에서는 y_k - 1, 나머지에서는 y_k - 0 = y_k이다. Softmax의 복잡한 지수함수 미분과 Cross-Entropy의 로그 미분이 상쇄되어 이 단순한 형태가 나온다. 이것이 Softmax와 Cross-Entropy를 합쳐서 구현하는 이유이다.

전체 역전파 흐름

%% NeuralNetwork.backward의 역순 호출 흐름
flowchart TD
  start["NeuralNetwork.backward()<br/>dout = (y_pred - y_true) / batch_size"]
  softmax["Softmax.backward(dout)<br/>dout 그대로 통과"]
  affine2["Affine2.backward(dout)<br/>dx"]
  dropout1["Dropout1.backward(dout)<br/>mask 적용"]
  relu1["ReLU1.backward(dout)<br/>음수 위치 차단"]
  batchnorm1["BatchNorm1.backward(dout)<br/>dgamma"]
  affine1["Affine1.backward(dout)<br/>dx"]
  start --> softmax
  softmax --> affine2
  affine2 --> dropout1
  dropout1 --> relu1
  relu1 --> batchnorm1
  batchnorm1 --> affine1

reversed()로 순서를 뒤집어 호출하는 것이 전부이다. 각 계층이 자기 backward 규칙대로 gradient를 변환하고, 필요하면 가중치 gradient도 저장한다.

정리

신경망의 역전파는 각 계층을 forward/backward 모듈로 분리하면 구현이 단순해진다. Affine은 전치 행렬을 곱해 gradient를 흘리고, ReLU는 음수 위치를 boolean mask로 차단하며, Softmax-with-Loss는 y_pred - y_true라는 깔끔한 형태로 시작 gradient를 만든다. 전체 역전파는 계층 리스트를 역순으로 호출하면 완성된다.
