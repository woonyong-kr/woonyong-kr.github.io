벡터·행렬 연산 — 신경망 계산의 기본 단위

벡터·행렬 연산 — 신경망 계산의 기본 단위

한 줄 요약: 이 문서에서 다루는 Affine 층은 행렬 곱 y = xW + b로 계산한다. 벡터와 행렬의 shape 규칙을 알면 순전파·역전파 코드의 연산 방향과 차원 불일치 원인을 파악할 수 있다.

여러 뉴런의 계산을 행렬 곱으로 묶기

퍼셉트론 하나는 스칼라 연산으로 나타낼 수 있다. 입력 x₁, x₂에 각각 가중치 w₁, w₂를 곱한 뒤 결과를 더한다. 그러나 한 층에 뉴런이 수백 개 있다면 뉴런마다 같은 계산을 for 루프로 반복해야 하므로 코드가 길어지고 계산도 느려진다.

이 반복은 행렬 곱으로 묶을 수 있다. y = xW + b에서 입력 벡터 x는 가중치 행렬 W를 거쳐 출력 벡터 y로 바뀌고, 각 출력에 편향 b가 더해진다. 이 문서의 Affine 층 코드에서도 순전파와 역전파를 행렬 곱으로 표현한다. 따라서 코드의 @ 연산이 성립하는 이유나 차원 불일치 에러의 원인을 이해하려면 먼저 shape 규칙을 알아야 한다.

스칼라·벡터·행렬·텐서와 shape

데이터를 담는 배열은 차원에 따라 다음과 같이 구분한다.

  • 스칼라 (scalar): 숫자 하나. 3.14
  • 벡터 (vector): 숫자를 한 줄로 나열. shape (n,). 입력 한 샘플, 가중치 한 뉴런분
  • 행렬 (matrix): 숫자를 행과 열로 배치. shape (m, n). 가중치 전체, 배치 입력
  • 텐서 (tensor): 3차원 이상. shape (batch, seq, dim) 등. 이미지, 시퀀스 데이터

여기서는 신경망 층의 계산을 이해하기 위해 2차원 행렬 곱을 중심으로 살펴본다.

내적 (dot product)

내적은 벡터 두 개에서 같은 위치의 원소끼리 곱한 뒤 모두 더하는 연산이다.

a = [a₁, a₂, a₃]
b = [b₁, b₂, b₃]

a · b = a₁b₁ + a₂b₂ + a₃b₃

퍼셉트론 하나의 계산은 입력 벡터 x와 가중치 벡터 w의 내적에 편향 b를 더한 형태다. 내적은 두 벡터의 “같은 방향 성분”을 측정한다. 값이 크면 두 벡터가 비슷한 방향을 가리키고, 0이면 직교한다. Attention에서도 내적을 유사도 점수로 사용한다.

행렬 곱 (matrix multiplication)

행렬 곱은 내적을 행과 열의 각 조합에 적용한 연산이다.

X: (m, n)  ×  W: (n, p)  →  Y: (m, p)

Y[i][j] = X의 i번째 행 · W의 j번째 열 (내적)

앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 곱할 수 있다. 이 조건을 만족하면 결과의 shape은 (앞 행렬의 행, 뒷 행렬의 열)이 된다.

(m, n) × (n, p) → (m, p)
       ↑   ↑
       이 둘이 같아야 곱할 수 있다

행렬 곱으로 층 전체 계산하기

입력이 2개이고 뉴런이 3개인 은닉층을 생각해 보자. 각 뉴런의 출력은 다음과 같다.

  • 뉴런 1: y₁ = x₁w₁₁ + x₂w₂₁ + b₁
  • 뉴런 2: y₂ = x₁w₁₂ + x₂w₂₂ + b₂
  • 뉴런 3: y₃ = x₁w₁₃ + x₂w₂₃ + b₃

세 뉴런은 입력을 공유하지만 서로 다른 가중치와 편향을 사용한다. 이 세 줄을 하나의 행렬 곱으로 묶으면 다음 구조가 된다.

%% 뉴런 3개짜리 은닉층을 행렬 곱 하나로 계산하는 구조
flowchart LR
  x["x: (1, 2)"]
  W["W: (2, 3)"]
  b["b: (1, 3)"]
  y["y: (1, 3)"]
  x --> W
  W --> b
  b --> y

W의 각 열은 뉴런 하나의 가중치 벡터다. 따라서 W의 열 수가 출력 뉴런 수를 결정한다.

배치 처리

샘플 N개를 한꺼번에 입력하면 X의 shape은 (N, 입력차원)이 된다. 이 X와 가중치 W를 곱하면 N개 샘플의 출력을 한 번의 행렬 곱으로 계산할 수 있다.

X: (N, 784)  ×  W: (784, 256)  +  b: (1, 256)  →  Y: (N, 256)
 배치 N개        가중치            편향 (브로드캐스팅)  출력 N개

이 예에서는 MNIST의 784개 픽셀 입력이 256개 은닉 뉴런의 출력으로 변환된다.

전치 (transpose)

전치는 행과 열을 뒤집는 연산이다. shape (m, n)인 행렬을 전치하면 (n, m)이 된다.

W:  (784, 256)  →  W.T:  (256, 784)

이 문서의 Affine 층 역전파에서는 전치로 행렬 곱의 shape을 맞춘다. 순전파가 y = xW이면 입력에 대한 기울기는 dx = dout × W^T, 가중치에 대한 기울기는 dW = x^T × dout으로 계산한다.

브로드캐스팅 (broadcasting)

shape이 다른 배열끼리 연산할 때 numpy는 작은 배열을 연산 가능한 형태로 자동 확장한다.

Y: (N, 256)  +  b: (256,)  →  (N, 256)

편향 벡터 b의 shape은 (256,)이지만 배치의 모든 행에 같은 값을 더해야 한다. numpy는 b를 N번 복사한 것처럼 처리하되, 실제 메모리에 같은 데이터를 N번 복사하지는 않는다.

Affine 층의 순전파와 역전파

순전파: Affine 층

@는 numpy의 행렬 곱 연산자다. self.x @ self.W가 배치 전체를 선형 변환하고, 이어지는 + self.b에서 브로드캐스팅이 일어난다.

역전파: Affine 층

역전파에서는 전치(.T)를 사용해 각 기울기의 shape을 원래 변수의 shape과 맞춘다.

  • dW = x^T @ dout: 입력을 전치해 결과의 shape을 W와 같은 (784, 256)으로 만든다.
  • dx = dout @ W^T: 가중치를 전치해 결과의 shape을 입력과 같은 (N, 784)로 되돌린다.
  • db = np.sum(dout, axis=0): 편향은 배치 전체에서 공유되므로 배치 축을 합산해 (256,)으로 만든다.

숫자로 확인

x의 shape (2, 3)과 W의 shape (3, 2)에서 안쪽 차원 3이 일치하므로 행렬 곱이 가능하다. 결과는 바깥쪽 차원을 따라 (2, 2)가 되고, shape (2,)인 b가 각 행에 더해진다.

shape 변환 다이어그램

%% Affine 층의 순전파와 역전파 shape 흐름
flowchart TD
  fx["입력 x<br/>(N, 784)"]
  fy_linear["선형변환<br/>(N, 784) @ (784, 256)"]
  fy["출력 y<br/>(N, 256)"]
  bdout["dout<br/>(N, 256)"]
  bdx["dx<br/>(N, 784)"]
  bdW["dW<br/>(784, 256)"]
  fx --> fy_linear
  fy_linear --> fy
  bdout --> bdx
  bdout --> bdW

순전파에서 W의 shape이 (784, 256)이면 역전파에서 W.T의 shape은 (256, 784)이다. 각 행렬 곱의 안쪽 차원을 맞춰 보면 어떤 행렬을 전치해야 하는지 알 수 있다.

다시 확인할 shape 규칙

  • 이 문서의 Affine 층은 y = xW + b로 순전파를 계산한다.
  • 행렬 곱은 (m, n) × (n, p) → (m, p)이며, 두 안쪽 차원이 같아야 한다.
  • 역전파에서는 전치(.T)를 사용해 dW와 dx의 shape을 각각 W와 x에 맞춘다.
  • 편향을 더할 때는 브로드캐스팅으로 작은 배열을 배치의 각 행에 적용한다.
  • 연결 문서: MLP 순전파
