GELU 활성화 함수 — Transformer가 ReLU 대신 선택한 비선형 함수

GELU 활성화 함수 — Transformer가 ReLU 대신 선택한 비선형 함수

범위: 이 문서는 GELU의 정의와 ReLU와의 차이, 근사식 및 FeedForward에서의 역할을 설명하는 개념·구현 예시이며, 제시된 코드와 수치는 특정 라이브러리 버전이나 실제 실행 기록을 검증한 결과가 아니다. 근사 방식의 정확도·연산 비용과 학습 안정성·성능에 관한 판단은 실제 코드, 버전, 실행 기록 및 성능 측정을 별도로 확인해야 한다.

한 줄 요약: GELU(Gaussian Error Linear Unit)는 입력값에 “이 값이 양수일 확률”을 곱하는 활성화 함수로, ReLU의 sharp한 꺾임을 부드럽게 대체한다.

GELU 활성화 함수 구분

신경망의 은닉층에는 활성화 함수가 필요하다. 활성화 함수가 없으면 여러 층을 쌓아도 전체가 하나의 선형 변환과 같다. ReLU는 max(0, x)로 단순하고 빠르지만, 입력이 0 이하면 기울기가 완전히 0이 된다. 한번 죽은 뉴런은 다시 살아나지 않는다 — dead neuron 문제다.

Transformer의 FeedForward 네트워크는 토큰별 특징을 추출하는 작은 MLP다. 여기서 ReLU를 쓰면 음수 입력의 정보가 완전히 사라진다. GPT는 이 자리에 GELU를 넣어 음수 입력도 확률적으로 통과시킨다.

GELU 활성화 함수 계산

비유

ReLU는 문지기가 “양수면 통과, 음수면 차단”하는 것이다. 기준이 칼같다. GELU는 문지기가 “이 값이 양수일 확률만큼 통과시키는” 것이다. -0.1처럼 0에 가까운 음수는 대부분 통과시키고, -3처럼 큰 음수는 거의 차단한다.

정의

GELU(x) = x * Phi(x)

Phi(x)는 표준정규분포의 누적분포함수(CDF)다. 입력 x가 표준정규분포에서 얼마나 큰 쪽에 있는지를 0~1 사이 확률로 돌려준다.

  • x = 0이면 Phi(0) = 0.5이므로 GELU(0) = 0
  • x = 2이면 Phi(2) ≈ 0.977이므로 GELU(2) ≈ 1.955
  • x = -2이면 Phi(-2) ≈ 0.023이므로 GELU(-2) ≈ -0.045

왜 이 수식인가?

Phi(x)를 곱하면 “입력이 클수록 그대로 통과, 작을수록 억제”라는 자연스러운 게이팅이 생긴다. ReLU처럼 0에서 꺾이지 않아 미분이 연속이고, 기울기 기반 최적화가 안정적이다.

실제 구현에서는 Phi(x)를 직접 계산하지 않고 근사식을 쓴다.

tanh 근사식:

GELU(x) ≈ 0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x

sigmoid 근사식 (더 간단):

GELU(x) ≈ x * sigmoid(1.702 * x)

두 근사 모두 원래 GELU와 거의 차이가 없다. 밑바닥 LLM 책에서는 두 방식 모두 사용할 수 있다.

GELU가 FeedForward에서 쓰이는 위치

%% FeedForward 안에서 GELU가 놓이는 위치
flowchart LR
  linear_expand["Linear<br/>d_model -&gt; 4*d_model"]
  gelu["GELU<br/>비선형 변환<br/>(게이팅)"]
  linear_project["Linear<br/>4*d_model -&gt; d_model"]
  linear_expand --> gelu
  gelu --> linear_project

FeedForward는 Linear → GELU → Linear → Dropout 순서다. 첫 번째 Linear가 차원을 4배로 확장하고, GELU가 비선형 변환을 적용한 뒤, 두 번째 Linear가 원래 차원으로 되돌린다.

GELU 역전파

GELU의 미분은 sigmoid 근사 기준으로 다음과 같다. PyTorch는 autograd가 자동으로 계산하지만, 수식을 알아야 gradient 크기를 예측할 수 있다.

d/dx [x * sigmoid(1.702x)] = sigmoid(1.702x) + x * 1.702 * sigmoid(1.702x) * (1 - sigmoid(1.702x))

x = 0일 때 기울기는 sigmoid(0) = 0.5다. ReLU는 x = 0에서 기울기가 정의되지 않지만, GELU는 0.5로 연속이다.

정리

GELU는 입력에 “표준정규분포 기준으로 이 값이 양수일 확률”을 곱하는 활성화 함수다. ReLU와 달리 음수 입력을 완전히 차단하지 않아 dead neuron 문제가 없고, 미분이 전 구간에서 연속이어서 기울기 기반 학습이 안정적이다. GPT를 포함한 대부분의 Transformer 모델은 FeedForward 내부에 GELU를 사용한다.
