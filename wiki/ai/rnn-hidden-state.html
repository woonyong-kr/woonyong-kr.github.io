RNN 은닉 상태

RNN 은닉 상태

한 줄 요약: RNN의 은닉 상태(hidden state) h_t는 현재 입력 x_t와 이전 기억 h_{t-1}을 합쳐 만든 고정 크기 벡터로, 순환 신경망이 sequence를 처리할 수 있게 하는 핵심 장치다.

RNN 은닉 상태 구분

Feedforward 네트워크는 입력 하나를 받아 출력 하나를 낸다. 이전 입력의 기억이 없다. “나는 고양이를 좋아한다”에서 “좋아한다”를 예측하려면 앞의 “나는”, “고양이를”을 기억해야 한다. Feedforward 네트워크는 이 순서 정보를 다룰 수 없다.

순서가 있는 데이터(텍스트, 음성, 시계열)를 처리하려면, 이전 시점에서 본 것을 현재 시점으로 전달하는 장치가 필요하다. 이 장치가 은닉 상태(hidden state)다. RNN은 매 시점마다 은닉 상태를 갱신하면서 sequence 전체를 순서대로 읽는다.

은닉 상태는 RNN의 “기억”이다. 이 기억이 어떻게 만들어지고, 어떤 한계를 갖는지 이해해야 Vanilla RNN의 한계와 GRU가 왜 필요한지 알 수 있다.

RNN 은닉 상태 흐름

은닉 상태의 정의

은닉 상태 h_t는 시점 t까지의 입력 sequence를 요약한 고정 크기 벡터다. 크기는 hidden_dim으로 사전에 정한다. sequence가 아무리 길어도 은닉 상태의 크기는 변하지 않는다.

비유하면, 은닉 상태는 요약 노트다. 강의를 들으면서 A4 한 장에 핵심만 적는다고 하자. 새 내용이 나오면 이전 노트를 보면서 중요한 것을 남기고, 새 내용을 추가한다. 노트의 크기(A4 한 장)는 고정이다. 강의가 길어지면 오래된 내용은 점점 밀려난다.

순환 공식 (Recurrence Formula)

RNN의 핵심은 한 줄 수식이다.

h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)
  • x_t: 시점 t의 입력 벡터. 크기 (input_dim,)
  • h_{t-1}: 이전 시점의 은닉 상태. 크기 (hidden_dim,)
  • W_xh: 입력을 은닉 공간으로 변환하는 가중치. 크기 (hidden_dim, input_dim)
  • W_hh: 이전 기억을 현재 기억에 반영하는 가중치. 크기 (hidden_dim, hidden_dim)
  • b_h: 편향. 크기 (hidden_dim,)
  • tanh: 활성화 함수. 출력을 [-1, 1] 범위로 제한

이 수식에서 핵심은 h_{t-1}이 다시 입력으로 들어온다는 점이다. Feedforward 네트워크에서는 이전 층의 출력이 다음 층으로 가지만, 같은 층으로 되돌아오지 않는다. RNN은 같은 cell의 출력이 다음 시점의 같은 cell로 되돌아온다. 이것이 “순환(recurrent)“이라는 이름의 유래다.

RNN cell의 구조

하나의 RNN cell 내부를 풀어보면 다음과 같다.

%% RNN cell의 은닉 상태 갱신
flowchart LR
  x_t["x_t<br/>현재 입력"]
  h_prev["h_{t-1}<br/>이전 은닉 상태"]
  input_proj["W_xh · x_t<br/>입력을 은닉 공간으로 변환"]
  hidden_proj["W_hh · h_{t-1}<br/>이전 기억을 현재에 반영"]
  bias["b_h<br/>편향"]
  sum["가중합<br/>W_xh · x_t + W_hh · h_{t-1} + b_h"]
  tanh["tanh<br/>값을 -1부터 1까지로 제한"]
  h_t["h_t<br/>새 은닉 상태"]
  x_t --> input_proj
  h_prev --> hidden_proj
  input_proj --> sum
  hidden_proj --> sum
  bias --> sum
  sum --> tanh
  tanh --> h_t

입력 x_t와 이전 은닉 상태 h_{t-1}이 각각 다른 가중치로 변환된 뒤 더해지고, tanh를 통과해 새 은닉 상태 h_t가 된다. 이 h_t는 두 가지로 쓰인다.

  • 현재 시점의 출력을 만드는 데 사용 (예: y_t = W_hy · h_t)
  • 다음 시점 t+1의 입력으로 전달

Feedforward와 RNN의 구조 비교

%% Feedforward와 RNN의 구조 차이
flowchart TD
  mlp_x["x<br/>입력"]
  mlp_h1["은닉층 1<br/>W1 고유<br/>기억 없음"]
  mlp_h2["은닉층 2<br/>W2 고유<br/>기억 없음"]
  mlp_y["y<br/>출력"]
  rnn_x1["x_1"]
  rnn_x2["x_2"]
  rnn_x3["x_3"]
  rnn_c1["RNN cell<br/>W_xh, W_hh 공유"]
  rnn_c2["RNN cell<br/>W_xh, W_hh 공유"]
  rnn_c3["RNN cell<br/>W_xh, W_hh 공유"]
  rnn_h0["h_0<br/>초기 기억"]
  rnn_h1["h_1<br/>x_1까지 요약"]
  rnn_h2["h_2<br/>x_1..x_2 요약"]
  rnn_h3["h_3<br/>x_1..x_3 요약"]
  mlp_x --> mlp_h1
  mlp_h1 --> mlp_h2
  mlp_h2 --> mlp_y
  rnn_x1 --> rnn_c1
  rnn_x2 --> rnn_c2
  rnn_x3 --> rnn_c3
  rnn_h0 --> rnn_c1
  rnn_c1 --> rnn_h1
  rnn_h1 --> rnn_c2
  rnn_c2 --> rnn_h2
  rnn_h2 --> rnn_c3
  rnn_c3 --> rnn_h3
  mlp_y --> rnn_x1

MLP는 각 층이 고유한 가중치를 가진다. RNN은 모든 시점에서 같은 가중치 W_xh, W_hh를 공유한다. 그래서 RNN은 가중치 수가 sequence 길이에 의존하지 않는다.

h_0 — 최초의 은닉 상태

sequence의 첫 시점 t=1에서 h_{t-1} = h_0이 필요하다. h_0은 보통 영벡터(zero vector)로 초기화한다. “아직 아무것도 본 적 없는 상태”를 뜻한다.

h_0 = [0, 0, 0, ..., 0]    # (hidden_dim,) 크기의 영벡터

학습 가능한 파라미터로 h_0을 두는 변형도 있지만, 영벡터 초기화가 가장 일반적이다.

RNN 은닉 상태 코드

가장 단순한 RNN cell — numpy 구현

rnn_cell 함수가 RNN의 전부다. 입력 x_t와 이전 기억 h_prev를 받아 새 기억을 반환한다. Feedforward의 Affine.forward()와 비교하면, 입력이 x만이 아니라 (x_t, h_prev) 쌍이라는 점만 다르다.

sequence 전체를 처리하는 루프

실행 결과 (seed=42 기준):

t=1: h = [ 0.0496 -0.0234 -0.0469]
t=2: h = [-0.0001 -0.0253  0.0461]
t=3: h = [ 0.0616  0.1605 -0.036 ]

h_1은 “나는”만 반영한다. h_2는 “나는”의 기억(h_1)과 “고양이를”(x_2)을 합친 결과다. h_3는 “나는 고양이를 좋아한다” 전체를 요약한 벡터다. sequence가 진행될수록 은닉 상태에 더 많은 정보가 축적된다.

텐서 shape 변환

한 시점에서 일어나는 shape 변환을 정리한다.

x_t: (input_dim,) = (4,)
h_{t-1}: (hidden_dim,) = (3,)

W_xh @ x_t:  (3, 4) @ (4,) = (3,)    ← 입력을 은닉 공간으로 변환
W_hh @ h_{t-1}: (3, 3) @ (3,) = (3,)  ← 이전 기억을 현재에 반영
         +b_h:                  (3,)   ← 편향

합산 후 tanh:                    (3,)   ← 새 은닉 상태 h_t

배치 처리(batch_size = N)일 때는 다음과 같다.

x_t:     (N, input_dim)
h_{t-1}: (N, hidden_dim)

x_t @ W_xh.T:     (N, 4) @ (4, 3) = (N, 3)
h_{t-1} @ W_hh.T: (N, 3) @ (3, 3) = (N, 3)
h_t:                                  (N, 3)

은닉 상태의 크기 hidden_dim은 설계자가 정하는 하이퍼파라미터다. 크게 잡으면 더 많은 정보를 기억할 수 있지만, 파라미터 수도 늘어난다.

은닉 상태는 왜 “은닉”인가

은닉 상태가 “hidden”인 이유는 외부에서 직접 관측할 수 없기 때문이다. 입력 x_t는 사용자가 제공하고, 출력 y_t는 사용자가 받는다. 하지만 h_t는 네트워크 내부에서만 존재하는 중간 표현이다. Feedforward 네트워크의 은닉층과 같은 맥락이다. 다만 RNN의 은닉 상태는 시간축을 따라 전달된다는 점이 다르다.

정리

RNN의 은닉 상태 h_t는 현재 입력 x_t와 이전 기억 h_{t-1}을 가중합하고 tanh를 씌워 만든 고정 크기 벡터다. 이 벡터가 시점 사이를 연결하면서 RNN이 sequence를 처리할 수 있게 한다. 모든 시점에서 같은 가중치 W_xh, W_hh를 공유하므로 임의 길이의 sequence를 다룰 수 있다. 다만 고정 크기 벡터에 모든 과거를 압축하기 때문에 sequence가 길어지면 앞쪽 정보가 희석되는 한계가 있다.
