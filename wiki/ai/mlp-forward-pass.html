MLP 순전파

MLP 순전파

확인 범위: 이 문서는 MLP 순전파의 일반 원리와 행렬 차원 규칙을 설명하고, 입력에 제시된 NumPy·PyTorch 및 MNIST 네트워크 코드를 구현 예시로 다룬다. 코드의 실제 동작, 라이브러리 버전별 세부 동작, 실행 출력의 정합성, Python for 루프 대비 성능 수치는 별도의 실행 기록과 성능 측정이 있어야 검증할 수 있다.

한 줄 요약: 순전파는 입력 데이터가 신경망의 각 층에서 행렬곱 + 활성화 함수를 반복 적용하며 최종 출력을 산출하는 과정이다.

MLP 순전파가 비용을 줄이는 자리

다층 퍼셉트론에서 층을 쌓으면 비선형 문제를 풀 수 있다는 것을 배웠다. 하지만 뉴런 하나하나를 개별 계산하면 for 루프가 필요하고 느리다.

순전파는 한 층 전체를 행렬곱 하나로 처리한다. 행렬곱은 BLAS(Basic Linear Algebra Subprograms)처럼 최적화된 수치 연산 라이브러리를 활용할 수 있어 개별 Python for 루프보다 효율적인 경우가 많다. 실제 성능 차이는 행렬 크기, 하드웨어, 라이브러리 구현과 실행 조건을 같은 기준으로 측정해 확인해야 한다.

BLAS 구현은 메모리 접근 패턴과 SIMD 명령어를 최적화하여 행렬곱을 효율적으로 처리한다.

MLP 순전파 흐름

한 층의 패턴

모든 층은 같은 패턴을 따른다:

Z = A(l-1) @ W(l) + b(l)    -- 선형 변환 (가중합)
A(l) = f(Z)                  -- 비선형 활성화

여기서 A(0) = X (입력)이다. 이 패턴을 층 수만큼 반복하면 순전파가 완성된다.

3층 신경망 예시 (2-3-2-2 구조)

밑바닥 딥러닝1 Ch3에서 사용하는 구조다. 입력 2개 → 은닉1 3개 → 은닉2 2개 → 출력 2개.

1층 (입력 → 은닉1):

Z(1) = X @ W(1) + b(1)
A(1) = sigmoid(Z(1))

2층 (은닉1 → 은닉2):

Z(2) = A(1) @ W(2) + b(2)
A(2) = sigmoid(Z(2))

3층 (은닉2 → 출력):

Z(3) = A(2) @ W(3) + b(3)
Y = softmax(Z(3))

각 계층의 Shape 변화

입력 X(N,2) → @W1(2,3) + b1(3,) → Z1(N,3) → sigmoid → A1(N,3)
          → @W2(3,2) + b2(2,) → Z2(N,2) → sigmoid → A2(N,2)
          → @W3(2,2) + b3(2,) → Z3(N,2) → softmax → Y(N,2)

여기서 N은 배치 크기(batch size)다. 단일 입력이면 N=1.

행렬곱의 차원 규칙: (N, a) @ (a, b) = (N, b). 앞 행렬의 열 수와 뒤 행렬의 행 수가 일치해야 한다.

순전파 흐름 다이어그램

%% 3층 MLP 순전파 흐름
flowchart LR
  x["입력층<br/>X(N, 2)"]
  z1["가중합 1<br/>Z1 = X @ W1 + b1<br/>W1: (2, 3), Z1: (N, 3)"]
  a1["은닉1<br/>A1 = sigmoid(Z1)<br/>(N, 3)"]
  z2["가중합 2<br/>Z2 = A1 @ W2 + b2<br/>W2: (3, 2), Z2: (N, 2)"]
  a2["은닉2<br/>A2 = sigmoid(Z2)<br/>(N, 2)"]
  z3["가중합 3<br/>Z3 = A2 @ W3 + b3<br/>W3: (2, 2), Z3: (N, 2)"]
  y["출력<br/>Y = softmax(Z3)<br/>(N, 2)"]
  x --> z1
  z1 --> a1
  a1 --> z2
  z2 --> a2
  a2 --> z3
  z3 --> y

순전파의 일반 패턴:

%% 한 층의 순전파 일반 패턴
flowchart LR
  input["입력<br/>A(l-1)"]
  affine["행렬곱<br/>Z = A @ W + b<br/>선형 변환"]
  activation["활성화<br/>A = f(Z)<br/>비선형 변환"]
  output["다음 단계<br/>마지막 층이면 출력<br/>아니면 다음 층의 입력"]
  input --> affine
  affine --> activation
  activation --> output

비유: 공장 조립 라인

  • 원재료(입력 X)가 투입된다
  • 1번 공정(1층): 원재료를 가공한다. 가공 방식은 W1(가중치)으로 결정되고, b1(편향)으로 기준을 조절한다. 가공 후 품질 검사(활성화 함수)를 거친다.
  • 2번 공정(2층): 1번 공정의 산출물을 추가 가공한다.
  • 출하 검사(출력층): 최종 제품이 어느 카테고리에 속하는지 판정한다(softmax).

숫자로 추적: x = [1.0, 0.5]

입력 x = [1.0, 0.5]를 밑바닥 딥러닝1의 가중치로 순전파하는 전체 과정이다.

1층 계산:

z1 = [1.0, 0.5] @ [[0.1, 0.3, 0.5],
                    [0.2, 0.4, 0.6]] + [0.1, 0.2, 0.3]

z1[0] = 1.0 * 0.1 + 0.5 * 0.2 + 0.1 = 0.3
z1[1] = 1.0 * 0.3 + 0.5 * 0.4 + 0.2 = 0.7
z1[2] = 1.0 * 0.5 + 0.5 * 0.6 + 0.3 = 1.1

z1 = [0.3, 0.7, 1.1]
a1 = sigmoid(z1) = [0.5744, 0.6682, 0.7503]

2층 계산:

z2 = [0.5744, 0.6682, 0.7503] @ [[0.1, 0.4],
                                   [0.2, 0.5],
                                   [0.3, 0.6]] + [0.1, 0.2]

z2[0] = 0.5744 * 0.1 + 0.6682 * 0.2 + 0.7503 * 0.3 + 0.1 = 0.5161
z2[1] = 0.5744 * 0.4 + 0.6682 * 0.5 + 0.7503 * 0.6 + 0.2 = 1.1144

z2 = [0.5161, 1.1144]
a2 = sigmoid(z2) = [0.6262, 0.7530]

3층 계산:

z3 = [0.6262, 0.7530] @ [[0.1, 0.3],
                          [0.2, 0.4]] + [0.1, 0.2]

z3[0] = 0.6262 * 0.1 + 0.7530 * 0.2 + 0.1 = 0.3132
z3[1] = 0.6262 * 0.3 + 0.7530 * 0.4 + 0.2 = 0.6891

z3 = [0.3132, 0.6891]

y = softmax(z3):
  exp(0.3132) = 1.368,  exp(0.6891) = 1.992
  합: 1.368 + 1.992 = 3.360
  y = [1.368 / 3.360, 1.992 / 3.360] = [0.407, 0.593]

최종 출력: 클래스 0의 확률 40.7%, 클래스 1의 확률 59.3%.

MLP 순전파 코드

numpy: 3층 신경망 순전파

각 층에서 x @ W + b(선형 변환) → 활성화 함수(비선형 변환)가 반복된다. @는 numpy의 행렬곱 연산자이고, 편향 b는 브로드캐스팅으로 더해진다.

numpy: 실제 MNIST 네트워크의 순전파

OrderedDict에 쌓인 층을 순서대로 호출한다. Ch3의 forward() 함수가 z = x @ W + b; a = sigmoid(z)를 수동으로 반복했던 것을 자동화한 것이다.

Affine 층의 forward:

self.x를 저장하는 이유: backward에서 gradient 계산에 필요하기 때문이다.

PyTorch: nn.Module 기반 순전파

numpy 구현과의 차이:

  • nn.Linear는 가중치를 자동 초기화(Kaiming/Xavier)하고 학습 가능하게 관리한다
  • 밑바닥 딥러닝1은 수동으로 가중치를 설정하여 순전파 메커니즘 자체에 집중한다
  • PyTorch에서 출력층 softmax를 별도로 적용하지 않는 이유: nn.CrossEntropyLoss가 내부적으로 log-softmax를 계산하므로, 중복 적용 시 잘못된 결과가 나온다

PyTorch: nn.Sequential로 층 연결하기

nn.Sequential은 등록한 층을 선언 순서대로 호출해 순전파를 구성한다. 층이 단순히 직렬로 이어지는 구조에서는 forward()에서 각 층을 직접 호출하는 코드를 줄일 수 있다.

정리

순전파는 입력에서 출력까지 각 층에서 “행렬곱(선형 변환) → 활성화 함수(비선형 변환)“을 반복하는 과정이다. 행렬곱을 사용하면 한 층 전체를 한 번의 연산으로 처리할 수 있어 효율적이다. 밑바닥 딥러닝1에서 수동으로 반복했던 패턴이 실제 네트워크에서는 OrderedDict + for 루프로 자동화된다.
