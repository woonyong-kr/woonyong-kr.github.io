후 학습 양자화 (Post Training Quantization)

한 줄 요약: 후 학습 양자화는 학습이 끝난 FP16/BF16 모델을 재학습 없이 배포 직전 INT8/INT4 같은 낮은 비트 표현으로 바꾸는 절차다.

이미 학습된 FP16/BF16 모델을 배포하려는데 GPU 메모리가 부족하거나, 추론 엔진이 특정 quantization format을 요구할 수 있다. 모델을 다시 학습할 데이터나 시간이 없다면 양자화 가운데 후 학습 양자화(Post Training Quantization, PTQ)를 고려할 수 있다. PTQ는 모델을 크게 재학습하지 않고 낮은 비트 표현으로 변환한 뒤, 품질과 배포 조건을 확인하는 절차다.

후 학습 양자화가 필요한 이유

PTQ는 “학습이 끝난 FP16/BF16 모델을 어떻게 INT8/INT4 같은 형식으로 바꿔서 배포할까?”라는 문제에 집중한다. 낮은 비트 표현은 모델의 weight 저장 폭을 줄이는 데 쓰이지만, 변환 과정에서 생긴 오차가 모델 출력에 영향을 줄 수 있다. 따라서 PTQ는 단순한 형식 변환으로 끝나지 않는다. 품질 하락이 감당 가능한지 확인하고, 변환된 형식을 추론 엔진이 지원하는지도 함께 살펴야 한다.

이런 성격 때문에 PTQ는 모델을 처음부터 다시 만드는 훈련 기법보다 배포 직전의 변환과 검증 절차에 가깝다.

후 학습 양자화 절차

calibration 데이터는 양자화의 기준으로 삼는 대표 입력이다. 전체 학습을 다시 수행하지는 않지만, 변환 과정에서 어떤 값 범위를 중요하게 볼지 정하는 데 사용한다. 이 데이터를 바탕으로 layer/channel/group 단위의 scale을 계산하고 weight를 INT8/INT4 등으로 바꾼다.

변환된 모델은 추론 엔진이 읽을 수 있는 형식으로 저장한다. 이어서 검증 데이터와 실제 prompt로 출력 품질을 확인하고, latency / memory / throughput을 측정한다. 이 과정에서 사용하는 scale, zero point, group size는 낮은 비트 숫자가 원래 값을 어떻게 근사할지 정하는 약속이다.

PTQ와 다른 양자화 방법을 선택하는 기준

이미 학습된 모델을 빠르게 배포해야 하거나 GPU 메모리가 부족해 weight 저장 폭을 줄여야 한다면 PTQ가 어울린다. 추가 학습 비용 없이 INT8/INT4 변환을 먼저 실험하려는 경우에도 적용할 수 있다.

낮은 비트로 바꾼 뒤 품질 하락이 너무 크거나, 모델이 학습 과정에서 quantization 오차를 미리 경험해야 한다면 QAT가 더 어울릴 수 있다.

LLM에서 단순 반올림의 품질 손실이 크고 layer별 오차 보정이나 activation-aware 보존이 필요하다면 GPTQ/AWQ 같은 LLM 전용 PTQ를 살펴볼 수 있다. 관련 방법은 LLM에서 자주 쓰는 후처리 양자화 방법에서 이어서 확인할 수 있다.

후 학습 양자화 결과를 확인하는 방법

PTQ 결과는 메모리 감소만으로 판단하지 않는다. 같은 모델을 FP16과 INT4로 각각 실행하고, GPU 메모리 사용량과 동일 prompt의 출력 품질을 나란히 비교해야 한다. 추론 엔진이 변환된 형식을 지원하는지 확인하고 latency / memory / throughput도 함께 측정한다.

양자화가 모델 경량화에서 차지하는 위치는 모델 경량화의 큰 분류에서, 양자화된 모델을 GPU 추론 엔진에서 다루는 맥락은 양자화된 모델을 GPU 추론 엔진에서 다루는 맥락에서 다시 찾을 수 있다.
