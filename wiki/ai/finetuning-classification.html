미세조정 — 사전 학습된 GPT를 감성 분류기로 바꾸기

범위: 이 문서는 사전 학습된 GPT를 감성 분류기로 미세조정하는 일반 원리와 선택 기준을 설명하며, 제시된 코드는 구현 흐름을 보여 주는 예시다. 특정 코드·데이터·하이퍼파라미터의 실제 동작과 성능은 버전, 실행 기록, 평가 결과가 제시되지 않았으므로 검증된 결과로 해석하지 않는다.

한 줄 요약: 미세조정(Fine-tuning)은 사전 학습된 언어 모델의 가중치를 특정 과업(감성 분류, 질의응답 등)의 라벨 데이터로 추가 학습하여 해당 과업의 성능을 끌어올리는 기법이다.

미세조정 필요성

GPT 사전 학습은 “다음 토큰 예측”이라는 범용 과업으로 언어의 문법, 의미, 세계 지식을 학습한다. 하지만 사전 학습만으로는 “이 리뷰가 긍정인가 부정인가?”처럼 특정 과업을 수행하지 못한다. 모델이 언어를 이해하긴 하지만, 그 이해를 특정 작업의 출력 형식으로 바꾸는 법을 모른다.

처음부터 분류 모델을 학습하면 수억 개의 파라미터를 전부 0에서 시작해야 한다. 데이터가 수천~수만 건밖에 없을 때 이렇게 하면 과적합이 일어난다. 미세조정은 이미 학습된 가중치를 출발점으로 삼아 적은 데이터로도 빠르게 높은 성능을 얻는다.

핵심 아이디어는 **전이 학습(Transfer Learning)**이다:

  1. 대규모 텍스트로 사전 학습(pre-training)하여 언어 표현을 얻는다.
  2. 과업별 라벨 데이터로 미세조정(fine-tuning)하여 특정 작업에 맞춘다.

미세조정 흐름

비유

사전 학습은 의대 교육이다. 의학 전반을 배운다. 미세조정은 전문의 수련이다. 이미 의학을 아는 상태에서 피부과, 정형외과 등 특정 분야를 집중 훈련한다. 처음부터 전문의를 키우는 것보다 훨씬 효율적이다.

구조 변경: LM Head → Classification Head

사전 학습된 GPT의 마지막 층은 LM Head(Linear → vocab_size)다. 다음 토큰을 예측하는 용도다. 감성 분류를 하려면 이 층을 떼어내고 새로운 Classification Head를 붙인다.

%% LM Head에서 Classification Head로 교체
flowchart LR
  pre_embed["InputEmbedding"]
  pre_block["TransformerBlock × N"]
  pre_norm["LayerNorm"]
  pre_head["LM Head<br/>(D → vocab_size)"]
  ft_embed["InputEmbedding<br/>동일, 가중치 유지"]
  ft_block["TransformerBlock × N<br/>동일, 가중치 유지"]
  ft_norm["LayerNorm<br/>동일, 가중치 유지"]
  ft_dropout["Dropout<br/>새로 추가"]
  ft_classifier["Classifier<br/>(D → 2)<br/>새로 추가, 긍정/부정"]
  pre_embed --> pre_block
  pre_block --> pre_norm
  pre_norm --> pre_head
  ft_embed --> ft_block
  ft_block --> ft_norm
  ft_norm --> ft_dropout
  ft_dropout --> ft_classifier
  pre_head -. LM Head 제거 .-> ft_dropout

Transformer Block까지의 가중치는 그대로 둔다. 이 층들이 이미 학습한 언어 표현이 미세조정의 출발점이다.

문장 대표 벡터 추출

GPT는 자기회귀 모델이다. 각 위치는 자신과 이전 토큰만 본다. 따라서 마지막 토큰의 hidden state가 문장 전체의 문맥을 가장 많이 담고 있다. 분류기는 이 벡터를 입력으로 받는다.

%% 마지막 유효 토큰 hidden state로 분류
flowchart LR
  input["나는 &#124; 이 &#124; 영화가 &#124; 좋다 &#124; &lt;PAD&gt; &#124; &lt;PAD&gt;"]
  valid["마지막 유효 토큰<br/>좋다"]
  hidden["이 위치의 hidden state"]
  classifier["classifier"]
  input -->|패딩 직전| valid
  valid --> hidden
  hidden --> classifier

패딩 토큰이 있을 때는 마지막 유효 토큰(패딩 직전)의 hidden state를 사용한다.

미세조정 학습 과정

  1. 사전 학습된 GPT 가중치를 로드한다.
  2. LM Head를 제거하고 Classification Head를 붙인다.
  3. 과업 데이터(리뷰 텍스트 + 긍정/부정 라벨)를 준비한다.
  4. 전체 모델을 작은 학습률로 학습한다. 사전 학습 가중치가 크게 망가지지 않도록 학습률을 낮춘다(보통 5e-5 이하).
  5. Cross Entropy Loss로 분류 오차를 줄인다.

사전 학습 vs 미세조정 비교

미세조정 코드

GPTForSequenceClassification — 분류 모델

이 코드가 하는 일: GPT의 Transformer Block까지는 그대로 쓰되, LM Head(lm_head) 대신 classifier를 통과시킨다. hidden[:, -1, :]로 마지막 토큰의 벡터를 뽑아 2-class 분류에 사용한다.

ReviewSentimentDataset — 데이터 전처리

이 코드가 하는 일: 리뷰 텍스트를 토큰 ID 시퀀스로 변환하고, max_length에 맞춰 자르거나 패딩한다. 모든 입력의 길이가 동일해야 배치 처리가 가능하다.

shape 변환 추적 (미세조정 forward)

%% 미세조정 forward shape 변환
flowchart TD
  input_ids["input_ids: (32, 128)<br/>batch=32, max_length=128"]
  embedding["embedding: (32, 128, 768)<br/>토큰 + 위치 임베딩"]
  blocks["blocks: (32, 128, 768)<br/>12개 Transformer Block"]
  final_norm["final_norm: (32, 128, 768)<br/>LayerNorm"]
  last_token["[:, -1, :]: (32, 768)<br/>마지막 토큰만 추출"]
  dropout["dropout: (32, 768)<br/>정규화"]
  classifier["classifier: (32, 2)<br/>긍정/부정 logits"]
  input_ids --> embedding
  embedding --> blocks
  blocks --> final_norm
  final_norm --> last_token
  last_token --> dropout
  dropout --> classifier

사전 학습에서는 모든 위치의 logits(32, 128, 50257)를 사용했지만, 미세조정에서는 마지막 위치 하나의 벡터(32, 768)만 classifier에 넣는다.

미세조정 학습 루프

이 코드가 하는 일: 배치마다 forward → loss 계산 → backward → optimizer step을 반복한다. 사전 학습 루프와 구조가 같다. 차이는 loss가 다음 토큰 예측이 아니라 분류 cross entropy라는 점이다.

NSMC 감성 데이터 예시

밑바닥 LLM 과제에서는 NSMC(Naver Sentiment Movie Corpus)를 사용한다. 한국어 영화 리뷰 15만 건에 긍정(1)/부정(0) 라벨이 붙어 있다.

text: "이 영화 진짜 재밌다 강추"    label: 1 (긍정)
text: "시간 낭비 최악의 영화"        label: 0 (부정)
text: "배우 연기는 좋은데 스토리가..." label: 0 (부정)

make_sentiment_dataset()이 TSV 파일을 읽어 train/val/test 분할을 만든다.

evaluate_sentiment — 검증/테스트 평가

torch.no_grad()로 gradient 계산을 끄면 메모리 사용량이 줄고 속도가 빨라진다. 평가 시에는 파라미터를 업데이트하지 않으므로 gradient가 필요 없다.

왜 학습률을 낮추는가?

사전 학습 가중치는 수십 GB 텍스트에서 수천 GPU-시간에 걸쳐 최적화된 값이다. 높은 학습률로 미세조정하면 이 가중치가 급격히 바뀌어 사전 학습에서 얻은 언어 표현이 망가진다. 이를 catastrophic forgetting(파괴적 망각)이라 한다.

사전 학습 학습률: 1e-4 ~ 6e-4 미세조정 학습률: 1e-5 ~ 5e-5 (10~60배 작음)

작은 학습률은 기존 가중치를 크게 바꾸지 않으면서 분류 과업에 맞게 미세하게 조정한다. “미세”조정이라는 이름이 여기서 나온다.

정리

미세조정은 사전 학습된 GPT의 가중치를 특정 과업에 맞게 추가 학습하는 기법이다. LM Head를 Classification Head로 교체하고, 마지막 토큰의 hidden state를 문장 대표 벡터로 사용한다. 사전 학습이 언어의 일반 표현을 익힌 덕분에, 적은 라벨 데이터와 낮은 학습률로도 높은 분류 성능을 얻을 수 있다. GPT backbone의 가중치는 유지하면서 출력 층만 바꾸는 것이 핵심이다.

연결 문서:

  • 미세조정의 backbone이 되는 GPT 모델 구조
  • LM Head를 유지한 supervised learning 방식
  • 사람의 선호로 모델 행동을 정렬하는 파이프라인
