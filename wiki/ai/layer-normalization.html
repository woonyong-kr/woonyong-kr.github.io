Layer Normalization — 샘플 하나 안에서 정규화하는 기법

한 줄 요약: Layer Normalization은 배치가 아닌 단일 샘플의 feature 차원을 기준으로 평균과 분산을 구해 정규화하며, Transformer의 기본 정규화 기법이다.

Layer Normalization이 필요한 이유

자연어 처리 모델은 길이가 서로 다른 문장을 배치로 묶어 처리한다. 이때 Batch Normalization(Batch Normalization)을 적용하면 미니배치의 통계가 정규화 결과를 좌우한다.

배치가 1~2개처럼 작으면 평균과 분산 추정이 불안정해진다. 추론할 때는 학습 중에 누적한 running 통계도 따로 사용해야 한다. 문장 길이가 다르면 패딩 토큰이 배치 축의 통계에 포함되어 정규화를 왜곡할 수도 있다.

Layer Normalization(2016, Ba et al.)은 이런 배치 축 대신 feature 축인 마지막 차원에서 통계를 계산한다. 샘플 하나의 feature만으로 평균과 분산을 구하므로 배치 크기에 의존하지 않는다. Transformer(2017)가 이 방식을 채택한 이후 LLM의 표준으로 사용되고 있다.

정규화 축에서 시작하는 Layer Normalization 흐름

Batch Norm과 Layer Norm의 차이

입력이 (batch, seq_len, d_model) 형태라고 하자. Batch Norm은 batch 축(axis=0)을 기준으로 같은 feature에 있는 여러 샘플의 값을 비교한다. 반면 Layer Norm은 feature 축(axis=-1, 즉 d_model)을 기준으로 한 샘플 안의 서로 다른 feature를 비교한다.

%% Batch Norm과 Layer Norm의 정규화 축
flowchart TD
  title["입력 텐서: (batch=2, seq_len=4, d_model=768)"]
  batch["Batch Norm &#124; batch 축(↓)<br/>샘플1 토큰1 &#124; [a b c d]<br/>샘플2 토큰1 &#124; [e f g h]<br/>같은 위치의 feature를 샘플끼리 비교"]
  layer["Layer Norm &#124; feature 축(→)<br/>샘플1 토큰1 &#124; [a b c d]<br/>한 토큰의 d_model 차원 안에서 통계 계산"]
  title --> batch
  title --> layer

평균에서 출력까지

Layer Normalization은 Batch Normalization과 같은 형태의 수식을 사용하지만, 통계를 계산하는 축이 다르다. feature 차원의 크기를 d라고 하면 먼저 평균을 구한다.

1단계: feature 평균 계산 mu = (1/d) * sum(x_i) (d는 feature 차원 크기, 즉 d_model)

이 평균을 기준으로 각 feature가 얼마나 떨어져 있는지 계산해 분산을 구한다.

2단계: feature 분산 계산 var = (1/d) * sum((x_i - mu)

평균과 분산을 얻으면 각 값을 정규화한다. eps는 분산에 더해지는 값이다.

3단계: 정규화 x_norm = (x - mu) / sqrt(var + eps)

마지막으로 학습 가능한 파라미터를 적용한다.

4단계: 스케일과 시프트 y = gamma * x_norm + beta

gamma와 beta는 (d_model,) 형태다. gamma는 정규화된 값의 스케일을 조절하고 beta는 값을 이동시킨다. 이 파라미터를 학습하면 네트워크가 정규화된 출력을 조절할 수 있다.

Transformer가 feature 축을 사용하는 이유

Transformer의 입력은 (batch, seq_len, d_model) 형태의 3차원 텐서다. Attention은 각 토큰의 벡터를 다루지만, 배치에는 길이가 다른 여러 문장과 이를 맞추기 위한 패딩이 함께 들어갈 수 있다.

배치 축으로 정규화하면 서로 다른 문장의 같은 위치에 있는 토큰을 함께 비교한다. 이 과정에서 패딩이 섞이면 통계도 영향을 받는다. feature 축으로 정규화하면 각 토큰의 d_model 차원 안에서만 통계를 계산하므로 다른 문장이나 패딩의 값에 의존하지 않는다.

Autoregressive 생성에서는 토큰을 하나씩 생성하며 배치 크기가 1일 수 있다. 이 조건에서는 배치 통계에 의존하는 Batch Norm을 사용하기 어렵지만, Layer Norm은 각 샘플의 feature로 필요한 통계를 계산할 수 있다.

TransformerBlock 안의 Pre-Norm과 Post-Norm

정규화 축을 정한 다음에는 Layer Norm을 잔차 연결의 어느 위치에 둘지도 결정해야 한다. 원래 Transformer 논문(2017)은 SubLayer의 출력과 잔차를 더한 뒤 정규화하는 Post-Norm을 사용했다. Pre-Norm은 SubLayer에 입력하기 전에 정규화하고, 그 출력에 원래 입력을 잔차로 더한다.

Post-Norm: LayerNorm(x + SubLayer(x)) → 잔차 뒤에 정규화 Pre-Norm: x + SubLayer(LayerNorm(x)) → 정규화 뒤에 잔차

GPT-2 이후 대부분의 LLM은 Pre-Norm을 사용한다. Pre-Norm은 gradient 흐름을 더 안정적으로 만들어 깊은 층의 학습을 돕는다(기울기 소실·폭발 — 깊은 신경망이 학습을 멈추는 이유). 밑바닥 LLM 책의 TransformerBlock도 Pre-Norm 구조를 따른다.

%% Pre-Norm TransformerBlock 흐름
flowchart LR
  x["x"]
  ln1["LayerNorm"]
  attn["MultiHead Attn"]
  drop1["Dropout"]
  add1["+<br/>잔차 연결"]
  result1["result1"]
  ln2["LayerNorm"]
  ffn["FeedForward"]
  drop2["Dropout"]
  add2["+<br/>잔차 연결"]
  result2["result2 (출력)"]
  x --> ln1
  ln1 --> attn
  attn --> drop1
  drop1 --> add1
  add1 --> result1
  result1 --> ln2
  ln2 --> ffn
  ffn --> drop2
  drop2 --> add2
  add2 --> result2
  x --> add1
  result1 --> add2

이 흐름에서는 입력 x가 LayerNorm과 MultiHead Attn을 거친 결과에 다시 더해져 result1이 된다. result1도 같은 방식으로 LayerNorm과 FeedForward를 거친 결과에 더해져 최종 출력을 만든다.

텐서 코드로 따라가는 Layer Normalization

밑바닥 LLM의 LayerNorm 클래스

dim=-1은 통계를 마지막 차원인 d_model에서만 계산하도록 지정한다. keepdim=True는 계산한 평균과 분산의 마지막 차원을 유지한다. 따라서 (batch, seq_len, d_model) 형태의 x에서 평균과 분산을 빼거나 나눌 때 브로드캐스팅할 수 있다.

shape 변환 추적

%% Layer Normalization shape 변환 추적
flowchart TD
  input["입력 x<br/>(batch=2, seq_len=4, d_model=768)"]
  mean["mean = x.mean(dim=-1, keepdim=True)<br/>(2, 4, 1)"]
  var["var = x.var(dim=-1, keepdim=True)<br/>(2, 4, 1)"]
  norm["x_norm = (x - mean) / sqrt(var + eps)<br/>(2, 4, 768)"]
  affine["gamma * x_norm + beta<br/>(768,)"]
  output["출력<br/>(2, 4, 768)"]
  input --> mean
  mean --> var
  var --> norm
  norm --> affine
  affine --> output

평균과 분산은 마지막 차원이 1인 형태로 계산된다. 정규화할 때는 이 값이 각 토큰의 d_model 차원으로 브로드캐스팅된다. (d_model,) 형태의 gamma와 beta도 같은 방식으로 적용되므로 최종 출력은 입력과 같은 shape을 유지한다.

Batch Norm과 축 비교하기

입력 x의 shape은 (2, 4, 768)이다. Batch Norm 방식으로 axis=0의 평균을 계산하면 배치 차원이 사라져 (4, 768)이 된다. Layer Norm 방식으로 axis=-1의 평균을 계산하면 feature 차원이 1로 유지되어 (2, 4, 1)이 된다. 두 결과의 차이는 어느 축의 값을 한 통계로 묶었는지 보여준다.

토큰 하나를 숫자로 확인하기

이 예에서는 토큰 하나를 나타내는 4개 feature의 평균이 2.5이고 분산이 1.25다. 각 feature에서 평균을 빼고 sqrt(var + eps)로 나누면 평균은 약 0, 분산은 약 1인 값이 된다. gamma=1, beta=0이면 이 정규화 결과가 그대로 출력된다.

Layer Normalization은 이 계산을 각 샘플의 feature 축에서 독립적으로 수행한다. 그래서 배치 크기나 다른 문장의 값에 통계를 의존하지 않는다. Transformer의 Pre-Norm 구조에서는 Attention과 FFN 앞에서 입력을 정규화하고, SubLayer의 결과에 잔차를 더해 gradient 흐름을 안정화한다(기울기 소실·폭발 — 깊은 신경망이 학습을 멈추는 이유).

연결 문서: 트랜스포머 블록, 숏컷 연결 — 깊은 신경망의 기울기를 살리는 우회 경로
