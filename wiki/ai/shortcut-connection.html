숏컷 연결 — 깊은 신경망의 기울기를 살리는 우회 경로

확인 범위: 이 문서는 숏컷 연결의 일반 원리와 Transformer Block에서의 구조·적용 조건을 설명하며, 제시된 PyTorch·NumPy 코드와 수치 계산은 개념을 보여 주는 구현 및 가정 기반 예시다. 특정 코드·버전의 실제 동작, 기울기 보존 정도나 성능 효과를 검증한 실행 기록 또는 측정 결과로 해석해서는 안 된다.

한 줄 요약: 숏컷 연결(Shortcut Connection)은 층의 입력을 출력에 그대로 더하는 구조로, 기울기가 소실 없이 깊은 층까지 전달되게 한다.

숏컷 연결 혼동

신경망을 깊게 쌓으면 성능이 올라갈 것 같지만, 실제로는 일정 깊이를 넘으면 오히려 성능이 떨어진다. 역전파 과정에서 기울기가 곱셈으로 전달되기 때문이다. 각 층의 기울기가 1보다 작으면 층을 거칠수록 기울기가 기하급수적으로 줄어든다 — 기울기 소실(vanishing gradient) 문제다.

GPT-2 small은 Transformer Block을 12개 쌓고, GPT-3은 96개를 쌓는다. 숏컷 연결 없이 96개 층을 통과하면 앞쪽 층의 가중치는 거의 학습되지 않는다. 숏컷 연결은 이 문제를 해결하기 위해 ResNet(2015)에서 처음 제안되었고, Transformer에서도 핵심 구조로 사용된다.

숏컷 연결 구조

비유

고속도로에 톨게이트가 100개 있다고 하자. 차(기울기)가 톨게이트를 하나씩 통과할 때마다 속도가 줄어든다면, 100번째 톨게이트를 지날 때쯤 차가 멈춰 버린다. 숏컷 연결은 각 톨게이트 옆에 우회 차선을 하나 더 놓는 것이다. 차는 톨게이트를 통과한 차량과 우회한 차량이 합류해서 다음으로 넘어간다. 우회 차선으로 최소한의 속도가 항상 유지되므로 100번째까지 도달할 수 있다.

정의

숏컷 연결(shortcut connection), 또는 잔차 연결(residual connection)은 다음 구조다.

y = x + f(x)

x는 층의 입력, f(x)는 층이 학습하는 변환, y는 층의 출력이다. 핵심은 + x 부분이다. 층의 변환 결과에 입력을 그대로 더한다.

왜 기울기가 살아남는가?

y = x + f(x)를 x에 대해 미분하면:

dy/dx = 1 + df(x)/dx

항등 경로가 Jacobian에 I를 더해 변환 경로를 거치지 않는 gradient 통로를 만든다. 다만 df(x)/dx가 음수이거나 행렬 Jacobian의 방향이 상쇄될 수 있으므로 gradient 크기가 항상 1 이상이라는 뜻은 아니다. 핵심은 모든 gradient가 변환 경로의 곱에만 의존하지 않게 된다는 점이다.

숏컷 연결이 없으면:

dy/dx = df(x)/dx

96개 층을 통과하면 기울기는 각 층의 미분값을 곱한 것이다. 하나라도 0에 가까우면 전체가 0에 수렴한다. 숏컷 연결이 있으면 항등 경로(identity path)를 통해 기울기가 직통으로 전달된다.

Transformer Block에서의 숏컷 연결

GPT의 Transformer Block은 숏컷 연결을 두 번 사용한다.

flowchart TD
  x["입력 x"] --> ln1["LayerNorm"] --> mha["Multi-Head Attention"] --> add1["합산"]
  x -->|"숏컷 1"| add1
  add1 --> y1["y1 = x + MHA(LN(x))"]
  y1 --> ln2["LayerNorm"] --> ffn["FeedForward + GELU"] --> add2["합산"]
  y1 -->|"숏컷 2"| add2
  add2 --> y2["y2 = y1 + FFN(LN(y1))"]

첫 번째 숏컷은 Attention을 우회하고, 두 번째 숏컷은 FeedForward를 우회한다. 이 구조를 Pre-Norm이라 부른다 — LayerNorm이 변환 전에 위치하기 때문이다. GPT-2 이후 표준이다.

숏컷 연결 코드

PyTorch 구현 (밑바닥 LLM 과제 템플릿)

shortcut = x로 입력을 저장해두고, 변환이 끝난 뒤 x = x + shortcut으로 더한다. 이것이 숏컷 연결의 전부다. 코드로 보면 단순한 덧셈이지만, 이 한 줄이 깊은 네트워크의 학습을 가능하게 한다.

NumPy 구현 (순전파 + 역전파)

역전파에서도 숏컷 연결은 덧셈이다. y = x + f(x)의 역전파는 d_out이 두 갈래로 갈라진다: 하나는 f(x)를 통해 역전파되고(d_ffn), 하나는 항등 경로로 그대로 통과한다(d_out). 이 둘을 더한 것이 다음 층으로 전달된다.

숫자로 확인하기 — 기울기 소실 비교

이 계산은 각 층의 도함수가 같은 양의 스칼라라는 가정에서 두 경로의 차이를 보여주는 예시일 뿐, 실제 행렬 Jacobian의 gradient 크기를 보장하는 증명은 아니다.

shape 변환 추적

숏컷 연결이 작동하려면 입력과 출력의 shape가 동일해야 한다.

  • x: (B, T, d_model)
  • LayerNorm → (B, T, d_model) shape 변화 없음
  • MHA → (B, T, d_model) 내부에서 head 분리/합치지만 최종 shape 동일
    • x → (B, T, d_model) 같은 shape끼리 원소별 덧셈

FeedForward 내부에서는 d_model → 4*d_model → d_model로 확장했다 축소하지만, FeedForward의 최종 출력은 (B, T, d_model)이므로 숏컷 덧셈이 가능하다.

정리

숏컷 연결은 y = x + f(x)로 층의 입력을 출력에 더하는 구조다. 미분 시 항등 Jacobian이 추가되어 gradient가 변환 경로의 연속 곱에만 의존하지 않는다. Transformer Block은 Attention과 FeedForward를 각각 우회하는 두 항등 경로를 사용한다.
