기댓값 · 분산 · 공분산

기댓값 · 분산 · 공분산

확인 범위: 이 문서는 기댓값·분산·공분산의 일반 개념과 신경망에서의 활용 원리를 설명하고, 제시된 NumPy 및 SW_AI-W13-mnist 코드 예시로 계산 흐름을 보여준다. 특정 구현의 정확성이나 버전별 동작, 실제 실행 결과와 성능은 검증하지 않으므로 이에 관한 판단에는 해당 코드·환경·실행 기록과 별도의 측정이 필요하다.

한 줄 요약: 기댓값은 분포의 중심, 분산은 중심에서 얼마나 퍼져 있는지, 공분산은 두 변수가 함께 움직이는 정도를 하나의 숫자로 요약한다.

기댓값 · 분산 · 공분산 필요성

신경망 코드를 읽다 보면 np.mean(), np.var()가 반복적으로 등장한다.

  • Batch Normalization은 각 층 입력의 평균과 분산을 맞춘다. “평균 0, 분산 1로 정규화”라는 말이 무엇인지 모르면 BatchNorm 코드를 읽을 수 없다.
  • 가중치 초기화(He, Xavier)는 층의 출력 분산을 일정하게 유지하도록 설계한다. 분산이 뭔지 모르면 np.sqrt(2.0 / fan_in)이라는 숫자가 어디서 왔는지 알 수 없다.
  • 손실 함수의 배치 평균 / batch_size는 기댓값의 추정이다.

기댓값과 분산을 모르면 신경망 학습의 안정화 기법 전체가 블랙박스로 남는다.

기댓값 · 분산 · 공분산 계산

기댓값 (Expectation)

기댓값은 “이 분포에서 값을 뽑으면 평균적으로 얼마가 나오는가”를 하나의 숫자로 답한다.

이산 확률 변수 X가 값 x_1, x_2, …, x_n을 확률 p_1, p_2, …, p_n으로 가질 때:

E[X] = x_1 * p_1 + x_2 * p_2 + … + x_n * p_n

데이터에서 확률을 모를 때는 관측값의 산술 평균으로 추정한다:

x_bar = (x_1 + x_2 + … + x_n) / n

이것이 np.mean(x)다. 관측값이 충분히 많으면 x_bar는 E[X]에 수렴한다(대수의 법칙).

분산 (Variance)

분산은 “값들이 평균에서 얼마나 떨어져 있는가”를 재는 척도다.

Var(X) = E[(X - E[X])

풀어 쓰면: 각 값에서 평균을 빼고, 제곱하고, 다시 평균을 낸다.

데이터에서의 추정:

var = (1/n) * sum((x_i - x_bar)

이것이 np.var(x)다. 표준편차(Standard Deviation)는 분산의 제곱근이다: std = sqrt(var). 단위를 원래 데이터와 맞춰준다.

왜 제곱인가?

평균과의 차이를 단순 합산하면 양수와 음수가 상쇄되어 0이 된다. 절대값을 쓸 수도 있지만, 제곱은 미분이 가능하고 계산이 깔끔하다. 신경망에서 MSE 손실이 제곱 오차를 쓰는 이유도 같다.

공분산 (Covariance)

공분산은 두 변수가 함께 움직이는 정도를 잰다.

Cov(X, Y) = E[(X - E[X]) * (Y - E[Y])]

  • Cov > 0: X가 커지면 Y도 커지는 경향
  • Cov < 0: X가 커지면 Y는 작아지는 경향
  • Cov = 0: 선형 관계 없음

공분산의 크기는 변수의 스케일에 의존한다. 스케일을 제거한 것이 상관계수다:

corr(X, Y) = Cov(X, Y) / (std(X) * std(Y))

신경망에서 공분산이 직접 등장하는 곳은 드물지만, PCA(주성분 분석)에서 공분산 행렬의 고유벡터를 구하는 것이 핵심이다.

기댓값의 성질

기댓값은 선형이다:

  • E[aX + b] = a * E[X] + b
  • E[X + Y] = E[X] + E[Y]

분산은 선형이 아니다:

  • Var(aX + b) = a^2 * Var(X)

이 성질이 가중치 초기화에서 결정적이다. 입력 x에 가중치 W를 곱하면 출력의 분산은 입력 분산에 W의 분산과 입력 차원 수를 곱한 것에 비례한다. 층을 거칠수록 분산이 커지거나 줄어드는 것을 막으려면, W의 분산을 1/fan_in 또는 2/fan_in으로 맞춰야 한다.

BatchNorm에서의 평균과 분산

axis=0은 배치 차원을 따라 평균을 낸다는 뜻이다. 배치 크기가 32이고 feature가 256개이면, mu는 길이 256 벡터다. 각 feature마다 32개 샘플의 평균을 구한다.

배치 차원을 줄여 feature별 통계 하나씩을 얻고, 다시 broadcasting으로 정규화하는 흐름은 다음과 같다.

%% BatchNorm 평균·분산 shape 흐름
flowchart TD
  input["입력 x<br/>shape: (batch=32, feature=256)"]
  stats["axis=0 축소<br/>np.mean(x, axis=0)<br/>mu, var: (256,)"]
  normalize["정규화<br/>std = sqrt(var + eps)<br/>(x - mu) / std<br/>broadcasting: (32, 256)"]
  xnorm["x_norm<br/>shape: (batch=32, feature=256)"]
  affine["학습 가능한 복원<br/>gamma * x_norm + beta"]
  output["out<br/>shape: (batch=32, feature=256)"]
  input --> stats
  stats --> normalize
  normalize --> xnorm
  xnorm --> affine
  affine --> output

축소(axis=0)로 shape가 (32,256) → (256,)이 되고, 정규화·복원 단계에서 broadcasting으로 다시 (32,256)이 된다.

정규화된 x_norm은 평균 0, 분산 1이다. 이후 학습 가능한 gamma와 beta로 다시 스케일·이동한다:

gamma = 1, beta = 0이면 그대로다. 학습을 통해 “이 층은 평균 0보다 살짝 양수가 낫다”고 판단하면 beta가 조정된다.

가중치 초기화에서의 분산

np.random.randn()은 평균 0, 분산 1인 표준 정규 분포에서 뽑는다. 여기에 sqrt(2/fan_in)을 곱하면 분산이 2/fan_in이 된다(Var(aX) = a^2 * Var(X)이므로).

fan_in = 784일 때: 분산 = 2/784 ≈ 0.00255, 표준편차 ≈ 0.0505. 가중치 하나하나는 아주 작은 값이지만, 784개를 합산하면 출력의 분산이 적절한 범위에 유지된다. 이것이 He 초기화다.

손실 함수의 배치 평균

개별 샘플의 loss를 합산한 뒤 batch_size로 나눈다. 이것은 loss의 기댓값을 추정하는 것이다. 배치 크기가 달라져도 loss의 스케일이 일정하므로, 학습률을 배치 크기에 따라 바꿀 필요가 줄어든다.

정리

기댓값은 분포의 중심, 분산은 퍼짐의 크기, 공분산은 두 변수의 동반 변동을 하나의 숫자로 요약한다. 신경망에서 이 세 통계량은 Batch Normalization의 정규화, 가중치 초기화의 분산 조절, 손실 함수의 배치 평균에서 직접 사용된다. 분산의 선형 변환 성질(Var(aX) = a^2 * Var(X))은 He/Xavier 초기화의 수학적 근거다.
