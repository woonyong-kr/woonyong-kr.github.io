언어 모델 목적함수 — Causal LM, Masked LM, Prefix LM

언어 모델의 목적함수는 입력에서 어떤 토큰을 예측할지 정한다. Causal LM, Masked LM, Prefix LM은 예측 대상뿐 아니라 각 토큰이 참조할 수 있는 문맥도 다르다.

언어 모델에 목적함수가 필요한 이유

Transformer 블록을 사용하더라도 학습 목표와 attention mask의 구성에 따라 모델이 처리하는 문맥은 달라진다. 이 문서에서 비교하는 GPT 계열은 다음 토큰을 예측하는 Causal LM을 사용하고, BERT는 가린 토큰을 복원하는 Masked LM을 사용한다. 따라서 두 모델의 차이를 Transformer 블록만으로 설명하기보다는 무엇을 예측하도록 학습하는지 함께 살펴봐야 한다.

목적함수는 예측할 위치를 정하고, attention mask는 각 위치가 볼 수 있는 범위를 제한한다. Causal LM에서는 미래 토큰을 가리고, Masked LM에서는 입력 전체를 양방향으로 참조한다. Prefix LM에서는 조건으로 주어진 prefix와 생성할 부분에 서로 다른 참조 범위를 적용한다. 이 차이는 모델이 학습 신호를 얻는 위치와 문맥을 사용하는 방식에 영향을 준다.

목적함수가 바꾸는 것

세 가지 학습 방식

입력: [A] [B] [C] [D] [E]

Causal LM (GPT):
  [A] → 예측: B
  [A][B] → 예측: C
  [A][B][C] → 예측: D
  [A][B][C][D] → 예측: E
  각 위치는 자기 왼쪽만 본다.

Masked LM (BERT):
  [A] [MASK] [C] [D] [E] → 예측: B (빈칸)
  모든 위치가 양방향으로 서로를 본다.

Prefix LM (T5 encoder):
  [A][B][C] | [D][E]
  prefix(A,B,C)는 서로 양방향으로 보고,
  생성부(D,E)는 왼쪽만 본다.

Causal LM — 다음 토큰 예측

Causal LM은 각 위치에서 지금까지 주어진 토큰을 바탕으로 다음 토큰을 예측하도록 학습한다. 이 문서에서 다루는 GPT 계열이 사용하는 방식이다.

미래 토큰을 보지 못하게 하는 장치가 causal mask다. attention score 행렬에서 미래 위치를 -inf로 채우면 softmax를 거친 뒤 그 위치의 값은 0이 된다. 그 결과 각 토큰은 자기 자신과 왼쪽에 있는 토큰만 참조한다.

Causal Attention Mask (4 토큰):

     t1   t2   t3   t4
t1 [ 0   -inf -inf -inf ]
t2 [ 0    0   -inf -inf ]
t3 [ 0    0    0   -inf ]
t4 [ 0    0    0    0   ]

0 = 볼 수 있음, -inf = 볼 수 없음 (softmax 후 0)

Loss는 모든 예측 위치의 cross-entropy를 합산한다. 길이가 T인 시퀀스에서 다음 토큰을 맞히는 쌍은 T-1개이며, 이 예측들을 동시에 학습할 수 있다.

수식으로 나타내면 다음과 같다.

L = -(1/T) * sum_{t=1}^{T} log P(x_t | x_1, ..., x_{t-1})

P(x_t | x_1, ..., x_{t-1})는 t번째 위치의 정답 토큰에 모델이 부여한 확률이다.

Causal LM은 학습과 생성에서 모두 왼쪽에서 오른쪽으로 토큰을 처리하므로 텍스트 생성과 자연스럽게 연결된다. 반면 각 위치가 오른쪽 문맥을 참조할 수 없으므로, 양쪽 문맥을 함께 사용해야 하는 빈칸 복원 방식과는 맞지 않는다.

Masked LM — 빈칸 맞히기

Masked LM은 입력 토큰의 일부를 [MASK] 토큰으로 바꾸고 원래 토큰을 예측하도록 학습한다. 이 문서의 예에서는 15%를 마스킹하며, BERT가 이 방식을 사용한다.

여기에는 causal mask와 같은 인과 제약이 없다. 각 토큰은 입력의 왼쪽과 오른쪽 문맥을 모두 참조할 수 있다.

Masked LM 예시:

원문:  나는 서울에서 개발자로 일한다
입력:  나는 [MASK] 개발자로 [MASK]
정답:  서울에서, 일한다

"[MASK]" 위치만 loss에 기여한다.
나머지 위치는 loss를 계산하지 않는다.

Loss는 마스킹된 위치에서만 계산한다.

L = -(1/|M|) * sum_{t in M} log P(x_t | x_masked)

M은 마스킹된 위치의 집합이고, x_masked는 마스킹된 입력 전체다.

양방향 문맥을 활용하므로 문장 이해, 감성 분류, 개체명 인식과 같은 과업에 사용할 수 있다. 다만 이 문서에서 비교한 설정에서는 한 번에 마스킹된 위치만 학습 신호를 만든다. 모든 다음 토큰 위치를 사용하는 Causal LM보다 한 시퀀스에서 얻는 학습 신호가 적다. 또한 토큰을 왼쪽에서 오른쪽으로 생성하도록 학습하는 구조가 아니므로 텍스트 생성에는 추가 기법이 필요하다.

Prefix LM — 양방향 입력과 단방향 생성

Prefix LM은 입력 시퀀스를 조건에 해당하는 prefix와 생성부로 나눈다. prefix 토큰끼리는 양방향으로 참조하고, 생성부의 각 토큰은 prefix 전체와 생성부에서 자기 왼쪽에 있는 토큰을 참조한다. 이 문서에서는 T5의 encoder 쪽을 이 개념에 가까운 사례로 다룬다.

Prefix LM Mask (prefix 3개 + 생성 2개):

     p1   p2   p3   g1   g2
p1 [ 0    0    0   -inf -inf ]   ← prefix끼리 양방향
p2 [ 0    0    0   -inf -inf ]
p3 [ 0    0    0   -inf -inf ]
g1 [ 0    0    0    0   -inf ]   ← 생성부는 prefix + 자기 왼쪽
g2 [ 0    0    0    0    0   ]

이 구성에서는 질문이나 문서처럼 조건으로 주어진 부분을 양방향으로 참조한 뒤 답변을 순서대로 생성할 수 있다. 대신 prefix와 생성부의 경계를 정해야 하며, causal mask 하나만 사용하는 경우보다 mask 구성이 복잡하다.

세 방식 비교

  • Causal LM (GPT)
    • mask: 왼쪽만 봄 (삼각형)
    • 학습 신호: 모든 다음 토큰 위치
    • 강점: 텍스트 생성, 대화
    • 대표 모델: GPT-2, GPT-3, GPT-4, LLaMA, Mistral
  • Masked LM (BERT)
    • mask: 양방향 (인과 제약 없음)
    • 학습 신호: 마스킹된 위치만 (~15%)
    • 강점: 문장 이해, 분류, NER
    • 대표 모델: BERT, RoBERTa, DeBERTa
  • Prefix LM (T5 encoder)
    • mask: prefix 양방향 + 생성부 단방향
    • 학습 신호: 생성부 위치
    • 강점: 조건부 생성 (번역, 요약, QA)
    • 대표 모델: T5, UL2

언어 모델 목적함수 코드

Causal LM: 입력-타깃 쌍 만들기

Causal LM에서는 원문에서 input과 label을 함께 만들 수 있다. 다음 토큰이 이미 텍스트에 있으므로 사람이 별도의 label을 붙이지 않아도 된다.

텍스트를 토큰 ID로 변환한 뒤 target을 한 칸 앞으로 밀어 input과 target의 쌍을 만든다. GPT의 forward 과정에서는 causal mask가 미래 위치를 가린다. 따라서 각 위치는 이후 토큰을 직접 보지 않은 상태로 다음 토큰을 동시에 예측한다.

Causal LM Loss 계산 (numpy 예시)

이 예시는 세 위치에서 다음 토큰을 동시에 예측한다. 각 위치에서 정답에 부여한 확률에 -log를 취한 뒤 평균하여 loss를 계산한다. 세 위치가 모두 학습 신호를 만든다는 점도 확인할 수 있다.

Causal Mask 구현

torch.triu로 상삼각 행렬을 만든 뒤 미래 위치를 -inf로 채운다. 이 mask를 attention score에 더하면 softmax 이후 미래 토큰의 attention weight가 0이 된다. 각 위치가 이후 토큰을 참조하지 않으므로 여러 위치의 다음 토큰 예측을 한 번에 학습할 수 있다.

목적함수별 입출력 비교 (numpy 예시)

이 예시는 같은 다섯 토큰을 사용했을 때 학습 신호가 생기는 위치를 비교한다. 여기에 설정된 마스킹 위치와 prefix 길이를 기준으로 Causal LM은 4개, Masked LM은 1개, Prefix LM은 2개의 학습 신호를 만든다. 이 숫자는 예시의 설정에서 나온 결과이며 모든 입력에 그대로 적용되는 고정값은 아니다.

Attention Mask 형태 비교

아래 표기에서 ○는 참조할 수 있는 위치, ×는 참조할 수 없는 위치다. Causal LM은 왼쪽까지 열린 삼각형이고, Masked LM은 모든 위치가 열려 있다. Prefix LM은 왼쪽 두 위치를 양방향 prefix로 두고 오른쪽 두 위치에는 단방향 제약을 적용한 예다.

  • Causal LM (4×4): Masked LM (4×4): Prefix LM (2+2):
  • ○ | × | × | × | | ○ | ○ | ○ | ○ | | ○ | ○ | × | ×
  • ○ | ○ | × | × | | ○ | ○ | ○ | ○ | | ○ | ○ | × | ×
  • ○ | ○ | ○ | × | | ○ | ○ | ○ | ○ | | ○ | ○ | ○ | ×
  • ○ | ○ | ○ | ○ | | ○ | ○ | ○ | ○ | | ○ | ○ | ○ | ○

세 목적함수의 차이를 설명하는 기준

세 방식은 어떤 토큰을 예측하고 어떤 문맥을 참조하는지로 구분할 수 있다. Causal LM은 왼쪽 문맥으로 다음 토큰을 예측하고, Masked LM은 양방향 문맥으로 가린 토큰을 복원한다. Prefix LM은 조건 부분을 양방향으로 참조하면서 생성부를 왼쪽에서 오른쪽으로 예측한다.

이 문서에 열거된 GPT-4, LLaMA, Mistral 같은 생성 모델은 Causal LM의 대표 모델로 분류되어 있다. 본문의 비교 범위에서는 Causal LM이 모든 다음 토큰 위치에서 학습 신호를 만들고 생성 방향과 같은 방식으로 동작한다는 점으로 그 선택을 설명할 수 있다.
