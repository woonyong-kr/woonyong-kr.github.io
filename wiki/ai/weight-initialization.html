가중치 초기화 — 신경망 학습의 출발점을 결정하는 방법

한 줄 요약: 가중치 초기화는 신경망의 각 층이 처음 시작할 때 가중치를 어떤 분포로 설정하느냐를 결정하며, 잘못 설정하면 기울기 소실·폭발로 학습이 멈춘다.

가중치 초기화 혼동

신경망은 가중치(weight)를 반복적으로 갱신하며 학습한다. 이 가중치의 초깃값이 학습 성패를 가른다.

모든 가중치를 0으로 초기화하면, 같은 층의 모든 뉴런이 동일한 출력을 내고, 역전파 시 동일한 기울기를 받는다. 결과적으로 뉴런이 아무리 많아도 하나와 같다. 이것을 “대칭 문제(symmetry problem)“라 한다.

반대로 가중치를 너무 크게 잡으면, 층을 거칠수록 출력 값이 기하급수적으로 커진다. Sigmoid 같은 활성화 함수는 포화 영역에 빠져 기울기가 0에 가까워지고, 역전파가 끊긴다(기울기 소실). 가중치를 너무 작게 잡으면, 출력 값이 0 근처로 몰리면서 역시 표현력을 잃는다.

핵심은 “각 층의 출력 분산이 일정하게 유지되도록” 가중치의 초기 분포를 설계하는 것이다.

가중치 초기화 변화

기본 아이디어: 분산을 맞춘다

한 층의 연산은 y = Wx + b이다. 입력 x가 평균 0, 분산 1이라 가정하면, 출력 y의 분산은 가중치 W의 분산 × 입력 차원수(fan_in)에 비례한다.

출력 분산을 입력 분산과 같게 유지하려면:

Var(W) = 1 / fan_in

이것이 가중치 초기화의 핵심 공식이다.

Xavier 초기화 (Glorot 초기화)

Xavier Glorot이 2010년에 제안했다. Sigmoid, Tanh처럼 원점 대칭인 활성화 함수에 적합하다.

순전파와 역전파 양쪽의 분산을 모두 고려한다:

Var(W) = 2 / (fan_in + fan_out)

fan_in은 입력 뉴런 수, fan_out은 출력 뉴런 수이다.

표준정규분포에서 뽑은 뒤 스케일링하면:

W = np.random.randn(fan_in, fan_out) * sqrt(2 / (fan_in + fan_out))

He 초기화 (Kaiming 초기화)

Kaiming He가 2015년에 제안했다. ReLU 활성화 함수에 적합하다.

ReLU는 음수 입력을 0으로 자른다. 이 때문에 출력의 절반이 0이 되어 분산이 반으로 줄어든다. 이를 보상하기 위해 분산을 2배로 키운다:

Var(W) = 2 / fan_in

코드로 표현하면:

W = np.random.randn(fan_in, fan_out) * sqrt(2 / fan_in)

왜 He 초기화가 ReLU에 필요한가?

Xavier 초기화로 ReLU 네트워크를 학습하면, 층이 깊어질수록 출력 분산이 줄어든다. ReLU가 음수를 0으로 만들어 분산을 절반으로 깎기 때문이다. 5~10층만 쌓아도 출력이 거의 0에 수렴한다.

He 초기화는 분산을 2/fan_in으로 설정해 ReLU의 절반 손실을 정확히 상쇄한다. 층을 깊게 쌓아도 출력 분산이 유지된다.

가중치 초기화 코드

He 초기화 — MNIST 신경망

layer_sizes가 [784, 512, 256, 10]이면 첫 번째 층의 가중치는 (784, 512) 형태이다. np.random.randn(784, 512)로 표준정규분포에서 뽑은 뒤, sqrt(2/784) ≈ 0.0505를 곱한다. 가중치 값이 대략 -0.15 ~ +0.15 범위에 분포한다.

편향(bias)은 0으로 초기화한다. 편향은 대칭 문제에 영향을 주지 않으므로 0이면 충분하다.

숫자로 확인

He 초기화의 표준편차가 Xavier보다 크다. ReLU의 절반 손실을 보상하기 위해서다.

층별 출력 분산 비교

  • 입력 x: shape (batch, 784), 분산 ≈ 1.0
  • Affine1 | W: (784, 512), He init
  • y = xW + b | 출력 분산 ≈ 2.0 (ReLU 전)
  • ReLU1 | 음수 → 0, 분산 ≈ 1.0 (절반)
  • Affine2 | W: (512, 256), He init
  • y = xW + b | 출력 분산 ≈ 2.0 (ReLU 전)
  • ReLU2 | 음수 → 0, 분산 ≈ 1.0 (절반)

He 초기화 덕분에 ReLU를 거쳐도 분산이 약 1.0으로 유지된다.

정리

가중치 초기화는 각 층의 출력 분산을 일정하게 유지하는 것이 목표다. Xavier 초기화는 Sigmoid/Tanh에 적합하고 sqrt(2/(fan_in+fan_out))을 사용한다. He 초기화는 ReLU에 적합하고 sqrt(2/fan_in)을 사용하며, ReLU가 음수를 0으로 만들어 분산을 절반으로 줄이는 것을 보상한다. 밑바닥 딥러닝1 MNIST 코드는 He 초기화를 사용한다.
