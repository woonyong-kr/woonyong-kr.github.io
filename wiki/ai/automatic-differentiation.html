자동 미분

자동 미분

한 줄 요약: 자동 미분은 연산 그래프를 기록해 두고 연쇄법칙을 기계적으로 적용해 기울기를 구하는 기법이다. numpy는 층마다 backward()를 손으로 짜야 하지만, PyTorch는 이 과정을 autograd가 대신한다.

자동 미분이 비용을 줄이는 자리

오차역전파법은 기울기를 구하는 알고리즘이고, 연쇄법칙은 그 수학적 근거다. 역전파 계층 구현에서는 Affine, ReLU 같은 층의 backward()를 직접 짰다.

이 방식에서는 층을 추가할 때마다 해당 층의 미분을 직접 유도해 코드로 옮겨야 한다. 새 연산을 실험할 때도 미분을 다시 계산해야 하므로 작업이 느려지고 실수가 생길 수 있다. Transformer처럼 여러 종류의 연산이 얽힌 모델에서는 사람이 모든 backward()를 관리하기가 더 어려워진다.

자동 미분(Automatic Differentiation, autodiff)은 이 부담을 줄인다. 순전파 연산을 작성하면 프레임워크가 연산들을 그래프로 기록하고 역전파를 수행한다. PyTorch에서 loss.backward()를 호출해 파라미터의 기울기를 채우는 과정이 여기에 해당한다.

자동 미분을 이해하려면 수치 미분, 기호 미분과 무엇이 다른지 함께 살펴볼 수 있다.

  • 수치 미분(numerical): 값을 흔들어 근사하므로 오차가 생길 수 있다. (비교 문서)
  • 기호 미분(symbolic): 수식 자체를 미분 공식으로 변형하며, 변형 과정에서 식이 크게 늘어날 수 있다.
  • 자동 미분(automatic): 기본 연산을 기록하고 각 연산의 국소 미분을 연쇄법칙으로 합성한다.

이 문서에서는 자동 미분이 항상 정확하거나 빠르다고 일반화하기보다, 아래에 나온 신경망과 PyTorch의 reverse-mode 맥락에서 계산 과정과 장점을 설명한다.

자동 미분 구조

비유: 영수증을 보관하는 계산

물건을 살 때 영수증을 모두 모아 두면, 나중에 “이 품목 가격이 1원 오르면 총액이 얼마 오르나”를 영수증을 거꾸로 따라가며 계산할 수 있다. 자동 미분도 순전파의 연산을 영수증처럼 기록(graph)해 두고, 역방향으로 따라가며 기울기를 계산한다.

정의

자동 미분은 프로그램이 수행한 기본 연산(덧셈, 곱셈, exp 등)의 순서를 기록하고, 각 연산의 국소 미분을 연쇄법칙으로 합성해 도함수를 구하는 기법이다.

  • 각 기본 연산에는 대응하는 미분 규칙이 있다. 곱셈에서는 상대방 값을 사용하고, exp에서는 자기 자신을 사용한다.
  • 순전파 때 연산 그래프(computational graph)를 만든다.
  • 역전파 때 그래프를 출력에서 입력 방향으로 거슬러 가며 국소 미분을 곱한다.

두 가지 모드: forward-mode와 reverse-mode

자동 미분은 미분을 전파하는 방향에 따라 두 모드로 나뉜다.

  • forward-mode (전방 모드)
    • 입력에서 출력 방향으로 미분을 함께 전파한다.
    • 입력이 적고 출력이 많을 때 유리하다.
  • reverse-mode (후방 모드)
    • 순전파로 값을 먼저 구하고, 출력에서 입력 방향으로 미분을 전파한다.
    • 출력이 1개인 스칼라 손실이고 입력인 파라미터가 많을 때 유리하다.

이 문서에서 다루는 신경망은 입력 파라미터가 수백만 개이고 출력은 손실 스칼라 1개인 구조다. 이 구조에서는 딥러닝 프레임워크가 사용하는 reverse-mode가 적합하다. 여기서 역전파(backpropagation)는 신경망에 적용한 reverse-mode 자동 미분을 가리킨다.

왜 reverse-mode가 신경망에 유리한가?

파라미터 N개와 출력 1개를 가진 함수를 생각해 보자.

  • forward-mode: 입력 방향마다 한 번씩 그래프를 훑어야 한다 → N번 통과.
  • reverse-mode: 출력 1개에서 한 번 거슬러 가며 모든 입력의 기울기를 구한다 → 1번 통과.

N = 530,000인 밑시딥1 예제 신경망에 이 설명을 적용하면, forward-mode는 53만 번의 통과가 필요하고 reverse-mode는 한 번의 역방향 통과로 각 입력의 기울기를 계산한다. 이 비교에서 reverse-mode의 비용은 순전파 1회와 역전파 1회로 설명할 수 있다. 이것이 그래디언트를 한 번에 구한다는 표현이 가리키는 계산 구조다.

정적 그래프 vs 동적 그래프

프레임워크는 연산 그래프를 만드는 시점에 따라 다음과 같이 구분할 수 있다.

  • 정적 그래프(define-and-run): 그래프를 먼저 정의하고 나중에 데이터를 흘린다. 옛 TensorFlow 1.x가 이 방식이다.
  • 동적 그래프(define-by-run): 순전파 코드가 실행되는 순간 그래프가 그려진다. PyTorch가 이 방식이다.

PyTorch의 autograd는 동적 그래프를 사용한다. c = a * b를 실행하면 그 순간 곱셈 노드가 그래프에 추가된다. 따라서 if, for 같은 파이썬 제어문을 그대로 사용할 수 있고 실행 흐름을 따라 디버깅할 수 있다.

자동 미분 코드

numpy — 자동 미분을 손으로 흉내 내기

밑바닥 딥러닝1에는 autograd가 없으므로, 각 층이 순전파 때 중간값을 저장하고 backward()에서 국소 미분을 직접 계산한다. 이 구현은 reverse-mode 자동 미분의 과정을 손으로 구성한 형태다.

forward에서 self.x를 저장하는 이유는 곱셈 노드의 미분을 계산할 때 순전파에서 사용한 상대방 값이 필요하기 때문이다. 그래서 순전파 때 본 입력을 backward()에서 다시 사용한다. 이 예에서 autograd도 같은 목적의 중간값을 내부에 저장한다.

reversed()로 층을 거꾸로 호출하는 과정이 reverse-mode에서 그래프를 거슬러 가는 동작에 해당한다. 이 루프는 이 예제에서 사람이 직접 구성한 autodiff 엔진 역할을 한다.

PyTorch — autograd가 같은 일을 자동으로 수행하기

PyTorch는 텐서에 requires_grad=True를 지정하면 연산을 그래프로 기록하고, .backward()를 호출할 때 역전파를 수행한다.

이 예에서는 numpy에서 self.dW = self.x.T @ dout을 직접 작성한 계산과 같은 값을 얻는다. 차이는 PyTorch가 y = x @ W + b라는 순전파 연산에서 미분 규칙을 적용한다는 점이다. loss.backward()는 이 예제에서 numpy의 for layer in reversed(...) 루프가 맡은 역전파 과정을 대신한다.

PyTorch — nn.Module과 실제 학습 루프

실제 모델은 nn.Module을 상속하고, 학습 루프에서 autograd가 기울기를 채운다.

  • zero_grad(): PyTorch는 기울기를 누적(+=)하므로 매 step마다 비워야 한다. numpy 구현에서 grads dict를 매번 새로 채우는 것과 같은 목적이다.
  • loss.backward(): 손실에서 시작해 그래프를 거슬러 모든 requires_grad=True 텐서의 .grad를 채운다.
  • optimizer.step(): 채워진 .grad로 파라미터를 갱신한다.

손실은 모델 안에서 F.cross_entropy로 만든다. 이 코드에서는 이 연산의 출력인 손실이 역전파의 시작점이 되고 출발 기울기는 1이다.

torch.no_grad — 추론에서는 그래프를 만들지 않는다

기울기가 필요 없는 추론(inference)에서는 그래프 기록을 꺼서 중간값 저장을 줄일 수 있다.

no_grad() 블록 안에서는 연산 그래프를 만들지 않으므로 backward를 호출할 수 없다. 이 문서의 코드에서는 학습이 아니라 생성과 평가에 사용한다.

텐서 shape과 기울기 흐름

%% 자동 미분의 텐서 shape과 기울기 흐름
flowchart LR
  x["x<br/>(1, 2)"]
  W["W<br/>(2, 3)"]
  matmul["matmul<br/>+ b (3,)"]
  y["y<br/>(1, 3)"]
  sum["sum"]
  loss["loss<br/>스칼라"]
  start_grad["1<br/>출발 기울기"]
  dy["dy<br/>(1, 3)"]
  matmul_backward["matmul 역전파"]
  W_grad["W.grad<br/>(2, 3)"]
  b_grad["b.grad<br/>(3,)"]
  x_grad["x.grad<br/>보통 불필요"]
  x --> matmul
  W --> matmul
  matmul --> y
  y --> sum
  sum --> loss
  start_grad --> dy
  dy --> matmul_backward
  matmul_backward --> W_grad
  matmul_backward --> b_grad
  matmul_backward --> x_grad

순전파에서 (1,2)와 (2,3)을 곱해 (1,3)을 만들면, 역전파에서는 같은 그래프를 거슬러 W.grad를 W와 같은 (2,3) 모양으로 채운다. 이 예에서 기울기 텐서의 shape은 대응하는 파라미터의 shape과 같다.

다시 살펴볼 연결 관계

자동 미분은 순전파 연산을 그래프로 기록하고 각 연산의 국소 미분을 연쇄법칙으로 합성해 기울기를 구한다. 이 문서의 신경망처럼 출력이 스칼라 1개이고 파라미터가 많은 구조에서는 reverse-mode가 사용된다. numpy 예제는 층마다 중간값을 저장하고 backward()를 직접 구현한다. PyTorch autograd는 requires_grad로 추적할 텐서를 정하고 loss.backward()를 호출해 .grad를 채운다. 생성과 평가처럼 기울기가 필요 없는 구간에서는 torch.no_grad()로 그래프 기록을 끈다.

이 관계를 더 살펴볼 때는 오차역전파법, 계산 그래프, 그래디언트 계산, 역전파 계층 구현을 함께 확인할 수 있다.
