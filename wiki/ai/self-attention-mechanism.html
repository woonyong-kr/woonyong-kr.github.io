Self-Attention 메커니즘 — 모든 토큰이 서로를 참조해 새 문맥 벡터를 만드는 연산

Self-Attention 메커니즘 — 모든 토큰이 서로를 참조해 새 문맥 벡터를 만드는 연산

확인 범위: 이 문서는 self-attention의 일반 원리와 선택 기준을 교육용으로 단순화한 예제 코드와 함께 설명한다. 제시된 출력값은 해당 예제의 계산 흐름을 보여 주는 데 한정된다. 특정 구현의 정확성, 라이브러리·코드 버전별 동작, 실제 실행 재현 여부, 성능 및 메모리 효과는 별도의 코드·버전·실행 기록·측정으로 검증해야 한다.

한 줄 요약: self-attention은 시퀀스의 각 토큰이 다른 모든 토큰을 일정한 비율로 섞어 새로운 문맥 표현을 만드는 연산이다.

Self-Attention 메커니즘 구분

RNN은 토큰을 순서대로 하나씩 처리한다. 앞선 토큰의 정보를 하나의 hidden state에 압축해 다음 단계로 전달하므로, 시퀀스가 길어질수록 앞쪽 정보가 뒤로 전달되는 과정에서 희미해질 수 있다. 멀리 떨어진 두 토큰의 관계도 한 단계에서 직접 연결하기 어렵다.

순차적인 계산 구조는 병렬화도 제한한다. t번째 토큰을 계산하려면 t-1번째 토큰까지의 계산이 끝나야 하므로, 시퀀스 길이에 비례해 직렬 단계가 쌓인다.

self-attention은 모든 토큰 쌍의 관련도를 행렬곱으로 계산해 이러한 한계를 다룬다. 거리에 관계없이 두 토큰을 직접 연결할 수 있고, 전체 토큰의 계산을 병렬로 구성할 수 있다. 이 차이를 이해하면 Transformer가 RNN과 다른 방식으로 문맥을 처리하는 이유를 파악할 수 있다.

Self-Attention 메커니즘 구조

Self-attention은 시퀀스 안의 각 토큰이 다른 모든 토큰을 참조해 자신의 표현을 갱신하는 연산이다. 예를 들어 “The cat sat on the mat”에서 “sat”은 “cat”을 강하게 참조하고 “the”는 상대적으로 약하게 참조할 수 있다. 각 토큰은 이렇게 계산한 참조 비율로 전체 토큰의 정보를 섞어 새로운 문맥 벡터를 만든다.

계산 흐름은 크게 세 단계다. 먼저 현재 토큰과 각 참조 대상의 관련도를 점수로 계산한다. 다음으로 softmax를 적용해 점수를 합이 1인 비율로 바꾼다. 마지막으로 각 토큰 벡터를 그 비율만큼 섞어 현재 토큰의 새 표현을 만든다.

Z만 나오는 것처럼 보이는 이유는 z0, z1, z2를 따로 출력하지 않고 하나의 행렬로 묶어 계산하기 때문이다. Z의 0번째 행이 z0, 1번째 행이 z1, 2번째 행이 z2다.

여기서 z2 = [0.79, 0.79]는 한 단어에 대한 기울기가 아니다. 순전파 과정에서 만들어진 세 번째 토큰 위치의 새로운 문맥 벡터다. 기울기는 손실 함수를 계산한 뒤 역전파 과정에서 dL/dz2 같은 형태로 나타난다.

실제 Transformer에서는 보통 Z = weights @ X 대신 Z = weights @ V를 사용한다. V는 입력 X에 학습 가능한 가중치 W_V를 곱해 만든 value 벡터다.

학습의 첫 단계에서 X를 그대로 사용하는 설명은 “각 토큰이 다른 토큰 벡터를 일정한 비율로 섞어 새 벡터를 만든다”는 self-attention의 핵심 구조를 먼저 이해하기 위한 단순화다.

학습 가능한 Q·K·V로 일반화

Q, K, V의 직관

실제 Transformer에서는 각 토큰의 임베딩 벡터 x로부터 역할이 다른 세 벡터를 만든다.

  • Query (Q): “나는 어떤 정보를 찾고 있는가?”
  • Key (K): “나는 어떤 정보를 가지고 있는가?”
  • Value (V): “내가 선택되면 어떤 정보를 제공하는가?”

Q와 K의 내적이 클수록 두 토큰의 관련도가 높다고 본다. 이 관련도를 softmax로 정규화한 뒤, 그 비율에 따라 V의 가중합을 계산한다. 앞의 단순 예제에서 하나의 입력 벡터가 맡았던 비교 기준과 제공 정보의 역할을 Q, K, V로 분리한 것이다.

NumPy 구현 — 순전파

sqrt(d_k)로 나누는 이유는 Q와 K가 분산 1인 분포를 따를 때 내적의 분산이 d_k에 비례하기 때문이다. d_k=64이면 내적이 ±8까지 커져 softmax가 한 토큰에 극단적으로 집중할 수 있다. 스케일링은 softmax에 들어가는 값의 분산을 1 근처로 유지한다.

NumPy 구현 — 역전파

순전파의 계산 구조를 이해했다면, 역전파는 softmax와 행렬곱을 거꾸로 따라가는 미분 체인으로 볼 수 있다.

핵심은 softmax의 역전파다. softmax 출력 s에 대해 ds_i/dz_j = s_i(δ_ij - s_j). 이를 행렬 형태로 정리하면 위 코드의 attn * (d_attn - sum(attn * d_attn)) 패턴이 된다.

Causal Mask

GPT 계열의 autoregressive 모델에서는 위치 i의 토큰이 0부터 i까지의 위치만 참조해야 한다. 그렇지 않으면 다음 token을 예측하면서 미래 정보를 미리 보게 된다. PyTorch 코드는 SW_AI-W13-gpt/src/attention.py의 apply_causal_score_mask()에서 torch.triu + masked_fill로 같은 제약을 적용한다.

mask가 False인 위치를 -1e9로 채우면 softmax를 거친 뒤 해당 위치의 가중치가 0이 된다.

시간·공간 복잡도

  • 시간: O(n² · d_k) — Q @ K.T에서 모든 토큰 쌍의 내적을 계산한다.
  • 공간: O(n²) — attention matrix를 저장한다.

시퀀스 길이 n이 늘어나면 모든 토큰 쌍을 다루는 비용도 빠르게 증가한다. Flash Attention은 이 행렬을 블록 단위로 계산하고 소비해 메모리 사용량을 줄인다.

정리

  • Q는 찾는 정보, K는 매칭 기준, V는 실제로 가져올 정보다.
  • Q @ K.T는 모든 토큰 쌍의 관련도를 계산하는 단계다.
  • softmax는 관련도 점수를 각 토큰이 참조할 비율로 바꾼다.
  • attention weight와 V의 행렬곱은 각 토큰의 새로운 context vector를 만든다.
  • causal mask는 미래 토큰을 참조하지 못하게 해 다음 토큰 예측 조건을 지킨다.
  • attention의 주요 비용은 시퀀스 길이에 대해 제곱으로 증가하는 토큰 쌍 계산에서 발생한다.
