인코더 블록

인코더 블록

한 줄 요약: 인코더 블록은 디코더 블록에서 인과 마스크를 빼고 양방향으로 어텐션을 수행하는 Transformer의 입력 처리 단위다.

인코더 블록 문제

GPT를 배우면 Transformer 블록이 곧 “인과 마스크가 걸린 Self-Attention + FFN”이라고 생각하기 쉽다. 그런데 Transformer 원논문(Vaswani et al., 2017)은 인코더와 디코더 두 종류의 블록을 나란히 사용했다. BERT는 인코더 블록만 쌓고, GPT는 디코더 블록만 쌓고, 번역 모델(T5, mBART)은 둘 다 사용한다.

인코더 블록의 구조를 모르면 세 가지 모델 계열 — Encoder-only, Decoder-only, Encoder-Decoder — 을 구분할 수 없다. 디코더 블록만 알고 있으면 “왜 BERT는 생성을 못 하는가?”, “왜 T5에는 Cross-Attention이 있는가?” 같은 질문에 답하지 못한다.

인코더 블록 흐름

인코더 블록과 디코더 블록의 차이

인코더 블록과 디코더 블록은 뼈대가 같다. 둘 다 Multi-Head Attention, FFN, LayerNorm, Residual Connection으로 구성된다. 차이는 두 가지다.

첫째, 어텐션 방향이 다르다. 인코더 블록은 양방향(bidirectional) Self-Attention을 사용한다. 모든 토큰이 시퀀스 내 모든 토큰을 본다. 디코더 블록은 인과적(causal) Self-Attention을 사용한다. 각 토큰은 자신과 이전 토큰만 본다.

둘째, 원본 Transformer의 디코더 블록에는 Cross-Attention 층이 하나 더 들어간다. 디코더의 Query가 인코더 출력의 Key, Value를 참조하는 구조다. GPT처럼 디코더만 쓰는 모델은 Cross-Attention이 없다.

인코더 블록 구조

%% 인코더 블록 구조
flowchart TD
  input["입력 x"]
  ln1["LayerNorm"]
  mha["양방향 MHA<br/>모든 토큰 참조"]
  add1["+<br/>잔차 연결"]
  ln2["LayerNorm"]
  ffn["FFN"]
  add2["+<br/>잔차 연결"]
  output["출력"]
  input --> ln1
  ln1 --> mha
  mha --> add1
  add1 --> ln2
  ln2 --> ffn
  ffn --> add2
  add2 --> output
  input --> add1
  add1 --> add2

인코더 블록에는 마스크가 없다. 토큰 “나는”이 뒤에 있는 “학생이다”를 자유롭게 참고한다. 문장 전체를 한 번에 읽고 각 토큰의 표현을 만드는 구조다.

%% GPT 디코더 블록 구조
flowchart TD
  input["입력 x"]
  ln1["LayerNorm"]
  mha["인과 MHA<br/>미래 토큰 마스크"]
  add1["+<br/>잔차 연결"]
  ln2["LayerNorm"]
  ffn["FFN"]
  add2["+<br/>잔차 연결"]
  output["출력"]
  input --> ln1
  ln1 --> mha
  mha --> add1
  add1 --> ln2
  ln2 --> ffn
  ffn --> add2
  add2 --> output
  input --> add1
  add1 --> add2

디코더 블록은 인과 마스크를 건다. 토큰 “나는”은 뒤의 “학생이다”를 볼 수 없다. 이 제약이 있어야 “다음 토큰 예측” 학습이 성립한다.

원본 Transformer 디코더 블록 (인코더-디코더 모델)

%% 원본 Transformer 디코더 블록 구조
flowchart TD
  decoder_input["디코더 입력 x"]
  encoder_output["인코더 출력<br/>K, V 제공"]
  ln1["LN"]
  causal_mha["인과 MHA"]
  add1["+<br/>잔차 연결"]
  ln2["LN"]
  cross_mha["Cross MHA<br/>Q=디코더<br/>K,V=인코더 출력"]
  add2["+<br/>잔차 연결"]
  ln3["LN"]
  ffn["FFN"]
  add3["+<br/>잔차 연결"]
  output["출력"]
  decoder_input --> ln1
  ln1 --> causal_mha
  causal_mha --> add1
  add1 --> ln2
  ln2 --> cross_mha
  cross_mha --> add2
  add2 --> ln3
  ln3 --> ffn
  ffn --> add3
  add3 --> output
  decoder_input --> add1
  add1 --> add2
  add2 --> add3
  encoder_output --> cross_mha

Cross-Attention에서 디코더의 Q가 인코더의 K, V를 조회한다. 번역에서 “나는”을 생성할 때 원문 “I am”의 표현을 참고하는 구조다.

세 가지 모델 계열

  • Encoder-only (BERT, RoBERTa)
    • 인코더 블록만 쌓는다. 양방향 어텐션이므로 문맥 이해(분류, NER, 질의응답)에 강하다. 다음 토큰을 순차 생성하는 구조가 아니므로 자기회귀 생성에는 쓸 수 없다.
  • Decoder-only (GPT, LLaMA)
    • 디코더 블록만 쌓되 Cross-Attention은 빠진다. 인과 마스크가 있어 자기회귀 생성이 된다. 현재 LLM의 주류 구조다.
  • Encoder-Decoder (T5, mBART, 원본 Transformer)
    • 인코더 블록으로 입력을 읽고, 디코더 블록이 Cross-Attention으로 인코더 출력을 참조하며 생성한다. 번역, 요약처럼 입력과 출력의 형식이 다른 과업에 적합하다.

인코더 블록 코드

밑바닥 LLM 책의 TransformerBlock은 GPT용 디코더 블록이다. causal_mask 파라미터 하나가 인코더 블록과 디코더 블록을 가르는 핵심이다.

causal_mask=True이면 디코더 블록이다. causal_mask=False로 바꾸면 인코더 블록처럼 양방향으로 동작한다. norm_first 플래그는 LayerNorm 위치(Pre-LN vs Post-LN)를 결정하며, 인코더·디코더 구분과는 무관하다. 블록의 구조적 차이는 causal_mask 플래그 하나에 집약된다.

인과 마스크의 실체는 apply_causal_score_mask에 있다.

torch.triu(..., diagonal=1)은 대각선 위쪽(미래 위치)을 True로 만든다. 이 위치의 score를 -inf로 채우면 softmax 후 가중치가 0이 된다. 인코더 블록에서는 이 함수가 호출되지 않으므로 모든 위치의 score가 살아 있다.

어텐션 스코어 행렬 비교

seq_len = 4인 경우 softmax 전 score 행렬의 차이다.

%% 어텐션 스코어 행렬 비교
flowchart LR
  encoder["인코더: 양방향<br/>s11 &#124; s12 &#124; s13 &#124; s14<br/>s21 &#124; s22 &#124; s23 &#124; s24<br/>s31 &#124; s32 &#124; s33 &#124; s34<br/>s41 &#124; s42 &#124; s43 &#124; s44<br/>모든 위치 참조 가능"]
  decoder["디코더: 인과적<br/>s11 &#124; -inf &#124; -inf &#124; -inf<br/>s21 &#124; s22 &#124; -inf &#124; -inf<br/>s31 &#124; s32 &#124; s33 &#124; -inf<br/>s41 &#124; s42 &#124; s43 &#124; s44<br/>미래 위치 차단"]
  encoder --> decoder

인코더에서 토큰 1은 토큰 2, 3, 4를 전부 본다. 디코더에서 토큰 1은 자기 자신만 본다.

인코더 블록과 디코더 블록을 같은 클래스로 만들기

기존 TransformerBlock 코드에서 인코더 블록은 호출 방식만 바꾸면 된다.

밑바닥 LLM의 TransformerBlock은 causal_mask 인자를 받도록 설계되어 있어 같은 클래스로 인코더와 디코더 블록을 모두 만들 수 있다. 실제 BERT 구현에서는 패딩 마스크(padding mask)가 추가로 필요하지만, 블록 수준의 핵심 차이는 인과 마스크 유무뿐이다.

정리

인코더 블록과 디코더 블록은 동일한 뼈대(MHA + FFN + LayerNorm + Residual)를 공유한다. 핵심 차이는 어텐션의 방향이다. 인코더는 양방향으로 전체 문맥을 읽고, 디코더는 인과 마스크로 미래를 가린다. 원본 Transformer의 디코더에는 인코더 출력을 참조하는 Cross-Attention 층이 추가로 들어간다.

이 차이가 모델 계열을 나눈다. BERT(Encoder-only)는 분류와 이해에, GPT(Decoder-only)는 생성에, T5(Encoder-Decoder)는 변환 과업에 각각 적합하다.
