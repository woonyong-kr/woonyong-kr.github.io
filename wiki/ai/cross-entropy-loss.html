Cross-Entropy Loss

Cross-Entropy Loss

범위: 이 문서는 cross-entropy loss의 일반 개념과 선택 기준을 설명하고, 제시된 numpy·PyTorch 코드는 그 원리를 구현하는 예시로 다룬다. 특정 코드·라이브러리 버전에서의 동작, 실제 학습 결과와 perplexity·성능에 관한 판단은 실행 기록이나 측정으로 검증한 결과가 아니다.

한 줄 요약: Cross-entropy loss는 모델이 출력한 확률 분포와 정답 분포 사이의 거리를 재는 손실 함수다. softmax 출력에 정답 토큰의 -log를 취한 값이며, 분류 신경망과 LLM 학습의 표준 목적 함수다.

Cross-Entropy Loss가 비용을 줄이는 자리

신경망의 출력층은 각 클래스(또는 토큰)에 대한 raw score(logit)를 내놓는다. 이 logit은 확률이 아니다. softmax를 통과하면 합이 1인 확률 분포가 되는데, 여기서 “정답 클래스의 확률이 얼마나 높은가”를 하나의 숫자로 측정해야 가중치를 갱신할 수 있다.

MSE(평균 제곱 오차)를 쓸 수도 있지만, 확률 분포 비교에는 적합하지 않다. 정답 확률이 0에 가까울 때 MSE의 기울기는 작아서 학습이 느리다. 반면 cross-entropy는 정답 확률이 낮을수록 기울기가 커져 빠르게 교정한다.

정보 이론 관점에서 cross-entropy는 MLE(최대 우도 추정)와 동치다. 정답 분포가 one-hot일 때 cross-entropy를 최소화하는 것은 정답 토큰의 log-확률을 최대화하는 것과 같다.

Cross-Entropy Loss 흐름

logit, softmax, loss 흐름

%% logit에서 softmax 확률과 cross-entropy loss로 이어지는 흐름
flowchart LR
  logits["logits<br/>(V,)"]
  probs["probs<br/>(V,)"]
  loss["loss<br/>스칼라"]
  logits --> probs
  probs --> loss
  • logit: 신경망 마지막 선형 레이어의 출력. 클래스 수(또는 어휘 크기 V)만큼의 실수 벡터.
  • softmax: logit을 합이 1인 확률 분포로 변환한다. softmax(z)_i = exp(z_i) / Σ exp(z_j).
  • cross-entropy loss: 정답 클래스 k에 대해 L = -log(softmax(z)_k).

왜 -log인가?

정답 확률 p에 대해 -log(p)의 성질:

  • p = 1.0이면 loss = 0. 완벽한 예측.
  • p = 0.5이면 loss = 0.693. 반반 수준의 불확실성.
  • p = 0.01이면 loss = 4.605. 정답을 거의 못 맞힘.

정답 확률이 낮을수록 loss가 급격히 커지므로, 기울기도 커져서 가중치가 빠르게 갱신된다.

배치/시퀀스 처리

분류: 배치 내 각 샘플의 loss를 구해 평균한다.

LLM: 시퀀스의 매 위치에서 다음 토큰을 예측한다. 전체 손실은 모든 위치의 cross-entropy 평균이다. 시퀀스 길이가 T, 어휘 크기가 V일 때:

L = -(1/T) × Σ_{t=1}^{T} log(p(x_{t+1} | x_{1:t}))

역전파: softmax + cross-entropy 결합 기울기

softmax와 cross-entropy를 합치면 역전파 공식이 놀랍도록 단순하다:

∂L/∂z_i = softmax(z)_i - 1{i = 정답}

즉 기울기 = probs - one_hot(정답). 정답 위치에서만 확률에서 1을 빼고, 나머지 위치는 확률 값 그대로가 기울기다.

왜 이렇게 깔끔한가:

  • softmax 출력 s_i에 대해: ∂s_i/∂z_j = s_i(δ_{ij} - s_j) (야코비안)
  • cross-entropy -log(s_t)에 대해: ∂L/∂s_t = -1/s_t
  • 체인룰로 합치면 야코비안의 s_t 항과 -1/s_t가 상쇄되어 s_i - δ_{it}만 남는다.

Perplexity

cross-entropy loss를 직관적으로 해석하는 지표: perplexity = exp(loss).

perplexity가 100이면 “모델이 매 토큰마다 100개 후보 중 균등하게 고민하는 수준”이라는 뜻이다. GPT-3 학습 완료 시 perplexity는 약 20이다.

Cross-Entropy Loss 코드

numpy 구현 — 밑바닥 딥러닝1

np.arange(batch_size)와 y_true로 각 샘플의 정답 위치 확률만 뽑아 -log를 취한다. np.clip으로 0을 방지한다.

기울기가 probs - one_hot인 것을 그대로 구현한 코드다. 배치 평균 loss를 쓰므로 batch_size로 나눈다.

학습 루프에서의 사용

forward()가 softmax까지 통과한 확률을 반환하고, cross_entropy_gradient()가 출력층 기울기를 만들어 backward()에 전달한다.

PyTorch 구현 — 밑바닥 LLM

PyTorch의 F.cross_entropy()는 내부에서 softmax + -log + 평균을 한 번에 처리한다. logit을 직접 받으므로 별도의 softmax 레이어가 필요 없다.

%% PyTorch cross_entropy에 넣기 위한 logits와 target shape 변환
flowchart TD
  logits_before["logits<br/>(B, T, V)"]
  logits_after["logits.flatten(0, 1)<br/>(B*T, V)"]
  target_before["target<br/>(B, T)"]
  target_after["target.flatten()<br/>(B*T,)"]
  loss["F.cross_entropy()<br/>평균 loss"]
  logits_before --> logits_after
  target_before --> target_after
  logits_after --> loss
  target_after --> loss

numpy 구현은 softmax를 먼저 적용한 뒤 loss와 gradient를 분리해서 계산한다. PyTorch는 F.cross_entropy()가 logit에서 바로 loss까지 한 번에 처리하며, loss.backward()가 autograd로 기울기를 자동 계산한다.

수치 안정성을 고려한 softmax

logit을 확률로 변환할 때는 최댓값을 먼저 빼서 exp()의 overflow를 피할 수 있다. softmax 값은 이 변환 전후로 동일하다.

정리

cross-entropy loss는 정답 클래스의 확률에 -log를 취한 값이다. 정답 확률이 낮을수록 loss가 급격히 커져 빠른 학습을 유도한다. softmax와 결합하면 역전파 기울기가 probs - one_hot으로 단순해진다. numpy에서는 이 과정을 명시적으로 구현하고, PyTorch에서는 F.cross_entropy()가 logit → loss를 한 번에 처리한다.
