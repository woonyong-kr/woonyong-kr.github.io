데이터 증강

데이터 증강

확인 범위: 이 문서는 데이터 증강의 일반 원리와 라벨을 보존하는 변형의 선택 기준을 설명하고, numpy 및 PyTorch 예시는 동작과 데이터 흐름을 보여 주기 위한 교육용 코드로 제시한다. 특정 코드·라이브러리 버전에서의 실행 결과나 실제 모델의 성능 개선을 검증한 문서는 아니므로, 구체적인 적용 효과는 해당 구현과 데이터에 대한 실행 기록 및 성능 측정으로 별도 판단해야 한다.

한 줄 요약: 데이터 증강은 원본 라벨은 유지한 채 입력을 살짝 바꿔서, 모델이 훈련 데이터의 우연한 모양을 외우지 못하게 만드는 일반화 기법이다.

데이터 증강 구분

모델은 훈련 데이터에서 보이는 패턴을 배운다. 그런데 데이터가 적거나 한쪽으로 치우쳐 있으면, 모델은 “진짜 규칙”이 아니라 훈련 데이터에만 우연히 나타난 특징을 외울 수 있다.

예를 들어 고양이 사진 분류 모델이 모든 고양이 사진을 정면, 밝은 배경, 가운데 위치로만 봤다고 하자. 실제 서비스에서 고양이가 약간 회전되어 있거나 어두운 방에 있으면 모델은 쉽게 틀린다.

데이터 증강은 같은 라벨을 유지할 수 있는 범위에서 입력을 바꾼다. 이미지는 좌우 반전, 작은 회전, 잘라내기, 밝기 변화가 가능하다. 텍스트는 동의어 치환이나 문장 순서 변화처럼 의미를 크게 바꾸지 않는 변형을 조심스럽게 쓸 수 있다.

이 말은 즉, 데이터 증강은 “새 라벨을 수집하지 않고도 모델이 다양한 상황을 본 것처럼 만드는 방법”이다.

데이터 증강 흐름

동작 방식

데이터 증강은 학습 루프에서 원본 샘플을 바로 모델에 넣지 않고, 중간에 변환 함수를 통과시키는 방식으로 작동한다.

%% 데이터 증강에서 라벨이 유지되는 흐름
flowchart TD
  original["원본 데이터<br/>이미지: 고양이.jpg<br/>label=cat"]
  augment["증강 변환<br/>좌우 반전<br/>10도 회전<br/>밝기 변화"]
  input["모델 입력<br/>변형된 고양이 이미지<br/>label=cat"]
  original --> augment
  augment --> input

라벨이 유지된다는 점이 핵심이다.

  • 좋은 증강
    • 고양이 이미지를 좌우 반전한다.
    • 글자 이미지를 약간 이동한다.
    • 음성 데이터를 아주 약하게 노이즈와 섞는다.
  • 위험한 증강
    • 숫자 6 이미지를 180도 회전해 9처럼 만든다.
    • 의료 영상에서 병변을 가릴 정도로 자른다.
    • 문장의 부정을 삭제해 의미가 반대로 바뀐다.

이미지 분류의 대표적 증강 흐름

%% 이미지 분류의 대표 증강 흐름
flowchart TD
  image["훈련 이미지"]
  crop["RandomCrop<br/>물체가 항상 가운데 있다는 가정을 줄인다."]
  flip["RandomHorizontalFlip<br/>좌우 방향에 덜 민감하게 만든다."]
  jitter["ColorJitter<br/>조명과 카메라 차이에 덜 민감하게 만든다."]
  normalize["Normalize<br/>입력 분포를 학습하기 좋게 맞춘다."]
  image --> crop
  crop --> flip
  flip --> jitter
  jitter --> normalize

검증 데이터에는 보통 무작위 증강을 넣지 않는다. 검증은 “모델이 같은 기준에서 얼마나 잘 일반화하는가”를 재는 과정이므로, 훈련에는 변형을 주고 검증에는 고정된 전처리를 적용한다.

다른 정규화 기법과의 관계

데이터 증강은 오버피팅과 정규화를 줄이는 방법 중 하나다. Dropout이나 Weight Decay와 L2 정규화와는 작동 위치가 다르다.

  • 데이터 증강 — 입력 데이터를 바꾼다. 모델이 더 다양한 입력을 보게 만든다.
  • Dropout — 모델 내부 뉴런 일부를 끈다. 특정 뉴런 조합에 과하게 의존하지 못하게 한다.
  • Weight Decay — 가중치가 너무 커지는 것을 벌한다. 복잡한 함수를 과하게 맞추지 못하게 한다.
  • Early Stopping과 체크포인팅

데이터 증강 코드

numpy로 변환의 본질 보기

밑바닥 딥러닝1 코드(SW_AI-W13-mnist)는 증강을 따로 구현하지 않는다. 증강 연산 자체는 단순한 배열 조작이다. 좌우 반전은 열 순서 뒤집기, 평행이동은 배열 밀기, 밝기 변화는 값 더하기다. 라벨은 건드리지 않는다.

구체적 숫자로 추적하면 변환의 효과가 보인다.

세 변환 모두 (3, 3) shape을 유지한다. 픽셀 배치만 바뀌고 “이것은 cat”이라는 라벨은 그대로다. 이것이 증강의 핵심이다. 입력은 다양해지지만 정답은 변하지 않는다.

PyTorch 증강 파이프라인

실제 학습에서는 변환을 직접 짜지 않고 torchvision.transforms로 묶는다. 텐서 shape이 어떻게 흐르는지 따라가면 각 변환의 역할이 드러난다.

%% PyTorch 증강 파이프라인의 shape 흐름
flowchart TD
  input["입력 이미지<br/>(H, W, C)"]
  crop["RandomResizedCrop(224)<br/>무작위 위치와 크기로 잘라 224x224<br/>출력: (224, 224, C)"]
  random_ops["무작위 증강<br/>RandomHorizontalFlip<br/>ColorJitter<br/>shape 불변"]
  tensor["ToTensor()<br/>(C, H, W)"]
  normalize["Normalize(mean, std)"]
  output["모델 입력<br/>(3, 224, 224)"]
  input --> crop
  crop --> random_ops
  random_ops --> tensor
  tensor --> normalize
  normalize --> output

ToTensor()가 채널 축을 맨 앞으로 옮긴다는 점이 중요하다. nn.Conv2d는 입력을 (N, C, H, W) 순서로 받기 때문이다.

핵심은 훈련용 train_transform에만 무작위성이 있다는 점이다. 같은 이미지라도 epoch마다 조금씩 다르게 들어가므로, 모델은 특정 픽셀 위치나 조명에 과하게 의존하기 어렵다.

정리

데이터 증강은 라벨을 유지한 채 입력을 변형하여, 모델이 훈련 데이터의 우연한 패턴을 외우지 못하게 만드는 일반화 기법이다. 훈련 데이터에만 무작위 증강을 적용하고, 검증 데이터에는 고정 전처리를 쓴다. 증강이 강할수록 일반화에 도움이 될 수 있지만, 라벨의 의미가 깨지면 오히려 학습을 방해한다. 이미지, 음성, 텍스트마다 안전한 증강의 기준이 다르다.
