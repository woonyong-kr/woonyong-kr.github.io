SVD와 PCA

SVD와 PCA

범위: 이 문서는 SVD와 PCA의 일반 원리와 선택 기준을 설명하며, 제시된 코드는 개념을 보여 주는 예시다. 특정 라이브러리 버전의 실행 결과, MNIST 설명 분산, 실제 데이터의 압축 효과와 성능은 해당 환경의 코드·데이터·실행 기록과 측정을 통해 별도로 검증해야 한다.

한 줄 요약: SVD는 임의의 행렬을 “회전 → 스케일 → 회전” 세 단계로 분해하는 도구이고, PCA는 SVD를 이용해 데이터에서 가장 중요한 축만 남기는 차원 축소 기법이다.

SVD와 PCA 구분

고유값·고유벡터에서 정방행렬을 “어떤 축으로 얼마나 늘리는가”로 분해할 수 있음을 봤다. 그런데 신경망의 가중치 행렬 W는 보통 정방행렬이 아니다. 입력 784차원, 출력 256차원이면 W는 (784, 256) 직사각행렬이다. 고유값 분해는 정방행렬에만 적용할 수 있으므로, 직사각행렬까지 분해하려면 더 일반적인 도구가 필요하다.

SVD(Singular Value Decomposition, 특이값 분해)가 그 도구다. 어떤 크기의 행렬이든 “회전 → 스케일 → 회전” 세 단계로 쪼갤 수 있다.

SVD를 알면 다음이 가능하다.

  • PCA(주성분 분석)의 원리를 이해한다. 고차원 데이터에서 분산이 큰 방향만 남겨 차원을 줄인다.
  • LoRA(Low-Rank Adaptation)가 왜 동작하는지 이해한다. 큰 가중치 행렬의 변화량을 저랭크 행렬로 근사하는 아이디어가 SVD의 저랭크 근사에서 나온다.
  • 데이터 압축의 수학적 근거를 이해한다. 작은 특이값을 버리면 정보 손실을 최소화하면서 행렬 크기를 줄일 수 있다.

SVD와 PCA 차이

SVD란 무엇인가

비유: 건물을 X선으로 찍으면 뼈대가 보인다. SVD는 행렬의 X선이다. 아무리 복잡한 행렬도 “세 가지 단순한 행렬의 곱”으로 나타낸다.

정의: 임의의 (m, n) 행렬 A는 다음과 같이 분해된다.

A = U Σ V

  • U: (m, m) 직교 행렬. 출력 공간의 회전 방향을 나타낸다.
  • Σ: (m, n) 대각 행렬. 대각 원소가 특이값(singular value) σ₁ ≥ σ₂ ≥ … ≥ 0이다. 각 방향의 스케일 크기다.
  • V^T: (n, n) 직교 행렬. 입력 공간의 회전 방향을 나타낸다.

직교 행렬이란 U^T U = I인 행렬이다. 회전만 하고 크기를 바꾸지 않는다.

동작 순서

벡터 x에 A를 곱하는 과정을 세 단계로 나누면:

1단계. V^T를 곱한다 — 입력 공간에서 주요 축 방향으로 회전한다. 2단계. Σ를 곱한다 — 각 축을 σᵢ만큼 늘리거나 줄인다. 3단계. U를 곱한다 — 출력 공간의 방향으로 다시 회전한다.

%% SVD를 입력 회전, 특이값 스케일, 출력 회전으로 나누어 보는 흐름
flowchart LR
  input["입력 벡터<br/>x"]
  input_rotation["입력 축 회전<br/>V^T x<br/>크기는 유지"]
  scale["특이값 스케일<br/>Σ (V^T x)<br/>σ_i만큼 축별 확대·축소"]
  output_rotation["출력 축 회전<br/>U Σ V^T x<br/>출력 공간 방향"]
  output["출력 벡터<br/>y = A x"]
  input --> input_rotation
  input_rotation --> scale
  scale --> output_rotation
  output_rotation --> output

고유값 분해와의 관계

정방행렬 A에 대해 고유값 분해는 A = PΛP⁻¹이다. SVD는 이를 직사각행렬로 일반화한 것이다.

  • 정방 + 대칭행렬이면 SVD와 고유값 분해가 같아진다. U = V = P, Σ = |Λ|.
  • A^T A의 고유값이 σᵢ²이다. 특이값은 고유값의 제곱근이다.
  • A^T A의 고유벡터가 V의 열이고, A A^T의 고유벡터가 U의 열이다.

저랭크 근사

핵심 아이디어: 특이값이 큰 것 k개만 남기고 나머지를 버리면, 원래 행렬에 가장 가까운 랭크-k 행렬을 얻는다.

A ≈ A_k = U_k Σ_k V_k

  • U_k: U의 앞 k열, shape (m, k)
  • Σ_k: Σ의 앞 k개 특이값, shape (k, k)
  • V_k^T: V^T의 앞 k행, shape (k, n)

원래 (m, n) 행렬을 저장하려면 m × n개 숫자가 필요하다. 저랭크 근사는 (m × k) + k + (k × n) = k(m + n + 1)개만 저장하면 된다.

왜 k개만 남겨도 되는가?

Eckart-Young 정리: 랭크-k 행렬 중에서 ‖A − A_k‖를 최소화하는 것이 SVD의 상위 k개 특이값을 남긴 것이다. 다른 어떤 랭크-k 행렬보다 이것이 원본에 가장 가깝다.

직관: 특이값이 σ₁ = 10, σ₂ = 5, σ₃ = 0.01이면, 세 번째 축은 데이터를 거의 늘리지 않는다. 이 축을 버려도 정보 손실이 0.01² / (10² + 5² + 0.01²) ≈ 0.00008% 수준이다.

PCA란 무엇인가

PCA(Principal Component Analysis, 주성분 분석)는 데이터의 분산이 가장 큰 방향을 찾아 그 방향으로만 데이터를 투영하는 차원 축소 기법이다.

절차:

  1. 데이터 행렬 X, shape (n_samples, n_features)에서 각 특성의 평균을 뺀다. X_centered = X − mean(X).
  2. X_centered에 SVD를 적용한다. X_centered = U Σ V
  3. V^T의 앞 k행이 주성분(principal component) 방향이다.
  4. 데이터를 주성분 방향으로 투영한다. X_reduced = X_centered @ V[:, :k]. 결과 shape은 (n_samples, k).

PCA와 공분산 행렬의 관계

공분산 행렬 C = (1/(n−1)) X_centered^T X_centered 의 고유값 분해가 곧 PCA다.

X_centered = U Σ V^T 이므로:

C = (1/(n−1)) V Σ^T U^T U Σ V^T = (1/(n−1)) V Σ² V

  • V의 열 = 공분산 행렬의 고유벡터 = 주성분 방향
  • σᵢ² / (n−1) = 공분산 행렬의 고유값 = 해당 주성분 방향의 분산

분산이 큰 방향이 데이터를 가장 잘 설명하는 축이다. k개 주성분이 전체 분산의 몇 %를 설명하는지는 (σ₁² + … + σ_k²) / (σ₁² + … + σ_n²)로 계산한다.

PCA로 MNIST 차원 축소

784차원에서 50차원으로 줄여도 분산의 약 82%가 보존된다(실제 MNIST 학습 60000장으로 검증한 값은 약 82.5%다). 원본 크기의 6.4%(50/784)만 사용해도 이미지의 주요 패턴이 살아있다.

LoRA와의 연결

LoRA(Low-Rank Adaptation)는 사전학습 가중치 W₀를 고정하고, 변화량 ΔW를 저랭크 행렬 B @ A로 근사한다.

W = W₀ + ΔW ≈ W₀ + B @ A

  • B: (d, r), A: (r, k). r은 랭크.
  • SVD의 저랭크 근사와 같은 원리다.
  • 전체 파라미터 d × k 대신 r × (d + k)개만 학습한다.
  • r = 8이고 d = k = 4096이면 파라미터 수가 1/256로 줄어든다.

정리

SVD는 임의의 행렬을 U Σ V^T로 분해하는 도구다. 특이값이 큰 것만 남기면 원본에 가장 가까운 저랭크 근사를 얻는다. PCA는 이 원리를 데이터 차원 축소에 적용한 기법이다. 신경망에서는 LoRA의 저랭크 파라미터 효율화와 데이터 전처리에 사용된다.

연결 문서:

  • SVD의 기반이 되는 정방행렬 고유값 분해
  • 가중치 행렬의 특이값 분포가 학습 안정성에 미치는 영향
