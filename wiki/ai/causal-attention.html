Causal Attention — 미래를 보지 못하게 하는 마스크

범위: 이 문서는 Causal Attention의 일반 원리와 마스크 적용 방식, 구현 선택 기준을 설명하고 PyTorch·NumPy 예시와 테스트 코드를 제시한다. 다만 특정 코드·환경·버전에서의 실행이나 성능을 검증한 결과는 아니므로, 구현별 동작과 수치적 특성 및 성능은 실제 실행 기록과 측정을 통해 별도로 확인해야 한다.

한 줄 요약: Causal Attention은 Self-Attention에 하삼각 마스크를 씌워, 각 토큰이 자신과 이전 토큰만 참조하도록 강제하는 메커니즘이다.

Causal Attention 문제

GPT는 자기회귀(autoregressive) 모델이다. “The cat sat on the”까지 보고 다음 토큰 “mat”을 예측한다. 학습할 때도 이 조건을 유지해야 한다. 만약 “mat”을 예측하는 시점에 정답인 “mat”을 이미 볼 수 있다면, 모델은 예측을 학습하지 않고 정답을 복사하는 법만 배운다.

Self-Attention은 기본적으로 시퀀스 내 모든 토큰 쌍의 관계를 계산한다. 위치 3의 토큰이 위치 5의 토큰을 참조하는 것도 허용된다. Causal Attention은 이 “미래 참조”를 차단하여 다음 토큰 예측이라는 학습 목표를 지킨다.

Causal Attention 흐름

비유

시험을 볼 때 앞 문제의 답은 볼 수 있지만 뒷 문제의 답은 가려져 있는 상황이다. 1번 문제를 풀 때는 1번만 보이고, 3번 문제를 풀 때는 1, 2, 3번이 보인다. causal mask는 이 가림판 역할을 한다.

정의

Causal Attention은 Self-Attention의 score 행렬에 하삼각 마스크(lower triangular mask)를 적용한 것이다. 위치 i의 토큰은 위치 0부터 i까지만 참조할 수 있다. 상삼각 영역(미래 위치)은 -무한대로 채워서 softmax 후 가중치가 0이 되게 한다.

동작 순서

  1. Q, K, V를 계산한다 (Self-Attention과 동일).
  2. score = Q @ K^T / sqrt(d_k)를 구한다.
  3. 하삼각 마스크를 만든다. 상삼각 영역을 -무한대(-1e9)로 채운다.
  4. softmax를 적용한다. -무한대 위치는 0이 된다.
  5. attention weight @ V로 출력을 계산한다.

마스크의 모양

시퀀스 길이가 5일 때 마스크는 다음과 같다.

  score --> masked

위치 0(첫 번째 행)은 자기 자신만 본다. 위치 4(마지막 행)는 모든 토큰을 본다. softmax를 적용하면 -무한대 위치의 가중치는 0이 되어, 해당 토큰의 V 값이 출력에 반영되지 않는다.

왜 -무한대인가?

softmax(z_i) = exp(z_i) / sum(exp(z_j))에서 z_i = -무한대이면 exp(z_i) = 0이다. 실제 구현에서는 -1e9처럼 충분히 큰 음수를 사용한다. float32의 exp(-1e9)는 0이 되므로 효과는 동일하다.

Causal Attention 코드

PyTorch 구현 (밑바닥 LLM 과제 템플릿)

torch.triu(ones, diagonal=1)은 대각선 위(미래 위치)가 1인 상삼각 행렬을 만든다. masked_fill로 해당 위치를 -inf로 채운다. 이것이 causal mask의 전부다.

테스트 코드 — 미래 위치의 가중치가 0인지 확인

이 테스트는 attention 가중치 행렬의 상삼각 영역이 모두 0인지 검증한다.

숫자로 확인하기

위치 0은 softmax 결과가 [1, 0, 0, 0]이다. 참조할 토큰이 자기밖에 없으므로 자기 자신에게 가중치 1을 준다. 위치 2는 0, 1, 2번 토큰에 가중치를 나누되, score가 가장 높은 2번(자기 자신)에 84%를 집중한다.

Causal Attention vs 양방향 어텐션

특성Causal Attention (GPT)양방향 어텐션 (BERT)
마스크상삼각 = -inf마스크 없음 (패딩만 마스크)
참조 범위자신 + 과거 토큰만전체 시퀀스
학습 목표다음 토큰 예측마스크된 토큰 예측
생성 가능가능 (자기회귀)불가 (양방향 의존)

BERT는 양방향으로 문맥을 보기 때문에 텍스트 이해(분류, QA)에 강하지만, 텍스트를 한 토큰씩 생성하는 데는 쓸 수 없다. GPT는 causal mask 덕분에 학습 때와 생성 때의 조건이 동일하다.

정리

Causal Attention은 Self-Attention의 score 행렬에 하삼각 마스크를 씌워 미래 토큰을 차단하는 메커니즘이다. torch.triu로 상삼각 마스크를 만들고 masked_fill로 -inf를 채우면, softmax 후 미래 위치의 가중치가 0이 된다. 이 마스크 하나가 GPT를 자기회귀 모델로 만드는 핵심이다. 구현은 attention 연산에 3줄을 추가하는 것이 전부다.
