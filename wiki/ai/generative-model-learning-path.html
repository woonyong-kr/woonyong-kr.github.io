Autoencoder와 GAN으로 생성 모델을 구분하는 기준

같은 얼굴 이미지를 다루더라도 “작게 압축했다가 복원하기”와 “새 얼굴을 만들기”는 다른 문제다. Autoencoder는 입력을 다시 만드는 과정에서 정보를 압축하고, GAN은 생성한 표본이 실제 데이터와 구별되지 않도록 학습한다.

Autoencoder는 복원할 정보를 고른다

Encoder는 입력 x를 latent vector z로 바꾸고 Decoder는 z에서 x̂를 복원한다. 학습은 x와 x̂의 차이를 줄인다. latent dimension이 너무 크면 복사에 가까워지고, 너무 작으면 중요한 구조까지 잃는다.

원본과 복원 결과를 나란히 보고 validation 이미지에서도 구조가 유지되는지 확인한다. anomaly detection에 사용할 때는 정상 데이터의 복원 오차 분포를 먼저 고정하고 threshold를 별도로 검증한다.

GAN은 두 모델의 균형을 맞춘다

Generator는 random noise에서 표본을 만들고 Discriminator는 실제와 가짜를 구분한다. Generator는 판별자를 속이도록, Discriminator는 더 잘 구분하도록 번갈아 갱신된다. 판별자가 너무 빨리 강해지면 유용한 gradient가 줄고, Generator가 몇 가지 출력만 반복하면 mode collapse가 생긴다.

loss 하나로 품질을 단정하지 않는다. 고정한 noise seed의 출력 변화, 표본 다양성, 실제 데이터와의 분포 지표를 함께 본다.

같은 질문으로 선택한다

질문AutoencoderGAN
목표정보를 압축하고 복원한다실제와 비슷한 새 표본을 만든다
먼저 볼 결과원본과 복원 차이고정 seed의 품질과 다양성
대표 실패과도한 복사 또는 정보 손실불안정 학습과 mode collapse

압축·denoising·representation이 목적이면 Autoencoder를 먼저 검토한다. 사실적인 새 표본이 목적이고 불안정한 학습을 관찰할 수 있다면 GAN이 후보가 된다. diffusion model은 별도의 노이즈 제거 목적을 사용하므로 이 설명을 그대로 적용하지 않는다.

스스로 확인할 질문

  • latent dimension의 비교 기준선이 있는가?
  • 복원 오차가 낮다는 사실이 실제 목적의 성공을 뜻하는가?
  • GAN의 고정 seed 출력과 다양성을 함께 보는가?
