CNN — 합성곱 신경망

확인 범위: 이 문서는 CNN의 합성곱·패딩·스트라이드·채널·풀링·im2col에 관한 일반 원리와 예시를 설명하며, 제시된 수식·텐서 형태·numpy 코드는 연산과 구현 패턴을 이해하기 위한 것이다. 특정 라이브러리·버전에서의 실행 결과나 성능 우위까지 검증한 문서는 아니므로, 실제 구현의 정확성·호환성·속도·메모리 효율은 해당 코드와 실행 기록 및 성능 측정으로 별도 확인해야 한다.

한 줄 요약: CNN(Convolutional Neural Network)은 이미지의 2차원 구조를 보존한 채 작은 필터를 슬라이딩하며 지역 특징을 추출하는 신경망이다.

CNN 혼동

완전연결층(Affine)은 입력을 1차원으로 펼친다. MNIST 28×28 이미지는 784개 숫자가 된다.

문제는 이것이다. 숫자 “3”의 곡선은 가까운 픽셀들의 공간 관계로 나타난다. 784개로 펼치면 “위치 (5,10)과 (5,11)은 인접하다”는 정보가 사라진다. 완전연결층은 모든 픽셀과 모든 뉴런을 연결하므로 파라미터 수도 많다. 784 × 256 = 200,704개.

CNN은 이미지를 2차원 그대로 보고, 작은 필터(예: 3×3)를 움직이며 지역 패턴을 찾는다. 같은 필터를 이미지 전체에 재사용하므로 파라미터가 적고, 패턴이 조금 이동해도 감지할 수 있다.

CNN 흐름

합성곱 (Convolution)

합성곱은 작은 필터를 입력 위에 올려놓고, 대응하는 원소끼리 곱한 뒤 합산하는 연산이다.

비유: 돋보기로 이미지를 훑는다. 돋보기(필터)가 보는 영역은 작지만, 한 칸씩 이동하며 전체를 살핀다. 각 위치에서 “이 패턴이 있는가?”를 점수로 매긴다.

연산 예시:

%% 2×2 합성곱 연산 예시
flowchart LR
  input["입력 일부 (2×2)<br/>1 &#124; 2<br/>3 &#124; 4"]
  filter["필터 (2×2)<br/>0.1 &#124; 0.2<br/>0.3 &#124; 0.4"]
  result["결과<br/>1×0.1 + 2×0.2 + 3×0.3 + 4×0.4<br/>= 0.1 + 0.4 + 0.9 + 1.6<br/>= 3.0"]
  input -->|원소별 곱| result
  filter -->|합산| result

이 결과 하나가 특징 맵(feature map)의 한 칸이 된다. 필터를 한 칸씩 이동하면 전체 특징 맵이 완성된다.

출력 크기 공식

입력 크기 H×W, 필터 크기 FH×FW, 패딩 P, 스트라이드 S일 때:

OH = (H + 2P - FH) / S + 1
OW = (W + 2P - FW) / S + 1

왜 패딩을 쓰는가?

28×28 입력에 3×3 필터를 패딩 없이 적용하면 출력은 26×26이 된다. 층을 쌓을수록 크기가 줄어든다.

패딩 1을 넣으면:

OH = (28 + 2×1 - 3) / 1 + 1 = 28

입력과 출력 크기가 같아진다. 가장자리 픽셀의 정보도 더 잘 활용된다.

스트라이드 (Stride)

필터를 몇 칸씩 이동할지 결정한다. 스트라이드 1이면 한 칸씩, 스트라이드 2이면 두 칸씩 이동한다. 스트라이드가 클수록 출력이 작아진다.

채널 (Channel)

흑백 이미지는 1채널, RGB 이미지는 3채널이다. MNIST는 (1, 28, 28) 형태다.

입력  shape: (C_in, H, W)
필터  shape: (C_out, C_in, FH, FW)
출력  shape: (C_out, OH, OW)

필터 하나는 입력의 모든 채널을 동시에 보고, 하나의 출력 채널을 만든다. 필터 개수가 출력 채널 수를 결정한다.

풀링 (Pooling)

풀링은 특징 맵 크기를 줄인다. 학습할 파라미터가 없다.

맥스 풀링(Max Pooling)은 영역에서 가장 큰 값만 남긴다.

%% 2×2 맥스 풀링 예시
flowchart LR
  pool["2×2 영역<br/>1 &#124; 3<br/>2 &#124; 4"]
  max["Max Pooling<br/>max = 4"]
  pool -->|최댓값만 남김| max

역전파 시에는 forward에서 최댓값이었던 위치에만 gradient를 전달한다. 나머지 위치는 0이다.

풀링의 효과: 작은 위치 변화에 둔감해진다(이동 불변성). 계산량도 줄어든다.

CNN 전체 구조

%% CNN 전체 구조
flowchart LR
  conv1["Conv<br/>필터 적용"]
  relu1["ReLU<br/>활성화"]
  pool1["Pooling<br/>크기 축소"]
  conv2["Conv<br/>필터 적용"]
  relu2["ReLU<br/>활성화"]
  pool2["Pooling<br/>크기 축소"]
  affine["Affine<br/>FC층"]
  softmax["Softmax<br/>분류"]
  conv1 --> relu1
  relu1 --> pool1
  pool1 --> conv2
  conv2 --> relu2
  relu2 --> pool2
  pool2 --> affine
  affine --> softmax

앞쪽 Conv 층은 선, 모서리 같은 낮은 수준 특징을 잡는다. 뒤쪽 Conv 층은 더 복잡한 패턴(눈, 코, 숫자 곡선)을 잡는다. 마지막 Affine 층이 클래스별 점수를 계산한다.

im2col — 합성곱을 행렬곱으로 바꾸기

합성곱을 for문으로 구현하면 느리다. im2col은 입력의 각 필터 적용 영역을 한 줄로 펼쳐서, 합성곱을 행렬곱 한 번으로 바꾸는 기법이다.

%% im2col 행렬 변환 흐름
flowchart LR
  input["입력<br/>(1, 1, 4, 4)"]
  patches["3×3 영역 4개<br/>행으로 펼침"]
  col["im2col 행렬<br/>(4, 9)"]
  filter["필터 펼침<br/>(9, 1)"]
  matmul["행렬곱<br/>(4, 9) × (9, 1) = (4, 1)"]
  output["reshape<br/>(1, 1, 2, 2) 출력"]
  input --> patches
  patches --> col
  col --> matmul
  matmul --> output
  filter --> matmul

행렬곱은 numpy가 최적화해 놓았으므로 빠르다. 단점은 메모리를 더 쓴다는 것이다.

CNN 코드

완전연결층과 합성곱층의 forward/backward 패턴 비교

밑바닥 딥러닝1의 Affine 레이어는 forward()에서 입력을 저장하고, backward()에서 gradient를 계산한다. 합성곱 레이어도 동일한 패턴을 따른다.

이 코드가 하는 일: Affine은 입력을 1차원으로 펼쳐서 행렬곱을 수행한다. 784개 픽셀 전부가 모든 뉴런에 연결된다. 합성곱 레이어는 이 구조에서 self.x @ self.W 대신 im2col + 행렬곱을 사용한다. 지역 영역만 연결하되, 같은 forward/backward 패턴을 유지한다.

%% Affine과 Convolution forward 비교
flowchart TD
  a1["x.reshape(B, -1)"]
  a2["@ W"]
  a3["전체 연결"]
  c1["im2col(x, FH, FW)"]
  c2["@ W.reshape(FN, -1).T"]
  c3["지역 연결 + 가중치 공유"]
  a1 --> a2
  a2 --> a3
  c1 --> c2
  c2 --> c3

합성곱 연산 (numpy 구현)

이 코드가 하는 일: 3×3 세로선 감지 필터를 4×4 이미지에 적용해 합성곱의 한 칸을 계산한다. 왼쪽 열은 +1, 오른쪽 열은 -1이므로 세로 방향 변화가 클수록 큰 값이 나온다.

맥스 풀링 (numpy 구현)

이 코드가 하는 일: 4×4 특징 맵을 2×2 영역으로 나누어 각 영역의 최댓값만 남긴다. 출력은 2×2가 된다.

텐서 shape 변환 흐름 (MNIST CNN 예시)

%% MNIST CNN 텐서 shape 변환 흐름
flowchart TD
  input["입력 이미지<br/>(1, 1, 28, 28)<br/>배치 1, 채널 1, 28×28"]
  conv1["Conv<br/>필터 32개, 3×3, pad=1, stride=1<br/>(1, 32, 28, 28)<br/>채널 32로 확장"]
  relu1["ReLU<br/>(1, 32, 28, 28)"]
  pool1["MaxPool<br/>2×2, stride=2<br/>(1, 32, 14, 14)<br/>크기 절반"]
  conv2["Conv<br/>필터 64개, 3×3, pad=1, stride=1<br/>(1, 64, 14, 14)<br/>채널 64로 확장"]
  relu_pool2["ReLU + MaxPool<br/>2×2<br/>(1, 64, 7, 7)<br/>크기 절반"]
  flatten["Flatten<br/>(1, 3136)<br/>64 × 7 × 7 = 3136"]
  affine["Affine<br/>3136 → 10<br/>(1, 10)<br/>클래스 10개 점수"]
  softmax["Softmax<br/>(1, 10)<br/>확률 분포"]
  input --> conv1
  conv1 --> relu1
  relu1 --> pool1
  pool1 --> conv2
  conv2 --> relu_pool2
  relu_pool2 --> flatten
  flatten --> affine
  affine --> softmax

정리

CNN은 완전연결층의 한계(공간 정보 손실, 파라미터 과다)를 해결하기 위해 합성곱과 풀링을 도입한 신경망이다. 합성곱 필터는 지역 패턴을 감지하고, 이미지 전체에 같은 필터를 재사용하므로 파라미터가 효율적이다. 풀링은 크기를 줄이고 이동 불변성을 부여한다. im2col 기법으로 합성곱을 행렬곱으로 변환하면 numpy 수준에서 빠르게 연산할 수 있다. 학습 흐름(순전파 → 손실 → 역전파 → 업데이트)은 MLP와 동일하다.
