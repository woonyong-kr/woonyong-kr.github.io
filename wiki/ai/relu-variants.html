ReLU 변형 — Dead Neuron 문제를 해결하는 활성화 함수들

확인 범위: 이 문서는 ReLU와 주요 변형의 일반 원리와 선택 기준을 설명하며, 포함된 코드는 동작을 보여 주는 구현 예시다. 특정 라이브러리·모델·버전에서의 정확성이나 실제 학습 효과, 실행 결과 및 성능 비교는 별도의 코드 검증과 실행·측정 기록이 필요하다.

한 줄 요약: ReLU는 음수 입력의 기울기를 완전히 0으로 만들어 뉴런을 죽인다. Leaky ReLU, ELU, GELU, SiLU는 각각 다른 방식으로 음수 구간에 기울기를 남겨 이 문제를 해결한다.

ReLU 변형 필요성

ReLU는 max(0, x)로 계산이 빠르고, 양수 구간에서 기울기가 1이라 기울기 소실 문제를 해결한다. 그래서 Sigmoid와 Tanh를 대체하며 딥러닝의 기본 활성화 함수가 되었다.

그런데 ReLU에는 치명적인 약점이 하나 있다. 입력이 0 이하면 출력이 0이고, 기울기도 0이다. 학습 중 가중치가 크게 갱신되어 한 뉴런의 입력이 항상 음수가 되면, 그 뉴런은 어떤 데이터가 들어와도 출력이 0이다. 기울기가 0이니 가중치도 갱신되지 않는다. 이 뉴런은 영원히 죽는다. 이것이 dead neuron 문제다.

학습률이 크거나 초기화가 나쁘면 전체 뉴런의 상당 비율이 죽을 수 있다. ReLU 변형들은 음수 구간에서 기울기를 완전히 0으로 만들지 않는 방법으로 이 문제를 해결한다.

ReLU 변형 흐름

비유

ReLU는 한쪽 방향만 열리는 문이다. 양수 신호는 그대로 통과하지만, 음수 신호는 완전히 차단된다. 문이 한번 닫히면 다시 열리지 않는다.

Leaky ReLU는 문에 작은 틈을 남긴 것이다. 음수 신호도 아주 조금 새어 나온다. ELU는 음수 구간을 부드러운 곡선으로 바꾼 것이다. GELU와 SiLU는 문이 서서히 닫히는 것이다 — 0 근처에서 갑자기 꺾이지 않고, 확률적으로 통과량을 조절한다.

각 변형의 정의

Leaky ReLU:

음수 구간에 작은 기울기 alpha를 준다. 보통 alpha = 0.01이다.

f(x) = x (x > 0) f(x) = alpha*x (x <= 0)

기울기: x > 0이면 1, x <= 0이면 alpha. 음수 구간에서도 기울기가 0이 아니므로 dead neuron이 발생하지 않는다. alpha가 고정 상수라서 하이퍼파라미터 하나만 추가된다.

PReLU (Parametric ReLU):

Leaky ReLU와 구조가 같지만 alpha를 학습 가능한 파라미터로 둔다. 채널별로 다른 alpha를 배울 수 있다. He 초기화 논문에서 함께 제안되었다.

ELU (Exponential Linear Unit):

f(x) = x (x > 0) f(x) = alpha*(exp(x) - 1) (x <= 0)

음수 구간이 지수 함수 곡선이라 0에서 부드럽게 연결된다. 출력 평균이 0에 가까워져 학습이 안정적이다. 단점은 exp() 연산이 ReLU보다 느리다는 것이다.

GELU (Gaussian Error Linear Unit):

GELU(x) = x * Phi(x)

Phi(x)는 표준정규분포의 누적분포함수(CDF)다. “입력이 양수일 확률”만큼 통과시킨다. x = -1이면 약 15%만 통과하고, x = 2이면 약 98% 통과한다. GPT, BERT 등 Transformer 모델의 표준 활성화 함수다. 상세는 GELU 활성화 함수 문서를 본다.

SiLU / Swish:

SiLU(x) = x * sigmoid(x)

Google Brain이 자동 탐색으로 찾은 함수다. GELU의 sigmoid 근사(x * sigmoid(1.702x))에서 상수 1.702를 1로 바꾼 것과 같다. LLaMA 등 최신 LLM에서 SiLU를 쓰는 경우가 많다.

왜 음수 구간의 기울기가 중요한가?

역전파에서 기울기는 출력에서 입력 방향으로 흐른다. 활성화 함수의 기울기가 0이면, 그 뉴런을 지나는 기울기 흐름이 끊긴다. 앞쪽 가중치는 갱신 신호를 받지 못한다.

ReLU에서 dead neuron이 생기는 과정을 숫자로 본다.

  1. 학습 초기, 뉴런 입력 z = W*x + b = -0.5 → ReLU 출력 = 0, 기울기 = 0
  2. 가중치 갱신: W_new = W - lr * 0 = W (변화 없음)
  3. 다음 배치에서도 z < 0이면 같은 상황 반복
  4. 이 뉴런은 학습에서 영구 이탈

Leaky ReLU라면 z = -0.5일 때 기울기가 0.01이므로, 작지만 갱신 신호가 전달된다. 충분한 배치를 거치면 뉴런이 살아날 수 있다.

ReLU 변형 코드

ReLU 구현 (밑바닥 딥러닝1)

self.mask가 핵심이다. forward에서 x <= 0인 위치를 저장해두고, backward에서 그 위치의 기울기를 0으로 만든다.

Leaky ReLU와 ELU 구현 (NumPy)

Leaky ReLU는 np.where(x > 0, x, alpha * x)로 한 줄이다. ELU는 음수 구간에서 exp(x) - 1을 계산한다. 역전파에서 ELU의 음수 구간 기울기는 alpha * exp(x)이며, x가 매우 작은 음수일수록 기울기가 0에 가까워진다.

숫자로 비교하기

음수 구간에서 차이가 드러난다. ReLU는 전부 0이다. Leaky ReLU는 0.01배로 매우 작다. ELU는 -1에 수렴하는 곡선이다. SiLU는 음수 구간에서 비교적 큰 값을 유지하다가 큰 음수에서 0으로 간다.

GELU 구현 (밑바닥 LLM 책)

GPT의 FeedForward 블록에서 Linear → GELU → Linear 순서로 사용된다. 상세는 GELU 활성화 함수 문서를 본다.

ReLU 변형 적용 기준

  • 기본 CNN/MLP → ReLU. 빠르고 충분히 잘 동작한다.
  • Dead neuron이 문제되면 → Leaky ReLU. 변경 비용이 가장 낮다.
  • Transformer FFN → GELU. GPT, BERT의 사실상 표준이다.
  • 최신 LLM (LLaMA, Mistral) → SiLU. GELU와 성능이 비슷하지만 구현이 더 간단하다.
  • ELU → 출력 평균을 0에 맞추고 싶을 때. 최근에는 BatchNorm이나 LayerNorm이 이 역할을 대신해서 사용 빈도가 줄었다.

정리

ReLU의 dead neuron 문제는 음수 입력의 기울기가 완전히 0이 되어 가중치 갱신이 멈추는 것이다. Leaky ReLU는 음수 구간에 작은 기울기를 주고, ELU는 지수 곡선으로 부드럽게 연결하고, GELU/SiLU는 확률적 게이팅으로 음수 정보를 일부 보존한다. 현재 CNN에서는 ReLU가, Transformer에서는 GELU 또는 SiLU가 표준이다.
