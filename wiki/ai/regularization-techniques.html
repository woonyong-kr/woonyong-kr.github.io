정규화 기법 — 과적합을 억제하는 네 가지 전략

정규화 기법 — 과적합을 억제하는 네 가지 전략

확인 범위: 이 문서는 Weight Decay, Dropout, Early Stopping, Data Augmentation의 일반 원리와 선택 기준을 설명하고, 제시된 밑바닥 딥러닝1 MNIST 코드에서 BatchNorm과 Dropout이 은닉층에 배치된 구조를 코드 수준에서 다룬다. 다만 특정 버전의 실행 기록이나 성능 측정 결과를 제시한 검증 보고서는 아니므로, 효과와 권장값에 관한 판단은 실제 코드·환경·데이터에 따른 별도 검증이 필요하다.

한 줄 요약: 정규화(Regularization)는 모델이 훈련 데이터의 노이즈까지 외우는 과적합을 방지하기 위해, 모델 복잡도를 의도적으로 제한하는 기법의 총칭이다.

정규화 기법 혼동

신경망의 파라미터 수는 쉽게 수백만을 넘긴다. 밑바닥 딥러닝1의 MNIST 분류기도 은닉층 2개(784→100→50→10)에 파라미터가 약 84,000개다. 훈련 데이터가 60,000장이므로, 모델은 데이터를 통째로 외울 수 있는 용량을 갖고 있다.

외우면 훈련 정확도는 99%를 넘지만, 새로운 데이터(테스트셋)에서는 성능이 떨어진다. 이것이 과적합(overfitting)이다. 반대로 모델이 너무 단순해서 훈련 데이터의 패턴조차 못 잡으면 과소적합(underfitting)이다.

정규화는 과적합과 과소적합 사이에서 일반화 성능이 가장 좋은 지점을 찾는 도구다. 방법은 크게 네 가지로 나뉜다: 가중치 제약, 뉴런 차단, 학습 중단, 데이터 확장.

정규화 기법 흐름

비유

시험 공부에 비유하면 과적합은 “기출문제 정답만 외우는 것”이다. 정규화는 “기출에만 최적화되지 않도록 제약을 거는 것”이다.

  • Weight Decay: 필기 분량을 제한한다. 핵심만 적어야 하니 노이즈가 빠진다.
  • Dropout: 매번 다른 스터디 멤버로 공부한다. 특정 조합에 의존하지 않는다.
  • Early Stopping: 모의고사 점수가 떨어지기 시작하면 공부를 멈춘다.
  • Data Augmentation: 같은 문제를 살짝 바꿔서 여러 번 푼다. 변형에 강해진다.

1. Weight Decay (L2 정규화)

손실 함수에 가중치 크기의 제곱합을 더한다.

L_total = L_data + (lambda/2) * sum(W

lambda가 크면 가중치가 작아지도록 강하게 압박한다. 가중치가 작으면 입력의 작은 변화에 출력이 크게 흔들리지 않는다. 즉 모델이 부드러운 함수를 학습한다.

gradient 갱신 시 가중치가 매 스텝 (1 - lr * lambda) 비율로 줄어든다. 이것이 “weight decay”라는 이름의 유래다.

상세는 Weight Decay와 L2 정규화 문서를 본다.

2. Dropout

학습 때마다 은닉층 뉴런 중 일부를 무작위로 꺼서 0으로 만든다. 비율은 모델·데이터·적용 위치에 따라 검증한다. 특정 뉴런 조합에 의존하는 “공모(co-adaptation)“를 방지한다. 추론 때는 모든 뉴런을 켜고 출력을 (1 - drop_ratio)로 스케일링한다.

밑바닥 딥러닝1 MNIST 코드에서는 Affine → BatchNorm → ReLU → Dropout 순서로 배치한다.

상세는 드롭아웃 문서를 본다.

3. Early Stopping

에폭마다 검증 데이터(validation set)의 손실을 측정한다. 훈련 손실은 계속 내려가는데 검증 손실이 올라가기 시작하면, 그 지점에서 학습을 멈춘다. 검증 손실이 최소였던 시점의 가중치를 최종 모델로 사용한다.

검증 지표와 체크포인트를 함께 관리해야 하며, 너무 짧은 patience는 일시적 잡음에 반응해 학습을 성급하게 끝낼 수 있다.

상세는 Early Stopping과 체크포인팅 문서를 본다.

4. Data Augmentation

기존 훈련 데이터를 변형하여 데이터 양을 늘린다. 이미지라면 회전, 좌우 반전, 크롭, 색상 변환 등을 적용한다. 모델이 변형에 불변(invariant)한 특징을 배우게 된다.

MNIST에서는 이미지를 살짝 회전하거나 이동하는 것만으로도 과적합이 줄어든다. 데이터가 부족한 상황에서 가장 효과적인 정규화 방법 중 하나다.

상세는 데이터 증강 문서를 본다.

분류·언어 모델의 추가 선택지

Label Smoothing은 정답 분포를 완전한 one-hot 대신 조금 부드럽게 만들어 출력 확률의 과신을 줄인다. 분류 문제에서는 유용할 수 있지만 확률 보정과 희소한 정답 신호에 영향을 주므로 검증 지표로 선택한다.

Gradient Clipping은 정규화라기보다 학습 안정화 기법이다. loss.backward() 뒤, optimizer의 step() 앞에서 전체 gradient norm을 제한한다. 과적합을 직접 해결하지 않으므로 Gradient Clipping에서 기울기 폭발 문제와 함께 본다.

기법 간 비교

%% 정규화 기법 비교
flowchart LR
  wd["Weight Decay<br/>L_total += λW²"]
  wd_effect["모델 복잡도 감소<br/>부드러운 함수"]
  dropout["Dropout<br/>mask * output"]
  dropout_effect["공모 방지<br/>독립적 특징 학습"]
  early["Early Stopping<br/>patience 기반"]
  early_effect["학습 시간 제한<br/>최적 시점 복원"]
  aug["Data Augmentation<br/>회전·반전·크롭"]
  aug_effect["데이터 다양성 확대<br/>불변 특징 학습"]
  wd --> wd_effect
  dropout --> dropout_effect
  early --> early_effect
  aug --> aug_effect

이 네 가지는 서로 배타적이지 않다. 실전에서는 보통 조합해서 쓴다.

flowchart TD

  batchnorm --> relu
  relu --> dropout
  dropout --> next

Weight Decay 원리 (참고)

밑바닥 딥러닝1 MNIST 코드에는 Weight Decay가 구현되어 있지 않다. 실제 적용 시에는 손실 함수에 L2 페널티를 추가하거나, 옵티마이저의 weight_decay 파라미터를 사용한다. 원리는 다음과 같다.

weight_decay_lambda가 0이면 정규화 없이 데이터 손실만 사용한다. 값이 클수록 가중치를 작게 유지하도록 강하게 압박한다. PyTorch에서는 torch.optim.AdamW(params, weight_decay=1e-2)처럼 옵티마이저에서 직접 지원한다.

정규화 기법 선택 기준

어떤 정규화를 먼저 적용할지 판단하는 순서가 있다.

  1. 먼저 훈련·검증 손실을 분리해 과적합 여부를 확인한다.
  2. Weight Decay는 optimizer와 모델 규모에 맞는 후보값을 비교한다.
  3. Dropout은 데이터가 적거나 경로 공의존이 강할 때 적용하고 비율을 검증한다.
  4. Early Stopping은 최저 검증 지표의 체크포인트와 patience를 함께 관리한다.
  5. Data Augmentation은 의미를 보존하는 변형만 사용한다.

BatchNorm은 정규화 목적으로 설계된 것은 아니지만, 미니배치 통계에 의한 노이즈가 간접적으로 정규화 효과를 낸다. BatchNorm과 Dropout의 상호작용은 모델 구조와 배치 크기에 따라 달라지므로 조합 자체를 규칙으로 두지 않고 검증 지표로 판단한다.

정리

정규화는 모델이 훈련 데이터에 과적합하는 것을 막는 기법의 총칭이다. Weight Decay는 가중치 크기를 제한하고, Dropout은 뉴런 조합 의존성을 끊고, Early Stopping은 학습 시점을 제한하고, Data Augmentation은 데이터 다양성을 확보한다. 실전에서는 이들을 조합하며, 밑바닥 딥러닝1 MNIST 코드에서는 BatchNorm + Dropout을 은닉층에 적용하는 구조를 확인할 수 있다.
