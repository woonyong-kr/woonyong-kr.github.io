하이퍼파라미터 탐색

하이퍼파라미터 탐색

한 줄 요약: 하이퍼파라미터는 학습 알고리즘이 스스로 조절하지 못하는 값이다. 검증 데이터로 성능을 측정하며 좋은 조합을 찾는 과정이 하이퍼파라미터 탐색이다.

하이퍼파라미터 탐색이 필요한 이유

신경망을 학습하려면 알고리즘이 갱신하는 값과 사람이 정하는 값을 구분해야 한다.

  • 파라미터 (Parameter): 가중치 W와 편향 b처럼 학습 도중 경사 하강법이 자동으로 갱신하는 값이다.
  • 하이퍼파라미터 (Hyperparameter): 학습률, 은닉층 크기, 배치 크기, 에폭 수처럼 학습을 시작하기 전에 사람이 정해야 하는 값이다.

하이퍼파라미터를 잘못 고르면 모델이 학습되지 않거나 새 데이터에서 충분한 성능을 내지 못한다. 학습률이 너무 크면 loss가 발산하고, 너무 작으면 수렴이 느리다. 은닉층이 너무 작으면 표현력이 부족하고, 너무 크면 과적합될 수 있다.

적절한 조합은 데이터, 모델 구조, 과제에 따라 달라진다. 미리 알 수 없으므로 여러 조합을 학습하고 검증 데이터의 성능을 비교해야 한다. 이 실험 과정이 하이퍼파라미터 탐색이다.

무엇을 탐색하는가: 주요 하이퍼파라미터

MNIST 분류 프로젝트를 기준으로 사람이 정해야 하는 값을 살펴본다.

  • 학습률 (learning rate)
    • SGD, Adam 같은 옵티마이저가 한 번에 파라미터를 얼마나 움직이는지 결정한다.
    • 다른 값을 고르기 전에 먼저 범위를 좁혀야 하는 중요한 하이퍼파라미터다.
  • 은닉층 크기 (hidden layer size)
    • 뉴런 수가 많을수록 표현력이 커지지만, 파라미터 수도 늘어나 과적합 위험이 올라간다.
  • 배치 크기 (batch size)
    • 한 번에 몇 개 샘플로 기울기를 계산하는지 결정한다.
    • 작으면 노이즈가 크지만 일반화에 유리할 수 있고, 크면 안정적이지만 메모리를 많이 쓴다.
  • 에폭 수 (epochs)
    • 전체 학습 데이터를 몇 번 반복하는지 결정한다.
    • 너무 적으면 과소적합되고, 너무 많으면 과적합될 수 있다.
  • 드롭아웃 비율 (dropout ratio)
    • 학습 중 무작위로 끄는 뉴런의 비율이다.
  • 가중치 초기화 방법 (weight initialization)
    • He 초기화, Xavier 초기화 등 학습을 시작할 때 사용할 가중치 분포를 결정한다.

무엇으로 비교하는가: 학습·검증·테스트 데이터

하이퍼파라미터를 평가할 때는 학습 데이터의 정확도가 아니라 검증 데이터의 성능을 봐야 한다. 학습 데이터에 과적합된 모델도 학습 정확도는 높을 수 있기 때문이다.

데이터는 용도에 따라 세 덩어리로 나눈다.

%% 하이퍼파라미터 탐색을 위한 데이터 분할
flowchart LR
  dataset["전체 데이터셋<br/>분할 전 원본 데이터"]
  train["학습 데이터<br/>(Training) ~80%<br/>파라미터 W"]
  val["검증 데이터<br/>(Val) ~10%<br/>하이퍼파라미터 선택"]
  test["테스트 데이터<br/>(Test) ~10%<br/>최종 성능 보고"]
  dataset --> train
  dataset --> val
  dataset --> test
  • 학습 데이터: 파라미터(W, b)를 갱신하는 데 사용한다.
  • 검증 데이터: 하이퍼파라미터 조합의 성능을 비교하는 데 사용한다. 학습에는 쓰지 않는다.
  • 테스트 데이터: 최종 모델의 실제 성능을 보고할 때 1회만 사용한다.

검증 데이터를 학습에 섞으면 하이퍼파라미터 선택이 검증 데이터의 영향을 받는다. 테스트 데이터로 하이퍼파라미터를 고르면 테스트 성능이 과대 추정된다. 따라서 학습 데이터로 파라미터를 갱신하고, 검증 데이터로 조합을 선택한 뒤, 테스트 데이터로 최종 성능을 보고해야 한다.

어떻게 조합을 만드는가: 격자 탐색과 랜덤 탐색

격자 탐색 (Grid Search)

격자 탐색은 미리 정한 값 목록의 모든 조합을 시도한다.

방법은 단순하지만 하이퍼파라미터 수가 늘어나면 조합도 빠르게 커진다. 3개 하이퍼파라미터에 각각 5개 후보가 있으면 125번 실험해야 한다.

랜덤 탐색 (Random Search)

랜덤 탐색은 각 하이퍼파라미터의 범위를 정한 뒤 그 안에서 값을 무작위로 뽑는다.

모든 하이퍼파라미터가 성능에 같은 정도로 영향을 주지는 않는다. 격자 탐색은 영향이 작은 축에도 같은 수의 후보를 배분한다. 랜덤 탐색은 정해진 시도 횟수 안에서 값을 뽑기 때문에 영향이 큰 축에서도 더 다양한 값을 시도할 수 있다.

학습률을 로그 스케일로 탐색하는 이유

학습률을 0.0001에서 0.1 사이에서 찾는다고 하자. 이 범위를 선형으로 균등하게 나누면 0.0001, 0.025, 0.05, 0.075, 0.1처럼 값이 정해져 0.0001~0.01 구간을 거의 살펴보지 못한다.

로그 스케일을 사용하면 10^(-4), 10^(-3), 10^(-2), 10^(-1)처럼 각 자릿수의 값을 고르게 탐색할 수 있다.

지수를 균등분포에서 뽑은 뒤 10을 거듭제곱하면 로그 스케일로 학습률을 샘플링할 수 있다.

하이퍼파라미터 탐색 절차

탐색은 후보 범위를 정하는 일에서 시작한다. 격자 또는 랜덤 방식으로 조합을 만든 뒤, 각 조합으로 학습 데이터의 파라미터를 갱신한다. 조합별 성능은 검증 데이터로 비교하고, 선택한 최종 모델만 테스트 데이터로 평가한다.

%% 하이퍼파라미터 탐색 절차
flowchart LR
  range["1. 범위 설정<br/>lr: 10^-4~10^-1<br/>hidden: 64~1024"]
  sample["2. 조합 생성<br/>랜덤 또는 격자"]
  train["3. 학습 실행<br/>학습 데이터로<br/>파라미터 갱신"]
  validate["4. 검증 평가<br/>검증 데이터로<br/>조합별 비교"]
  test["5. 최종 평가<br/>테스트 데이터로<br/>1회만 보고"]
  range --> sample
  sample --> train
  train --> validate
  validate --> test

MNIST 코드에서 찾는 하이퍼파라미터

MNIST 프로젝트 코드에서는 모델 구조, 학습 반복, 옵티마이저 설정에서 하이퍼파라미터를 찾을 수 있다.

모델 구조와 초기화

이 코드에서는 hidden_sizes, dropout_ratio 등이 하이퍼파라미터다. [784] + [512, 256] + [10]은 입력 784차원, 은닉층 512와 256, 출력 10으로 이어지는 구조를 만든다.

에폭 수와 배치 크기

epochs=20, batch_size=128은 학습 루프의 하이퍼파라미터다.

옵티마이저의 학습률

optimizer가 사용하는 lr도 사람이 정하는 하이퍼파라미터다.

MNIST 랜덤 탐색 구현 예제

랜덤 탐색을 시작하기 전에 학습 데이터에서 검증 데이터를 분리한다.

이렇게 분리한 검증 데이터는 파라미터 학습에 사용하지 않고 하이퍼파라미터 조합을 비교할 때 사용한다.

다음 루프는 학습률, 은닉층 크기, 드롭아웃 비율을 무작위로 뽑는다. 각 조합으로 모델을 학습한 뒤 검증 정확도를 기록하고, 그 정확도가 높은 순서로 결과를 정렬한다.

조합을 비교하는 지점은 evaluate(model, x_val, y_val)이다. 학습 데이터의 정확도가 높더라도 검증 데이터의 정확도가 낮다면 학습 데이터에 과적합된 것으로 볼 수 있다.

결과를 해석하는 기준

학습률에 따른 loss 변화 패턴

%% 학습률에 따른 loss 변화 패턴
flowchart LR
  small["lr = 0.0001<br/>너무 작음<br/>loss가 느리게 내려가다 정체"]
  good["lr = 0.01<br/>적절<br/>loss가 빠르게 내려가 안정"]
  large["lr = 1.0<br/>너무 큼<br/>loss가 진동하거나 발산"]
  small --> good
  good --> large

학습률이 적절하면 loss가 빠르게 내려가 안정된다. 너무 작으면 수렴이 느리고, 너무 크면 loss가 진동하거나 발산한다. 이런 차이 때문에 학습률은 먼저 넓은 범위에서 탐색하고 점차 범위를 좁힌다.

은닉층 크기와 파라미터 수

은닉층 크기를 바꾸면 모델의 파라미터 수도 달라진다.

이 계산은 은닉층 크기를 줄일 때 학습 비용과 과적합 위험뿐 아니라 표현력도 함께 달라진다는 점을 보여준다. 따라서 은닉층 크기는 파라미터 수의 변화와 검증 성능을 함께 보며 선택해야 한다.

탐색 결과를 선택할 때 확인할 점

하이퍼파라미터 탐색에서는 학습 데이터, 검증 데이터, 테스트 데이터의 역할을 섞지 않아야 한다. 학습 데이터는 W, b 같은 파라미터를 갱신하고, 검증 데이터는 학습률·은닉층 크기·배치 크기·드롭아웃 비율 등의 조합을 비교한다. 테스트 데이터는 선택을 마친 모델의 최종 성능을 보고할 때만 사용한다.

학습률처럼 자릿수에 따라 값의 차이가 큰 항목은 로그 스케일로 탐색한다. 여러 하이퍼파라미터를 제한된 횟수 안에서 함께 살펴볼 때는 랜덤 탐색으로 다양한 조합을 만들 수 있다. 선택한 전략과 관계없이 최종 판단 기준은 조합별 검증 성능이다.
