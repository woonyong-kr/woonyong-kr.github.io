손실 함수 — 모델이 얼마나 틀렸는지 측정하는 기준

확인 범위: 이 문서는 손실 함수의 일반 개념과 대표적인 선택 기준을 설명하고, 제시된 NumPy 구현과 계산 예시로 동작을 보여준다. 특정 코드의 실제 실행 결과나 버전별 동작, 성능은 검증하지 않으므로 이에 관한 판단에는 별도의 실행 기록과 측정이 필요하다.

한 줄 요약: 손실 함수는 모델의 예측과 정답 사이의 차이를 하나의 숫자로 바꾸는 함수다. 이 숫자를 줄이는 방향으로 파라미터를 갱신하는 것이 학습이다.

손실 함수 구분

신경망의 학습은 “좋은 가중치를 찾는 것”이다. 그런데 “좋다”를 어떻게 판단하는가? 정확도(accuracy)를 쓸 수도 있지만, 정확도는 미분이 안 된다. 100개 중 70개를 맞히든 71개를 맞히든 가중치의 미세한 변화가 정확도를 바꾸지 못하는 구간이 대부분이다.

손실 함수는 이 문제를 해결한다. 예측과 정답의 차이를 연속적인 숫자로 표현하므로 미분이 가능하다. 가중치를 살짝 바꿨을 때 손실이 줄어드는 방향을 알 수 있고, 그 방향으로 파라미터를 갱신하면 모델이 점점 나아진다. 이것이 경사 하강법의 출발점이다.

왜 정확도 대신 손실 함수를 쓰는가?

정확도를 W에 대해 미분하면 대부분의 구간에서 0이다. W를 아무리 바꿔도 예측 라벨이 바뀌지 않으면 정확도는 그대로이기 때문이다. 이것을 “계단 함수 문제”라 한다. 손실 함수는 확률 값을 직접 다루므로 W의 미세한 변화에도 연속적으로 반응한다.

손실 함수 계산

대표적인 손실 함수 두 가지

MSE (Mean Squared Error, 평균 제곱 오차) — 회귀 문제에 사용한다.

E = (1/N) * sum((y_i - t_i)

예측 y와 정답 t의 차이를 제곱해서 평균낸다. 차이가 클수록 제곱에 의해 벌칙이 급격히 커진다.

Cross-Entropy Error (교차 엔트로피 오차) — 분류 문제에 사용한다.

E = -(1/N) * sum(t_i * log(y_i))

정답 클래스의 예측 확률에 -log를 취한다. 확률이 1에 가까우면 손실이 0에 가깝고, 확률이 0에 가까우면 손실이 무한대로 발산한다. 상세 유도는 Cross Entropy Loss와 Softmax 출력 참고.

왜 분류에 MSE 대신 Cross-Entropy를 쓰는가?

MSE를 softmax 출력에 적용하면 기울기가 매우 작아지는 구간이 생긴다. softmax 출력이 0.99일 때 MSE의 기울기는 거의 0이지만, 정답이 아닌 클래스에 0.99 확률을 부여한 것이라면 심각한 오류다. Cross-Entropy는 이런 상황에서도 큰 기울기를 만들어 빠르게 교정한다.

미니배치와 평균

실제 학습에서는 전체 데이터의 손실을 매번 계산하지 않는다. 미니배치(보통 32~256개 샘플)를 무작위로 뽑아 평균 손실을 구한다. 전체 데이터의 손실을 미니배치로 근사하는 것이다. 배치 크기로 나누는 이유는 배치 크기가 달라져도 기울기의 스케일이 일정하게 유지되어야 하기 때문이다.

손실 함수 텐서 코드

Cross-Entropy Loss 구현

핵심 라인은 clipped[np.arange(batch_size), y_true]다. 이것은 각 샘플에서 정답 클래스의 확률만 뽑아내는 인덱싱이다. 예를 들어 batch_size=3이고 y_true=[2, 0, 7]이면, 0번 샘플의 2번 확률, 1번 샘플의 0번 확률, 2번 샘플의 7번 확률을 가져온다.

np.clip(y_pred, 1e-7, 1.0)은 확률이 정확히 0일 때 log(0) = -inf가 되는 것을 막는다.

구체적 숫자로 보기

3번째 샘플의 손실(0.916)이 가장 크다. 정답 클래스에 40%밖에 확률을 주지 않았기 때문이다. 역전파에서 이 샘플의 기울기가 가장 커서, 다음 갱신에서 이 샘플을 더 잘 맞히는 방향으로 파라미터가 움직인다.

Cross-Entropy의 역전파

Softmax와 Cross-Entropy를 합쳐서 미분하면 y_pred - one_hot이라는 놀랍도록 단순한 결과가 나온다. 이 기울기가 역전파의 출발점이 된다.

정리

손실 함수는 “모델이 얼마나 틀렸는가”를 미분 가능한 숫자로 바꾼다. 회귀에는 MSE, 분류에는 Cross-Entropy를 쓴다. 분류에서 MSE 대신 Cross-Entropy를 쓰는 이유는 softmax 출력의 기울기가 더 안정적이기 때문이다. 미니배치 평균 손실을 구하고, 이 손실에서 시작해 역전파로 모든 파라미터의 기울기를 구한 뒤, 경사 하강법으로 파라미터를 갱신하는 것이 학습의 전체 흐름이다.

연결 문서: 계산 그래프 → 오차역전파법 (Backpropagation)
