계산 그래프

계산 그래프

한 줄 요약: 계산 그래프는 수식을 노드(연산)와 간선(데이터 흐름)으로 분해한 그래프다. 순전파로 값을 구하고, 역전파로 각 변수의 기울기를 구한다.

계산 그래프 필요성

신경망은 수십만 개의 파라미터가 얽힌 거대한 합성 함수다. 손실 L을 각 파라미터 W로 미분하려면 합성 함수 전체를 한 번에 미분해야 하는데, 이것은 수학적으로도 구현적으로도 어렵다.

계산 그래프는 이 문제를 “각 노드는 자기 앞뒤만 안다”로 바꾼다. 덧셈 노드는 덧셈의 미분만, 곱셈 노드는 곱셈의 미분만 계산한다. 이 국소 미분(local gradient)을 연쇄 법칙으로 연결하면 전체 기울기가 자동으로 나온다. 이것이 역전파의 토대다.

계산 그래프 흐름

비유: 공장 조립 라인

공장에서 완성품을 만들 때 각 작업자는 앞 작업자에게 받은 부품에 자기 공정만 적용하고 다음 작업자에게 넘긴다. 불량이 발생하면 역순으로 “네가 준 부품이 문제였다”고 책임을 추적한다. 계산 그래프의 순전파가 조립이고, 역전파가 책임 추적이다.

정의

계산 그래프(Computational Graph)는 수식을 방향 그래프로 표현한 것이다.

  • 노드: 하나의 연산 (덧셈, 곱셈, ReLU 등)
  • 간선: 연산의 입력과 출력 (데이터 흐름)
  • 순전파(forward): 입력 → 출력 방향으로 값을 계산한다.
  • 역전파(backward): 출력 → 입력 방향으로 기울기를 전파한다.

동작 순서: 덧셈과 곱셈 노드

가장 단순한 예로 z = (x + y) * t를 계산 그래프로 그린다.

%% 덧셈과 곱셈 노드의 순전파와 역전파
flowchart LR
  fx["x = 2"]
  fy["y = 3"]
  fadd["(+) 덧셈 노드"]
  fs["s = 5"]
  ft["t = 3"]
  fmul["(*) 곱셈 노드"]
  fz["z = 15"]
  bz["dz = 1"]
  bmul["(*) gradient switcher"]
  bds["ds = 3"]
  bdt["dt = 5"]
  badd["(+) gradient distributor"]
  bdx["dx = 3"]
  bdy["dy = 3"]
  fx --> fadd
  fy --> fadd
  fadd --> fs
  fs --> fmul
  ft --> fmul
  fmul --> fz
  bz --> bmul
  bmul --> bds
  bmul --> bdt
  bds --> badd
  badd --> bdx
  badd --> bdy

덧셈 노드: z = x + y이면 dz/dx = 1, dz/dy = 1이다. 상류 기울기를 양쪽에 그대로 복사한다. 그래서 “gradient distributor”라 부른다.

곱셈 노드: z = x * y이면 dz/dx = y, dz/dy = x이다. 상류 기울기에 상대방 값을 곱한다. 그래서 “gradient switcher”라 부른다. 순전파 때 상대방 값을 저장해 둬야 역전파에서 쓸 수 있다.

왜 역전파의 출발점은 1인가?

역전파는 dL/dL에서 시작한다. 자기 자신에 대한 미분이므로 항상 1이다. 이 1이 연쇄 법칙에 의해 각 노드를 거치며 국소 미분과 곱해지면서 점점 복잡한 기울기로 바뀐다.

연쇄 법칙과 국소 미분

연쇄 법칙(chain rule): 합성 함수 L = f(g(x))의 미분은 각 함수 미분의 곱이다.

dL/dx = dL/dg * dg/dx

계산 그래프에서 각 노드는 국소 미분 dg/dx만 알면 된다. 상류에서 dL/dg가 흘러오면, 여기에 국소 미분을 곱해서 dL/dx = dL/dg * dg/dx를 하류로 넘긴다. 노드가 아무리 많아도 이 원리가 반복될 뿐이다.

계산 그래프 코드

밑바닥 딥러닝1의 신경망은 이 원리를 그대로 코드로 옮긴다. 각 층(layer)이 계산 그래프의 노드이고, forward()와 backward() 메서드가 순전파와 역전파다.

곱셈 노드 구현 예시

사용 예시로 사과 2개를 개당 100원에 사는 계산을 그래프로 표현한다.

가격의 기울기가 2인 이유: 2개를 사고 있으므로 가격이 1원 오르면 총액은 2원 오른다. 곱셈 노드가 상대방 값(개수=2)을 곱하기 때문이다.

Affine 층 — 행렬 곱셈 노드

신경망의 Affine 층은 Y = XW + B를 계산하는 노드다. 곱셈 노드의 원리가 행렬로 확장된 것이다.

행렬 곱셈도 곱셈 노드와 같은 원리다. dW를 구할 때 X.T를 곱하는 것은 스칼라 곱셈에서 “상대방 값을 곱한다”가 행렬로 확장된 것이다.

텐서 shape 변환:

forward:  X(N, D_in) @ W(D_in, D_out) + B(D_out) = Y(N, D_out)

backward: dout(N, D_out) 이 주어지면

  dW = X.T @ dout
       (D_in, N) @ (N, D_out) -> (D_in, D_out)  <- W와 같은 shape

  db = sum(dout, axis=0)
       (N, D_out) -> (D_out,)                    <- B와 같은 shape

  dx = dout @ W.T
       (N, D_out) @ (D_out, D_in) -> (N, D_in)   <- X와 같은 shape

기울기의 shape이 원래 변수의 shape과 일치하는 것은 우연이 아니다. 기울기는 “이 변수를 살짝 바꿨을 때 손실이 얼마나 변하는지”이므로 변수와 같은 크기여야 한다.

신경망 전체를 계산 그래프로 보기

밑시딥1의 신경망은 OrderedDict에 노드를 순서대로 쌓는다. 순전파는 순서대로, 역전파는 역순으로 호출한다.

이 코드가 계산 그래프의 역전파 그 자체다. 각 layer가 노드이고, backward(dout)가 “상류 기울기에 국소 미분을 곱해서 하류로 넘기는” 동작이다.

정리

계산 그래프는 복잡한 합성 함수를 단순한 노드의 연결로 분해한다. 각 노드는 순전파에서 값을 계산하고, 역전파에서 국소 미분을 곱해 기울기를 전파한다. 덧셈 노드는 기울기를 복사하고, 곱셈 노드는 상대방 값을 곱한다. 이 두 가지 규칙이 신경망 전체 역전파의 기초다.
