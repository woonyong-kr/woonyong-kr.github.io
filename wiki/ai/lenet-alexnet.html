LeNet-5과 AlexNet — CNN 아키텍처의 시작과 딥러닝 혁명

LeNet-5과 AlexNet — CNN 아키텍처의 시작과 딥러닝 혁명

확인 범위: 이 문서는 LeNet-5과 AlexNet의 구조적 공통점과 차이, CNN 아키텍처의 일반적인 설계 요소와 비교 기준을 설명하며, 포함된 코드는 텐서 shape·파라미터 수·gradient를 예시 입력과 계산식으로 확인하는 수준이다. 특정 구현·라이브러리·버전의 재현 결과나 실제 학습 실행 기록·성능 측정을 제시하지 않으므로, 학습 속도와 모델 성능에 관한 판단은 별도의 구현 및 실험 검증이 필요하다.

한 줄 요약: LeNet-5(1998)는 합성곱-풀링-완전연결 구조를 실용화한 CNN이고, AlexNet(2012)은 이 구조를 깊고 넓게 확장해 ImageNet 대회에서 기존 방법을 크게 앞섰다.

두 모델을 함께 보는 이유

CNN은 합성곱, 풀링, 완전연결층 같은 부품으로 구성된다. 실제 모델을 설계하려면 이 부품을 몇 층 쌓을지, 필터 크기와 개수를 어떻게 정할지, 풀링을 어디에 넣을지 선택해야 한다. 이러한 선택의 조합이 아키텍처다.

LeNet-5는 Conv → Pool → Conv → Pool → FC 패턴으로 우편번호 손글씨 인식 문제를 다뤘다. 14년 뒤 등장한 AlexNet은 Conv와 Pool을 반복한 뒤 FC로 분류하는 흐름을 더 깊고 넓게 확장했다. 여기에 ReLU, Dropout, GPU 학습을 적용했으며, ImageNet 분류 대회에서 오류율을 10% 이상 낮췄다.

두 모델의 공통 구조와 차이를 따라가면 CNN 아키텍처의 기본 패턴을 파악할 수 있다. 또한 이후 VGGNet과 ResNet 같은 모델이 어떤 설계 요소를 바꾸었는지 비교하는 기준으로 삼을 수 있다.

LeNet-5에서 AlexNet으로

LeNet-5 (1998, Yann LeCun)

LeNet-5는 32×32 흑백 이미지를 10개 클래스로 분류하도록 설계되었다. 합성곱 2층과 풀링 2층을 차례로 통과한 뒤 완전연결 3층에서 분류한다.

%% LeNet-5 구조 흐름
flowchart TD
  input["입력<br/>(1, 32, 32)"]
  conv1["Conv1<br/>필터 6개"]
  pool1["AvgPool1<br/>2×2"]
  conv2["Conv2<br/>필터 16개"]
  pool2["AvgPool2<br/>2×2"]
  flatten["Flatten<br/>(400,)"]
  fc1["FC1<br/>400 → 120<br/>(120,)"]
  fc2["FC2<br/>120 → 84<br/>(84,)"]
  fc3["FC3<br/>84 → 10<br/>(10,)"]
  input --> conv1
  conv1 --> pool1
  pool1 --> conv2
  conv2 --> pool2
  pool2 --> flatten
  flatten --> fc1
  fc1 --> fc2
  fc2 --> fc3

이 구조에서는 다음과 같은 설계 요소를 확인할 수 있다.

  • 활성화 함수: Sigmoid/Tanh를 사용한다.
  • 풀링: 평균 풀링(Average Pooling)을 사용한다. 영역의 평균을 구한 뒤 학습 가능한 계수를 곱하고 편향을 더한다.
  • 파라미터 수: 약 60,000개다.
  • 입력 크기: 원래 입력은 32×32다. MNIST(28×28)를 사용할 때는 패딩으로 32×32에 맞추거나 필터 크기를 조정한다.

Conv와 Pool을 반복하면 무엇이 달라지는가?

Conv 층은 입력의 지역 특징을 추출하고, Pool 층은 공간 크기를 줄인다. 이 과정을 반복하면 상위 층의 뉴런 하나가 바라보는 입력 영역인 수용 영역이 점차 넓어진다. 이에 따라 앞쪽 층은 모서리나 선을, 뒤쪽 층은 숫자의 곡선이나 꼭짓점 같은 더 넓은 범위의 패턴을 다룬다.

AlexNet (2012, Alex Krizhevsky)

AlexNet은 ImageNet의 224×224 RGB 이미지를 1000개 클래스로 분류하도록 설계되었다. LeNet-5와 마찬가지로 Conv와 Pool로 특징을 추출한 뒤 FC에서 분류하지만, 합성곱 층을 5개로 늘리고 필터 수도 크게 확장했다. 학습 방식에는 세 가지 변화가 더해졌다.

  1. ReLU 활성화 함수: Sigmoid 대신 max(0, x)를 사용한다. 양수 영역에서는 gradient가 유지되므로 Sigmoid에서 나타나는 기울기 소실을 줄이고 학습 속도를 높인다.
  2. Dropout: 완전연결층에 Dropout(0.5)을 적용해 과적합을 억제한다.
  3. GPU 학습: 필터를 2개 GPU에 나누어 병렬로 학습한다.
%% AlexNet 구조 흐름
flowchart TD
  input["입력<br/>(3, 224, 224)"]
  conv1["Conv1<br/>필터 96개"]
  pool1["ReLU → MaxPool<br/>3×3"]
  conv2["Conv2<br/>필터 256개"]
  pool2["ReLU → MaxPool<br/>3×3"]
  conv3["Conv3<br/>필터 384개"]
  conv4["ReLU → Conv4<br/>필터 384개"]
  conv5["ReLU → Conv5<br/>필터 256개"]
  pool3["ReLU → MaxPool<br/>3×3"]
  flatten["Flatten<br/>(9216,)"]
  fc1["FC1<br/>9216 → 4096 + ReLU + Dropout(0.5)<br/>(4096,)"]
  fc2["FC2<br/>4096 → 4096 + ReLU + Dropout(0.5)<br/>(4096,)"]
  fc3["FC3<br/>4096 → 1000<br/>(1000,)"]
  input --> conv1
  conv1 --> pool1
  pool1 --> conv2
  conv2 --> pool2
  pool2 --> conv3
  conv3 --> conv4
  conv4 --> conv5
  conv5 --> pool3
  pool3 --> flatten
  flatten --> fc1
  fc1 --> fc2
  fc2 --> fc3

AlexNet의 구조에는 다음과 같은 특징이 있다.

  • 파라미터 수: 약 6,100만 개로, 약 60,000개인 LeNet-5보다 약 1,000배 많다.
  • Conv1의 큰 필터: 11×11 필터와 stride 4로 입력의 공간 크기를 빠르게 줄인다. 원 논문은 입력을 224×224로 표기하지만, (224-11)/4+1은 54.25이므로 그대로는 55×55가 나오지 않는다. 227×227 입력을 사용하거나 pad=2를 적용하면 55×55가 된다((224+2·2-11)/4+1 = 55). 이후 VGGNet은 작은 필터(3×3)를 여러 번 사용하는 방식을 택했다.
  • Conv3~5 연속 합성곱: 중간 풀링 없이 합성곱을 3층 연속으로 쌓는다. 공간 크기를 유지하면서 수용 영역을 넓힌다.
  • Local Response Normalization (LRN): 인접 채널 사이에 정규화를 적용한다. 이후에는 Batch Normalization이 주로 사용되면서 LRN은 잘 쓰이지 않게 되었다.

구조와 학습 방식 비교

두 모델은 Conv와 Pool을 반복한 뒤 FC를 거쳐 출력한다는 흐름을 공유한다. 구체적인 차이는 다음과 같다.

  • 입력 크기: LeNet-5 → 32×32×1 (흑백), AlexNet → 224×224×3 (RGB)
  • 합성곱 층 수: LeNet-5 → 2, AlexNet → 5
  • 활성화 함수: LeNet-5 → Sigmoid/Tanh, AlexNet → ReLU
  • 풀링: LeNet-5 → Average Pooling, AlexNet → Max Pooling
  • 정규화: LeNet-5 → 없음, AlexNet → Dropout(0.5)
  • 파라미터: LeNet-5 → ~60K, AlexNet → ~61M
  • 학습 하드웨어: LeNet-5 → CPU, AlexNet → GPU 2개 병렬

따라서 AlexNet의 변화는 단순히 층을 늘린 데 그치지 않는다. 더 큰 입력과 많은 필터를 처리하도록 구조를 확장하고, ReLU와 Dropout을 적용했으며, 계산량을 감당하기 위해 GPU 병렬 학습을 사용했다.

AlexNet의 파라미터 분포 계산

다음 계산은 AlexNet의 Conv 층과 FC 층에 각각 몇 개의 파라미터가 배치되는지 비교한다.

코드에 적힌 계산식에 따르면 전체 파라미터의 약 94%가 완전연결층(FC)에 배치된다. Conv 층은 가중치를 공유하므로 같은 규모의 완전연결층보다 파라미터가 적다. 이후 모델들은 FC 층을 Global Average Pooling으로 대체해 이 비중을 줄였다.

ReLU와 Sigmoid의 gradient 비교

다음 코드는 동일한 양수 입력에서 Sigmoid와 ReLU의 gradient가 어떻게 다른지 비교한다.

이 예제의 양수 입력 범위에서는 값이 커질수록 Sigmoid의 gradient가 0에 가까워지는 반면, ReLU의 gradient는 1로 유지된다. 이 차이는 깊은 네트워크에서 기울기 소실을 줄이는 데 ReLU가 유리한 이유를 보여준다. 다만 이 코드는 gradient 값만 비교하며 AlexNet의 실제 학습 속도나 성능을 직접 검증하지는 않는다.

두 모델에서 이어지는 설계 질문

LeNet-5는 Conv → Pool 반복 → FC → 출력이라는 흐름을 보여준다. AlexNet은 이 흐름을 합성곱 5층과 96~384개의 필터로 확장하고 ReLU, Dropout, GPU 학습을 적용했다. 그 결과 ImageNet에서 기존 방법을 크게 앞섰다.

AlexNet의 파라미터 계산에서는 약 94%가 FC 층에 집중된다. 이후 모델들은 이 비중을 줄이기 위해 Global Average Pooling을 사용했다. AlexNet의 Conv1은 11×11 필터를 사용하지만, VGGNet은 작은 3×3 필터를 여러 번 쌓는 방식을 선택했다. 따라서 후속 모델을 볼 때는 깊이뿐 아니라 필터 크기, FC 층의 비중, 정규화와 학습 방식이 어떻게 달라지는지를 함께 비교해야 한다.
