Teacher Forcing 학습

한 줄 요약: Teacher Forcing은 디코더 학습에서 모델이 예측한 토큰 대신 정답 이전 토큰을 다음 입력으로 넣어, 초기 오류가 뒤 예측까지 연쇄적으로 번지는 문제를 줄이는 방법이다.

Teacher Forcing은 디코더를 학습할 때 “모델이 방금 예측한 토큰” 대신 “정답 이전 토큰”을 다음 입력으로 넣는 방법이다. Seq2Seq처럼 출력도 시퀀스인 모델에서 학습을 안정화하기 위해 쓴다.

Teacher Forcing 학습 구분

Seq2Seq 인코더 디코더에서 디코더는 토큰을 하나씩 만든다.

추론할 때는 정답 문장이 없다. 그래서 모델이 예측한 y_1을 다음 입력으로 넣고, 다시 y_2를 예측한다. 이것이 자기회귀(autoregressive) 생성이다.

문제는 학습 초기에 모델이 자주 틀린다는 점이다. 첫 토큰을 틀리면 두 번째 입력도 틀린 토큰이 되고, 그 뒤 예측까지 연쇄적으로 흔들린다. 이러면 모델이 “정답 문장 흐름에서 다음 토큰을 맞히는 법”을 배우기 전에 엉뚱한 상태를 너무 많이 보게 된다.

Teacher Forcing은 이 문제를 줄이기 위해 학습 중에는 정답 토큰을 입력으로 넣는다.

Teacher Forcing 학습 흐름

Teacher Forcing에서 디코더의 입력과 target은 한 칸 어긋난다.

각 시점에서 모델은 다음 토큰을 맞힌다.

  • 시점 1
    • 입력: <SOS>
    • 정답: 나는
  • 시점 2
    • 입력: 나는
    • 정답: 고양이를
  • 시점 3
    • 입력: 고양이를
    • 정답: 좋아한다

이 말은 즉, 학습 중 디코더는 “이전 정답 토큰이 주어졌을 때 다음 정답 토큰을 맞히는 문제”를 푼다.

학습과 추론의 입력 차이

Seq2Seq 학습 흐름은 다음처럼 볼 수 있다.

학습과 추론의 입력 기준은 다르다.

  • 학습
    • 이전 시점의 정답 토큰을 입력으로 넣는다.
    • loss가 안정적으로 계산된다.
  • 추론
    • 이전 시점의 모델 예측을 입력으로 넣는다.
    • 한 번 틀린 예측이 다음 시점에 영향을 준다.

이 차이를 exposure bias라고 부르기도 한다. 학습 때는 정답 흐름만 보다가, 추론 때는 자기 예측이 만든 흐름을 만나기 때문이다.

Teacher Forcing 학습 코드

Seq2Seq 문서의 최소 예시는 Teacher Forcing 입력을 이렇게 표현한다.

여기서 중요한 줄은 prev_tok = tgt_tokens[t]다. 모델이 방금 예측한 pred_tok를 넣지 않고, 정답 시퀀스의 현재 토큰을 다음 입력으로 넣는다.

로컬 GPT 학습 코드에도 “입력과 target을 한 칸 밀어 다음 토큰을 맞힌다”는 같은 학습 신호가 보인다. SW_AI-W13-gpt/src/learning/common.py의 GPTDatasetV1은 token ID가 [10, 20, 30, 40]이면 다음처럼 자른다.

이 코드는 Seq2Seq Teacher Forcing 자체는 아니다. GPT는 별도 encoder-decoder가 아니라 decoder-only next-token prediction 모델이기 때문이다. 그래도 “현재 입력보다 한 칸 뒤의 정답 token ID를 target으로 둔다”는 학습 데이터 구성은 Teacher Forcing을 이해하는 데 좋은 비교 예시다.

로컬 LLM 책 코드의 실제 PyTorch 구현은 다음과 같다. torch.Tensor로 input/target chunk를 만들고, target은 input을 한 칸 오른쪽으로 민 결과다.

torch.tensor(..., dtype=torch.long)이 핵심이다. token ID는 임베딩 룩업의 인덱스이자 cross entropy의 정답 class 번호이므로 실수가 아니라 정수 tensor여야 한다. target을 i+1부터 자르는 한 줄이 “한 칸 밀어 다음 토큰을 정답으로 둔다”는 Teacher Forcing 신호를 만든다.

DataLoader가 이 샘플들을 묶으면 batch tensor의 shape는 다음처럼 흐른다.

  • token_ids (1D, 길이 N)
  • sliding window (max_length=L, stride=S)
  • input_ids : (배치당 L,)
  • target_ids : (배치당 L,) target = input을 한 칸 우측 이동
  • DataLoader batch_size=B
  • inputs : (B, L) 정수 token ID
  • targets : (B, L) 정수 token ID (한 칸 밀림)
  • nn.Embedding(vocab, d)
  • embeddings : (B, L, d) 실수 벡터, 모델 입력

정리

  • Teacher Forcing은 디코더 학습에서 모델의 직전 예측 대신 직전 정답 토큰을 다음 입력으로 넣는 방법이다.
  • 디코더 입력과 target은 한 칸 어긋난다. 각 시점은 “이전 정답이 주어졌을 때 다음 정답을 맞히는 문제”가 된다.
  • 학습은 정답 흐름만 보고 추론은 자기 예측 흐름을 보므로 둘의 분포가 어긋난다. 이를 exposure bias라 한다.
  • GPT의 GPTDatasetV1은 input을 한 칸 밀어 target을 만드는 같은 신호를 decoder-only 방식으로 보여준다.
