Weight Decay와 L2 정규화 — 가중치를 작게 유지하는 두 가지 방법

Weight Decay와 L2 정규화 — 가중치를 작게 유지하는 두 가지 방법

확인 범위: 이 문서는 L2 정규화와 Weight Decay의 일반 원리, SGD와 Adam에서의 차이, 선택 기준을 개념적으로 설명하고 예시 코드를 제시한다. 제시된 코드의 특정 라이브러리 버전별 동작, 실제 학습 실행 결과, 모델별 설정값의 적합성이나 성능 효과를 검증한 문서는 아니다.

한 줄 요약: L2 정규화는 손실 함수에 가중치 크기의 제곱합을 더해 큰 가중치에 벌점을 주고, Weight Decay는 매 업데이트마다 가중치를 일정 비율로 줄인다. SGD에서는 둘이 같지만, Adam에서는 다르다.

Weight Decay와 L2 정규화 구분

신경망이 학습 데이터를 외우면 가중치가 극단적으로 커진다. 가중치가 크면 입력의 작은 변화에도 출력이 크게 흔들린다. 학습 데이터에는 맞지만 새 데이터에는 틀리는 오버피팅이 발생한다.

이런 반응을 줄이려면 가중치가 지나치게 커지지 않도록 제한해야 한다. 가중치를 작게 유지한 모델은 데이터의 노이즈에 덜 반응하고 더 부드러운 함수를 표현한다. L2 정규화와 Weight Decay는 서로 다른 방식으로 가중치를 억제한다.

밑바닥 딥러닝1 Ch6에서는 weight decay를 정규화 기법의 하나로 소개한다. 실무에서는 PyTorch의 AdamW optimizer에서 weight_decay 파라미터 하나로 적용한다.

Weight Decay와 L2 정규화 차이

비유

가중치를 학생의 필기 습관에 비유한다. 오버피팅은 시험 범위를 글자 하나하나 통째로 암기하는 것이다. L2 정규화는 “노트를 너무 길게 쓰면 감점”이라는 규칙이다. 학생은 핵심만 짧게 정리하게 된다. 결과적으로 처음 보는 문제에도 대응할 수 있는 일반화된 지식이 남는다.

L2 정규화: 손실 함수에 벌점 추가

원래 손실 함수가 L_model이면, L2 정규화는 다음과 같이 변경한다.

L_total = L_model + (lambda / 2) * sum(w_i

  • lambda는 정규화 강도를 조절하는 하이퍼파라미터다. 보통 0.01 ~ 0.0001 범위다.
  • sum(w_i^2)는 모든 가중치의 제곱합이다. 편향(bias)은 보통 포함하지 않는다.
  • 1/2는 미분했을 때 깔끔하게 만들기 위한 상수다.

이 벌점의 기울기는 간단하다.

dL_total/dw = dL_model/dw + lambda * w

기존 기울기에 lambda * w가 추가된다. 가중치가 클수록 더 큰 기울기가 붙어서, 가중치를 0 방향으로 끌어당긴다.

Weight Decay: 업데이트 시 직접 축소

Weight Decay는 기울기 계산과 별개로, 매 업데이트마다 가중치를 일정 비율로 줄인다.

w_new = w - lr * dL_model/dw - lr * lambda * w = (1 - lr * lambda) * w - lr * dL_model/dw

(1 - lr * lambda)를 곱하므로, 가중치가 매 스텝마다 조금씩 줄어든다. 이것이 “decay(감쇠)“라는 이름의 이유다.

왜 SGD에서는 같고 Adam에서는 다른가?

SGD의 경우:

L2 정규화를 적용한 SGD 업데이트는 다음과 같다.

w_new = w - lr * (dL_model/dw + lambda * w) = (1 - lr * lambda) * w - lr * dL_model/dw

Weight Decay를 적용한 SGD 업데이트와 완전히 같은 식이다. SGD에서는 L2 정규화 = Weight Decay다.

Adam의 경우:

Adam은 기울기를 1차 모멘트(m)와 2차 모멘트(v)로 나눠서 적응적 학습률을 만든다.

L2 정규화를 Adam에 넣으면, lambda * w가 기울기에 합쳐진 뒤 모멘트에 들어간다. 정규화 신호가 Adam의 적응적 스케일링에 의해 왜곡된다. 자주 갱신되는 가중치일수록 2차 모멘트(v)가 커서 정규화 효과가 줄어든다.

Weight Decay(AdamW)는 기울기 계산과 완전히 분리한다. Adam으로 기울기 방향을 정한 뒤, 별도로 w = (1 - lr * lambda) * w를 적용한다. 정규화가 모멘트의 영향을 받지 않는다. 이것이 “decoupled weight decay”다.

  • Adam + L2 (비추천)
  • g = dL/dw + lambda*w ← 정규화가 기울기에 섞임
  • m = beta1*m + (1-beta1)*g
  • v = beta2*v + (1-beta2)*g
  • w = w - lr * m_hat / (sqrt(v_hat) + eps)
  • ↑ lambda*w가 m,v에 영향을 줌
  • AdamW (권장)
  • g = dL/dw ← 순수 기울기만
  • m = beta1*m + (1-beta1)*g
  • v = beta2*v + (1-beta2)*g
  • w = w - lr * m_hat / (sqrt(v_hat) + eps)
  • w = w - lr * lambda * w ← 별도로 감쇠

Weight Decay와 L2 정규화 코드

L2 정규화 손실 계산 (NumPy)

0.5를 곱하는 이유: d/dw (0.5 * w^2) = w로 미분이 깔끔하다. 0.5가 없으면 기울기가 2 * lambda * w가 된다.

SGD + Weight Decay (NumPy)

편향(bias)에는 weight decay를 적용하지 않는다. 편향은 출력의 기준점을 조절하는 역할이라, 크기를 제한할 이유가 없다.

AdamW (PyTorch)

optim.Adam에 weight_decay를 주면 L2 정규화(coupled)가 적용된다. optim.AdamW에 weight_decay를 주면 decoupled weight decay가 적용된다. GPT 학습에서는 반드시 AdamW를 쓴다.

숫자로 효과 확인하기

가중치가 클수록 decay 효과가 크다. w = 5.0이면 매 스텝 0.005가 줄고, w = 0.1이면 매 스텝 0.0001만 준다. 큰 가중치를 우선적으로 억제하는 셈이다.

실무 설정값

  • GPT-2: weight_decay = 0.01, AdamW
  • GPT-3: weight_decay = 0.1, AdamW
  • LLaMA: weight_decay = 0.1, AdamW
  • 밑바닥 딥러닝1 실습: weight_decay = 0.001 ~ 0.01, SGD

값이 너무 크면 가중치가 지나치게 작아져 언더피팅이 된다. 너무 작으면 정규화 효과가 없다. 검증 손실을 기준으로 조절한다.

정리

L2 정규화는 손실 함수에 가중치 제곱합 벌점을 더해 큰 가중치를 억제한다. Weight Decay는 업데이트 시 가중치를 직접 축소한다. SGD에서는 수학적으로 같지만, Adam에서는 다르다. Adam의 적응적 스케일링이 L2 벌점을 왜곡하므로, AdamW의 decoupled weight decay를 써야 한다. GPT를 포함한 현대 LLM 학습에서 AdamW + weight_decay는 사실상 필수 설정이다.
