오차역전파법

오차역전파법

한 줄 요약: 역전파는 연쇄 법칙을 이용해 출력에서 입력 방향으로 기울기를 전파하여, 순전파 1회와 역전파 1회만으로 모든 파라미터의 gradient를 구한다.

왜 필요한가

신경망의 목표는 손실 함수 L을 최소화하는 가중치 W를 찾는 것이다. 이를 위해 각 가중치가 손실에 얼마나 영향을 미치는지, 즉 ∂W∂L​를 알아야 한다.

가장 단순한 방법은 수치 미분이다. 가중치 하나를 h만큼 바꿔 손실 변화를 관찰한다.

∂w∂L​≈2hL(w+h)−L(w−h)​

그러나 파라미터 하나마다 순전파가 2회 필요하다. 예제 네트워크의 파라미터 수가 약 53만 개(784×512+512+512×256+256+256×10+10)라면 gradient 한 번을 수치 미분으로 계산하는 데 순전파가 100만 회 이상 필요하다.

역전파는 순전파 1회와 역전파 1회로 모든 파라미터의 gradient를 함께 구한다. 실제 학습에는 역전파를 사용하고, 수치 미분은 구현을 검증하는 gradient checking에 사용한다.

비교수치 미분역전파
계산 비용파라미터 N개당 순전파 2회, 총 2N회순전파 1회 + 역전파 1회
정확도O(h2) 근사 오차해석적 미분과 부동소수점 오차
구현단순층마다 backward() 구현 필요
실용 용도gradient checking실제 학습

53만 파라미터 기준으로 수치 미분은 약 106만 회의 순전파가 필요하므로, 이 비교에서는 역전파가 약 50만 배 적은 순전파 횟수로 gradient를 계산한다.

핵심 원리와 실제 흐름

연쇄 법칙과 계산 그래프

합성 함수 L=f(g(x))에서는 연쇄 법칙에 따라 다음이 성립한다.

∂x∂L​=∂g∂L​⋅∂x∂g​

신경망은 층이 쌓인 합성 함수다. 계산 그래프에서 각 노드는 연산, 간선은 데이터 흐름을 뜻한다. 순전파는 입력에서 출력으로 값을 계산하고, 역전파는 출력에서 입력으로 상류 gradient에 국소 미분을 곱해 전파한다.

연쇄법칙은 무엇을 곱해야 하는지를 정하는 수학 규칙이고, 역전파는 뒤에서 계산한 누적 gradient를 앞 층이 재사용하도록 계산 순서를 조직한 알고리즘이다. 이 재사용 때문에 파라미터마다 같은 미분 경로를 처음부터 다시 계산하지 않는다.

각 층은 다음 두 일을 한다.

  1. forward(): 입력에서 출력을 계산하고 backward()에 필요한 값을 저장한다.
  2. backward(): 상류 gradient를 받아 국소 미분을 적용한 하류 gradient를 반환하며, 필요한 파라미터 gradient를 저장한다.

기본 연산

덧셈 z=x+y에서는 ∂x∂z​=1, ∂y∂z​=1이므로 상류 gradient를 두 입력에 그대로 전달한다.

곱셈 z=x⋅y에서는 ∂x∂z​=y, ∂y∂z​=x이므로 상대방의 forward 값을 곱한다. 따라서 backward에서 사용할 상대방 값을 forward 때 저장해야 한다.

Affine, ReLU, Softmax + Cross-Entropy

Affine 층은 Y=XW+B를 계산한다. 배치 차원을 포함하면 다음과 같다.

∂X∂L​=∂Y∂L​WT,∂W∂L​=XT∂Y∂L​,∂B∂L​=batch∑​∂Y∂L​
  • X: (batch_size, input_dim) 입력 행렬
  • W: (input_dim, output_dim) 가중치 행렬
  • B: (output_dim,) 편향 벡터
  • ∂Y∂L​: (batch_size, output_dim) 상류 gradient

XT 또는 WT를 곱하는 것은 곱셈 노드에서 상대방 값을 곱하는 원리가 행렬 곱으로 확장된 것이다. 편향은 배치의 모든 샘플이 공유하므로 batch 방향으로 합산한다.

ReLU는 다음과 같이 미분한다.

ReLU(x)=max(0,x),∂x∂ReLU​={10​(x>0)(x≤0)​

forward에서 x≤0이었던 위치를 mask로 저장하고, backward에서 해당 위치의 gradient를 0으로 만든다.

Softmax와 Cross-Entropy Loss를 결합한 출력층의 logit ak​에 대한 gradient는 다음과 같다.

∂ak​∂L​=yk​−tk​

여기서 yk​는 softmax 예측 확률이고 tk​는 정답 원-핫 레이블이다. 배치 평균 손실을 사용하면 이 값을 batch_size로 나눈다. 자세한 유도는 소프트맥스 및 Cross Entropy Loss를 참고한다.

flowchart LR
  x["x (N, 784)"] --> a1["Affine1: W1"] --> r1["ReLU"] --> a2["Affine2: W2"] --> r2["ReLU"] --> a3["Affine3: W3"] --> sm["Softmax"] --> ce["Cross-Entropy"] --> loss["L (scalar)"]
  dout["(y - t) / batch"] --> b3["Affine3: dW3, db3"] --> br2["ReLU"] --> b2["Affine2: dW2, db2"] --> br1["ReLU"] --> b1["Affine1: dW1, db1"] --> dx["dx (N, 784)"]

레이어 단위 구현

예제 구현에서는 각 층이 forward()와 backward()를 제공하고, NeuralNetwork가 이를 순서대로 호출한다.

original_x_shape을 저장하는 이유는 CNN처럼 다차원 입력이 들어와도 backward 결과를 원래 shape으로 복원하기 위해서다.

cross_entropy_gradient()는 배치 평균 손실에 맞춰 (y-t)/batch_size를 반환하는 역전파 출발점이다. 이 결합 gradient를 사용한다면 Softmax 층의 backward()는 gradient를 그대로 반환할 수 있다.

reversed(self.layers.values())는 순전파와 반대 순서로 층을 순회한다. 각 Affine 층이 저장한 dW, db는 model.grads에 수집되고, 학습 루프에서 optimizer가 사용한다.

flowchart TD
  forward["1. 순전파: x → layers → y_pred"] --> loss["2. 손실: L = CrossEntropy(y_pred, y_true)"]
  loss --> start["3. 출발점: dout = (y_pred - y_true) / batch"]
  start --> backward["4. 역전파: reversed(layers), 각 층이 dW·db 저장"]
  backward --> update["5. 갱신: optimizer.update(params, grads)"]
