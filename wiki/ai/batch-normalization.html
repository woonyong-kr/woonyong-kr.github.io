Batch Normalization

Batch Normalization

한 줄 요약: Batch Normalization은 각 층의 입력을 미니배치 단위로 평균 0, 분산 1로 정규화한 뒤, 학습 가능한 파라미터로 다시 스케일·이동하여 학습을 안정화한다.

학습 중 입력 분포가 달라지는 문제

가중치 초기화(가중치 초기화 — 신경망 학습의 출발점을 결정하는 방법)는 학습 시작 시점의 분산을 맞출 수 있다. 그러나 학습이 진행되어 앞 층의 가중치가 바뀌면 뒷 층이 받는 입력 분포도 계속 달라진다. 이 문서에서는 이러한 현상을 “내부 공변량 이동(Internal Covariate Shift)“이라 부른다.

입력 분포가 달라지면 뒷 층은 매 스텝마다 새로운 분포에 적응해야 한다. 이 과정에서 학습이 느려질 수 있다. 입력이 Sigmoid/Tanh의 포화 영역으로 밀리면 기울기 소실이 발생할 수 있고, 큰 학습률(learning rate)에서는 발산하기 쉬워질 수 있다.

Batch Normalization(2015, Ioffe & Szegedy)은 각 층의 입력을 정규화해 이 문제를 다루는 방법이다. 이 문서가 제시한 설명과 구현의 범위에서는 학습을 안정화하고 초기화에 대한 민감도를 낮추며, 더 높은 학습률을 사용할 여지를 준다. 다만 이 문서에는 효과를 비교한 실험이나 외부 근거가 포함되어 있지 않으므로, 이러한 효과를 모든 모델과 학습 조건에서 검증된 결과로 해석해서는 안 된다.

미니배치 통계를 이용한 정규화

동작 순서

Batch Normalization은 다음 네 단계로 입력을 변환한다.

1단계에서는 미니배치 평균을 계산한다.

mu = (1/m) * sum(x_i) (m은 배치 크기)

2단계에서는 미니배치 분산을 계산한다.

var = (1/m) * sum((x_i - mu)

3단계에서는 평균을 빼고 표준편차로 나누어 정규화한다.

x_norm = (x - mu) / sqrt(var + eps) eps는 0으로 나누는 것을 방지하는 작은 값 (보통 1e-7)

4단계에서는 학습 가능한 파라미터로 결과의 크기와 위치를 조정한다.

y = gamma * x_norm + beta gamma(스케일)와 beta(시프트)는 학습 가능한 파라미터이다.

gamma와 beta가 필요한 이유

정규화만 적용하면 출력은 평균 0, 분산 1로 제한된다. 이 문서의 설명에 따르면 Sigmoid의 중심 부근은 거의 선형이므로, 정규화된 값이 그 부근에 모이면 활성화 함수의 비선형성을 충분히 활용하지 못할 수 있다.

gamma와 beta는 네트워크가 정규화된 분포의 크기와 위치를 다시 조정할 수 있게 한다. gamma = sqrt(var), beta = mu로 두면 해당 배치 통계를 기준으로 정규화 전 값을 복원할 수 있다. 따라서 이 변환에는 정규화된 값을 그대로 사용하거나 원래 값에 대응하는 형태로 되돌릴 수 있는 표현상의 여지가 있다. 이것만으로 실제 학습 성능이 정규화 전보다 나쁘지 않다고 보장되지는 않는다.

학습과 추론에서 사용하는 통계

학습(train=True)에서는 현재 미니배치의 평균과 분산을 사용한다. 추론(train=False)에서는 학습 중 누적한 이동평균(running_mean, running_var)을 사용한다. 추론할 때는 배치에 샘플이 하나만 있을 수도 있어 현재 배치 통계만으로 입력 분포를 나타내기 어렵기 때문이다.

이동평균은 다음과 같이 갱신한다.

running_mean = momentum * running_mean + (1 - momentum) * mu running_var = momentum * running_var + (1 - momentum) * var

momentum이 0.9이면 과거 통계에 90%, 현재 배치 통계에 10%의 비중을 둔다.

코드에서 동작 확인하기

순전파

x가 (32, 512) 형태(배치 32, 특성 512)라면, mu와 var는 각각 (512,) 형태이다. 즉, 각 feature 차원의 평균과 분산을 독립적으로 계산해 정규화한다.

역전파

역전파에서는 연쇄법칙에 따라 gamma, beta, 입력 x에 대한 기울기를 계산한다. 이 가운데 dgamma와 dbeta는 옵티마이저가 gamma와 beta를 갱신할 때 사용한다.

네트워크에서의 위치

이 네트워크에서는 BatchNorm을 Affine(선형 변환) 뒤와 ReLU(활성화 함수) 앞에 배치한다. 이어서 Dropout을 적용한다.

%% BatchNorm 네트워크 배치 흐름
flowchart TD
  input["입력 x<br/>shape: (batch, feature)"]
  affine["Affine<br/>선형 변환<br/>y = xW + b<br/>shape: (batch, feature)"]
  batch_norm["BatchNorm<br/>분포 안정화<br/>gamma * x_norm + beta<br/>shape: (batch, feature)"]
  relu["ReLU<br/>비선형 활성화<br/>max(0, x)"]
  dropout["Dropout<br/>뉴런 무작위 제거<br/>정규화<br/>shape: (batch, feature)"]
  input --> affine
  affine --> batch_norm
  batch_norm --> relu
  relu --> dropout

숫자로 확인

이 코드는 생성한 미니배치의 각 feature 차원을 해당 배치의 평균과 분산으로 정규화한다. 주석에 적힌 출력값은 코드가 의도하는 결과를 보여 주지만, 이 문서에는 실제 실행 기록이 없으므로 검증된 실행 결과로 단정하지 않는다. 또한 평균 0과 분산 1이라는 설명은 이 계산에 사용한 미니배치 통계를 기준으로 한다.

학습과 설명에 연결하기

Batch Normalization을 읽을 때는 학습 단계와 추론 단계를 구분해야 한다. 학습 단계에서는 현재 미니배치의 평균과 분산으로 입력을 정규화하고 gamma와 beta로 다시 조정한다. 추론 단계에서는 현재 배치가 아니라 학습 중 누적한 이동평균을 사용한다.

이 문서의 MNIST 코드에서는 layers.py의 BatchNorm 클래스가 순전파와 역전파를 구현한다. 네트워크는 Affine → BatchNorm → ReLU → Dropout 순서로 층을 구성한다. 학습 안정화, 빠른 수렴, 높은 학습률 사용과 같은 효과는 이 구조를 도입하는 이유로 제시되어 있지만, 문서 안의 비교 실험으로 확인된 결과는 아니다.
