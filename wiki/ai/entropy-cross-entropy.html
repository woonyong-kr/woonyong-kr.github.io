엔트로피 교차 엔트로피 (Entropy Cross Entropy)

엔트로피 교차 엔트로피 (Entropy Cross Entropy)

분류 모델의 확률을 비용으로 바꾸기

분류 모델과 언어 모델은 마지막에 “각 클래스나 다음 토큰이 얼마나 그럴듯한가”를 확률 분포로 낸다. 이 분포를 학습하려면 모델이 정답에 준 확률을 하나의 비용으로 바꿔야 한다. 정답에 높은 확률을 줬다면 비용이 작아야 하고, 낮은 확률을 줬다면 비용이 커야 한다.

엔트로피와 교차 엔트로피를 구분하면 이때 모델이 줄이는 값이 무엇인지 알 수 있다.

  • 엔트로피 H(P)
    • 실제 데이터 분포 P 자체가 가진 평균 불확실성
    • 모델이 바꿀 수 없는 기준값
  • 교차 엔트로피 H(P, Q)
    • 실제 분포 P를 모델 분포 Q로 설명할 때의 평균 비용
    • 학습에서 줄이려는 손실값
  • KL 발산 D_KL(P || Q)
    • 모델 분포 Q가 실제 분포 P에서 벗어나 생기는 추가 비용

세 값의 관계는 다음과 같다.

데이터 분포가 정해져 있으면 H(P)는 상수다. 이 조건에서 교차 엔트로피를 줄이는 일은 모델 분포 Q가 실제 분포 P에서 벗어나 생기는 추가 비용, 즉 KL 발산을 줄이는 일과 같다.

두 클래스 분포에서 비용 비교하기

자연로그를 사용하는 두 클래스 문제에서 실제 분포와 모델 분포를 다음과 같이 놓을 수 있다.

0.500은 실제 분포 자체의 불확실성이다. 데이터가 원래 가진 흔들림이므로 모델이 직접 없앨 수 있는 값은 아니다. 반면 0.092는 모델 분포가 실제 분포와 달라서 추가로 생긴 비용이다. 학습 과정에서 Q가 P에 가까워지면 이 추가 비용도 작아진다.

정답 분포가 one-hot이면 교차 엔트로피는 정답 클래스에 모델이 부여한 확률만으로 계산할 수 있다.

모델이 정답에 높은 확률을 줄수록 손실은 작아진다. 정답에 낮은 확률을 주면 손실은 빠르게 커진다. 같은 손실을 “평균 몇 개 후보 중에서 고르는가”라는 감각으로 바꾼 값이 perplexity다.

학습할 때 구분할 값

엔트로피 H(P)는 데이터 분포 자체의 평균 불확실성이다. 데이터 분포가 고정되어 있다면 모델이 줄일 수 없는 상수로 취급한다.

교차 엔트로피는 H(P,Q) = H(P) + D_KL(P||Q)로 나뉜다. 따라서 이 조건에서 학습으로 줄어드는 부분은 모델 분포와 실제 분포의 차이에서 생기는 KL 발산이다. one-hot 정답에서는 교차 엔트로피가 -log Q(정답) 한 항으로 단순해진다.

계산을 다시 확인하려면 P=[0.8,0.2], Q=[0.6,0.4]를 넣어 H(P)=0.500, H(P,Q)=0.592를 구한 뒤, 그 차이 0.092가 D_KL(P||Q)와 일치하는지 비교한다.
