단일 퍼셉트론 — 입력을 받아 0 또는 1을 출력하는 가장 작은 판별기

한 줄 요약: 퍼셉트론은 여러 입력의 가중합에 편향을 더한 뒤 계단 함수를 통과시켜 0 또는 1을 출력하는 가장 단순한 인공 뉴런이다.

단일 퍼셉트론 문제

신경망을 이해하려면 가장 작은 단위부터 시작해야 한다. 퍼셉트론은 “입력에 가중치를 곱하고, 편향을 더하고, 임계값을 넘으면 활성화한다”는 신경망의 기본 동작을 가장 단순한 형태로 보여준다.

퍼셉트론 하나로 AND, OR, NAND 게이트를 만들 수 있다. 하지만 XOR은 만들 수 없다. 이 한계가 왜 생기는지 이해하면, 다층 퍼셉트론(MLP)이 왜 필요한지 자연스럽게 따라온다.

단일 퍼셉트론 구조

퍼셉트론의 구조

퍼셉트론은 1957년 프랭크 로젠블랫이 제안한 가장 단순한 인공 뉴런이다. 동작은 세 단계로 나뉜다.

  1. 각 입력에 가중치를 곱한다.
  2. 곱한 값을 모두 더하고 편향을 더한다 (가중합).
  3. 가중합이 0보다 크면 1을 출력하고, 아니면 0을 출력한다 (계단 함수).

수식으로 쓰면 다음과 같다.

z = w1*x1 + w2*x2 + b
y = step(z) = 1 (z > 0), 0 (z <= 0)
  • x1, x2: 입력 신호
  • w1, w2: 각 입력의 가중치 (weight). 입력이 결과에 미치는 영향력을 조절한다.
  • b: 편향 (bias). 뉴런이 얼마나 쉽게 활성화되는지를 조절한다.
  • y: 출력 신호 (0 또는 1)
flowchart LR
  x1["입력 x1"] --> weighted["가중합<br/>z = w1·x1 + w2·x2 + b"]
  x2["입력 x2"] --> weighted
  bias["편향 b"] --> weighted
  weighted --> step["계단 함수<br/>z &gt; 0이면 1, 아니면 0"]
  step --> y["출력 y"]

이 구조가 신경망 전체의 기본 단위다. 나중에 Affine 층이 하는 y = xW + b도 가중합이고, 그 뒤에 붙는 ReLU나 Sigmoid도 계단 함수의 확장이다.

결정 경계 — 직선 하나로 나누기

2차원 입력 공간 (x1, x2)에서 w1*x1 + w2*x2 + b = 0은 직선 하나를 정의한다. 이 직선이 공간을 둘로 나눈다. 직선 위쪽은 출력 1, 아래쪽은 출력 0이다.

AND 게이트(w1=0.5, w2=0.5, b=-0.7)의 결정 경계는 0.5*x1 + 0.5*x2 = 0.7이다. (1,1)만 이 직선 위에 있으므로 AND 동작이 된다.

OR 게이트(w1=0.5, w2=0.5, b=-0.2)의 결정 경계는 0.5*x1 + 0.5*x2 = 0.2이다. (0,0)만 이 직선 아래에 있으므로 OR 동작이 된다.

왜 XOR이 안 되는가?

XOR은 (0,1)→1, (1,0)→1, (0,0)→0, (1,1)→0이다. (0,0)과 (1,1)을 한쪽에, (0,1)과 (1,0)을 반대쪽에 놓아야 한다. 직선 하나로는 이 배치가 불가능하다. 어떤 w1, w2, b를 골라도 네 점을 두 그룹으로 나누는 직선이 존재하지 않는다.

이것이 “선형 분리 불가능(linearly inseparable)” 문제다. 퍼셉트론 하나의 근본적 한계이며, 이 한계를 넘으려면 층을 쌓아야 한다. XOR = NAND(x1, x2) AND OR(x1, x2)이므로, 퍼셉트론 두 층이면 해결된다. 이것이 다층 퍼셉트론(MLP)의 출발점이다.

단일 퍼셉트론 코드

AND, NAND, OR 게이트 구현

세 함수의 구조는 동일하다. np.sum(w * x) + b로 가중합을 구하고 z > 0으로 계단 함수를 적용한다. 가중치와 편향만 바꾸면 서로 다른 논리 게이트가 된다.

구체적 계산 — AND 게이트 (w1=0.5, w2=0.5)

(x1, x2) = (0, 0):  z = 0.5*0 + 0.5*0 + (-0.7) = -0.7  → 0
(x1, x2) = (1, 0):  z = 0.5*1 + 0.5*0 + (-0.7) = -0.2  → 0
(x1, x2) = (0, 1):  z = 0.5*0 + 0.5*1 + (-0.7) = -0.2  → 0
(x1, x2) = (1, 1):  z = 0.5*1 + 0.5*1 + (-0.7) =  0.3  → 1

(1,1)만 z가 양수이므로 AND 동작이다. 편향 -0.7이 “두 입력이 모두 켜져야 넘는 문턱”을 만든다.

OR은 편향을 -0.2로 낮춰 입력 하나만 1이어도 활성화한다.

x1x2z = 0.5*x1 + 0.5*x2 - 0.2OR 출력

100.31

110.81

NAND는 -0.5*x1 - 0.5*x2 + 0.7 = 0을 결정 경계로 사용한다. AND의 가중치와 편향 부호를 모두 뒤집어 (1,1)에서만 0을 출력한다.

PyTorch로 같은 판별기 표현

nn.Linear가 가중치와 편향을 parameter로 관리한다. 계단 함수는 거의 모든 점에서 gradient가 0이므로 이 코드는 수동 설정한 AND 추론 예제이며, gradient 기반 학습에는 Sigmoid나 ReLU 같은 미분 가능한 활성화 함수를 사용한다.

퍼셉트론에서 Affine 층으로의 연결

밑바닥부터 배우는 딥러닝1 프로젝트에서 퍼셉트론의 가중합은 Affine 층으로 확장된다.

퍼셉트론의 np.sum(w * x) + b는 입력 2개, 출력 1개짜리 가중합이다. Affine은 이것을 입력 784개(MNIST 픽셀), 출력 N개(은닉 뉴런 수)로 확장한 것이다. 행렬 곱 x @ W는 모든 입력-출력 쌍의 가중합을 한 번에 계산한다.

퍼셉트론의 계단 함수는 프로젝트에서 ReLU로 대체된다.

계단 함수가 0 또는 1만 출력하는 반면, ReLU는 양수 입력을 그대로 통과시킨다. 이 차이가 왜 중요한지는 활성화 함수 문서에서 다룬다.

텐서 shape 변환 — 퍼셉트론에서 신경망으로

퍼셉트론 (입력 2개, 출력 1개):
(x1, x2)  →  w1*x1 + w2*x2 + b  →  step()  →  y
  (2,)              스칼라              스칼라

Affine 층 (입력 784개, 출력 512개):
(batch, 784)  →  x @ W + b  →  ReLU()  →  (batch, 512)
                  (784, 512)

퍼셉트론의 가중합 하나가 행렬 곱으로 확장되고, 계단 함수가 ReLU로 바뀐 것이 신경망의 한 층이다.

정리

퍼셉트론은 가중합 + 편향 + 계단 함수로 이루어진 가장 단순한 판별기다. 가중치와 편향을 조절하면 AND, OR, NAND 게이트를 만들 수 있지만, 직선 하나로 나눌 수 없는 XOR 문제는 풀 수 없다. 이 선형 분리 한계를 넘으려면 퍼셉트론을 여러 층 쌓아야 한다. 퍼셉트론의 가중합은 신경망의 Affine 층, 계단 함수는 ReLU 같은 활성화 함수로 자연스럽게 확장된다.
