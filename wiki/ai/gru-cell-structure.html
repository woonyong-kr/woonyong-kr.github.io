GRU 셀 구조

GRU 셀 구조

한 줄 요약: GRU cell은 reset gate와 update gate 두 개로 이전 은닉 상태를 얼마나 보존하고 새 후보 상태를 얼마나 반영할지 정하는 RNN 구조다.

GRU 셀 구조 필요성

GRU 게이팅에서 gate가 왜 필요한지 봤다. 이 문서는 GRU cell 내부에서 실제로 어떤 값이 계산되는지 펼친다.

LSTM은 장기 기억을 위해 c_t라는 별도 cell state를 둔다. 효과적이지만 forget gate, input gate, output gate, candidate까지 네 계산이 필요하다.

GRU(Gated Recurrent Unit)는 이 구조를 줄인다. 별도의 c_t 없이 은닉 상태 h_t 하나만 유지하면서도, gate를 써서 “이전 정보를 유지할지, 새 정보로 갱신할지”를 조절한다. 그래서 LSTM보다 파라미터가 적고 계산이 단순하다.

GRU 셀 구조 흐름

GRU cell 하나의 입력과 출력은 다음과 같다.

LSTM과 비교하면 c_{t-1}와 c_t가 없다. 장기 기억과 출력 기억을 h_t 하나에 함께 담는다.

%% GRU 셀 계산 흐름
flowchart TD
  x_t["x_t<br/>현재 입력"]
  h_prev["h_{t-1}<br/>이전 은닉 상태"]
  concat_gate["[x_t, h_{t-1}]<br/>gate 입력"]
  update_gate["update gate<br/>z_t = sigmoid(W_z · [x_t, h_{t-1}] + b_z)"]
  reset_gate["reset gate<br/>r_t = sigmoid(W_r · [x_t, h_{t-1}] + b_r)"]
  reset_hidden["r_t * h_{t-1}<br/>과거 기억 조절"]
  concat_candidate["[x_t, r_t * h_{t-1}]<br/>candidate 입력"]
  candidate["candidate<br/>h~_t = tanh(W_h · [x_t, r_t * h_{t-1}] + b_h)"]
  mix["old/new mix<br/>h_t = (1 - z_t) * h_{t-1} + z_t * h~_t"]
  h_t["h_t<br/>새 은닉 상태"]
  x_t --> concat_gate
  h_prev --> concat_gate
  concat_gate --> update_gate
  concat_gate --> reset_gate
  reset_gate --> reset_hidden
  h_prev --> reset_hidden
  x_t --> concat_candidate
  reset_hidden --> concat_candidate
  concat_candidate --> candidate
  update_gate --> mix
  h_prev --> mix
  candidate --> mix
  mix --> h_t

이 문서에서는 z_t가 1에 가까울수록 새 후보 상태를 더 많이 반영하는 표기를 쓴다. 책이나 프레임워크에 따라 z_t의 의미를 반대로 쓰는 경우도 있으니, 수식을 볼 때는 “1이면 유지인가, 갱신인가”를 먼저 확인해야 한다.

실제 흐름

GRU의 한 step은 세 계산으로 끝난다.

1. Update gate

z_t는 이전 은닉 상태와 새 후보 상태를 어떤 비율로 섞을지 정한다.

  • z_t가 0에 가까움
    • h_{t-1}를 많이 유지한다.
  • z_t가 1에 가까움
    • 새 후보 상태 h~_t를 많이 반영한다.

2. Reset gate

r_t는 후보 상태를 만들 때 과거 은닉 상태를 얼마나 참고할지 정한다.

  • r_t가 0에 가까움
    • 과거 은닉 상태를 거의 무시하고 현재 입력 중심으로 후보를 만든다.
  • r_t가 1에 가까움
    • 과거 은닉 상태를 충분히 반영해 후보를 만든다.

3. Candidate와 최종 은닉 상태

후보 상태는 reset gate를 거친 과거 기억을 사용한다.

최종 은닉 상태는 이전 상태와 후보 상태를 update gate로 섞는다.

이 식이 GRU의 핵심이다. Vanilla RNN처럼 매번 h_t = tanh(...)로 완전히 덮어쓰지 않는다. 이전 상태를 남겨 둘 수 있기 때문에 긴 sequence에서 정보가 조금 더 오래 살아남는다.

LSTM과 비교하기

구분LSTMGRU
상태h_t, c_t 두 개h_t 하나
주요 gateforget, input, outputupdate, reset
기억 유지 방식cell state c_t를 별도 통로로 유지은닉 상태 h_t 안에서 유지와 갱신을 섞음
파라미터 수상대적으로 많음상대적으로 적음
읽는 감각오래 가져갈 기억과 밖으로 낼 출력을 분리단순한 구조로 이전 기억과 새 후보를 섞음

둘 중 하나가 항상 우월한 것은 아니다. LSTM은 명시적인 장기 기억 통로가 있고, GRU는 구조가 단순하다. 작은 데이터나 빠른 실험에서는 GRU가 편할 수 있고, 복잡한 장기 의존성에서는 LSTM이 더 안정적인 경우가 있다.

정리

  • GRU는 별도 cell state c_t 없이 은닉 상태 h_t 하나만 유지한다.
  • update gate z_t는 이전 상태와 새 후보를 섞는 비율을, reset gate r_t는 후보를 만들 때 과거를 얼마나 참고할지를 정한다.
  • h_t = (1 - z_t) * h_{t-1} + z_t * h~_t는 완전히 덮어쓰지 않고 이전 기억을 남길 수 있어, 긴 sequence에서 정보가 더 오래 살아남는다.
  • gate 묶음이 LSTM 4개에서 3개로 줄어 같은 차원이면 파라미터가 더 적다.
