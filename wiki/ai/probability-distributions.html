확률 분포

확률 분포

한 줄 요약: 확률 분포는 확률 변수가 어떤 값을 얼마나 자주 취하는지를 정의하며, 신경망에서 Softmax 출력은 카테고리컬 분포, 가중치 초기화는 가우시안 분포, 이진 분류는 베르누이 분포를 사용한다.

확률 분포 혼동

신경망 코드를 열면 확률 분포가 명시적으로 이름 붙지 않은 채 곳곳에 숨어 있다.

  • np.random.randn()으로 가중치를 초기화한다. 이것이 가우시안(정규) 분포다.
  • Softmax 출력은 “각 클래스에 속할 확률”이다. 이것이 카테고리컬 분포다.
  • Sigmoid 출력은 “양성일 확률”이다. 이것이 베르누이 분포다.
  • Cross-entropy 손실은 “정답 분포와 예측 분포의 차이”를 잰다. 분포를 모르면 이 말이 공허하다.

확률 분포를 이해하면 “왜 이 출력 함수를 쓰는가”, “왜 이 손실 함수를 쓰는가”, “왜 이 초기화를 쓰는가”에 대한 답이 연결된다.

확률 분포 흐름

확률 분포란

확률 분포는 확률 변수가 취할 수 있는 모든 값에 확률을 배정하는 규칙이다.

  • 이산 확률 분포: 확률 변수가 유한하거나 셀 수 있는 값을 가진다. 각 값에 확률이 배정된다. 모든 확률의 합은 1이다.
  • 연속 확률 분포: 확률 변수가 실수 구간의 값을 가진다. 확률 밀도 함수(PDF)로 정의하며, 구간의 넓이(적분)가 확률이다.

베르누이 분포 (Bernoulli)

결과가 두 가지뿐인 시행이다. 동전 던지기, 이메일이 스팸인지 아닌지, 환자가 양성인지 음성인지.

파라미터 p 하나로 정의한다:

P(X=1) = p, P(X=0) = 1 - p

기댓값: E[X] = p 분산: Var(X) = p(1-p)

신경망에서 Sigmoid 활성화 함수의 출력이 곧 베르누이 분포의 파라미터 p다. 이진 분류의 출력층에서 사용한다.

카테고리컬 분포 (Categorical)

결과가 K개 중 하나인 시행이다. 주사위 던지기, MNIST에서 0~9 중 하나 고르기.

파라미터는 확률 벡터 (p_1, p_2, …, p_K)이며, 합이 1이다:

P(X=k) = p_k, sum(p_k) = 1

K=2이면 베르누이 분포와 같다.

신경망에서 Softmax의 출력이 곧 카테고리컬 분포의 파라미터 벡터다. MNIST 분류기가 [0.01, 0.02, 0.05, 0.80, 0.03, ...]을 출력하면, 이것은 “숫자 3일 확률 80%“라는 카테고리컬 분포를 표현한다.

가우시안 분포 (Gaussian / Normal)

연속 확률 분포의 대표다. 평균 mu와 분산 sigma^2 두 파라미터로 정의한다.

확률 밀도: f(x) = (1 / sqrt(2 * pi * sigma^2)) * exp(-(x - mu)^2 / (2 * sigma

평균 0, 분산 1인 특수한 경우를 표준 정규 분포(Standard Normal)라 한다. np.random.randn()이 여기서 값을 뽑는다.

가우시안이 중요한 이유:

  • 중심극한정리: 어떤 분포든 많이 더하면 가우시안에 가까워진다. 많은 작은 요인이 합쳐진 결과는 가우시안으로 모델링할 수 있다.
  • 가중치 초기화: 가중치를 가우시안에서 뽑되, 분산을 조절해 출력 분포를 안정화한다.
  • Batch Normalization: 각 feature를 평균 0, 분산 1로 정규화하면, 입력이 대략 표준 정규 분포에 가까워진다.

균등 분포 (Uniform)

모든 값이 같은 확률을 가지는 분포다. 이산이면 주사위(1~6 각각 1/6), 연속이면 구간 [a, b]에서 어디든 같은 밀도다.

신경망에서는 드물지만, Xavier 초기화의 균등 분포 변형에서 사용한다.

이 대응은 최대우도추정(MLE)에서 유도된다. 출력 분포를 가정하고, 그 분포에서 정답이 나올 확률을 최대화하면 각각의 손실 함수가 자연스럽게 나온다.

확률 분포 코드

Softmax → 카테고리컬 분포

입력 로짓이 [2.0, 1.0, 0.1]이면:

exp([2.0, 1.0, 0.1]) = [7.389, 2.718, 1.105] 합 = 11.212 softmax = [0.659, 0.242, 0.099] → 카테고리컬 분포 파라미터

“클래스 0일 확률 65.9%, 클래스 1일 확률 24.2%, 클래스 2일 확률 9.9%“라는 분포를 정의한다.

Cross-Entropy → 분포 간 차이 측정

y_pred는 Softmax 출력(카테고리컬 분포의 파라미터), y_true는 정답 레이블이다. 정답 클래스에 배정된 확률이 높을수록 -log(p)는 작아진다. 모델이 정답에 확률 1.0을 몰아주면 loss는 0이다.

수학적으로 이것은 정답 분포(one-hot)와 예측 분포(softmax 출력) 사이의 cross-entropy다.

가우시안에서 가중치 초기화

np.random.randn(fan_in, fan_out)는 표준 정규 분포 N(0, 1)에서 값을 뽑는다. * np.sqrt(2.0 / fan_in)을 곱하면 분포가 N(0, 2/fan_in)이 된다.

fan_in = 784일 때: 가중치 하나의 표준편차 = sqrt(2/784) ≈ 0.0505. 가중치 값은 대부분 -0.15 ~ +0.15 범위 안에 있다.

정리

확률 분포는 신경망의 출력, 손실, 초기화 세 곳에서 핵심 역할을 한다. Sigmoid 출력은 베르누이 분포의 파라미터이고, Softmax 출력은 카테고리컬 분포의 파라미터이며, 가중치 초기화는 가우시안 분포에서 뽑는다. 출력층의 분포 가정이 손실 함수의 모양을 결정하며, 이 연결은 최대우도추정(MLE)에서 유도된다.
