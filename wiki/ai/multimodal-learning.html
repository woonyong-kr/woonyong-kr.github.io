멀티모달 학습에서 표현을 정렬하고 결합하는 기준

상품 이미지와 설명 문장을 함께 분류하려면 두 입력이 같은 대상을 가리킨다는 사실부터 보장해야 한다. 멀티모달 학습은 텍스트·이미지·오디오처럼 다른 modality를 하나의 판단에 사용한다. 성능 차이는 model 크기보다 데이터 짝과 표현 정렬에서 먼저 생긴다.

각 modality의 단독 기준선을 만든다

이미지는 pixel tensor, 텍스트는 token sequence, 오디오는 waveform이나 spectrogram으로 들어온다. 먼저 modality 하나씩 사용한 기준선을 만든다. 그래야 결합 모델이 실제로 추가 정보를 얻었는지, 한 입력을 무시했는지 판단할 수 있다.

이미지와 caption의 sample ID, 영상 frame과 audio timestamp, 증강 뒤 pair가 유지되는지 작은 batch에서 직접 확인한다. 잘못 짝지은 데이터는 우연한 상관관계를 학습하게 만든다.

표현을 같은 비교 공간에 정렬한다

각 encoder 출력을 같은 차원으로 projection하고 대응 pair는 가깝게, 다른 pair는 멀게 만드는 contrastive objective를 사용할 수 있다. 이미지로 설명을 찾고 문장으로 이미지를 찾는 양방향 retrieval은 정렬을 확인하는 작은 실험이다.

Early fusion과 late fusion을 구분한다

Early fusion은 중간 feature를 일찍 결합해 상호작용을 깊게 학습하지만 데이터와 계산량이 많이 필요하다. Late fusion은 각 modality의 예측이나 고수준 feature를 마지막에 합쳐 진단은 쉽지만 세밀한 상호작용을 놓칠 수 있다.

누락과 충돌을 평가한다

배포 환경에서는 카메라가 가려지거나 설명이 비어 있을 수 있다. 모든 입력이 있을 때의 평균 점수만 보지 말고 각 modality 제거, 품질 저하, 서로 충돌하는 입력을 따로 시험한다. 민감한 modality가 하나라도 있으면 전체 pipeline의 공개 범위를 그 입력에 맞춘다.

스스로 확인할 질문

  • 각 modality 단독 기준선보다 실제로 나은가?
  • pair의 ID와 시간 정렬을 어떻게 검증했는가?
  • 입력 하나가 없거나 틀렸을 때 출력은 어떻게 변하는가?
  • fusion 위치가 필요한 상호작용 깊이와 맞는가?

근거와 확인 범위

2026-08-29에 보존한 Microsoft AI-For-Beginners 한국어판 Multi-Modal Networks 문서를 바탕으로 표현 정렬, fusion과 결측 입력 검증을 재구성했다. 특정 상용 model 기능 비교는 포함하지 않는다.
