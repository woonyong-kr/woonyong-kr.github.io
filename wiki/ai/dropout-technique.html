드롭아웃

드롭아웃

범위: 이 문서는 Dropout의 일반 원리와 학습·추론 시 스케일링 선택 기준을 설명하고, 제시된 Dropout 클래스와 연산 예시를 코드 수준에서 해설한다. 특정 라이브러리 버전의 실행 기록이나 성능 측정을 검증한 결과는 아니므로, 실제 환경에서의 동작과 효과를 판단하려면 해당 코드·버전·실행 결과와 성능 측정을 별도로 확인해야 한다.

한 줄 요약: Dropout은 학습할 때마다 은닉층 뉴런 일부를 무작위로 비활성화해서, 특정 뉴런 조합에 의존하는 과적합을 방지한다.

드롭아웃 구분

신경망의 파라미터 수가 훈련 데이터 양에 비해 많으면 과적합이 일어난다. 모델이 훈련 데이터의 노이즈까지 외워버리는 것이다. 정규화(regularization) 기법은 모델의 표현력을 인위적으로 제한해서 이 문제를 줄인다.

Dropout 이전에는 L2 정규화(Weight Decay)가 주된 방법이었다. 하지만 L2는 가중치 크기만 제한할 뿐, 뉴런 간 “공모(co-adaptation)” 문제를 직접 막지 못한다. 공모란 특정 뉴런 몇 개가 항상 함께 활성화되면서 훈련 데이터에만 맞는 복잡한 패턴을 학습하는 현상이다.

Dropout은 매 배치마다 뉴런을 무작위로 끄기 때문에, 각 뉴런이 다른 뉴런의 존재에 의존하지 않고 독립적으로 유용한 특징을 배우도록 강제한다.

드롭아웃 계산

비유

시험 공부를 할 때 4명이 항상 같이 공부하면, 한 명이 빠지면 나머지가 무너진다. 매번 팀원을 랜덤으로 바꾸면, 각자가 독립적으로 공부하게 된다. Dropout은 신경망에서 같은 효과를 낸다.

동작 방식

학습 시(train=True):

  1. 각 뉴런 출력에 대해 확률 p로 0을 만든다 (drop_ratio = p).
  2. 살아남은 뉴런의 출력은 그대로 통과한다.
  3. 매 forward마다 새 mask를 생성한다.

추론 시(train=False):

  1. 모든 뉴런을 활성화한다.
  2. 출력에 (1 - p)를 곱해서 학습 때의 평균 출력 크기와 맞춘다.

왜 (1 - p)를 곱하는가?

학습 때 뉴런이 살아남을 확률은 (1 - p)이다. 살아남은 뉴런만 출력을 내보내니, 학습 때의 기대 출력은 x * (1 - p)이다. 추론 때는 모든 뉴런이 살아 있으므로, 출력을 (1 - p)로 스케일링해야 학습-추론 간 출력 규모가 일치한다.

대안으로 “inverted dropout”이 있다. 학습 때 살아남은 값을 1 / (1 - p)로 나눠서 추론 때는 아무 스케일링 없이 쓰는 방식이다.

드롭아웃 코드

이 코드가 하는 일: np.random.rand로 0~1 균등분포 난수를 뽑고, drop_ratio보다 큰 위치만 True인 boolean mask를 만든다. 곱셈으로 해당 뉴런의 출력을 0으로 만든다. backward에서는 같은 mask를 재사용해서, forward에서 꺼진 경로에는 gradient도 차단한다.

구체적 연산 예시

네트워크에서의 위치

%% Dropout의 네트워크 내 위치
flowchart LR
  affine["Affine<br/>선형 변환<br/>y = xW + b"]
  batch_norm["BatchNorm<br/>분포 정규화<br/>활성값 규모 안정화"]
  relu["ReLU<br/>비선형 활성화<br/>max(0, x)"]
  dropout["Dropout<br/>무작위 차단<br/>mask = rand &gt; drop_ratio"]
  next_layer["다음 층<br/>살아남은 출력 전달"]
  affine --> batch_norm
  batch_norm --> relu
  relu --> dropout
  dropout --> next_layer

밑바닥 딥러닝1 구현에서 은닉층 하나는 Affine → BatchNorm → ReLU → Dropout 순서로 쌓인다. Dropout은 비선형 활성화 뒤에 위치해서, 활성화된 출력 중 일부를 무작위로 끈다.

정리

Dropout은 학습 때마다 뉴런 일부를 무작위로 꺼서 뉴런 간 공모를 방지하는 정규화 기법이다. forward에서 boolean mask를 만들어 곱하고, backward에서 같은 mask로 gradient를 차단한다. 추론 때는 (1 - drop_ratio)를 곱해 출력 크기를 맞춘다.
