Transformer Explainer 로컬 실행 가이드

Transformer Explainer 앱을 로컬에서 다시 띄우고, 브라우저에서 모델 로딩과 Generate 동작을 확인하는 절차.

로컬 실행에서는 설치 조합, tokenizer 캐시, GPT-2 ONNX 파트 로딩 시간이 자주 막힌다. 여기서는 실행·검증·장애 대응 절차를 모으고, 화면을 읽는 순서는 Transformer Explainer에서 이어 본다.

바로 실행하기

Vault 루트에서 고정한 원본 커밋과 tokenizer를 준비한다. 캐시가 이미 같은 커밋이면 다시 받지 않는다.

브라우저에서 연다.

처음 열면 600MB가 넘는 GPT-2 ONNX 파트를 브라우저가 읽는다. 잠시 동안 Try the examples while GPT-2 model is being downloaded (600MB) 안내가 보이고, 이때는 Generate 버튼이 비활성이다. 예제 시각화는 먼저 볼 수 있고, 모델 세션이 준비되면 Generate 버튼이 활성화된다.

새로 설치해야 할 때

원본 lockfile 조합은 확인 당시 환경에서 Svelte 5 계열과 Vite 5 조합이 충돌했다. 캐시를 새로 만들었다면 Svelte 4 호환 조합으로 설치한다.

테스트 자동화가 필요하면 Playwright를 임시로 쓴다.

로컬 tokenizer 캐시

앱은 AutoTokenizer.from_pretrained('Xenova/gpt2')를 호출한다. 기본 동작은 먼저 로컬 경로를 찾고, 없으면 Hugging Face로 fallback하는 방식이다.

재현 스크립트가 다음 파일을 내려받고 기록된 SHA-256과 대조한다.

확인 결과:

ONNX 모델 파트는 이미 repo의 static/model-v2/에 들어 있다.

캐시는 원자료를 다시 확인할 때만 필요하다. 학습 문서 열람이나 Quartz 빌드에는 사용하지 않으므로 작업이 끝나면 캐시 디렉터리를 지워도 된다.

남은 진단

npm run check는 아직 실패한다.

주요 범주:

  • TypeScript 타입 누락
    • window.dataLayer
    • implicit any
    • D3 scale 타입
    • 일부 Svelte component prop 타입
  • Svelte 접근성 경고
    • img alt 누락
    • iframe title 누락
    • click handler가 있는 non-interactive element
  • 사용되지 않는 CSS selector와 export prop

이 진단은 로컬 실행 자체를 막지는 않았다. 다만 이 앱을 학습용 복제 실행이 아니라 공개 서비스나 장기 유지보수 대상으로 쓰려면 별도 정리 작업이 필요하다.

보안과 배포 메모

npm install 과정에서 npm audit 취약점 경고가 표시됐다. 현재 목적은 학습용 로컬 실행이므로 즉시 대규모 의존성 업그레이드를 하지 않았다. 외부 공개 서비스로 배포하려면 다음을 먼저 해야 한다.

  • npm audit 상세 확인
  • Svelte/Kit/Vite 호환 버전 재정리
  • 접근성 경고 수정
  • 번들 chunk 분리
  • tokenizer/model 파일의 출처와 라이선스 메모 유지

자주 막히는 지점

  • 화면에 spinner만 보인다.
    • 처음에는 tokenizer와 앱 bundle이 준비되는 중일 수 있다.
    • data-click="input-area"가 보일 때까지 기다린다.
  • Generate 버튼이 비활성이다.
    • GPT-2 ONNX 63개 파트를 읽고 ONNX Runtime session을 만드는 중이다.
    • 안내 문구가 사라지면 Generate가 활성화된다.
  • npm ci가 실패한다.
    • peer dependency 충돌 가능성이 있다.
    • 위의 Svelte 4 호환 설치 명령을 사용한다.
  • npm run check가 실패한다.
    • 현재 알려진 upstream 타입/접근성 진단이다.
    • 실행 확인은 npm run build와 브라우저 smoke test를 기준으로 본다.

다시 확인할 체크포인트

  • 로컬 URL이 200으로 응답하는가?
  • Examples 버튼과 Generate 버튼이 보이는가?
  • ONNX 모델 로딩 후 Generate 버튼이 활성화되는가?
  • 직접 입력 뒤 오른쪽 probability 후보가 바뀌는가?
  • 앱을 학습 문서와 함께 볼 때 Transformer Explainer에서 설명한 순서대로 화면을 읽을 수 있는가?
